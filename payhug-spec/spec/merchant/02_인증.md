## A. 화면 개요

- **목적**: 가맹점(사장님)이 서비스에 들어오기 위한 계정 인증 진입점이다. 로그인, 신규 회원가입(약관 동의 → 본인 인증 → 비밀번호 설정), 회원가입 완료 환영, 비밀번호 찾기(본인 인증 → 재설정)를 한곳에서 담당하며, 선정산 계약·서류(M-03)로 넘어가기 전의 앞단 게이트 역할을 한다.
- **진입·권한**: 로그인하지 않은 상태에서 접근하는 공개 화면이다. `AuthGuard`가 보호하는 화면(대시보드 등)에 인증 없이 들어오면 `/login`으로 강제 이동시키고, 토큰이 만료(401)되면 `/login?reason=expired`로 보낸다. 반대로 이미 로그인한 상태로 `/login`에 진입하면 `redirect` 목적지(기본 `/dashboard`)로 되돌린다.
- **주요 상태 변형(캡처된 케이스, 01_IA.md M-02 기준, 17개)**:

## D. 미확정 지뢰 관련

- 이 메뉴(로그인·회원가입·완료·비번찾기)의 어떤 화면에도 **수수료율 / 지급 캘린더 / 예상 지급 차액** 라벨·계산이 나타나지 않는다. (인증 단계에는 금액·정산 표기 없음.)
- 단, 회원가입 단계에서 캡처하는 **추천/파트너/투자자/영업/제휴 코드**는 가입 이후 **수수료율(C1)** 결정 경로와 연결될 수 있다. 이 화면은 값을 표기·계산하지 않으므로 어떤 요율도 임의 채택하지 않는다(코드 캡처 사실만 기록).

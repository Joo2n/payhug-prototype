## A. 화면 개요

- **목적**: 모든 가맹점 화면 최상단에 공통으로 렌더되는 **글로벌 헤더·내비게이션**이다. 왼쪽 로고(클릭 시 홈 이동), 로그인 상태에 따라 달라지는 우측 영역(비로그인이면 로그인·시작하기, 로그인이면 알림 벨·프로필), 모바일 햄버거 드로어, 로그아웃 확인 모달을 제공한다. 공용 레이아웃에 묶여 자동으로 붙는 방식이 아니라, 각 페이지(`page.tsx`)가 개별적으로 `<Header />`를 직접 삽입한다.
- **진입·권한**: 헤더 전용 라우트는 없다. 랜딩(`app/page.tsx`), 계약(`app/contract/*`), 정산(`app/settlement/*`), 알림(`app/notifications`), 내 정보(`app/my-info/*`) 등 여러 페이지가 헤더를 직접 임포트해 사용한다. 로그인 여부는 클라이언트에서 인증 토큰(쿠키 `access_token` 우선, 없으면 `sessionStorage`)의 존재로 판별하며, 헤더 자체는 접근을 막는 인증 게이트가 아니다(실제 보호는 각 라우트의 `AuthGuard`가 담당). 사용자 이름은 저장된 사용자 정보(`user_data.name`)에서 읽는다.
- **주요 상태 변형(캡처된 케이스)** (01_IA.md M-09):
  - node 815:2 모바일 메뉴 드로어(햄버거 열림)
  - node 908:2 프로필 드롭다운(로그인 상태)
  - node 909:2 로그아웃 확인 모달
  - node 910:2 알림 드롭다운(빈 상태)
  - (헤더의 3분기 렌더는 별도 캡처가 아니라 코드 기준 구분이다: 로딩 스켈레톤 · 메인+비로그인=녹색 마케팅 헤더 · 그 외=화이트 헤더. 녹색·화이트 렌더 자체는 M-01 등 각 화면 캡처에 포함된다.)

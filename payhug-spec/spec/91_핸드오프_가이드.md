## 2. 파일 전달 방법 (택1)

1. **경로 지정**: `payhug-spec/_inbox/` 폴더(아래 생성됨)에 넣고 "인박스 처리해" 라고 하기.
2. **직접 경로/URL**: 메시지에 파일 경로나 링크를 붙이고 "이거 반영해" 라고 하기.
3. **붙여넣기**: 내용을 그대로 붙여넣기.

전달 시 한 줄만 알려주면 정확도가 크게 오른다: **"이건 [무슨] 문서이고 [어느 메뉴/정책]에 관한 것"**.
(예: "이건 최종 확정된 수수료율 정책 — C1 해소용")

## 3. 반영 절차 (내가 하는 일)

1. **매핑** — 받은 문서의 각 항목을 대상 메뉴 파일 B표의 **행(#)** 에 연결. 매핑 안 되면 → 표에 없던 기능이므로 **신규 행 추가**(개발/기획 누락 발견).
2. **대조** — `동작·결과`(코드에서 관찰된 사실) ↔ 받은 정책:
   - **일치** → 상태 `확인 필요`/`가설` → **`확정`으로 승격**, `근거`에 문서 출처 추가.
   - **불일치** → **`⚠️충돌`** 표시 + `90_정책레지스터.md`에 등록. **임의로 한쪽 채택 안 함** — 당신에게 판단 요청.
3. **미확정 해소** — C 섹션·`90`의 항목 중 해소되는 것 갱신 (특히 3대 지뢰 C1/C2/C4).
4. **역방향 검증(현행화)** — 정책엔 있는데 코드엔 없는 기능 → **`미구현(기획-개발 갭)`** 으로 별도 표기.
5. **리포트** — 무엇이 확정됐고, 무엇이 충돌이며, 무엇이 여전히 확인 필요인지 요약 diff 제출.

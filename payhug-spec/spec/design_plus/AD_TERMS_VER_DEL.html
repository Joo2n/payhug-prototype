약관 버전 삭제 확인 다이얼로그의 특수 로직. 삭제 버튼과 이 다이얼로그는 '미게시' 상태 버전에만 노출되며(게시된 버전은 삭제 진입 자체가 불가), 화면은 삭제 가능 여부를 최종 판단하지 않는다. '사용자 동의 이력이 있으면 거부'는 서버가 최종 판정하고 화면은 안내 문구만 고정 노출하며, 실제 거부는 삭제 실행 후 서버 오류 메시지를 토스트로 되돌려받아 전달한다.
정책삭제 버튼·다이얼로그 노출 조건
다이얼로그 진입 경로
미게시(게시 OFF) 버전에서만 삭제 버튼이 나타나고, 그 버튼을 눌러야 이 확인 다이얼로그가 열린다.게시(ON) 상태 버전에는 삭제 버튼 자체가 없어 이 화면으로 올 수 없음확정
미게시 판정 기준
각 버전의 게시 여부 값으로만 판단.목록의 게시 토글로 껐다 켤 수 있고, 이 값이 꺼진 버전에만 삭제 진입 허용확정
동의 이력 있는 미게시 버전
미게시라 삭제 버튼은 보이나, 사용자 동의 이력이 있으면 삭제는 거부된다는 안내가 다이얼로그에 고정 노출.노출 조건(미게시)과 실제 삭제 가능 여부(동의 이력 없음)는 별개확정
최종 삭제 허용 판단 주체
화면은 동의 이력 유무를 조회·검증하지 않는다. 서버가 최종 판단하며, 화면은 안내 문구만 미리 보여줄 뿐확인필요
연결삭제 실행·결과 처리
삭제 대상 요약 표시
확인 박스에 제목 · v버전 · 종류명을 그대로 보여줌.삭제 직전 목록에서 고른 그 버전의 값을 다시 담아 오해 방지용으로만 표시확정
성공 처리
삭제 성공 시 "약관 버전이 삭제되었습니다." 안내 후 다이얼로그를 닫고 목록 전체를 다시 불러옴확정
거부·실패 처리
동의 이력 등으로 서버가 거부하면 서버가 돌려준 오류 메시지를 그대로 토스트로 표시하고 다이얼로그를 닫음.화면에 별도의 거부 전용 문구·분기는 없음확정
되돌리기 불가
"이 작업은 되돌릴 수 없습니다." 안내. 삭제는 복구 절차가 없는 것으로 표기됨확정
삭제 확정 버튼 방어
확인 다이얼로그의 삭제 버튼은 저장류 모달과 달리 연타·중복 클릭 방지 처리가 없음.응답 지연 시 중복 삭제 요청 가능성 (개선 여지)가설

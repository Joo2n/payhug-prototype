1:1 문의 목록에서 '정산' 카테고리만 걸러 보는 필터 상태. 카테고리 필터는 서버에 조건을 넘겨 서버가 걸러주지만, 상태(대기/처리중 등)와 검색어는 이미 받아온 목록 안에서 화면이 다시 거른다. 정산 문의라도 이 화면에서 하는 일은 답변 등록과 상태 변경뿐이며, 실제 정산 금액 조정은 여기서 하지 않고 가맹점 상세로 넘어가야 한다. 카테고리는 가맹점이 문의를 쓸 때 정한 값이라 운영이 이 화면에서 바꿀 수단이 없다.
연결정산 카테고리 필터 동작
정산 필터 적용 방식
'정산' 배지를 누르면 서버에 카테고리=정산 조건을 실어 다시 목록을 받아온다.상태 탭·검색어와 달리 서버가 걸러 내려주는 값이라, 정산 외 문의는 애초에 목록에 들어오지 않는다확정
같은 배지 재클릭
이미 켜진 '정산' 배지를 다시 누르면 필터 해제(전체)로 돌아간다. 정산만 켰다 껐다 하는 토글 방식확정
상태·검색과의 조합
상태 탭(대기/처리중/답변완료/종료)과 상단 검색(제목·가맹점명·작성자)은 정산으로 받아온 목록 안에서만 다시 걸러진다.즉 정산 필터가 큰 그물, 상태·검색은 그 안에서의 잔손질확정
상단 건수·상태별 카운트
'총 N건'과 상태 탭 옆 숫자는 정산으로 걸러 받아온 목록 기준으로 다시 센다. 전체 문의 수가 아니라 정산 문의 수가설
데이터정산 카테고리 값의 출처와 표기
카테고리를 정하는 주체
'정산' 분류는 가맹점이 문의를 작성할 때 고른 값이 그대로 넘어온 것. 이 화면에는 카테고리를 바꾸는 수단이 없어 운영이 재분류할 수 없다가설
정산 배지 색
정산은 초록(에메랄드) 배지로 고정 표기. 일반=회색, 결제=파랑, 기술=보라, 계정=주황과 구분확정
'NEW' 표시 조건
마지막 메시지를 가맹점이 보냈고 아직 종료가 아닌 정산 문의에만 빨간 NEW 배지가 붙는다.운영이 답할 차례인 정산 건을 눈에 띄게 하려는 표시확정
정산 문의라는 이유의 특별 처리
화면 로직상 정산 카테고리라고 해서 다른 카테고리와 다르게 계산하거나 분기하는 부분은 없다. 색·필터값만 다를 뿐 목록/상세/답변 흐름은 동일확정
정책정산 문의에서 할 수 있는 것 / 없는 것
이 화면의 처리 범위
정산 문의라도 여기서 하는 건 답변 등록과 상태 변경뿐. 미지급금·과지급·바로이체 같은 실제 정산 금액을 이 화면에서 조정하지는 않는다확정
실제 정산 조치로 넘어가는 길
상세 패널의 가맹점명을 누르면 가맹점 상세로 이동. 정산 내역 확인·조정이 필요하면 거기서 처리하는 구조확정
종료된 정산 문의
상태가 '종료'면 답변 입력창이 사라지고 '종료된 문의입니다' 안내만 남아 추가 답변 불가확정
상태 변경 자유도
상세 패널 우측 드롭다운으로 대기↔처리중↔답변완료↔종료를 순서 제약 없이 아무 값으로나 바꿀 수 있다. 정산 건에 대한 별도 승인·잠금 절차는 없음확정
답변 처리 시 상태 자동 변화
답변을 보내면 목록을 새로 불러오는데, 답변 등록이 서버에서 상태를 자동으로 '답변완료' 등으로 바꾸는지는 서버 동작이라 확인 필요확인필요

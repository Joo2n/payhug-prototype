3결과 표 표·요약 구성은 [AD_SALES_DT]와 동일 · 선택 카드사에 맞는 건만 표시

매출 유형에서 '카드'를 선택했을 때만 나타나는 카드사 2뎁스 하위 필터 상태. 이 필터의 칩 목록은 고정이 아니라 조회 결과에 실제 존재하는 카드사만 서버가 내려주며, 카드 선택을 풀면 자동으로 '전체'로 초기화된다. 카드 유형에서만 의미를 갖는 데이터(카드사, 카드 수수료, 예상↔실제 차액 정산)가 이 상태에서 핵심으로 드러난다. 최종 산술·확정 수수료율은 서버 전용이라 확인 필요.
설정카드사 필터 노출·자동 초기화 규칙
노출 조건
매출 유형에 '카드'가 포함되고, 동시에 조회 결과에 카드사가 1개 이상 존재할 때만 카드사 칩 줄이 뜬다.둘 중 하나라도 아니면 칩 줄 자체가 화면에 없음확정
카드 해제 시 자동 초기화
매출 유형에서 카드 선택을 풀면, 골라뒀던 카드사 선택이 자동으로 '전체'로 되돌아감.목적: 카드 아닌데 특정 카드사만 남아 빈 결과/혼선 나는 것 방지확정
배치 위치
칩 줄은 기존 필터 카드 바깥(아래)에 별도로 붙인다.조회·초기화 버튼 위치는 건드리지 않으려는 의도대신 이 줄이 생기면서 아래 액션 버튼·요약 카드·표가 한 칸씩 내려감확정
선택 방식
복수 선택 가능. '전체'를 누르면 개별 선택이 모두 풀리고, 개별 카드사를 누르면 '전체'가 풀린다.개별 선택을 다 해제하면 다시 '전체'로 복귀확정
연결카드사 목록·조회 연결
칩 목록 출처
칩에 나오는 카드사 목록은 고정 목록이 아니라 서버가 조회 결과와 함께 내려주는 '실제 존재하는 카드사'다.매출 조회 응답 안에 카드사 목록이 같이 담겨 옴즉 이 가맹점·이 기간에 거래가 있는 카드사만 버튼으로 뜸확정
선택 변경 시 동작
카드사 선택을 바꾸는 것만으로 즉시 재조회되지는 않고, 조회 요청 시 선택한 카드사들이 조건으로 함께 전달돼 서버가 다시 집계한다.전체 선택이면 카드사 조건 없이 전체로 조회요약 카드·차액 등 집계값도 선택 카드사 기준으로 다시 계산됨가설
엑셀 다운로드에도 반영
엑셀 다운로드도 현재 선택한 카드사 조건을 그대로 적용해 서버에서 전체 건을 다시 받아 내려받는다.화면에 보이는 필터 = 받는 파일 범위확정
계산카드 유형 전용 데이터·차액 계산
카드사 컬럼 의미
'카드사/플랫폼' 컬럼은 카드 건일 때만 카드사명을 표시하고, 배달앱 건은 이 값이 비어 '-'로 나온다.카드사 필터는 카드 건에만 걸리는 조건확정
적용수수료 출처
적용수수료는 카드 건이면 카드 수수료, 배달 건이면 배달 수수료로 갈라 표시.이 화면(카드 필터)에서는 사실상 카드 수수료만 노출됨확정
실제수수료 산출
실제수수료는 별도 값이 아니라 정산적용 수수료 − 차액으로 화면에서 도출한다.카드 건이면서 매입완료일 때만 계산재수집(스크래핑) 때 안 깨지도록 차액을 빼서 역산하는 방식확정
차액정산 상태 판정
차액정산 상태는 카드 건에서만: 선정산 대상 아님/매입완료 아님이면 '-', 이미 반영됐으면 '완료', 차액이 남았으면 '대기', 차액이 0이면 '차액없음'.배달 건은 항상 '-'확정
차액 = 예상↔실제
여기서 '차액'은 예상 카드수수료로 먼저 선정산한 뒤 실제 카드수수료가 확정돼 생기는 차이다(환급 또는 추가차감).예상매출 차액(C4)과는 별개 개념원거래일이 조회 기간과 달라 표에는 안 보이고 요약에만 잡히기도 함확정
최종 산술·확정 수수료율
실제 카드수수료 확정값, 수수료율(C1), 스크래핑/재수집 스케줄은 서버가 정하는 값이라 화면 코드만으로 단정 불가.확인필요

가맹점이 앱에서 접수한 1:1 문의를 관리자가 인박스 형태로 받아 답변하는 화면. 목록(상태·카테고리 필터 + 검색) + 우측 슬라이드 패널(대화 스레드형 답변)으로 구성된다. 상태는 4단계(대기/처리중/답변완료/종료)이고 목록 상단 필터는 여기에 '전체'를 더한 5개 탭이다. 카테고리 5종(일반/결제/정산/기술/계정)으로 분류하며, 마지막 발신자가 가맹점이고 종료 상태가 아니면 제목 옆에 미답변 NEW 표시가 붙는다. 정산 카테고리 문의를 담을 수 있으나 이 화면은 순수 고객대응 인박스로, 정산현황 VOC 대응 탭과는 별개다. 상태 자동전환 여부·카테고리 지정 주체·정렬 기준 등은 서버 로직이라 이 화면에서 확인 불가.
설정문의 분류 체계 (상태·카테고리)
상태 단계
4단계 고정: 대기 → 처리중 → 답변완료 → 종료.목록 필터 탭은 여기에 '전체'를 더해 5개, 패널 내 상태변경 드롭다운은 '전체' 뺀 4개확정
카테고리
5종 고정: 일반 / 결제 / 정산 / 기술 / 계정.'정산' 문의가 여기 들어올 수 있으나, 정산현황 VOC 대응 탭과는 별개 화면확정
카테고리 필터 동작
이미 선택된 카테고리를 다시 누르면 해제(전체로 복귀) — 단일 선택 토글확정
카테고리·상태를 누가 정하나
가맹점이 문의 작성 시 카테고리를 고르는지, 관리자가 재분류하는지는 이 화면에 없음(작성은 앱 쪽). 상태는 이 화면에서 관리자가 수동 변경 가능확인필요
계산미답변(NEW) 판정 로직
NEW 뱃지 조건
마지막 발신자가 가맹점이고 상태가 종료가 아닐 때 제목 옆에 빨간 NEW 표시.'관리자가 아직 응답 안 한 공'이 넘어와 있는 상태를 뜻함확정
상태값과 무관
NEW는 대기/처리중/답변완료 어느 상태여도 가맹점이 마지막으로 말했으면 붙음 — 상태 라벨과 별개 신호. 단 종료 상태에서는 붙지 않음확정
판정 기준 데이터
마지막 메시지 발신자 유형(가맹점/관리자)을 서버가 목록 항목에 함께 내려줌확정
데이터목록 조회·필터·검색 (서버 vs 화면 분담)
상태·카테고리 필터
서버 조회 조건으로 전달 → 필터를 바꿀 때마다 목록 재조회확정
검색
화면 내 필터링(재조회 아님): 이미 불러온 목록에서 제목·가맹점명·작성자 부분일치로 걸러냄확정
상태별 건수 배지
각 탭 옆 숫자는 현재 불러온 목록을 화면에서 집계한 값 — 서버 총계가 아님. 상태 필터가 걸려 있으면 서버가 그 상태만 내려주므로 다른 탭은 0, 선택 탭·전체만 값이 보임. 검색어는 이 집계에 반영되지 않음확정
헤더 총건수
상단 '총 N건'은 현재 불러온 목록 건수 — 검색·상태필터 적용 후 서버가 내려준 개수확정
메시지 수 컬럼
각 행에 그 문의의 누적 메시지 건수를 별도 컬럼으로 표시확정
페이징
화면에 페이지네이션 UI 없음. 조회 파라미터도 상태·카테고리뿐이라 조건에 맞는 문의를 한 번에 받는 구조. 서버측 반환 상한 여부·대량 시 성능은 확인 필요가설
정렬 기준
화면에서 정렬을 지정하지 않음 → 서버 반환 순서 그대로. 최근 활동순인지 확인 불가확인필요
최근 활동 표기
마지막 메시지 시각(없으면 최초 접수 시각)을 '방금 전/N분 전/N시간 전/N일 전' 상대시간으로. 7일 넘으면 날짜로 표기확정
연결답변·상태변경 동작
답변 등록
우측 패널 하단 입력창에서 전송. 로그인한 관리자 정보가 발신자로 함께 기록됨(관리자 로그인 정보 없으면 전송 중단).전송 후 상세·목록 자동 새로고침확정
상태 자동전환
답변 전송 시 화면은 상세·목록만 새로고침 — 상태를 자동으로 '답변완료'로 바꾸는지는 서버 몫이라 화면에서 단정 불가확인필요
상태 변경
패널 우상단 드롭다운으로 관리자가 수동 변경(대기/처리중/답변완료/종료). 변경 즉시 패널에 반영되고 목록도 새로고침확정
가맹점 상세 이동
패널 헤더의 가맹점명 클릭 → 해당 가맹점 상세 화면을 탭으로 오픈.탭 모드일 때만 동작(탭 모드 아니면 이동 없음)확정
가맹점 상세 안의 문의
가맹점별 문의만 따로 조회하는 별도 경로가 서비스 계층에 존재(가맹점 상세용 문의 목록). 이 인박스 화면 자체와는 별도 조회확정
정책대화 스레드·종료 정책·실시간성
대화 표시
관리자/가맹점 메시지를 좌우 말풍선으로 구분(관리자=우측, 가맹점=좌측), 발신자명·상대시간 표기확정
종료 문의 답변 차단
상태가 종료면 답변 입력창이 사라지고 '종료된 문의입니다' 안내만 노출 — 종료 후엔 대화 불가확정
종료 후 재개
종료를 다시 다른 상태로 되돌리면(드롭다운) 입력창이 다시 살아남 — 되살릴 수 있음확정
자동 새로고침
탭 활성화·창 포커스 복귀 시 목록 자동 재조회 — 실시간 인박스처럼 최신화. 다만 실시간 푸시(소켓)는 아님, 화면 진입/포커스 트리거확정
전송 단축키
Ctrl(⌘)+Enter로 답변 전송(전송 중이면 중복 전송 방지)확정

회원 관리 목록 상단의 유형 필터 탭에서 '영업조직'을 눌렀을 때의 동작. 핵심은 유형 필터는 서버를 다시 부르는 재조회(선택 유형을 조건으로 서버에 넘김)인 반면, 이름·아이디 검색창은 서버를 부르지 않고 이미 받아온 목록을 화면에서 걸러내기만 한다는 점이다. 목록에 보이는 범위 자체가 로그인한 운영자의 소속(자기+하위)으로 제한되며, 영업조직은 가입 링크 생성 시 '영업'과 한 묶음으로 취급된다.
연결유형 필터 = 서버 재조회 (검색창과 다름)
유형 탭 클릭 시 동작
상단 유형 탭(전체·투자자·페이허그·파트너·제휴사·영업·영업조직·관리자)을 누르면 선택한 유형을 조건으로 서버를 다시 호출해 목록을 새로 받아온다.'전체'는 유형 조건 없이 전부 요청'영업조직'은 영업조직 유형만 서버에 요청확정
이름·아이디 검색창
검색창은 서버를 부르지 않는다. 이미 받아온 목록에서 이름 또는 아이디(전화번호)에 입력값이 포함되는 행만 화면에서 걸러 보여줄 뿐.즉 검색 결과는 현재 선택된 유형 범위 안에서만 좁혀짐확정
재조회를 다시 트리거하는 경우
유형 탭 변경 외에도, 이 화면 탭이 다시 활성화되거나 브라우저 창에 포커스가 돌아올 때 현재 선택된 유형 그대로 목록을 자동 재조회한다. '새로고침' 버튼도 동일.확정
데이터영업조직 필터로 보이는 데이터 범위
보이는 회원 범위
필터가 서버 재조회라도, 애초에 목록에 담기는 회원은 로그인한 운영자의 소속(자기 + 하위)으로 제한된다. 영업조직 필터도 이 범위 안의 영업조직만 나온다.상위 조직에 있는 회원은 목록 조회 범위 밖 (별도 '상위 조회' 경로로만 링크 생성기에서 참조)가설
빈 결과 문구가 갈림
영업조직 필터 결과가 없을 때, 검색어 없이 서버가 0건이면 "등록된 회원이 없습니다", 검색어까지 걸어 0건이면 "검색 결과가 없습니다"로 문구가 달라진다.확정
행에 함께 뜨는 값
각 영업조직 행에는 유형 배지(영업조직=주황), 법인/개인·사업자 배지, 추천코드, 상위 회원명, 상태(활성/비활성)가 함께 표시. 상위 회원명이 없으면 '-'(최상위).확정
설정영업조직의 특수 취급
가입 링크 생성 시 '영업'과 한 묶음
하단 가입 링크 생성기에서 영업조직은 '영업' 드롭다운에 영업과 함께 들어가, 선택하면 그 추천코드가 링크의 영업 코드 자리에 붙는다.파트너·제휴사와 달리 상호배타 제약 없이 파트너/제휴사와 조합 가능확정
링크에 노출 조건
가입 링크 후보로 뜨려면 상태가 활성이고 추천코드가 있어야 한다. 비활성이거나 추천코드 없는 영업조직은 링크 생성기 목록에서 제외.확정
등록 버튼·유형 선택지
영업조직을 신규 등록할 수 있는지는 화면이 정하지 않고 서버가 내려주는 '생성 가능 유형'에 영업조직이 포함될 때만 등록 버튼과 유형 선택지에 나타난다.확정

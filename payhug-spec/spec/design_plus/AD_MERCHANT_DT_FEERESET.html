'카드사별 수수료 관리' 카드 우측 상단 [기본값 초기화] 버튼을 누르면 뜨는 확인 다이얼로그. 개별 카드사 수수료를 직접 수정하던 것을 되돌려, 모든 카드사 수수료율을 한 번에 '기본값'으로 일괄 되돌린다. 되돌아가는 기본값 자체는 어드민 화면에 노출되지 않고 서버가 정하며, 그 근거가 미확정(C1)이라 이 화면의 핵심 미결 지점이다. 하드리셋 모달과 달리 확인 문구 타이핑이 없는 1회 확인 방식이다.
정책이 초기화가 실제로 바꾸는 것
초기화 범위
특정 카드사 하나가 아니라 그 가맹점의 모든 카드사 수수료율을 한 번에 기본값으로 되돌림개별 카드사를 관리자가 손으로 수정(직접 입력)해 둔 값이 있어도 전부 덮어씀확정
되돌아가는 '기본값'의 출처
초기화 요청 시 어드민은 어떤 수치도 함께 보내지 않음 — 되돌릴 기본 수수료율은 전적으로 서버가 정함화면 어디에도 '기본값이 몇 %인지' 표시되지 않음확정
기본 수수료율 값의 근거
1% / 0.604% / 0.6+0.11+0.1% / 0.25% 등 여러 수치가 병존해 미확정(C1)서버 규칙이라 어드민 코드만으로는 확인 불가, 서버 확인 필요확인필요
선정산 제외 토글과의 관계
카드사별 '선정산 제외/포함' 스위치는 별도 설정 — 이 초기화가 되돌리는 건 수수료율뿐인지, 제외 상태도 함께 초기화되는지는 서버 처리라 확인 필요확인필요
설정다이얼로그 자체의 규칙
확인 방식
제목 "수수료 기본값 초기화" + 안내문 "모든 카드사 수수료를 기본값으로 초기화하시겠습니까?"버튼은 [취소] / [초기화] 단 두 개확정
확인 문구 타이핑 없음
같은 화면의 하드리셋 모달은 '하드리셋'을 직접 입력해야 버튼이 열리지만, 이 초기화는 문구 입력 단계가 없는 1회 클릭 확인되돌리기 파괴력은 낮게 취급된 셈확정
버튼 강조 단계
확정 버튼이 경고(앰버) 단계로 표시 — 계약 초기화/하드리셋의 빨강(위험)보다 한 단계 낮음되돌릴 수 있는 설정 변경으로 분류확정
권한 조건
읽기 전용 열람자에게는 [기본값 초기화] 버튼 자체가 보이지 않음수정 권한이 있는 관리자만 실행 가능확정
연결확정을 누른 뒤 처리 흐름
처리 순서
[초기화] → 서버에 초기화 요청 → 성공 시 카드사 수수료 목록을 다시 불러와 화면 갱신 → "카드사 수수료가 기본값으로 초기화되었습니다." 토스트확정
실패 시
서버가 실패를 주면 목록은 그대로 두고 오류 토스트만 노출(서버 메시지 우선, 없으면 "초기화 실패")부분 초기화/재시도 정책은 서버 소관이라 확인 필요가설
초기화 후 값의 향방
초기화로 되돌린 수수료율은 이후 스크래핑으로 자동 갱신될 수 있고, 가맹점 승인·예상 수수료 계산에 이 값이 쓰임즉 초기화는 '지금 기준값 리셋'이지 영구 고정이 아님가설
개별 수정과의 대비
카드사 하나를 직접 고칠 때는 0%~10% 범위 검증이 걸리지만, 초기화는 값을 사람이 넣지 않으므로 이 범위 검증을 타지 않음(서버 기본값 그대로 적용)확정

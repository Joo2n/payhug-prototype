'페이허그' 유형 탭을 켠 회원 목록 상태. 탭 클릭은 화면 내 거르기가 아니라 서버 재조회(유형값을 조회 조건으로 실어 보냄)이며, 그 위에 이름/아이디 검색이 화면단 2차 거르기로 겹친다. '페이허그' 유형 자체가 관리자와 동급 권한을 갖는 내부 운영 계정이라는 점이 이 필터의 핵심 맥락이다. 최종 조회 범위·재조회 스케줄은 서버 소관이라 확인 필요.
연결필터 재조회 동작 — 서버조회 + 화면검색 2단
탭 전환 = 서버 재조회
유형 탭을 바꾸면 그 유형만 담아 목록을 서버에 다시 요청한다.이미 받아둔 15행을 화면에서 거르는 방식이 아님'페이허그' 탭 = '페이허그' 유형만 서버가 골라 내려줌확정
함께 새로 불러오는 것
목록 재조회 때 등록 가능한 유형 목록도 매번 같이 다시 불러온다(둘을 한 번에 요청).단, 등록 가능 유형은 선택한 필터값과 무관하게 항상 전체확정
검색창은 별개 층
이름·아이디(전화번호) 검색은 서버가 내려준 결과 위에 화면에서 한 번 더 거르는 2차 필터.서버 재요청 없음, 입력 즉시 화면에서만 좁혀짐즉 '페이허그 유형 → 그중 이름검색' 2단 구조확정
재조회가 다시 도는 시점
탭 전환 외에도 새로고침 버튼·다른 탭 갔다 돌아올 때·브라우저 탭 재활성화 시 목록을 다시 불러온다.확정

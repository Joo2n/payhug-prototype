'일반' 카테고리 칩이 켜진 목록 상태. 카테고리 필터는 검색과 달리 서버에 조건을 넘겨 다시 불러오는 방식이고, 상태별 건수·총 건수도 이 서버 결과(=일반 문의만) 기준으로 다시 계산된다. 카테고리는 5종 고정 분류이며 '일반'이 기본·미분류 대체값 역할을 한다.
연결일반 칩 상태의 데이터·필터 동작
필터가 걸리는 방식
'일반' 칩을 켜면 서버에 카테고리=일반 조건을 붙여 목록을 다시 요청한다.화면에 이미 받아둔 목록을 걸러내는 게 아니라, 서버가 일반 문의만 추려서 새로 내려준다상태 탭(대기/처리중 등)과 조합되면 두 조건이 함께 서버로 넘어간다확정
검색창과의 차이(중요)
상단 검색창은 서버가 아니라 화면에서만 걸러진다.검색 대상: 제목·가맹점명·작성자즉 '일반' 칩으로 서버가 추려온 결과 안에서만 다시 검색이 먹는다. 검색이 전체 카테고리를 다시 뒤지지는 않는다확정
동시 선택 불가
카테고리는 한 번에 하나만. 같은 칩을 다시 누르면 조건이 풀려 전체로 돌아가고, 이때도 서버 재조회가 일어난다.확정
계산건수 표시가 다시 계산되는 지점
상태 탭 옆 숫자
각 상태 탭의 건수는 지금 화면에 올라온 목록을 세어 만든다.'일반' 칩이 켜진 상태에서는 서버가 일반 문의만 내려주므로, 대기/처리중/답변완료/종료 숫자도 일반 카테고리 안에서의 건수가 된다전체 카테고리 기준 건수가 아니다확정
우측 상단 '총 N건'
받아온 목록 전체 개수를 그대로 표시. 일반 칩이 켜져 있으면 이 값도 일반 문의 개수다.검색어를 넣어도 '총 N건'은 줄지 않는다(검색은 표만 거를 뿐 이 숫자에는 반영 안 됨)가설
정책카테고리 분류 규칙
카테고리 5종
일반 · 결제 · 정산 · 기술 · 계정 고정 5분류.문의 카테고리는 가맹점이 접수 시 정한 값을 어드민이 필터로 다시 고르는 구조확정
'일반'이 기본·대체값
목록의 카테고리 뱃지를 그릴 때 알 수 없는 카테고리 값이 오면 '일반'으로 표시된다.즉 미분류·비정상 값은 화면상 일반으로 흡수됨. 이 상태의 목록에 실제로 순수 일반 건만 있는지는 서버 분류 정확도에 달림가설

약관 관리 화면의 '컨텍스트 관리' 패널에서 '컨텍스트 추가'를 누르면 뜨는 빈 폼 모달. 코드·이름·정렬순서 3개 필드만 입력하며, 컨텍스트는 약관을 묶는 최상위 분류(회원가입/계약 등)다. 이 모달의 특수점은 (1) 코드 입력이 실시간으로 소문자로 강제 변환되는 점(종류 추가 모달의 코드는 반대로 대문자 변환), (2) 이름·코드가 모두 필수이고 저장 시 각각 개별 검증되는 점, (3) 신규 코드는 색상 매핑에 없어 목록에서 기본 회색 배지로 표시되는 점이다.
설정이 모달만의 입력 필드
코드 (필수)
입력하는 즉시 소문자로 자동 변환된다.안내 예시: signup, contract종류 추가 모달의 '약관 코드'는 정반대로 대문자 변환되므로 혼동 주의확정
이름 (필수)
화면·필터 칩·배지에 노출되는 표시명.안내 예시: 회원가입확정
정렬 순서
숫자만 입력 가능(숫자 외 문자는 자동 제거), 비우면 0으로 저장.컨텍스트 목록/필터 노출 순서를 정하는 값확정
추가 모달에 없는 항목
수정 모달과 달리 코드 입력칸이 열려 있음(수정 시엔 코드가 잠겨 변경 불가). 활성/비활성 토글은 추가 폼에 없음 → 신규는 활성 상태로 생성되는 것으로 추정가설
정책저장 검증·처리 규칙
이름 미입력 시
'컨텍스트 이름을 입력해주세요' 오류 토스트, 저장 중단확정
코드 미입력 시
이름을 통과해도 코드가 비면 '컨텍스트 코드를 입력해주세요' 오류 토스트로 2차 차단 (추가 모달에서만 검사, 수정 모달엔 없음)확정
중복 코드 처리
같은 코드가 이미 있을 때의 거부 여부는 화면 코드에 없음 → 서버 검증 영역, 확인 필요확인필요
저장 성공 후
'등록되었습니다' 토스트 → 모달 닫힘 → 목록 전체 재조회로 새 컨텍스트 반영확정
연결데이터 연결·저장 후 파급
저장 대상
약관 컨텍스트 등록 요청으로 코드·이름·정렬순서를 전송. 신규 생성이므로 활성 여부는 서버 기본값에 의존확정
신규 코드의 색상
목록/배지 색은 signup(하늘)·contract(보라)만 코드로 하드코딩됨. 그 외 신규 코드는 모두 기본 회색 배지로 표시 → 색을 주려면 코드 배포 수정 필요확정
생성 후 즉시 사용처
등록되면 상단 필터 칩과 '종류 추가' 모달의 컨텍스트 선택 목록에 바로 노출 → 이후 이 컨텍스트에 약관 종류를 붙일 수 있음확정
삭제 기능
컨텍스트는 이 화면에서 삭제 수단이 없음(추가·수정만 존재). 잘못 만든 컨텍스트 정리 방법은 확인 필요확인필요

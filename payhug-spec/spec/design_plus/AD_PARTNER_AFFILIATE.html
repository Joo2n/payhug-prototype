회원 관리 목록에서 유형 탭 중 '제휴사'를 고른 상태다. 유형 탭을 바꾸면 화면 내 걸러내기가 아니라 서버에 유형값을 실어 목록을 다시 불러온다(제휴사만 서버가 추려서 내려줌). 반면 이름/아이디 검색창은 서버 재조회 없이 이미 받아온 목록에서만 걸러낸다. 이 상태에서 특수한 것은 (1) 유형 탭=서버 재조회 / 검색창=화면 내 필터의 이원 구조, (2) 제휴사로 걸러도 결과는 로그인한 운영자의 권한 범위(자기+하위)로 이미 제한되어 있다는 점, (3) 가입링크 생성에서 제휴사 코드가 파트너 코드와 상호배타로 묶인다는 점이다.
연결유형 탭(제휴사) = 서버 재조회 / 검색창 = 화면 내 필터
유형 탭이 곧 조회 조건
제휴사 탭을 누르면 그 유형값을 서버에 실어 목록을 통째로 다시 받아온다.화면에 이미 있는 목록을 걸러내는 방식이 아니라 서버 재조회다.'전체' + 투자자·페이허그·파트너·제휴사·영업·영업조직·관리자 7개 유형 탭이 고정으로 노출된다.확정
탭 변경 시 함께 다시 부르는 것
제휴사로 바꾸면 목록과 '등록 가능한 유형' 목록을 동시에 다시 조회한다.등록 가능 유형이 하나도 없으면 상단 '+ 등록' 버튼 자체가 사라진다(제휴사 필터 여부와 무관하게 로그인 권한에 따름).확정
검색창은 성격이 다름
이름/아이디 검색창은 서버를 다시 부르지 않고, 이미 받아온 제휴사 목록 안에서만 이름·전화번호로 걸러낸다.그래서 '제휴사 탭 + 검색어'는 서버가 추린 제휴사들 위에 화면단 걸러내기가 한 번 더 얹히는 구조다.확정
자동 재조회 시점
새로고침 버튼, 탭(브라우저) 재활성화·포커스 복귀 때도 현재 걸린 제휴사 조건 그대로 서버를 다시 부른다.확정
정책제휴사로 걸러도 결과는 '운영자 권한 범위'로 이미 좁혀져 있음
조회 범위는 자기+하위
제휴사 탭을 눌러도 모든 제휴사가 아니라, 로그인한 운영자 기준 자기·하위 조직에 속한 제휴사만 서버가 내려준다.회원 수정 화면 주석에 '조회 스코프(자기+하위)'가 명시돼 있어, 유형 필터는 이 권한 범위 위에 얹히는 2차 조건임.확정
범위 밖 상위는 안 보임
권한 범위를 벗어난 상위 제휴사는 이 목록엔 안 나온다. 다만 수정 화면의 상위 회원 칸에서는 현재 상위가 범위 밖이라도 '(현재 상위)'로 별도 보정해 표시한다(제휴사 필터 목록 자체는 보정 안 함).확정
실제 스코프 판정 로직
'자기+하위'를 서버가 어떤 소속 트리·권한 규칙으로 확정하는지는 서버 전용이라 화면 코드만으론 단정 불가.확인필요
데이터제휴사에 특수한 데이터·연결
가입링크에서 파트너와 배타
하단 가입 링크 생성기에서 제휴사와 파트너는 동시에 고를 수 없다(한쪽 선택 시 다른 쪽 비활성, '동시 선택 불가' 경고 노출).영업은 이 배타와 무관하게 별도로 함께 붙일 수 있다.확정
링크 후보엔 상위 제휴사도 포함
가입링크 후보는 목록의 자기·하위뿐 아니라 별도로 불러온 상위 제휴사(활성 + 추천코드 보유)까지 합쳐 보여준다. 즉 링크 후보 범위 ≠ 제휴사 탭 목록 범위.확정
제휴사 행 자체는 공통 컬럼
제휴사라고 목록 컬럼(추천코드·상위회원·사업자등록증·직인·프로필)이 달라지진 않는다. 유형 배지 색만 제휴사 전용(청록)으로 구분된다.확정

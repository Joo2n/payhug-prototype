약관 종류를 수정하는 작은 모달. 종류명·필수동의 여부·정렬 순서 3가지만 수정 가능하고, 소속 컨텍스트와 약관 코드는 화면에 아예 표시되지 않으며 저장 시에도 서버로 전송되지 않아 사실상 변경 불가다. 약관 본문·버전은 이 모달에서 다루지 않고 별도 개정 모달로 분리돼 있다.
설정이 모달에서만 수정되는 3개 항목
수정 가능 항목
종류명 · 필수 동의 여부 · 정렬 순서 3개뿐종류 추가 모달에는 있던 '컨텍스트' 선택과 '약관 코드' 입력칸이 수정 모드에서는 아예 화면에 나타나지 않음확정
종류명
유일한 필수 입력값비우고 저장하면 “약관 종류명을 입력해주세요.” 안내 후 저장 중단확정
필수 동의 여부
체크박스 필수 동의 약관. 켜면 목록에서 주황색 '필수', 끄면 회색 '선택' 배지로 표시가맹점 가입·계약 동의 화면의 필수/선택 노출을 좌우하는 값(가설)가설
정렬 순서
숫자만 입력(문자·기호 자동 제거). 비우면 0으로 저장같은 컨텍스트 안에서 약관 종류가 나열되는 순서를 정하는 값(가설)가설
정책변경 불가 항목 (표시조차 안 됨)
소속 컨텍스트
수정 모달에 노출 안 됨. 저장할 때도 서버로 안 보냄한 번 정해진 종류의 소속(예: 회원가입/계약)은 이 화면에서 못 바꿈확정
약관 코드
수정 모달에 노출 안 됨. 저장 시 전송 항목에서 제외코드는 종류 추가 시점에만 정해지고 이후 불변으로 취급됨확정
저장 시 실제 전송값
종류명 · 필수 여부 · 정렬 순서 3개만 수정 대상 주소로 전달컨텍스트·코드가 폼 상태엔 남아있어도 전송 목록에 없어 반영되지 않음확정
연결저장 처리
저장 결과
성공 시 “수정되었습니다.” 토스트 → 모달 닫힘 → 약관 전체 목록 재조회로 화면 갱신확정
저장 중 상태
저장 버튼이 '저장 중...'으로 바뀌고 비활성화되어 중복 저장 방지확정
서버 검증
종류명 공란 외 추가 검증(중복 코드, 사용 중인 종류 제약 등)은 서버 처리라 화면만으론 확인 불가확인필요

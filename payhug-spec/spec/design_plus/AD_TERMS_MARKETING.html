약관 관리 목록에서 상단 컨텍스트 필터 칩으로 '마케팅' 컨텍스트만 걸러 본 상태. 마케팅은 색상 팔레트에 정의가 없어 회색 기본 배지로 표시되며, 필터는 순수 화면단 걸러내기라 서버를 다시 부르지 않는다. 이 상태에 특수한 것은 (1) 필터 동작·빈 그룹 숨김 규칙, (2) 회색 배지가 나오는 색상 매핑 규칙, (3) 필터 칩의 개수 표기 기준 세 가지다.
연결마케팅 필터 동작 규칙
필터는 화면 안에서만 걸러냄
'마케팅' 칩을 눌러도 서버를 다시 부르지 않는다.처음 화면 열 때 한 번 받아둔 전체 약관 목록(컨텍스트·종류·버전)을 화면 메모리에서 마케팅 컨텍스트만 골라 보여줄 뿐.즉 마케팅 전용 조회 API는 없고, '전체'로 받은 뒤 필터링확정
종류가 하나도 없으면 그룹 자체가 사라짐
마케팅 컨텍스트에 등록된 약관 '종류'가 0개면 그 컨텍스트 블록을 아예 그리지 않는다.결과적으로 화면 전체가 비면 "등록된 약관이 없습니다." 안내만 남음확정
탭 재진입 시 자동 새로고침
다른 탭 갔다가 이 화면 탭으로 돌아오면 목록을 다시 불러온다.단, 선택해둔 마케팅 필터 상태는 유지됨(필터는 다시 걸림)확정
설정회색 배지가 나오는 이유 (색상 규칙)
색상은 컨텍스트 코드별로 하드코딩
배지 색은 컨텍스트 코드에 미리 박아둔 표에서 가져온다.회원가입 계열 = 하늘색, 계약 계열 = 보라색 두 개만 지정돼 있음확정
마케팅은 표에 없어 회색 기본값
마케팅 컨텍스트 코드는 색상 표에 등록돼 있지 않다.→ 지정 색이 없으면 무조건 회색 기본 배지로 떨어짐.새 컨텍스트를 어드민에서 추가해도 코드에 색을 심기 전까지는 전부 회색으로 보임(운영 설정이 아니라 개발 반영 필요 사항)확정
데이터필터 칩의 개수 표기
칩 옆 숫자 = 해당 컨텍스트의 약관 종류 수
마케팅 칩 오른쪽 작은 숫자는 마케팅에 속한 약관 '종류' 개수다(버전 수 아님).이 숫자는 어떤 필터가 걸려 있든 항상 전체 기준으로 계산 — 마케팅을 선택해 다른 컨텍스트가 화면에서 사라져도 각 칩의 숫자는 그대로확정
필터 상태는 저장되지 않음
마케팅 필터 선택은 브라우저 화면 상태로만 존재.새로고침하면 '전체'로 초기화됨가설

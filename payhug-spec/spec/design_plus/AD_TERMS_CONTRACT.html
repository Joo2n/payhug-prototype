전자계약(contract) 필터를 켠 약관 관리 목록. 필터는 화면 표시만 좁히는 클라이언트 동작이며, 필터가 걸린 컨텍스트에 약관 종류가 하나도 없으면 그 컨텍스트 자체가 목록에서 사라진다. 전자계약 컨텍스트는 보라색 배지로 고정 매핑되고, 개정 시 버전은 최신값을 정수 올림(예 2.5→3.0)해 자동 채번되며 수정 불가다. 삭제는 미게시 버전에만 버튼이 뜨고, 게시된 버전·동의 이력이 있는 버전은 삭제가 막힌다. 확정 수수료율·지급 캘린더 등 서버 산술은 이 화면과 무관.
연결전자계약 필터의 실제 동작
필터는 표시만 좁힌다
전자계약 탭은 서버 재조회 없이 화면 표시만 필터링한다.전체/회원가입/전자계약 탭 모두 처음에 3종(컨텍스트·종류·버전) 데이터를 한 번에 다 받아두고, 화면에서만 걸러 보여준다.탭을 눌러도 새 조회가 일어나지 않음확정
빈 컨텍스트는 사라진다
전자계약 필터를 켰을 때 전자계약에 약관 종류가 하나도 없으면 컨텍스트 블록 자체가 목록에서 빠진다.종류가 0개인 컨텍스트는 화면에서 통째로 숨김이 경우 "등록된 약관이 없습니다" 안내만 표시확정
탭 옆 숫자
전자계약 탭 옆 작은 숫자는 그 컨텍스트에 속한 약관 종류 개수(버전 수가 아님).확정
다른 탭 복귀 시 갱신
브라우저 탭이 다시 활성화되면 목록 3종을 자동 재조회. 다른 창에서 약관을 바꾸고 돌아오면 최신 상태로 갱신됨.확정
설정전자계약 컨텍스트 표기·색상
보라색 배지 고정
전자계약(contract)은 보라색 배지, 회원가입(signup)은 하늘색으로 코드에 하드코딩.새 컨텍스트를 추가하면 지정 색이 없어 회색으로 표시됨확정
코드 대소문자 강제
컨텍스트 코드는 입력하는 즉시 소문자로 강제 변환(contract), 약관 종류 코드는 대문자로 강제 변환(SERVICE 등).코드 형식이 자동 정규화되어 운영자가 대소문자를 신경 쓸 필요 없음확정
코드 수정 잠금
컨텍스트를 수정할 때 코드 칸은 잠겨서 못 바꾼다(이름·정렬 순서만 변경 가능).확정
계산개정(새 버전) 자동 채번·프리필
버전 자동 채번 규칙
개정 시 버전은 기존 최신 버전을 정수로 내림 후 +1, 소수 첫째자리는 0으로 자동 계산.예: 최신 1.0 → 2.0, 최신 2.5 → 3.0, 버전이 하나도 없으면 1.0버전 칸은 읽기전용이라 운영자가 직접 못 바꿈확정
제목·본문 자동 채움
특정 종류에서 [개정]을 누르면 직전 최신 버전의 제목·본문이 그대로 복사되어 들어온다.기존 문구를 수정해 새 버전을 만드는 방식확정
상단 '약관 개정' vs 행별 '개정'
상단 약관 개정 버튼은 종류를 드롭다운에서 골라야 하고(종류 0개면 막힘), 행별 개정 버튼은 해당 종류가 고정되어 못 바꾼다.두 경로의 차이는 종류 선택 가능 여부뿐확정
시행일 기본값
새 버전의 시행일 기본값은 오늘 날짜. 등록자는 로그인한 어드민 이름(없으면 admin)으로 기록됨.확정
정책게시·삭제 처리 규칙
게시 토글 즉시 반영
버전별 게시 스위치는 확인창 없이 클릭 즉시 반영. 켜면 "게시됨", 끄면 "미게시됨" 안내.확정
삭제 버튼 노출 조건
삭제 버튼은 미게시 버전에만 표시된다. 게시 중인 버전에는 삭제 버튼 자체가 없음(수정·미리보기만).확정
동의 이력 있으면 삭제 거부
삭제 확인창에 "사용자 동의 이력이 있는 경우 삭제가 거부됩니다" 문구 고정.실제 거부 판정은 서버가 수행, 화면은 안내만가설
삭제 되돌림 불가
삭제는 되돌릴 수 없다는 경고와 함께 대상(제목·버전·종류)을 다시 보여준 뒤 확정.확정

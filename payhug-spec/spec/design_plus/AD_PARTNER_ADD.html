회원 등록은 목록 상단 '회원 등록' 버튼으로 여는 빈 폼 모달이다. 수정 모달과 같은 컴포넌트를 공유하지만 등록일 때만의 규칙이 있다: 비밀번호가 필수이고, 유형 드롭다운은 서버가 내려준 '생성 가능 유형'만 보이며, 상태·프로필(사업자정보/직인/사업자등록증 OCR)은 이 화면에 없다(등록 후 목록에서 별도 관리). 확정 수수료율·지급 캘린더 등 정산 수치와는 무관한, 계정 생성용 화면이다.
정책등록 폼에만 있는 입력·검증 규칙
비밀번호 필수 여부
등록에서는 비밀번호가 필수입니다.수정 화면은 비워두면 기존 유지지만, 등록은 빈 값이면 "비밀번호를 입력해주세요" 경고로 막힘확정
필수 3종
이름 · 아이디/휴대폰번호 · 비밀번호 세 가지가 비면 등록 불가.순서대로 검사해 첫 빈 항목의 경고 문구를 띄움확정
상태 항목 없음
등록 폼에는 활성/비활성 선택이 없음.신규는 항상 활성으로 생성(상태 드롭다운은 수정에서만 노출)확정
프로필·직인·사업자등록증 없음
등록 모달에는 사업자정보 입력, 직인 업로드, 사업자등록증 OCR 인식이 포함되지 않음.이 기능들은 계정 생성 이후 목록에서 '프로필 관리'로만 접근확정
아이디 겸용 안내
'아이디/휴대폰번호' 한 칸에 예: payhug_partner 또는 010-... 를 받고, 로그인 아이디로 사용한다고 안내.전송 시 하이픈 제거 후 저장확정
설정유형 선택 — 생성 가능 유형만 노출
고를 수 있는 유형
전체 7종(투자자·페이허그·파트너·제휴사·영업·영업조직·관리자) 중 서버가 내려준 '생성 가능 유형'만 드롭다운에 표시.로그인한 운영자 권한에 따라 만들 수 있는 대상이 제한됨(서버 판단)확정
기본 선택값
생성 가능 유형에 파트너가 있으면 파트너를 기본 선택, 없으면 목록의 첫 번째 유형.그마저 비면 파트너로 폴백확정
생성 가능 유형 판정
어떤 운영자가 어떤 유형을 만들 수 있는지의 실제 기준은 서버 규칙이라 화면에서 알 수 없음확인필요
연결조직 연결·부가 필드
상위 회원 연결
소속 조직의 상위 회원을 선택. 후보는 활성 회원만 노출(이름+유형 표기).미선택 시 '없음(최상위)'확정
상위 후보 범위
후보 목록은 현재 운영자가 조회 가능한 자기+하위 범위로 한정될 수 있음(조회 스코프 의존)가설
법인/사업자 여부 토글
법인 여부, 사업자 여부 두 스위치. 관리자·페이허그 권한만 조작 가능, 그 외 잠김.사업자 여부에 "(VAT 적용 기준)" 표기 → 부가세 처리 갈림확정
추천 코드
가맹점 가입 URL에 쓰이는 고유 코드. 입력 즉시 대문자로 자동 변환(예: P001, I001).비우면 미전송확정
VAT 실제 적용 로직
사업자 여부 on/off가 정산 부가세 계산에 실제로 어떻게 반영되는지는 서버 정산 로직 영역확인필요

유저 하드리셋 모달은 회원 로그인 계정만 남기고 해당 가맹점의 모든 데이터를 영구 삭제하는 어드민 전용·복구 불가 기능이다. 삭제 요청이 가맹점이 아니라 그 가맹점에 연결된 회원 계정을 기준으로 실행되는 점, 확인 입력창에 "하드리셋"을 글자 그대로 정확히 입력해야만 실행 버튼이 열리는 점, 성공 시 상세 탭을 닫고 목록 탭을 여는 점, 그리고 비슷한 이름의 비밀번호 초기화·계약 프로세스 초기화와 완전히 다른 처리라는 점이 이 화면 고유의 로직이다.
설정실행 권한과 버튼 노출 조건
버튼 노출 대상
관리자 권한 운영자에게만 [하드리셋] 버튼이 보임일반 운영자에게는 버튼 자체가 표시되지 않음 (같은 줄의 비밀번호 초기화 버튼은 권한 제한 없음)확정
버튼 위치·잠금
가맹점 상세 상단 액션 영역에 위치다른 저장/처리 작업이 진행 중이면(제출 중 상태) 버튼이 비활성화됨확정
권한 서버 재검증
화면에서 관리자에게만 버튼을 보여주지만, 서버가 실제 실행 시점에 권한을 다시 검증하는지는 코드로 확인 불가확인필요
데이터삭제 대상과 남는 것
영구 삭제되는 데이터
경고 박스에 명시된 6종을 전부 영구 삭제사업자 등록 정보(전체)계약서·약관 동의·신분증등록된 계좌 정보매출·거래·정산 데이터수수료·외부 계정·라우팅메모·문의·첨부파일(파일 저장소 포함)확정
유일하게 남는 것
회원 계정(로그인 수단·소셜 연동)만 유지즉 사람(회원)은 남기고 그 사람에게 붙어 있던 가맹점 관련 모든 데이터를 비워 초기 상태로 되돌리는 개념확정
삭제 기준 대상
삭제 요청이 가맹점이 아니라 그 가맹점에 연결된 회원 계정을 기준으로 실행됨한 회원에 여러 가맹점이 연결된 경우 삭제 범위가 어디까지인지는 서버 처리에 달려 있어 확인 필요확인필요
복구 가능 여부
복구 불가능으로 안내 — 되돌리기·휴지통 개념 없음확정
정책실행 조건과 처리 후 흐름
확인 문구 입력
확인 입력창에 "하드리셋"을 글자 그대로 정확히 입력해야만 [하드리셋 실행] 버튼이 열림오타·앞뒤 공백·다른 글자면 버튼 잠김 (완전 일치만 허용)확정
모달 닫힘 시 초기화
취소하거나 배경을 눌러 닫으면 입력한 확인 문구가 지워짐다시 열면 처음부터 입력해야 함확정
성공 후 화면 이동
성공하면 모달을 닫고 가맹점 관리 목록 탭[AD_MERCHANT]을 새로 열면서 현재 보던 상세 탭을 닫음삭제된 가맹점 상세에 그대로 머무르지 않도록 처리확정
실패 시
실패하면 상세 화면 상단에 오류 메시지 표시(서버 메시지 또는 "하드리셋 실패"), 모달은 유지확정
서버 실제 삭제 처리
실제로 어떤 테이블·저장소를 어떤 순서로 지우는지, 진행 중 거래·미회수금이 있어도 강제 삭제하는지 등 최종 삭제 규칙은 서버 전용이라 확인 필요확인필요
정책비슷한 이름의 다른 기능과 구분
vs 비밀번호 초기화
비밀번호 초기화는 로그인 비밀번호만 새로 지정(4자 이상)하는 것 — 데이터 삭제 아님, 별개 모달확정
vs 계약 프로세스 초기화
반려 처리된 가맹점 전용으로, 계약 데이터를 지워 처음부터 재계약하게 하는 기능 — 가맹점 기준으로 동작하고 하드리셋(회원 계정 기준·전체 삭제)과 대상·범위가 다름확정
어드민 '매출 회수'와 무관
이 기능은 락계좌→모계좌 스윕(어드민 매출 회수)이나 과지급 회수와 전혀 관련 없는 데이터 삭제 기능확정

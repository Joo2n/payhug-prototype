1:1 문의 목록에서 상단 '처리중' 탭을 누른 상태. 이 탭은 서버에 처리중 상태만 걸러 달라고 요청해 목록을 좁히는 필터일 뿐, 처리중 전용 입력 필드나 별도 모달은 없다. 다만 (1) 탭 옆 건수 배지가 서버가 이미 걸러 보낸 목록만 세는 구조라 필터를 켜면 다른 탭 건수가 어긋나고, (2) 답변을 보내도 상태가 자동으로 답변완료로 넘어가지 않고 담당자가 드롭다운으로만 바꿔야 하며, (3) 마지막 발신자가 가맹점이면 처리중 건에 빨간 NEW 배지가 붙는 점이 이 상태에서 실질적으로 특수하다.
설정처리중 필터 동작
필터 적용 방식
'처리중' 탭을 누르면 서버에 처리중 상태만 걸러서 목록을 다시 요청한다.화면에 이미 받아둔 목록을 감추는 방식이 아니라, 매번 서버 재조회확정
카테고리와 조합
처리중 필터와 카테고리(일반·결제·정산·기술·계정) 필터가 동시에 서버 조건으로 함께 걸린다.둘 다 서버 재조회 대상확정
검색창은 별도
제목·가맹점명·작성자 검색은 서버가 아니라 화면에 받아둔 목록 안에서만 걸러낸다.즉 처리중으로 좁혀진 결과 안에서 다시 찾는 것확정
정책상태 전이·답변 규칙
답변해도 자동 전환 없음
처리중 건에 답변을 전송해도 상태가 자동으로 답변완료로 바뀌지 않는다.상태 변경은 오른쪽 상단 드롭다운으로 담당자가 수동으로만확정
상태 선택지
드롭다운에서 대기·처리중·답변완료·종료 중 아무 상태로나 자유 이동 가능.처리중→대기 되돌리기도 막혀 있지 않음확정
답변 입력 가능 여부
처리중 상태에서는 답변 입력창이 열려 있다.'종료' 상태로 바꾸면 입력창이 사라지고 '종료된 문의입니다' 안내로 대체확정
상태를 어느 시점에 넘길지
'처리중'을 언제 붙이고 언제 답변완료로 넘기는지에 대한 운영 기준이 코드에 없다. 전적으로 담당자 판단.확인필요
데이터건수 배지·NEW 표시
탭 옆 건수의 함정
각 탭 옆 숫자는 지금 화면에 받아둔 목록만 세어 표시한다. 처리중 필터를 켜면 목록에 처리중 건만 있어서 '전체' 숫자도 처리중 건수와 같아지고 다른 탭은 0으로 보인다.전체 건수를 보려면 '전체' 탭으로 돌아가야 정확확정
NEW 배지 조건
처리중 건이라도 마지막 메시지를 가맹점이 보낸 경우 제목 옆에 빨간 NEW가 붙는다.담당자가 아직 회신 안 한 처리중 건을 눈에 띄게 하는 용도확정
최근 활동 시각
목록의 '최근 활동'은 마지막 메시지 시각 기준(없으면 접수 시각)으로 '○분 전' 형태로 표시.확정

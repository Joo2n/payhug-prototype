'차액 정산' 화면의 배달 수수료 차액 서브탭. 상위 대사 데이터에서 '배달 수수료 차액' 건만 골라 보여주는 변형으로, 배달 채널(배민·요기요·쿠팡이츠) 매출에서 예상 배달수수료와 실제 배달수수료의 차이를 환급/차감으로 정리한다. 카드 차액과 달리 카드사 필터가 무관하고, 색·유형 라벨·부호 처리가 배달 전용으로 분기된다. 최종 수수료 산출·확정 배달수수료율은 서버 전용이라 확인필요.
데이터이 서브탭에서만 다른 데이터·필터
표시 대상 좁히기
상위 '차액 정산' 조회 결과 전체를 한 번에 받아온 뒤, 화면에서 '배달 수수료 차액' 구분만 골라 보여주는 방식이다.이 서브탭 전용으로 서버를 따로 부르지 않는다 (전체 탭과 같은 데이터 덩어리 공유)확정
배달 채널 필터
매출 유형에서 배달의민족·요기요·쿠팡이츠를 (복수) 선택하면 서버가 그 채널 건만 다시 집계해 KPI까지 반영한다.'전체'를 고르면 원장에 아직 연결 안 된 건도 포함되고, 특정 채널을 고르면 원장 연결 건만 남는다는 안내가 붙음확정
카드사 필터는 무관
카드사(2뎁스 칩) 필터는 매출 유형에서 '카드'를 골랐을 때만 뜬다.배달 차액을 보려고 배달 채널을 고르면 카드사 필터 자체가 사라지므로 이 서브탭에선 쓸 일이 없다확정
배달수수료 값 출처
'예상 배달수수료'와 '실제 배달수수료'는 배달 플랫폼 매출 대사에서 나오는 값으로, 계산 로직·스크래핑 시점은 서버 전용이라 화면 코드만으로 확인 불가.확인필요
계산배달 전용 유형·부호 처리
두 가지 유형
이 구분 안에는 배달수수료 환급과 배달수수료 차감 두 유형만 나온다.환급은 파란 뱃지, 차감은 주황 뱃지로 구분 (배달 차액의 대표색은 주황)확정
차액 부호
환급이면 금액 앞에 +(가맹점에 더 준다), 차감이면 -(가맹점에서 뺀다)로 표시한다.엑셀 내려받기 때도 환급은 양수, 차감은 음수로 부호를 뒤집어 기록확정
KPI 카드 색·부호
'배달 수수료 차액' KPI는 합계가 0 이상이면 주황, 마이너스면 빨강으로 바뀌고, 건수와 함께 대기 건수를 괄호로 덧붙인다.확정
일별 추이 차트
추이 막대는 환급(파랑)·차감(빨강)·취소환수(보라)로 그려진다.취소환수는 배달 차액이 아닌 별도 구분이라, 배달 서브탭 맥락에선 환급/차감 두 막대만 의미 있음가설
정책개념 분리·상태 처리
환급 = 6대 개념의 '환급'
'배달수수료 환급'은 예상보다 실제 배달수수료를 덜 떼서 가맹점에 돌려주는 환급으로 읽힌다. 카드 '취소 환수'나 '과지급 회수'와 섞지 말 것.가설
차감의 성격은 미확정
'배달수수료 차감'이 지급 전 당일 차감인지, 지급 후 과지급 회수 성격인지 화면만으론 구분 안 됨.6대 개념 중 어디에 붙일지 근거 필요확인필요
반영 상태
각 건은 반영완료(초록, 반영일자 함께 표기) 또는 대기중(주황)으로 표시. KPI의 대기 건수는 아직 정산에 안 태운 건 수를 뜻한다.확정
확정 배달수수료율
예상↔실제 차이를 만드는 기준 배달수수료율은 서버 산출값이라 화면에 안 드러남 (미확정 지뢰 C1 계열).확인필요

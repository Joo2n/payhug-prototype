회원 목록에서 유형=관리자 탭을 켠 상태. 이 상태의 핵심은 "유형 필터는 서버 재조회 / 검색어는 화면 내 거르기"로 두 필터의 처리 위치가 다르다는 점, 필터를 바꿀 때마다 목록과 등록가능 유형을 함께 다시 불러오는 점, 그리고 관리자 유형 행에 붙는 버튼(프로필·삭제)이 운영자 권한에서만 보이는 점이다. 나머지 표·뱃지·검색·가입링크는 기본 목록과 동일하므로 생략.
연결유형 필터의 재조회 방식
필터 = 서버 재조회
유형 탭(관리자 등)을 누르면 선택한 유형만 서버에 다시 요청해 목록을 갈아끼운다.이미 받은 목록을 화면에서 거르는 방식이 아니라, 매번 새 목록을 받아옴'전체' 탭은 유형 조건 없이 전체를 다시 받아옴확정
검색어 = 화면 내 거르기
같은 화면의 이름/아이디 검색창은 필터와 달리 서버를 부르지 않고 이미 받은 목록에서만 걸러낸다.이름은 소문자 부분일치, 전화번호는 숫자 부분일치즉 '관리자 탭 결과' 안에서만 다시 좁혀짐확정
필터 변경 시 함께 갱신
탭을 바꿀 때 목록뿐 아니라 등록 가능 유형(=+등록 버튼에 뜨는 유형)도 매번 다시 조회한다. 두 요청이 동시에 나감.확정
화면 복귀 시 자동 재조회
다른 탭/창을 보다 이 화면으로 돌아오면 현재 필터 그대로 목록을 자동으로 다시 불러온다.스크린샷만으론 안 보이는 백그라운드 갱신 동작확정
목업의 한계 표시
현재 목업은 유형이 섞인 고정 데이터라 탭을 바꿔도 같은 15행이 그대로 보임. 실제 연동 시에는 해당 유형만 표시됨.확정
정책관리자 유형 행의 특수 노출 조건
프로필·삭제 버튼
관리자 유형 회원 행에서도 프로필/삭제 버튼은 운영자 본인이 관리자·페이허그 권한일 때만 보인다.그 외 권한에는 수정·비활성화 버튼만 노출확정
법인/사업자 토글 잠금
등록·수정 창의 법인 여부·사업자 여부(VAT 기준) 토글은 운영자가 관리자·페이허그 권한이 아니면 잠김(비활성).확정
등록 버튼 노출
'+등록' 버튼은 등록 가능 유형이 하나라도 있을 때만 나타남. 권한에 따라 등록할 수 있는 유형 목록이 서버에서 정해짐.확정
데이터목록 데이터 출처와 빈 상태
관리자 탭 결과 출처
관리자 탭 목록은 회원 조회에 유형=관리자 조건을 붙여 받아온 결과. 표의 상위 회원·추천코드·법인/사업자 뱃지·첨부(사업자등록증·직인) 모두 이 응답에 담겨 옴.확정
조회 범위
운영자 권한에 따라 보이는 회원 범위(본인+하위 등)가 서버에서 제한될 수 있음 — 수정창의 '상위 회원' 후보가 조회 범위 밖이면 '현재 상위'로 별도 표기하는 처리로 유추.가설
빈 상태 문구 구분
받은 목록 자체가 0건이면 "등록된 회원이 없습니다", 검색어로 걸러 0건이면 "검색 결과가 없습니다"로 다르게 표시.확정

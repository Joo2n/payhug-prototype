정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
약관 버전의 실제 게시 모습을 그대로 보여주는 읽기전용 미리보기 모달. 목록에서 '미리보기'를 누르면 이미 불러와 둔 해당 버전 데이터를 그대로 화면에 띄우며(별도 상세 조회 없음), 본문은 입력한 줄바꿈·공백을 그대로 살려 렌더한다. 상단에는 컨텍스트·약관종류·버전·시행일·게시상태가 요약되고, 하단 '수정하기'는 미리보기를 닫고 곧바로 같은 버전의 수정 모달로 이어진다.
설정본문 표시 규칙
줄바꿈·공백 보존
입력한 본문을 서식 변환 없이 그대로 표시운영자가 넣은 줄바꿈·연속 공백·들여쓰기가 화면에서도 동일하게 보임마크다운/HTML 해석이 아니라 '보이는 그대로(텍스트)' 방식확정
읽기 전용
미리보기 모달에는 입력칸이 없고 본문·제목·시행일 등 어떤 값도 수정 불가. 보기 전용 화면.확정
긴 본문 처리
본문 영역만 세로 스크롤(모달 높이 최대 화면의 85%). 제목 바(상단)와 버튼 바(하단)는 고정.확정
데이터상단 요약 정보
표시 항목
제목을 크게 띄우고 그 아래 한 줄로 컨텍스트(색 배지) · 약관종류명 · v버전 · 시행일 · 게시/미게시 상태를 나열확정
게시 상태 배지
게시된 버전이면 초록 '게시', 아니면 회색 '미게시'로 표기. 목록의 게시 토글 값과 동일.확정
컨텍스트 배지 색
회원가입(signup)=하늘색, 계약(contract)=보라색, 그 외 컨텍스트=회색 기본값으로 자동 지정확정
연결데이터 출처 · 이어지는 동작
표시 데이터 출처
미리보기는 목록을 그릴 때 이미 받아 둔 그 버전 데이터를 그대로 사용모달을 열 때 서버에 다시 상세를 조회하지 않음따라서 목록 로딩 이후 다른 사람이 바꾼 최신 내용은 반영되지 않을 수 있음확정
'수정하기' 버튼
미리보기를 닫고 곧바로 같은 버전의 '버전 수정' 모달을 여는 이어달리기 동작. 별도 저장/확인 없이 화면만 전환.확정
'닫기' 버튼 / 바깥 클릭
모달을 닫고 목록으로 복귀. 어떤 값도 저장하지 않음(읽기 전용이므로 저장 개념 자체가 없음).확정
서버가 채우는 값
게시 여부·게시일시·생성자·시행종료일 등은 서버가 관리하는 값이라 이 화면에서 확인만 가능. 실제 계산·확정 시점 규칙은 화면 코드로 확인 불가.확인필요

No이름설명
1헤더 "{플랫폼} — 락계좌 연결 상세"(캡처 "여신협회 — 락계좌 연결 상세")플랫폼 상태 뱃지(정상 등) + "최종 검증: {일시}"
2매장 표 표 항목 : 이름 · 계좌 · 상태 · 사유 · 락계좌 검증 제외(조회 전용이면 마지막 열 숨김)행별 검증 제외 토글 — 제외=빨강 · 포함=초록, 제외 행은 회색 배경(캡처는 두 행 모두 포함=초록)건너뜀(SKIPPED)+미제외면 사유칸에 "다시 검증하기를 실행해 주세요."
3하단 안내 "검증 제외 시 락계좌 불일치 알림·이상 집계에서 제외됩니다. 선정산 제외와 별개 설정입니다.""이상 해소는 재검증(스크래핑) 성공으로만 가능합니다."
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
플랫폼별 매장(카드사/배달앱) 결제계좌↔락계좌 연결 상태를 매장 단위로 펼쳐 보고, 매장 행마다 '락계좌 검증 제외'를 켜고 끄는 다이얼로그. 스크린샷 밖의 특수 로직은 (1) 검증 상태 5종의 의미와 뱃지 매핑, (2) 검증 제외 토글의 확인창·낙관적 반영·저장 연결, (3) 검증 제외가 선정산 제외와 별개이며 이상 해소는 재검증으로만 가능하다는 정책 경계 세 가지에 집중된다.
데이터검증 상태 5종 — 뱃지·행 표현 규칙
매장 상태값 종류
매장(행)마다 정상 / 이상 / 장애 / 스킵 / 검증 제외 5가지 중 하나로 표시.정상=초록, 이상·장애=주황/빨강, 스킵·검증제외=회색 뱃지확정
'이상'과 '장애'의 구분
이상은 락계좌 연결이 어긋난 개별 매장 문제, 장애는 스크래핑 자체 실패(플랫폼 단위로도 표시)를 뜻함 — 사유칸의 오류 문구가 함께 노출됨.둘 다 이상 집계 대상가설
'스킵' 매장의 특수 안내
상태가 스킵인데 검증 제외가 꺼져 있으면 사유칸에 주황색으로 "다시 검증하기를 실행해 주세요." 문구를 추가로 노출 — 이 화면에서만의 조건 분기확정
'검증 제외' 행의 표현
검증 제외이거나 상태값이 검증제외면 해당 행 배경을 회색으로 처리해 대상에서 빠졌음을 시각화확정
최종 검증 시각 표기
헤더의 '최종 검증: {일시}'는 서버가 yyMMdd HH:mm 형태로 준 값을 20yy.MM.dd HH:mm으로 변환해 표시 (형식 안 맞으면 원문 그대로)확정
정책락계좌 검증 제외 토글 — 처리 규칙
적용 단위
제외 설정은 플랫폼 전체가 아니라 매장(행) 단위. 카드사·배달앱별 개별 매장 각각을 켜고 끔확정
토글 = 확인창 2종
토글을 누르면 곧바로 반영하지 않고 경고 확인창을 띄움.제외 켤 때: "해당 매장(카드사)을 락계좌 검증에서 제외합니다. 이상 알림이 발생하지 않습니다."다시 포함할 때: "다음 검증 시 락계좌 불일치면 이상으로 표시됩니다."확정
저장 성공 시 반영
확인 시 저장하고, 서버가 돌려준 그 매장 값으로 해당 행만 교체(부분 갱신) 후 성공 토스트. 저장 중엔 그 행 토글만 잠금(비활성)확정
실패 처리
저장 실패 시 서버 메시지 또는 "설정 변경 실패", 통신 오류 시 "설정 변경 중 오류가 발생했습니다." 토스트. 화면 값은 되돌아감확정
조회 전용일 때
편집 권한이 없으면(readOnly) '락계좌 검증 제외' 열 자체가 숨김 — 토글 불가, 상태만 열람확정
연결정책 경계 & 데이터 연결
검증 제외 ≠ 선정산 제외
하단 안내로 명시 — 검증 제외는 '락계좌 불일치 알림·이상 집계'에서만 빼는 설정이며 선정산 제외금액과는 완전히 별개. (6대 개념 중 '선정산 제외금액'을 건드리지 않음)확정
이상 해소 방법
이상 상태는 이 화면에서 수동으로 지울 수 없고 재검증(스크래핑) 성공으로만 해소 — 토글은 '알림 끄기'일 뿐 이상 자체를 해결하지 않음확정
상세 데이터 출처
다이얼로그는 상위 '플랫폼 락계좌 연결 상태' 조회 결과를 그대로 받아 표시(별도 재조회 안 함). 원 데이터는 매장별 락계좌 연결 상태 조회 경로에서 옴확정
저장/재검증 처리 시점
제외 값 저장·재검증(스크래핑) 성공/실패 판정과 상태 산정은 서버에서 수행 — 스크래핑 스케줄·판정 기준은 화면에서 알 수 없음확인필요

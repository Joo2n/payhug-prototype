'차액 정산' 탭의 CANCEL_CLAWBACK(취소 환수) 서브탭. 지급 완료 후 원거래가 취소되어 이미 나간 금액을 되돌려받아야 하는 건을 모은 필터 뷰다. 기존 워크스루가 다룬 '음수·빨강 표시/유형 열 숨김/빈 상태 문구'는 제외하고, 이 서브탭에만 특수한 부호·색상 처리, 별도 집계 시리즈, 데이터 출처, 정책 미확정 지점을 정리한다. 취소 환수 건은 별도 API가 아니라 차액 정산 대시보드 한 번의 조회 결과를 화면단에서 category로 걸러 보여주며, 실제 회수 실행·대상 판정은 서버·정책 미확정 영역이다.
데이터취소 환수 건은 어디서 오고 어떻게 걸러지나
데이터 출처 (전용 조회 아님)
취소 환수만 부르는 별도 요청은 없다.차액 정산 탭이 기간·카드사·매출유형으로 차액 정산 대시보드를 한 번 조회하면 모든 유형(카드수수료 차액·배달 차액·취소 환수·예상매출 대사·미회수 이월)이 한 묶음으로 내려온다.그 목록에서 구분값이 '취소 환수'인 행만 화면단에서 추려 이 서브탭에 표시확정
카드사·매출유형 필터는 서버 집계
상단 매출유형/카드사 필터는 서버에서 이미 적용되어 내려온다(KPI 합계까지 반영).취소 환수는 카드 원거래에 연결된 건이라 카드사 필터의 영향을 받음(가설)에이전시·가맹점명 검색만 화면단에서 추가로 거름가설
한 건에 담긴 정보
거래일 · 가맹점명/사업자번호 · 승인번호(원거래) · 카드사 · 예상수수료 · 실제수수료 · 차액(환수액) · 상태.승인번호가 있어 어느 원거래의 취소인지 추적 가능확정
정렬·건수
거래일 기준 정렬(기본 최신순, 토글로 오름차순), 같은 날은 접수 순서로 안정 정렬.서브탭 옆 숫자 = 필터 적용 후 취소 환수 건수확정
예상/실제 수수료 열의 의미
이 서브탭에도 예상수수료·실제수수료 열이 그대로 노출되나, 취소 환수 맥락에서 두 값이 무엇을 뜻하는지(원거래 수수료인지, 환수 대상 원금인지)는 화면 코드만으로 판별 불가.서버가 채워 내리는 값이라 정의 확인 필요확인필요
계산부호·색상 처리 — 취소 환수는 '항상 차감' 취급
차액은 언제나 음수(-)·빨강
환급으로 보는 유형은 카드/배달/예상매출 '환급' 3종뿐이고 취소 환수는 여기에 없다.→ 취소 환수 행의 차액은 조건 없이 '-' 부호·빨강으로 표시(가맹점에서 돈이 빠져나가는 방향 고정)확정
구분 뱃지도 빨강 고정
구분 뱃지 '취소 환수'는 카드수수료 차감과 같은 빨강 계열.유형 자체가 곧 카테고리(둘 다 '취소 환수'로 동일)라 별도 세부 유형이 없음확정
엑셀은 음수값으로 기록
다운로드 시 취소 환수 차액은 마이너스 숫자로 저장(환급 유형만 양수).화면의 '-' 표기와 저장 부호가 일치확정
일별 추이에서 별도 막대
일별 차액 추이 차트에서 취소 환수는 '차감'과 섞지 않고 독립 시리즈(취소환수)로 분리 집계된다.즉 서버가 일반 카드수수료 차감과 취소 환수를 다른 값으로 합산해 내려줌확정
색상 불일치 (전달 리스크)
표의 취소 환수는 빨강인데, 추이 차트의 취소환수 막대는 보라색이다.같은 개념이 화면 두 곳에서 다른 색 → 디자인 확정 시 통일 필요확인필요
취소 환수 전용 열 라벨은 미구현
코드에 '취소 환수 서브탭이면 열 제목을 다르게' 분기 자리가 있으나 양쪽 값이 같아 실제로는 동일하게 나온다.취소 환수용 별도 열 표기를 의도했다가 비워둔 흔적(가설)가설
정책정책 판단 — 실제 회수는 이 화면 밖·미확정
이 화면은 '집계·조회'까지만
취소 환수 행에는 반영완료/대기중 상태 표시와 반영일자만 있고, 회수를 실행하거나 대상을 확정하는 버튼·모달이 없다.상태를 바꾸는 실제 처리(회수 집행)는 이 서브탭 밖·서버 영역확정
상태값의 판정 기준 불명
'반영완료(반영일자)'와 '대기중'을 무엇으로 가르는지, 대기 건이 다음 정산에서 자동 차감되는지 별도 회수 절차인지 화면만으로 알 수 없다.서버 확정 필요확인필요
지급 전 취소와 반드시 구분
이 서브탭은 지급 완료 후 원거래가 취소되어 이미 나간 돈을 되받는 건.지급 전 취소(당일 차감)와는 처리 자체가 다름(CLAUDE.md 원칙 4)화면상 둘의 구분 표식은 없어 혼동 소지확정
6개념 매핑 미확정 (C4·C5)
'취소 환수'가 6개념 중 과지급 회수인지 미회수금인지 정해지지 않음.어드민 '매출 회수'(락계좌→모계좌 스윕)와도 다른 개념임의 매핑 금지, 정책 확정 대기확인필요
환수 대상·시점 규칙 없음
취소가 얼마 지나야 환수하는지, 부분취소·재승인은 어떻게 처리하는지, 회수 실패 시 이월 규칙(미회수 이월과의 관계)은 이 화면에 근거가 없다.별도 정책 정의 필요확인필요

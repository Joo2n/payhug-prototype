가맹점 매출·매입 원장 상세의 심화 로직 — 카드/배달 매출 원천과 수기·엑셀 등록, 순지급액에서 실제 이체액까지의 분해식, 예상↔정산적용 수수료 차액정산, 현장결제(만나서결제) 회수, 3종 수수료 툴팁, 거래·매입·정산·이체 상태 배지의 판정 규칙을 다룬다.
데이터매출 원천과 수기·엑셀 등록
매출 원천 5종
매출은 카드와 배달 3사(배달의민족·요기요·쿠팡이츠)에서 들어오고, 상단 요약 카드에선 배달 3사를 배달앱으로 묶어 보여준다.유형 필터는 복수 선택 가능, 카드를 고르면 카드사 2뎁스 필터가 열린다확정
단건 등록 — 3개 유형 탭
스크래핑에 안 잡힌 매출을 운영자가 직접 넣는 창으로 카드 승인 / 카드 매입 / 배달 플랫폼 3탭이며 탭마다 입력칸이 다르다.카드 승인: 승인번호·거래일·매출금액·카드사·결제수단(신용/체크)카드 매입: 위 + 매입일·지급예정일·수수료합계(필수)배달: 플랫폼·수수료·매장명·현장결제 여부확정
엑셀 업로드 — 자동 인식 + 3단계
카드(여신금융협회 승인/매입) 또는 배달 엑셀을 올리면 유형을 자동 인식한다.업로드 → 미리보기 → 결과 3단계, 미리보기에서 신규/중복/에러 건수 집계중복 건은 버리지 않고 기존 데이터를 갱신확정
등록 출처 표시
직접 넣은 건은 매출 표 유형칸에 수동/엑셀 보라 태그가 붙어 스크래핑분과 구분된다.확정
계산실제 이체액 구성 분해
순지급액의 정의
순지급액 = 전체 매출 − 수수료. 카드는 카드수수료, 배달은 배달수수료를 뺀 값이다.취소 건은 순지급액을 '-'(회색), 현장결제 건은 '현장수령'으로 표기해 이체 대상에서 제외확정
실제 이체액 노출 조건
실제 이체액(실제로 통장에 나간 돈)이 0보다 클 때만 요약 카드와 '실제 이체액 구성' 블록이 나타난다.확정
실제 이체액 구성식
선정산 순지급액에서 아래를 가감해 실제 이체액에 정확히 떨어지도록 분해한다(각 항목은 0이 아닐 때만 줄 표시).− 당일 카드수수료 차액(익일 이후 배치 반영) − 선정산수수료 ± 차액정산(전일 이전 거래분)− 광고비 차감(배민 우리가게클릭) − 현장결제 회수 = 실제 이체액확인필요
미회수 안내 문구
현장결제 미회수분이 있으면 블록 하단에 '미회수 N원은 다음 정산 배치에서 회수 예정' 안내가 붙는다.확정
계산차액정산 — 예상↔정산적용 수수료
차액의 정의
차액 = 정산적용수수료 − 실제수수료. 선정산은 예상 수수료로 먼저 지급하고, 나중에 실제 수수료가 확정되면 그 차이를 정산한다.화면의 실제수수료는 '정산적용 − 차액'으로 역산해 보여준다(재수집에도 값이 안 깨지게)확인필요
정산적용수수료 vs 최초 예상
정산적용수수료는 정산 당시 실제 적용한 수수료로 최초 예상과 다를 수 있다.둘이 다를 때만 셀에 점선 밑줄+툴팁이 생겨 '정산 당시 적용'과 '최초 예상'을 나란히 보여준다확정
차액정산 유형 8종
차액 반영 내역은 유형으로 구분된다: 카드 환급/추가차감, 예상매출 환급/차감, 취소 환수, 배달 환급/추가차감, 미회수 이월.'예상매출'·'취소 환수'·'미회수 이월'은 앞의 예상↔실제 차액과 성격이 달라 정의 확인 필요가설
차액정산 상태 배지
카드 행: 선정산 대상 아님·매입 미완료는 '-', 그 외 완료(초록 ✓) / 대기(노랑 ⏳) / 차액없음.배달 행은 대기 시 예정 차액을 부호와 함께(±금액) 미리 보여준다확정
차액 반영 펼침표 — 조회기간과 원거래일
요약의 '차액 반영' 카드를 누르면 건별 내역표(거래일·주문번호·카드사·유형·예상/실제수수료·차액)가 펼쳐진다.이 차액의 원거래일이 조회 기간과 달라 위 매출 표에는 안 보일 수 있음을 안내확정
정책현장결제(만나서결제) 회수
현장결제의 성격
배달 만나서결제는 대금을 라이더가 현장에서 받으므로 우리가 선정산해 줄 대상에서 빼야 하는 돈이다.이 회수는 6대 개념 중 미회수금과 연관되며 과지급·환급과는 구분한다가설
매출 표에서의 표기
만나서결제 행은 순지급액 '현장수령'(회색), 선정산대상 '차감'(빨강), 선정산지급액을 음수로 보여준다.확정
현장결제 차감 카드
만나서결제 회수분을 회수 완료와 미회수(다음 배치)로 나눠 집계한다.미회수분은 이번에 못 뺐으니 다음 정산 배치에서 회수 예정확정
등록 시 현장결제 지정
단건 등록의 배달 탭에서 '현장결제(만나서결제)' 체크로 이 성격을 직접 지정할 수 있다.확정
데이터수수료 툴팁 3종
적용수수료 툴팁
적용수수료 셀에 올리면 매출/주문금액 − 차감수수료 = 지급예정액/실정산금액 흐름을 보여준다.배달은 차감수수료를 '(주문금액 − 정산금액)'으로 부연확정
선정산수수료 툴팁 — 금액 분해
선정산수수료 셀 툴팁은 금액을 채권매입 수수료 + 시스템 이용료로 나눈다.확정
선정산수수료 툴팁 — 비율 분해
같은 툴팁 아래에 투자자 / 페이허그(마진+시스템이용료) / 상위총판 / 하위총판 / 영업사원 비율과 합계율을 보여준다.이 비율·합계 산정 근거는 미확정(C1)이라 화면은 서버값을 그대로 노출확인필요
정산적용수수료 툴팁
정산적용수수료 셀 툴팁은 '정산 당시 적용'과 '최초 예상'을 비교하고, 차액 정산은 정산 당시 적용 수수료 기준임을 명시한다.확정
설정거래·매입·정산·이체 상태 배지
거래상태 판정 우선순위
승인상태가 있으면 그 값, 없고 매입취소면 '취소', 둘 다 아니면 '성공'으로 정한다.승인·성공=초록, 취소=빨강확정
매입상태 — 승인취소 특례
매입상태칸에선 '승인취소'를 거래상태의 '취소'와 달리 '승인취소' 그대로 노출한다.매입완료=보라, 매입취소=빨강, 대기=회색확정
정산상태 + 정산방식 서브배지
정산상태(대기/정산처리완료/차액정산완료) 아래에 처리 방식을 작은 배지로 덧붙인다: 선정산(초록) / 바로이체(파랑) / 이미지급(회색).'바로이체'는 선정산 없이 곧장 이체한 건으로 6대 개념의 바로이체, '이미지급'은 이미 수동이체돼 기록만 남긴 건확정
이체상태 배지
실제 이체 진행은 이체대기(회색)·이체중(주황)·이체완료(파랑)·이체실패(빨강) 4단계로 표시한다.확정

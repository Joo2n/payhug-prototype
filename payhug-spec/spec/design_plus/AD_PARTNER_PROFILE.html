회원(파트너/제휴사 등) 프로필 관리 모달. 사업자등록증 이미지를 올리면 OCR로 필드를 자동 인식하고, 사업자 유형(개인사업자/법인사업자/개인) 선택에 따라 입력폼이 달라진다. 직인 이미지와 사업자등록증 원본 이미지는 서로 저장 시점·규칙이 다르다. isAdmin 권한자만 접근하는 내부 관리 화면.
데이터사업자등록증 OCR 자동 인식
인식 방식
사업자등록증 이미지를 올리면 OCR 서버가 필드를 읽어 폼에 자동 채움상호/법인명·사업자등록번호·대표자명·소재지·업태·종목·개업일 등이 채워짐사람이 올린 뒤 검토·수정 가능확정
다중 이미지 (최대 3장)
여러 장 선택 가능하나 앞 3장까지만 처리앞뒤/여러 페이지를 한 번에 인식하는 용도확정
원본 이미지 세로 병합
OCR에 넣은 여러 장을 세로로 한 장으로 합쳐 원본 보관용 이미지로 만듦확정
개인/법인 자동 판별
인식된 사업자등록번호로 법인 여부를 판별해 유형을 개인사업자/법인사업자로 자동 지정번호가 5자리 이상이면 번호 규칙으로 판별, 아니면 OCR가 준 법인여부 값 사용확정
개업일·등록일 형식
OCR가 준 날짜에서 숫자만 남겨 yyyyMMdd로 저장 (예: 20240101)확정
OCR 판독 정확도·항목 규칙
실제 어떤 필드까지 얼마나 정확히 뽑는지는 OCR 서버(별도 시스템) 소관 — 화면 코드로는 확인 불가확인필요
설정사업자 유형별 입력폼 분기
유형 3종
개인사업자 / 법인사업자 / 개인 중 선택유형은 필수, 선택 안 하면 저장 불가확정
사업자(개인·법인) 공통 필드
상호/법인명, 사업자등록번호, 대표자명, 개업일, 사업장 소재지, 업태, 종목확정
법인 전용 추가 필드
법인사업자일 때만 노출법인등록번호, 대표유형(단독대표/공동대표), 사업자등록일, 본점 소재지확정
개인(비사업자) 필드
이름, 주소만 입력 (사업자 필드·법인 필드 모두 숨김)확정
사업자등록증 업로드 노출 조건
유형이 개인사업자·법인사업자·미선택일 때만 업로드 영역 표시 (개인 유형이면 숨김)확정
회원 등록폼의 법인/사업자 토글과의 관계
회원 등록·수정폼에 있는 '법인 여부'·'사업자 여부(VAT 기준)' 토글과 이 프로필 유형이 서로 어떻게 연동/검증되는지 규칙 미확인 — 각각 별도 저장확인필요
정책직인 vs 사업자등록증 이미지 — 저장 규칙 차이
직인은 즉시 저장
직인 이미지는 고르는 즉시 서버에 바로 저장됨 (프로필 '저장' 버튼과 무관)삭제도 즉시 반영확정
직인 삭제 불가역
직인 삭제 시 '되돌릴 수 없습니다' 재확인 후 삭제확정
직인 용도·권장 형식
계약서 서명란에 쓰이는 직인/인감 이미지, PNG 권장확정
사업자등록증은 저장 시 반영
OCR로 올린 원본 이미지는 '대기' 상태로 보류됐다가 프로필 '저장'을 눌러야 함께 업로드됨확정
저장 순서·부분 실패 처리
저장 시 프로필 정보 먼저 저장 → 그다음 사업자등록증 이미지 업로드이미지 업로드가 실패해도 프로필 저장 자체는 성공 처리(이미지만 누락)확정
사업자등록증 삭제
저장된 원본 이미지는 개별 삭제 가능(재확인 후) — 직인과 달리 프로필 저장과 별개로 즉시 삭제확정
연결데이터 출처·첨부 연결
프로필 데이터 로드
모달 열 때 해당 회원의 프로필을 조회 — 유형 값이 있어야 기존 프로필로 인식, 없으면 신규 작성으로 시작확정
첨부 이미지 표시
직인·사업자등록증 썸네일은 첨부 다운로드로 이미지 원본(base64)을 받아 표시하고, 클릭 시 크게 보기·다운로드확정
OCR 서버 연결처
OCR는 일반 관리 서버가 아닌 별도 분석 서버(FastAPI)로 호출됨 — 장애 시 'OCR 서버 연결 실패' 별도 안내가설

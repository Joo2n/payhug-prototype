정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
쿠콘 회수는 '출금이체 1건 + 입금이체 1건'이 발생하지만 실제 돈 이동은 1회이므로, 어드민이 두 건을 하나의 '회수(2단계)' 묶음 행으로 합쳐 보여준다. 이 화면(펼침 상태)에 특수한 것은 (1) 출금·입금 2건을 자동으로 짝짓는 페어 매칭 규칙, (2) 묶음 행의 금액·상태를 두 건에서 종합해 만드는 계산, (3) 펼쳤을 때 노출되는 계정 흐름 라벨(락계좌→미지급계정→모계좌) 세 가지다. 여기 '회수'는 락계좌의 매출대금을 모계좌로 쓸어담는 스윕(C5)이며 과지급 회수와는 다른 개념이다. 페어 매칭·표시 종합은 모두 화면단 가공이고, 실제 출금·입금 성공 여부와 금액 산출은 서버(쿠콘 연동)에서 결정된다.
계산출금·입금 2건 짝짓기(페어 매칭) 규칙
묶는 대상
구분이 회수인 이체 건만 대상.그 중 쿠콘 '출금이체'와 '입금이체'를 각각 따로 모아 짝을 찾음지급 이체나 수동 지급은 묶지 않고 그대로 단건 표시확정
출금·입금 판별 기준
쿠콘 거래 종류값으로 구분.출금이체 / 입금이체를 나누는 값이 각 건에 따로 들어옴즉 '회수인지'가 아니라 '출금이냐 입금이냐'까지 데이터로 구분됨확정
짝짓는 조건
출금 1건에 대해 같은 가맹점이면서 금액이 정확히 같은 입금 건을 찾아 하나로 묶음.시각·거래번호는 매칭 기준 아님, 오직 가맹점+금액한 입금 건은 한 출금과만 짝됨(이미 짝된 입금은 재사용 안 함)확정
짝을 못 찾으면
매칭 실패한 출금 또는 입금은 단건 행으로 그대로 노출(2단계 묶음 아님).금액이 어긋나거나 한쪽만 발생한 경우 → 담당자가 육안으로 확인해야 함가설: 이 단건 잔류가 회수 오류 신호일 수 있으나 별도 경고 문구·플래그는 없음가설
묶음 행의 정렬 시각
묶음은 출금 요청 시각 기준으로 목록에 배치(입금 시각 아님)확정
계산묶음(대표) 행의 금액·상태 종합
대표 행 금액
출금액과 입금액을 더하지 않고, 출금액 하나만 대표 금액으로 표시.실제 돈 이동은 1회라는 전제(중복 합산 방지)확정
대표 행 상태 종합
두 건 상태를 하나로 합쳐 표시.출금·입금 둘 다 성공(성공/확인완료) → '성공'둘 중 하나라도 실패 → '실패'그 외(요청중·타임아웃 등 섞임) → 출금 건 상태를 그대로 노출확정
일자 요약·상단 집계 반영
날짜별 헤더와 상단 요약 카드의 '매출 회수' 성공/실패 집계도 이 종합값·대표금액 기준으로 계산됨.즉 묶음 1건 = 회수 1건으로 세고, 출금액만 금액에 반영확정
실패 사유 문구
대표 행에는 거래번호만, 실패 상세 사유는 대표 행에 노출 안 됨.확인 필요: 단건 실패는 쿠콘 결과 메시지를 잘라 보여주나, 묶음 대표 행엔 사유 표시 경로 없음 → 어느 단계가 실패했는지는 펼쳐서 확인해야 함확인필요
정책펼침 2단계 계정 흐름 라벨
① 출금 줄
고정 문구 '락계좌 → 미지급계정'.가맹점 락계좌에 잠겨 있던 매출대금을 빼내는 단계확정
② 입금 줄
고정 문구 '미지급계정 → 모계좌'.빼낸 대금을 페이허그 모계좌로 최종 귀속시키는 단계확정
라벨 순화 금지
락계좌·미지급계정·모계좌 원문 그대로 유지. '정산계좌' 등으로 순화 금지 — 내부 운영 계좌 개념을 정확히 드러내야 함확정
이 '회수'의 정의
여기 회수 = 락계좌 매출대금을 모계좌로 쓸어담는 스윕(00_종합 C5).정책의 '회수'(과지급금 되받기)와 다른 개념 — 혼동 금지확정
두 줄에 표시되는 값
각 줄마다 은행·계좌번호·수취인·상태·거래번호를 개별로 노출.출금 줄과 입금 줄의 은행/계좌/거래번호가 서로 다름(단계별 실제 이체 정보)확정
데이터데이터 출처·펼침 동작
원천 데이터
이체 내역 조회 결과(기간 기준)에 실려 오는 쿠콘 실제 이체 기록을 화면에서 묶어 가공.출금·입금 매칭과 종합은 전부 화면단 계산, 서버가 미리 묶어주지 않음확정
펼침 상태
묶음 행 클릭 시 아래 2줄 펼침, 다시 클릭 시 접힘.펼침 여부는 화면 임시 상태(저장 안 됨, 새로고침 시 초기화)여러 묶음 동시 펼침 가능확정
실제 이체 성패·금액
확인 필요(서버): 출금·입금 각 건의 성공/실패 판정, 스크래핑·이체 스케줄, 회수 대상 금액 산출은 쿠콘 연동 서버 몫 — 화면은 결과만 표시확인필요
엑셀 내려받기 시
엑셀은 묶지 않고 출금·입금을 각각 별도 행으로 내보냄.화면(묶음)과 엑셀(펼친 상태) 표현이 다름에 주의확정

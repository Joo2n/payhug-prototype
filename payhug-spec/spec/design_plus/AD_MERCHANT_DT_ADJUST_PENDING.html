차액 정산 이력 화면의 [대기] 필터 활성 상태. 표 구조·컬럼·구분 배지는 베이스(AD_MERCHANT_DT_ADJUST)와 동일하므로 여기서는 대기 필터에만 특수한 것 — 조회 조건·정산일 미표기·통계 재집계·목업 버그 — 만 다룬다. 대기 = 아직 다음 선정산에 반영되지 않은 차액 건으로, 환급/추가차감이 확정 예약된 상태다.
설정대기 필터 조회 조건
필터 탭 구성
전체 / 완료 / 대기 3개만 노출취소 상태는 배지 라벨은 있으나 필터 탭이 없어 취소건만 따로 걸러볼 수 없음확정
대기 탭 조회 방식
탭 누르면 대기 상태만 서버에 재요청조건을 조회 파라미터로 붙여 그때그때 다시 불러옴(클라이언트 필터링 아님)완료 탭·전체 탭과 각각 별도 호출확정
서버 필터 지원 범위
화면은 상태 외에 기간(시작일·종료일) 조건도 서버에 넘길 수 있게 준비돼 있으나, 현재 대기 필터 화면 UI에는 기간 입력이 노출되지 않음가설
정책대기 상태의 의미와 표시
대기 = 미반영 예약건
실제 수수료 확인으로 차액은 계산됐으나 아직 다음 선정산에 반영되지 않은 상태반영되면 완료로 넘어감대기 건의 환급/추가차감은 아직 실제 지급에 미포함확정
정산일 표기
대기 건은 반영일이 없어 정산일 칼럼이 '-'로 표시완료 건만 실제 반영 날짜가 채워짐확정
차액 방향(환급/차감)
구분 배지로 카드수수료·예상매출·배달수수료의 환급(+) / 차감(-), 미회수 이월, 취소 환수를 구분이 방향값은 대기 시점에 이미 정해져 배지로 노출여기서 말하는 '환급/차감'은 카드수수료 차액 정산이며, 정책상 과지급 회수와는 다른 개념확정
계산통계 카드 재집계와 목업 한계
상단 통계 산출 기준
전체건수·환급·추가차감·순차액 카드는 서버 합계가 아니라 현재 화면에 불러온 목록으로 매번 다시 더함대기 탭이면 대기 건만, 완료 탭이면 완료 건만 집계 대상순차액 = 환급합계 − 차감합계, 양수면 파랑·음수면 빨강확정
통계 집계 누락
통계는 순수 환급/차감 구분만 세고 합산예상매출·배달수수료·미회수 이월·취소 환수 구분은 건수·금액 통계에서 빠짐그래서 표에 보이는 행 수와 통계 '전체 건수'가 어긋날 수 있음확정
목업 필터 미작동
설계서 메모상 목업은 서버 필터가 안 걸려 대기 탭에서도 완료 행까지 14건 전부 노출실제 동작이 아닌 캡처 한계이며, 실서버 연결 시 대기만 나와야 정상확인필요

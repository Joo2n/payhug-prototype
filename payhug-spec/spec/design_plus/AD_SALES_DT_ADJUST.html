'차액 반영' 요약 카드를 눌러 차액정산 내역 표를 인라인으로 펼친 변형 상태. 이 화면만의 특수 로직은 (1) 펼침 가능/불가능의 이중 조건, (2) 차액정산 내역이 '전일 이전 거래분'만 담고 원거래일이 조회기간 밖일 수 있다는 점, (3) 표 합계가 행 합이 아니라 서버 차액총액을 그대로 쓴다는 점이다. 모든 금액(예상수수료·실제수수료·차액)은 서버가 계산해 내려주며 화면은 표시만 한다.
설정펼침 동작 · 카드 노출 조건
카드 자체 노출
차액 반영 카드는 이번 정산의 차액 총액이 0이 아닐 때만 나타남차액이 0이면 카드 자체가 없음확정
펼침 가능 여부
카드가 보여도 세부 내역이 1건 이상 있을 때만 클릭해 펼칠 수 있음차액 총액은 있는데 내역 목록이 비어 있으면 카드는 보이되 눌러도 안 펼쳐짐(라벨·화살표 없음)확정
토글 라벨
접힘 상태 "내역 N건 ▼" → 펼치면 "내역 닫기 ▲", 다시 누르면 접힘N = 내려온 내역 건수확정
펼침 표 표시 조건
표는 펼침 ON + 내역 1건 이상 동시 충족 시에만 그려짐 (카드와 별개 블록)확정
데이터차액정산 내역 표 — 데이터 출처 · 구성
내역 데이터 출처
표의 각 행은 매출 조회와 같은 응답에 함께 실려 오는 별도 '적용된 차액' 목록화면에서 새로 계산·조합하지 않음, 서버가 준 그대로확정
표 항목(열)
거래일 · 주문번호 · 카드사 · 유형 · 예상수수료 · 실제수수료 · 차액(지급 기준)확정
유형 라벨 8종
카드 환급 · 카드 추가차감 · 예상매출 환급 · 예상매출 차감 · 취소 환수 · 배달 환급 · 배달 추가차감 · 미회수 이월서버 코드→한글 라벨 매핑, 못 맞추면 원본 코드 그대로 노출확정
차액 부호 색
차액(지급 기준) 값이 + 이면 초록 / − 이면 빨강 (0 이상은 초록 계열)확정
예상↔실제 산정 근거
'예상수수료'·'실제수수료'·차액의 산출 규칙은 서버 전용, 화면은 표시만 함예상 차액 정의(C4)·확정 수수료율(C1) 미확정확인필요
정책합계 · '전일 이전 거래분' 구분
안내문(정책 성격)
"예상 수수료로 선정산된 뒤 실제 수수료가 확정되어 이 정산에 반영된 차액입니다. 원거래일이 조회 기간과 다를 수 있어 위 표에는 나타나지 않습니다."즉 이 내역은 위쪽 매출 내역 행과 별개 집합확정
차액정산 내역 = 전일 이전 거래분
차액정산 내역은 전일 이전 거래분의 차액만 모음당일 거래 카드수수료 차액은 익일 이후 배치에서 별도 반영(실제 이체액 구성의 다른 줄), 이 표에 안 들어옴가설
표 합계 = 카드 값과 동일
맨 아래 합계(= 차액 반영) 행은 각 행 차액의 산술 합이 아니라 서버 차액 총액을 그대로 씀 (카드 숫자와 동일)개별 행 합과 총액이 어긋날 여지, 표는 총액을 정답으로 둠확정
'미회수 이월' 개념 주의
유형 중 미회수 이월은 이번 정산에서 못 채운 차액이 다음으로 넘어간 건정책의 미회수금과 연결되는지, 과지급/회수와의 경계는 서버 정의 확인 필요확인필요

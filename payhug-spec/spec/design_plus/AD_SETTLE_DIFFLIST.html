이 화면은 '정산 현황' 화면의 '차액 정산' 탭이다(IA상 A-04이나 실제로는 overview 탭 중 하나로 중첩 구현). 서버가 통째로 집계해 내려주는 '차액 정산 대시보드'를 그대로 보여주는 성격으로, 화면 특수 로직은 (1) 5개 차액 구분/8개 처리유형 라벨 매핑, (2) 서버 집계 필터(매출유형·카드사)와 클라이언트 필터(에이전시·가맹점명)의 이중 구조, (3) 환급/차감 부호 규칙, (4) 매출유형 선택 시 원장 연결 건만 보이는 정책에 집중돼 있다. 최종 차액 산술·확정 수수료율·예상매출 대사 기준은 모두 서버 전용이라 화면에서는 확인 불가.
연결데이터 출처·집계 방식
화면 전체 데이터 1건
이 탭의 KPI 카드·일별 추이 차트·상세 테이블은 모두 서버가 한 번에 계산해 내려주는 '차액 정산 대시보드' 응답 하나에서 나온다. 화면은 그 안의 요약(summary)/일별추이(dailyTrend)/건별목록(adjustments)/카드사후보(availableCardCorps)를 그대로 배치만 한다.확정
KPI 숫자도 서버 집계
상단 '전체 차액'·구분별 카드의 금액/건수/대기건수는 서버 요약값을 그대로 표시. 화면에서 재계산하지 않는다.따라서 매출유형·카드사 필터를 바꾸면 KPI까지 서버 기준으로 다시 내려받아 갱신된다.확정
조회 기간 기준
상단 기간 필터(시작~종료)로 조회. 최초 진입 시 자동 조회는 '선정산 결과' 탭만 돌고, 이 탭은 탭을 처음 열 때 한 번 자동 조회된다.확정
최종 차액 산출식
예상수수료·실제수수료·차액 금액 자체를 어떤 기준으로 뽑는지는 서버 전용이라 화면에서 확인 불가.확정 수수료율(C1)·예상매출 대사 기준(C4)에 종속되는 값.확인필요
설정5개 차액 구분과 8개 처리 유형
차액 구분(카드/서브탭)
5종 고정: 카드 수수료 차액 · 배달 수수료 차액 · 취소 환수 · 예상매출 대사 · 미회수 이월. 서브탭·KPI 카드가 이 5종으로 나뉜다.확정
처리 유형(뱃지) 8종
카드수수료 환급/차감, 배달수수료 환급/차감, 취소 환수, 예상매출 환급/차감, 미회수 이월.'환급'은 가맹점에 더 주는 방향, '차감'은 덜 주는 방향으로 색·부호가 갈린다.확정
6대 개념 대조
'카드/배달/예상매출 환급'은 정책의 환급 개념선상. '취소 환수'·'미회수 이월'은 취소·미회수 성격이나, 과지급/미회수금 개념과의 정확한 매핑은 미확정 — 임의 매핑 금지.어드민 '매출 회수'(락→모계좌 스윕)와는 무관.확인필요
예상매출 대사의 위치
예상매출 대사(ESTIMATED_DIFF)가 이 화면에 독립 구분/서브탭으로 존재. 예상값 기반 사후 정산 차액이 여기로 흘러든다는 뜻 — 예상차액 정의(C4)와 직결.가설
계산필터 이중 구조 (서버 vs 화면)
서버에서 거르는 필터
매출 유형(전체/카드/배민/요기요/쿠팡이츠)과 카드사는 서버 집계 조건. 바뀌면 대시보드 전체를 재조회 → KPI·차트·목록이 모두 그 기준으로 바뀐다.확정
화면에서만 거르는 필터
에이전시와 가맹점명·사업자번호 검색은 이미 받아온 목록을 화면에서만 걸러낸다(부분일치). 이 둘은 KPI 숫자를 바꾸지 않는다 — 표시 건수와 상단 합계가 어긋날 수 있음.확정
카드사 2뎁스 조건
카드사 칩 필터는 매출 유형에서 '카드'를 선택했을 때만 노출. 카드를 해제하면 하위 카드사 선택은 '전체'로 자동 초기화(빈 결과 방지).확정
카드사 후보 목록 출처
카드사 칩 목록은 서버가 필터 적용 전 전체 기준으로 내려준 목록. 특정 카드사를 골라도 후보 목록은 줄지 않고 유지된다.확정
복수 선택 규칙
매출유형·카드사 모두 복수 선택. '전체' 누르면 단독 선택, 개별 선택 중 '전체' 누르면 개별로 전환, 마지막 하나 해제하면 '전체'로 복귀.확정
계산부호·정렬·상태 처리 규칙
차액 부호 규칙
처리 유형이 환급 계열(카드수수료 환급·예상매출 환급·배달수수료 환급) → '+' 파란색, 그 외(차감·취소환수·미회수 이월) → '-' 빨간색으로 표시.확정
엑셀 다운로드 부호
엑셀에는 환급 계열은 양수, 나머지는 음수로 부호 반전해 기록. 상태는 반영완료/대기중 한글로. 화면 필터·정렬·서브탭이 적용된 목록만 내려받는다.확정
정렬 기준
거래일 기준 정렬(기본 내림차순), 같은 날짜는 내부 등록순으로 tie-break. 토글로 오름/내림 전환.확정
상태 2종·반영일시
반영완료(초록)·대기중(노랑) 2종. 반영완료 건은 반영일자(appliedAt 앞 10자리)를 함께 표기. KPI에도 '대기 N건'이 별도 노출.확정
일별 추이 차트 구성
환급·차감·취소환수 3개 막대. 일자가 2개 이상일 때만 차트 노출(하루치면 생략).확정
정책원장 연결·노출 정책 (툴팁 명시)
매출유형 선택 시 제약
매출유형 안내 툴팁 원문: 특정 유형(카드·배민·요기요·쿠팡이츠)을 고르면 원장과 연결된 건만 표시되고, 예상매출 대사처럼 원장 미연결 건은 '전체'에서만 확인 가능.확정
정책적 함의
예상매출 대사 건은 개별 매출 원장에 아직 매칭 안 된 상태 → 유형 필터를 걸면 사라진다. 운영자가 '카드'만 걸고 보면 예상 대사분이 누락돼 보일 수 있으므로 전체 조회가 대사의 기본이라는 정책.가설

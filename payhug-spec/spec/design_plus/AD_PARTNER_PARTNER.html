유형 필터 탭(전체+7개 유형)을 누르면 클라이언트에서 거르지 않고 서버를 다시 조회한다. 반면 바로 아래 검색창은 서버를 건드리지 않고 이미 받아온 목록만 이름/아이디로 거르는 방식이라, 같은 화면에서 두 필터의 동작 원리가 서로 다르다. 필터 탭 목록은 등록 시 선택 가능한 유형과 무관하게 항상 전체 7개 유형을 노출한다.
연결유형 필터 = 서버 재조회
필터 변경 시 동작
유형 탭을 바꾸면 화면에서 거르는 게 아니라 회원 목록을 서버에 다시 요청한다.선택한 유형을 조건으로 붙여 새로 받아온 결과로 표를 통째로 교체확정
'전체' 선택 시
유형 조건 없이 조회 → 운영자 권한 범위(자기+하위) 안의 모든 유형이 한 번에 내려옴확정
재조회에 딸려오는 것
목록 재요청과 동시에 '등록 가능 유형'도 다시 조회된다 (두 요청을 묶어 함께 실행). 필터를 바꿀 때마다 등록 버튼 노출 판정도 갱신되는 셈확정
탭 전환·복귀 시
이 화면 탭이 활성화되거나 다른 창에 갔다 돌아올 때도 같은 재조회가 자동 실행 → 최신 선택 유형 기준으로 새로고침확정
서버 필터 산식
선택 유형으로 어느 범위까지 내려주는지(권한 스코프 적용 규칙)는 서버 소관 → 확인필요확인필요
설정검색은 필터와 다르게 동작
검색 방식
필터 탭 아래 검색창은 서버를 다시 부르지 않는다. 이미 받아온 목록 안에서만 걸러 보여줌즉 현재 선택된 유형 결과 위에 추가로 얹히는 화면단 필터확정
검색 대상
이름과 아이디(휴대폰번호) 두 가지만 대소문자 무시로 매칭. 추천코드·상위회원명 등은 검색에 안 걸림확정
빈 결과 문구 분기
서버가 0건이면 "등록된 회원이 없습니다", 목록은 있는데 검색으로 0건이면 "검색 결과가 없습니다"로 문구가 갈린다확정
설정필터 탭 구성
탭 목록
전체 / 투자자 / 페이허그 / 파트너 / 제휴사 / 영업 / 영업조직 / 관리자 (전체+7종 고정)확정
등록 유형과의 차이
필터 탭은 권한과 무관하게 항상 7종 전부 노출. 반면 '등록' 모달의 유형 선택지는 운영자에게 허용된 유형만 나옴 → 필터로는 보이지만 못 만드는 유형이 존재할 수 있음확정

정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
'바로이체 확인'은 미정산 누락 추적 배너에서 선택한 건을 '바로이체'로 처리할 때 뜨는 확인 다이얼로그 + 처리 전 미리보기 모달이다. 핵심 특수 규칙은 (1)선정산 로직을 태우지 않고 카드/배달 수수료만 제외한 순지급액 전액을 가맹점 계좌로 실제 이체, (2)한 가맹점의 여러 거래일을 합산해 1회만 이체하되 원장은 거래일별로 쪼개 기록, (3)'바로이체'(실제 이체)와 '이미지급(기록만)'(이체 없이 완료 기록)의 2갈래 분기, (4)이체 일부 실패 시 부분 실패로 되돌려 재시도 유도. 지급 권한 어드민(내부)만 진입/처리 가능.
정책바로이체 처리 규칙 (이 확인창의 핵심)
이 화면이 처리하는 대상
정산 배치가 이미 끝난 날짜에 뒤늦게 도착해 선정산이 누락된 미지급 건.6대 개념상 '미지급금'을 뒤늦게 해소하는 창구확정
이체 금액 계산 방식
선정산 로직(채권매입·시스템·이체수수료·차액)을 태우지 않는다.이틀 이상 지난 건은 카드/배달 수수료만 제외한 순지급액 전액을 그대로 이체즉 선정산 수수료 0원확정
'바로이체' vs '이미지급(기록만)'
같은 선택 건을 두 갈래로 처리:바로이체: 가맹점 계좌로 순지급액 전액을 실제 이체(확인창 warning 색)이미지급(기록만): 이미 수동이체된 건으로 간주, 이체 없이 원장에만 지급 완료 기록(info 색)확정
확인창 문구
'선택한 N건 / M원을 가맹점 계좌로 순지급액 전액을 실제 이체합니다'건수·합계금액을 문구에 박아 오처리 방지확정
입금예정일 경과 표시의 성격
'예정일 경과' 뱃지는 참고용 추정일 뿐, 실제 입금 확인은 어드민이 별도 판단.이 값만 보고 자동 이체하지 않는다확정
차등 기준 '이틀'의 근거·수수료 면제 여부
'이틀 이상'이라는 경계값과 '선정산 수수료를 완전히 면제'하는 것이 확정 정책인지 프론트 문구 외 근거 미확인.지급캘린더(C2)와도 연결확인필요
계산바로이체 미리보기 모달 (실행 전 예상 결과)
합산 이체 vs 원장 기록의 분리
한 가맹점의 여러 거래일치를 합산해 1회만 실제 이체하되, 원장(기록)은 거래일별로 쪼개 남긴다.실제 이체 횟수 ≠ 처리 건수확정
모달 상단 3개 지표
총 이체예정 금액 / 실제 이체 횟수 / 처리 건수를 분리 표시.이체 횟수는 가맹점·합산 단위, 처리 건수는 원장 기록 단위확정
제외(skipped) 건
가맹점별로 '제외 N건'이 뜰 수 있음 → 미리보기에서 이체 대상에서 빠지는 건이 존재.제외 사유·기준은 서버 판단, 프론트에 미표기확인필요
미리보기는 무부작용
'실제 이체·원장 기록 없음 · 처리 시 예상 결과' 명시.미리보기 호출은 상태를 바꾸지 않음확정
데이터처리 결과·부분 실패
이체 일부 실패 처리
이체 실패 건수가 1건이라도 있으면 전체를 실패로 되돌려 'N건 중 K건 이체 실패 - 재시도 필요' 안내.성공 건만 슬쩍 넘어가지 않도록 방어확정
성공 시 후처리
처리 후 선택 초기화 + 미정산 누락 목록과 선정산 요약을 함께 재조회.방금 처리분이 목록에서 사라지고 요약 수치에 반영확정
결과 토스트
'바로이체 완료: N건 / M원' 형태로 처리 건수·합계 노출확정
연결진입 권한·데이터 출처
진입/처리 권한
미정산 누락 배너 자체가 지급 권한이 있는 페이허그 내부 어드민(내부 관리자·페이허그 계정)에게만 노출.파트너·영업·투자자 계정엔 배너와 바로이체 버튼 모두 안 보임확정
목록 데이터 출처
미정산 누락 목록은 조회 기간과 무관하게 미해소 누락 전량을 별도로 불러온다(기간 필터와 분리된 상시 추적).가설
미리보기·실행 연결
미리보기와 실제 처리는 선택한 건 식별자 묶음을 서버로 보내는 별도 두 경로.미리보기 경로는 조회 전용, 실행 경로가 이체+원장 기록 수행확정
최종 이체·원장 산술
합산 금액·제외 판정·거래일별 원장 분개는 모두 서버에서 계산.프론트는 결과만 렌더확인필요

계약서 카드 하단 '이전 계약서 (N)' 접이식 펼침 variant. 재서명으로 대체된(SUPERSEDED) 구계약만 골라 서명 오래된 순으로 쌓고, 각 항목에 'N차 · 대체됨' 뱃지·서명일·재서명 사유·미리보기/다운로드를 노출한다. 현재 유효 계약에는 대체 횟수를 '재서명 N회'로 요약 표시. 이 화면 고유 로직은 (1)구계약 필터·정렬·차수 계산, (2)현재계약 사유와 구계약 사유의 표기 차이, (3)서명현황 조회 시 구버전 제외 세 가지.
연결이전 계약서 펼침 목록의 구성
펼침 노출 조건
대체된 구계약이 1건 이상일 때만 '이전 계약서 (N)' 토글이 나타남재서명 이력이 없으면 이 접이식 영역 자체가 없음확정
구계약 선별 기준
전체 계약 중 상태가 '대체됨(SUPERSEDED)'인 것만 골라 이 목록에 담음대체되지 않은 계약은 위쪽 '현재 계약' 영역에 별도 표시확정
목록 정렬
오래된 계약이 위, 최신이 아래 (내부 생성 순서 오름차순)그래서 맨 위가 1차, 다음이 2차로 쌓임확정
각 항목 표시 정보
차수 뱃지 · 서명일 · 재서명 사유 · 미리보기 · 다운로드확정
미리보기·다운로드 출처
각 구계약에 연결된 첨부 원본 파일을 임시 열람주소로 받아 열거나 내려받음첨부가 없는 구계약은 두 버튼 모두 숨김확정
계산차수·대체 횟수 계산과 뱃지
구계약 차수(N차)
구계약 목록 안에서의 순번으로 붙임 (위에서부터 1차·2차…)실제 계약 번호가 아니라 펼침 목록 내 표시 순서 기준확정
대체됨 뱃지
모든 구계약 항목에 'N차 · 대체됨' 회색 뱃지 부착확정
현재 계약의 재서명 횟수
'재서명 N회' 뱃지의 N = 대체된 구계약의 개수서비스/선정산 이용계약 유형에만 붙고, 이관 계약서에는 안 붙음확정
미리보기 제목
구계약 미리보기 창 제목에 계약서명 뒤에 '(N차)'를 덧붙여 몇 번째 버전인지 구분확정
정책재서명 사유·서명현황 처리 규칙
구계약의 사유 표기
각 구계약에 저장된 사유를 '재서명 사유: …'로 회색 표시그 계약이 왜 대체됐는지를 이력으로 남김확정
현재 계약의 사유 표기 차이
현재 계약이 재서명 대기(가맹점 서명 전) 상태일 때만 '사유: …'를 노랑으로 표시같은 사유 값이라도 구계약은 '재서명 사유', 현재계약은 '사유'로 라벨이 다름확정
서명현황 조회 시 구버전 제외
직인/서명 현황을 조회할 때 대체된 구계약은 건너뛰고 최신 유효 계약만 대상으로 삼음구버전의 서명 상태가 현재 화면 서명현황에 섞이지 않음확정
구계약의 수정 가능 여부
이 펼침 목록은 열람 전용(미리보기·다운로드만)재서명 요청/취소 버튼은 현재 계약 항목에만 있고 구계약에는 없음확정
구계약이 쌓이는 시점
가맹점이 재서명을 완료해 계약이 갱신되는 순간 직전 버전이 대체됨으로 넘어가 이 목록에 편입되는 것으로 보임가설

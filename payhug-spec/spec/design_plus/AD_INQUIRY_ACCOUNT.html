1:1 문의 목록을 '계정' 카테고리로 필터링한 상태. 카테고리는 서버에 필터 조건으로 전달되며(상태 필터와 조합 가능), 카테고리 칩은 같은 값을 다시 누르면 전체로 풀리는 단일 선택 토글이다. 계정 문의는 가맹점이 접수 시 스스로 분류한 값이라 어드민은 상세에서 카테고리를 바꿀 수 없고 상태만 변경한다. 계정성 문의(로그인/비밀번호 등)의 실제 처리는 문의 상세에서 가맹점 상세로 이동해 처리하는 것으로 추정된다.
설정계정 카테고리 필터 동작
이 화면의 성격
전체 문의 목록에서 카테고리=계정만 남긴 상태.계정 문의는 오렌지색 배지로 표시된다.확정
카테고리 선택 방식
칩은 단일 선택 토글.다른 카테고리(일반/결제/정산/기술/계정)를 누르면 그 값으로 교체이미 선택된 '계정'을 다시 누르면 전체로 해제확정
서버 전달 방식
카테고리는 서버 필터 조건으로 전달된다(전체일 땐 미전달).상태 필터(대기/처리중/답변완료/종료)와 조합 가능 — 예: '계정 + 대기'.확정
검색과의 차이
제목·가맹점명·작성자 검색은 화면 내 필터라 계정으로 이미 좁혀진 목록 안에서만 다시 걸러진다(서버 재조회 아님).확정
상단 건수 표시
'총 N건'과 상태 탭 옆 숫자는 현재 카테고리로 조회된 결과 기준이며, 검색어 필터는 반영하지 않는다.확정
정책계정 문의의 분류·처리 규칙
카테고리를 정하는 주체
카테고리(계정 포함)는 가맹점이 접수 시 스스로 선택한 값.어드민은 상세 패널에서 상태만 바꿀 수 있고 카테고리는 변경 불가.가설
계정 문의의 처리 동선
계정성 문의(로그인 실패·비밀번호 등)는 답변만으로 끝나지 않고, 상세 패널의 가맹점명 링크로 가맹점 상세로 이동해 처리(예: 비밀번호 재설정)하는 흐름으로 추정.가설
오분류 대응
가맹점이 실제로는 정산/결제 건인데 '계정'으로 잘못 접수한 경우, 어드민이 카테고리를 교정하는 수단은 이 화면에 없음 → 정책 확인 필요.확인필요

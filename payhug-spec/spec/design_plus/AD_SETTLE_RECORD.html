'미정산 누락 추적' 배너에서 선택 건을 처리하는 두 갈래(바로이체 / 이미지급 기록만) 중 '기록만' 갈래에 특수한 로직만 추린 것. 이 상태는 실제 계좌이체 없이, 이미 수동으로 이체가 끝난 건을 원장에만 '지급완료'로 남겨 미정산 누락 목록에서 제거하는 처리다. 확인 모달 문구·확인 버튼·처리 결과 토스트가 바로이체와 다르고, 미리보기 화면은 바로이체 전용이라 기록만 처리에는 대응 미리보기가 없다.
정책이미지급(기록만)의 처리 성격과 갈래 분기
이 처리가 하는 일
선택한 미정산 누락 건을 이미 가맹점 계좌로 수동이체가 끝난 건으로 간주해, 실제 이체를 하지 않고 원장에만 '지급완료'로 기록한다.바로이체(실제 계좌 송금)와는 다른 갈래다.6대 개념의 '바로이체(실이체)'가 아니라, 이미 지급된 사실을 장부에 맞추는 기록 보정에 해당(가설).가설
같은 목록, 두 버튼의 분기
선택 건에 대해 바로이체 / 이미지급(기록만) 두 버튼이 나란히 있고, 누른 버튼에 따라 처리 구분값만 다르게 서버로 보낸다. 대상 건·선택 합계 계산은 두 갈래가 동일하다.확정
선택 합계 계산
선택된 건들의 순지급액을 단순 합산해 '선택 N건 · 합계 금액'으로 보여준다. 기록만 처리도 이 합계를 그대로 확인 문구에 넣는다.확정
처리 후 목록 갱신
처리가 끝나면 미정산 누락 목록과 선정산 요약을 다시 불러온다. 지급완료로 기록된 건은 더 이상 '누락'이 아니므로 목록에서 사라진다.확정
설정확인 모달·처리 결과 (기록만 전용 문구)
확인 모달 문구
"선택한 N건 / 금액원을 이미 수동이체된 건으로 간주하여 이체 없이 원장에만 지급 완료로 기록합니다."바로이체는 "가맹점 계좌로 순지급액 전액을 실제 이체합니다"로, 문구 자체가 다르다.확정
모달 제목·버튼·스타일
제목 이미지급(기록만) 처리, 확인 버튼 기록만 처리, 버튼 강조 스타일은 정보(info) 톤.바로이체는 제목 '바로이체 처리', 버튼 '바로이체', 경고(warning) 톤으로 시각적으로 구분.확정
완료 토스트
성공 시 "이미지급 기록 완료: N건 / 금액원". 라벨이 바로이체와 갈리며 처리 건수·합계 금액을 서버 응답값으로 표시.확정
이체 실패 분기의 공유
완료 처리 응답에 '이체 실패 건수'가 있으면 실패 안내로 바뀌는 분기가 두 갈래에 공통으로 걸려 있다. 기록만 처리는 실이체가 없어 이 값이 0이어야 정상 — 실제로 어떤 서버 상황에서 이 값이 채워지는지는 확인 필요.확인필요
데이터미리보기 부재·데이터 출처·노출 권한
기록만 전용 미리보기 없음
미리보기 버튼은 갈래 구분 없이 하나이고, 열리는 화면은 '바로이체 미리보기'(이체예정 금액·이체 횟수)만 보여준다. 이미지급(기록만)에 대응하는 결과 미리보기 화면은 별도로 없다.확정
미리보기의 성격 고지
미리보기 화면 상단에 "실제 이체·원장 기록 없음 · 처리 시 예상 결과"라고 명시 — 미리보기 단계에서는 어떤 갈래도 원장을 건드리지 않음을 알린다.확정
처리·미리보기 데이터 연결
처리는 미정산 누락 정리(resolve) 창구에 '처리 구분 = 기록만'과 선택 건 식별값을 실어 보내고, 미리보기는 별도 미리보기 창구를 쓴다. 어느 쪽도 화면에서 금액을 계산하지 않고 서버 결과를 받아 표시.확정
화면 노출 권한
이 배너·기록만 처리 자체가 실제 지급 권한이 있는 페이허그 내부 어드민에게만 노출된다. 외부(파트너 등)에는 미정산 누락 추적 영역과 두 처리 버튼이 아예 보이지 않음.확정
'입금예정일 경과' 표식의 한계
건별로 붙는 '예정일 경과' 표식은 참고용 추정이며 실제 입금 확인은 별도 판단이라고 배너에 고지. 기록만 처리를 정당화하는 근거로 그대로 신뢰하면 안 됨.확정

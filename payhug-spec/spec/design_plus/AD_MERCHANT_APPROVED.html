가맹점 관리 목록의 '승인' 필터 변형. 승인 상태는 내부적으로 두 개의 상태값(승인/활성)이 하나의 초록 '승인' 배지로 합쳐져 표시되며, 승인=정산 활성이 아니라는 점이 핵심. 승인 탭은 계약진행 막대를 '완료' 한 단어로 대체하고, 행 클릭 시 심사가 아닌 '관리' 화면으로 연결된다. 승인 탭의 건수 집계와 필터 조건에 '활성' 상태가 누락돼 보이는 지점(확인 필요)이 있다.
데이터승인 상태의 이중 구조와 배지 병합
'승인' 배지 = 두 내부 상태의 합
계약상태 컬럼의 초록색 승인 배지는 내부적으로 서로 다른 두 상태(계약 승인 / 정산 활성)를 하나로 합쳐 보여준다.목록에서는 둘을 구분하지 않으므로, '승인'으로 보이는 가맹점이 실제로 어느 단계인지는 배지만으로 알 수 없다.확정
승인 ≠ 정산 활성
승인된 가맹점도 정산 컬럼은 별도로 활성/비활성이 갈린다.즉 계약은 승인됐지만 정산은 아직 비활성인 상태가 정상적으로 존재한다.정산 활성 여부는 승인과 다른 축의 상태값이다.확정
정렬 우선순위 (승인 내부 서열)
목록 정렬은 승인+정산활성 → 승인+정산비활성 → 그 외 순.승인 그룹 안에서도 정산 활성 건이 위로 올라온다. (매출 조회 화면과 동일 기준)확정
설정승인 탭 필터·집계·표시 규칙
승인 탭 건수에 '활성' 누락 의심
탭별 건수와 필터 매칭이 계약상태='승인' 값만 세고 거른다.배지로는 '승인'으로 보이는 '활성' 상태 가맹점이 승인 탭 카운트·목록에서 빠질 수 있음.전체 탭엔 보이는데 승인 탭엔 안 잡히는 불일치 가능 → 운영 확인 필요.확인필요
계약 진행 컬럼 = '완료'로 대체
승인 가맹점은 6단계 계약 진행 막대를 표시하지 않고 초록색 '완료' 한 단어로만 표기.심사대기 단계에서 보이던 진행률 막대·단계 툴팁(사업자/신분증/락계좌/정산계좌/플랫폼/계약동의)이 승인 탭에선 사라진다.확정
행 액션 라벨 = '관리'
행에 마우스를 올리면 나오는 이동 안내가 상태별로 다름.승인: 관리 / 심사대기: 심사 / 미등록: 상세.승인 가맹점은 심사가 아니라 관리 목적의 상세로 진입한다는 의미.확정
예상정산 경고 배지
승인 가맹점이라도 실제 매출 데이터가 안 들어오면 가맹점명 옆에 빨간 예상정산 배지가 붙는다.해당 매출일 매출이 예상 데이터로 정산 처리 예정임을 표시(사업자번호 기준 매칭).예상 데이터 처리 로직·산식 자체는 서버 소관.가설
연결승인 상태에서만 열리는 후속 동작 (상세 연결)
수동 이체 버튼 조건
상세 화면의 수동 이체 버튼은 승인 + 정산 활성일 때만 노출된다.승인만 됐고 정산 비활성이면 수동 이체 진입 불가.(정책상 '회수'가 아닌 지급성 이체 — 개념 혼동 주의)확정
승인 후 파트너 변경 → 재서명 경고
이미 승인된 가맹점의 소개 파트너를 바꾸면 '기존 계약서는 자동 갱신되지 않으니 재서명 요청 필요' 경고가 뜬다.승인 이전 상태에는 없는, 승인 이후에만 발생하는 계약 정합성 경고.확정
직인 서명 현황 조회는 승인건만
계약서 서명(직인) 현황 조회는 계약상태='승인'인 가맹점의 최신 유효 계약에 대해서만 이뤄진다.재서명으로 대체된 구버전 계약은 제외하고 최신 계약 기준.확정
승인 취소/재심사 경로 부재
목록·상세 어디에도 승인 → 미승인 되돌리기 버튼은 없음.승인 후 되돌리려면 반려 처리 또는 계약 초기화(하드리셋 등) 경로를 타야 하는 것으로 보임 → 정책 확인 필요.확인필요

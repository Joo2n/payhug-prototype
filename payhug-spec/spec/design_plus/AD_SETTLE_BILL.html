정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
선정산에서 발생한 수수료 3종을 세무 신고용 계산서(세금/면세) 발행 자료로 만들어 주는 화면이다. 정해진 기간의 정산 원장을 '가맹점 × 발행 주체 × 수수료 항목' 단위로 서버가 합산해 내려주면, 누가 누구에게 얼마짜리 어떤 계산서를 끊어야 하는지를 가맹점별 카드(요약표+발행내역표)와 엑셀로 보여준다. 화면은 대부분 받아서 보여주기만 하고, 요율(%)과 발행 합계 정도만 자체 계산한다.
정책발행 대상·권한·기간 조건
누가 볼 수 있나
이 '계산서 발행' 탭 자체가 페이허그 내부(관리자·페이허그) 계정에게만 보인다.에이전시/파트너 계정으로 로그인하면 탭이 아예 나타나지 않음탭이 보이더라도 내용도 같은 권한으로 한 번 더 가려짐(내부 계정만 조회)세무 신고 자료라 외부에 노출하지 않으려는 의도로 해석됨확정
발행 대상 가맹점
서버가 해당 기간에 계산서 발행 대상 정산 내역이 있는 가맹점만 골라 내려준다.각 가맹점에는 사업자번호가 함께 붙어 옴 (신고 시 상대방 식별용)서버가 하나도 안 주거나, 화면 필터(에이전시·가맹점 검색)로 전부 걸러지면 "해당 기간에 계산서 발행 대상 정산 내역이 없습니다" 안내가 뜸확정
기간 기준
매출일 기준 시작일~종료일로 조회한다 (지급일·정산일이 아니라 매출이 일어난 날 기준). 화면 안내문에도 '매출일 기준'이라고 명시돼 있음.화면 진입 시 기본값은 '이번 달 1일 ~ 오늘'초기화하면 다시 이번 달 1일~오늘로 돌아감확정
조회 방식
기간을 고르고 조회 버튼을 눌러야 자료가 뜬다. 탭을 처음 열면 자동으로 한 번 조회함.아직 한 번도 조회하지 않은 상태에서만 "기간을 선택하고 조회 버튼을 눌러주세요" 안내가 보임(자동 조회 때문에 실제로는 거의 안 보임)확정
데이터데이터 출처·집계 단위
무엇을 합산하나
해당 기간의 정산 원장을 계산서 발행 단위로 서버가 합산한 결과다. 개별 거래·배치가 아니라 이미 만들어진 정산 결과를 모아서 신고용으로 재집계한 것.확정
합산 단위
가맹점 × 발행 주체 × 수수료 항목 3중 단위로 묶는다.같은 가맹점이라도 발행 주체(예: 저축은행/페이허그)가 다르면 줄이 나뉨같은 주체라도 항목(채권매입·시스템이용료·이체수수료)이 다르면 별도 줄확정
계산은 어디서 하나
화면은 합산된 값을 받아서 보여주기만 한다. 공급가·세액·합계 같은 실제 금액 산출은 전부 서버에서 끝난 상태로 내려옴.화면이 자체로 만드는 값은 '요율(%)' 표시, 이체수수료 '단가×횟수' 역산, 가맹점 '발행 합계' 정도뿐확정
한 가맹점 카드에 담기는 것
가맹점별로 접었다 펼치는 카드 형태. 카드 머리에 가맹점명·사업자번호·에이전시 코드 뱃지와 '선정산대상 합계·발행 합계'가 보이고, 펼치면 두 개의 표가 나옴.매출유형별 요약 표 (카드/배달앱별 수수료 원자재)발행 주체별 내역 표 (실제 계산서 끊을 줄 단위)확정
정책세금계산서 / 면세계산서 구분과 발행 주체
핵심 분기 규칙
화면 상단 안내문에 명시된 원칙: 채권매입은 면세계산서, 시스템 이용료·이체 수수료는 세금계산서 대상이다.이 세 항목이 각각 다른 종류의 계산서로 발행되고, 각 줄 '비고'에 '면세계산서 발행'/'세금계산서 발행' 뱃지로 표시됨확정
채권매입 수수료 → 면세계산서
안내 원칙상 면세계산서 대상이다. 금융 채권 매입이라 부가세 면세로 처리되는 것으로 해석됨.면세라 세액(부가세)이 0으로 내려오는 것으로 보이나, 실제 세액 값은 서버가 계산해 내려줌발행 주체(채권을 사들이는 금융사, 예: 저축은행)는 서버가 지정 → 실체는 확인 필요확정
시스템 이용료 → 세금계산서
안내 원칙상 과세 대상(공급가 + 세액)이다.발행 주체는 서버 지정(예시상 페이허그)예시 데이터에선 세액이 공급가의 10%(일반 부가세율)로 보이나, 실제 세액은 서버 값확정
이체 수수료 → 세금계산서
안내 원칙상 과세 대상(공급가 + 세액). 발행 주체는 서버 지정(예시상 페이허그).다른 항목과 달리 매출액 비례가 아니라 지급(이체) 건당 정액 성격 (아래 계산 참고)확정
발행 주체 표기(법인/사업자)
발행 주체 이름 옆에 '법인' 뱃지·'사업자' 뱃지가 붙는다. 계산서 상대방의 성격을 표시하는 용도.두 뱃지는 서버가 주는 별개 표시값이라 이론상 둘 다/둘 다 아님도 가능 (예시에선 한쪽만 붙음)어느 회사가 어떤 성격인지는 서버 값에 따름가설
계산요율·금액 계산 로직 (화면 표시 규칙)
요율(%) 표시 방식
채권매입·시스템이용료 줄의 요율은 공급가액 ÷ 기준액(선정산대상액) × 100으로 그 자리에서 계산해 %로 보여준다 (소수점 3자리까지).그 줄의 기준액이 없거나 0이면 '-'로 표시확정
이체 수수료 요율 표시
이체수수료는 비율이 아니라 이체(배치) 1회당 정액이다. 그래서 요율 칸에 '단가 × 횟수'로 표시함 (예: 273원×1회).공급가를 배치 횟수로 나눠떨어지면 단가×횟수, 안 나눠떨어지면 '정액'으로만 표시이 항목엔 기준액(선정산대상액)이 없음(비율 개념이 아니므로 '-')확정
'선정산대상액'이 두 군데 나옴
'선정산대상액'이라는 이름이 두 곳에 뜬다: ① 가맹점 카드 머리의 '선정산대상 합계' ② 발행내역 각 줄의 요율 기준액.둘 다 서버가 주는 별개 값이라 반드시 같다는 보장이 화면엔 없음예시 데이터에선 카드 머리 합계가 카드+배달앱 매출 합과 같게 떨어지나, 정의·일치 여부는 서버 확인 필요확인필요
실제 수수료율 값
예시 데이터에선 채권매입 0.6%·시스템이용료 0.3% 꼴로 딱 떨어지지만, 실제 확정 수수료율은 미확정 상태(1%/0.604%/0.6+0.11+0.1%/0.25% 등 병존).화면 %는 서버가 준 공급가에서 역산한 표시값일 뿐, 정책상 요율을 규정하지 않음확인필요
발행 합계
가맹점 카드 머리와 발행내역 표 맨 아래에, 그 가맹점의 모든 발행 줄 합계값을 더해 보여준다. 화면에서 단순 합산(머리·표 아래 값 동일).확정
계산매출유형별 요약과 이체수수료 처리
매출유형 구분
요약 표는 신용카드 / 배달앱 두 줄로 나뉜다. 각 줄에 그 유형의 선정산대상액·채권매입수수료·시스템이용료(부가세 포함)가 붙음.'어떤 매출에서 수수료가 얼마 나왔나'를 보여주는 원자재 성격확정
이체수수료는 왜 유형별로 안 나뉘나
이체수수료는 매출 유형이 아니라 지급(배치) 단위로 발생하기 때문이다. 그래서 카드/배달앱 줄에 쪼개지 않고 가맹점 단위로 한 번만 잡아, 요약 표 오른쪽(공급가·부가세·소계 3칸)을 첫 줄에 병합해 표기한다.그 기간 이체가 몇 번 있었는지(배치 횟수)가 함께 집계됨확정
정렬 순서
발행 주체별 내역은 항목 순서(채권매입 → 시스템이용료 → 이체수수료)로, 같은 항목이면 공급가 큰 순으로 정렬해 보여준다. (가맹점 카드끼리의 순서는 서버가 준 순서 그대로)확정
여기 금액은 전부 수수료(양수)
이 화면 금액은 모두 발행할 수수료(양수)다. 차감·환급·과지급·미회수 같은 부호가 갈리는 정산 조정은 여기에 섞이지 않는다.그런 차액 조정은 별도 '차액 정산' 탭 소관이 탭은 순수하게 '세무 계산서를 끊기 위한' 자료확정
설정필터·엑셀 내보내기
가맹점 필터
가맹점명 또는 사업자번호 부분 일치로 걸러볼 수 있다 (한 칸에서 둘 다 검색).확정
에이전시 필터
에이전시 코드로 좁혀 볼 수 있고, '미지정'(에이전시 없는 가맹점)만 따로 보는 옵션도 있다.이 필터는 이미 받아온 자료를 화면 안에서 거르는 방식(재조회 아님)확정
엑셀 2개 시트
다운로드하면 '정산요약' + '계산서 발행 내역' 두 시트가 한 파일로 나온다.정산요약: 가맹점·사업자번호·매출구분별 수수료 원자재 (이체수수료 공급가·부가세는 화면과 달리 각 줄에 반복해서 들어감)계산서 발행 내역: 발행 주체·항목·기준액·요율·공급가·세액·합계·발행구분(세금/면세)파일명: 계산서발행자료_[시작일]_[종료일].xlsx확정
화면 필터와 엑셀의 관계
엑셀은 지금 화면에 걸린 필터(에이전시·가맹점 검색)가 적용된 결과를 그대로 내보낸다. 필터를 바꾸면 받는 엑셀 내용도 달라짐.확정
정책확인 필요·주의
세액 산식은 서버 소관
공급가·세액(부가세)·합계의 실제 계산은 전부 서버에서 확정돼 내려온다. 화면은 못 바꾸고 검증도 못 함. 부가세 10% 적용·반올림 규칙 등은 서버 로직으로 확인 필요.확인필요
발행 주체 실체 확인

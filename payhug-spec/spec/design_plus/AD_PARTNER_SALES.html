회원 관리 목록에서 상단 유형 필터 탭으로 '영업'(또는 다른 유형)을 고른 상태. 이 화면의 핵심 특수성은 '유형 필터는 서버 재조회, 이름/아이디 검색은 클라이언트 필터'로 동작 방식이 다르다는 점, 그리고 필터를 걸어도 조회 범위가 로그인 관리자의 자기+하위 조직으로 한정된다는 점이다. '영업'과 '영업조직'은 별개 탭으로 분리돼 있다.
연결유형 필터 = 서버 재조회 (검색과 다른 방식)
필터 탭 클릭 시 동작
유형 탭(영업 등)을 누르면 선택 유형을 조건으로 붙여 서버에서 목록을 다시 불러온다.즉 화면에 이미 있던 목록을 거르는 게 아니라 새로 조회하는 방식확정
이름/아이디 검색은 반대
검색창 입력은 서버 재조회 없이 이미 받아온 목록 안에서만 즉시 걸러 보여준다.이름·전화번호(아이디) 두 항목만 대상, 대소문자 무시확정
필터+검색 조합
영업만 서버에서 받은 뒤, 그 결과 안에서 다시 이름/아이디로 좁히는 2단 구조확정
'전체' 탭
유형 조건 없이 전부 조회. 탭 목록은 전체 + 7개 유형(투자자·페이허그·파트너·제휴사·영업·영업조직·관리자)확정
데이터조회 범위 · 영업 유형 구분
필터해도 보이는 대상
영업으로 필터해도 로그인한 관리자 본인과 그 하위 조직에 속한 회원만 내려온다. 상위·타 조직 영업은 애초에 목록에 없음가설
근거
수정 모달에서 '기존 상위 회원이 조회 범위(자기+하위) 밖이면 옵션에 없다'고 코드 주석이 명시 → 목록 조회 자체가 자기+하위 스코프임을 시사가설
'영업' vs '영업조직'
두 유형은 별개 탭으로 분리. 영업조직 밑에 영업이 소속되는 상하 관계로 보이나, 필터는 각각 단일 유형만 조회(합산 안 함)가설
상위 회원 표시
목록 각 행의 '상위 회원' 칸은 그 회원의 소속 상위 이름. 없으면 '-'(최상위)확정
설정필터 상태 유지 · 재조회 시점
탭 전환·복귀 시
브라우저 탭을 다시 활성화하거나 포커스가 돌아오면 현재 걸려 있는 유형 필터를 유지한 채 자동 재조회. 최신 목록으로 갱신됨확정
'새로고침' 버튼
현재 필터 그대로 서버에서 다시 조회. 필터를 풀지 않음확정
필터 탭과 등록 유형은 별개
필터 탭은 항상 7종 고정. 반면 '+등록' 모달에서 고를 수 있는 유형은 서버가 내려준 '생성 가능 유형'만 → 로그인 권한에 따라 다름확정
권한별 버튼
프로필·삭제 버튼은 관리자/페이허그 권한에서만 노출. 필터 결과 행이라도 권한 없으면 수정·비활성화만확정

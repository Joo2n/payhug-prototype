No이름설명
1안내 제목 "플랫폼 락계좌 검증""플랫폼 결제계좌를 수집하고 락계좌 연결을 검증합니다. 배달 3사와 여신협회를 순차 조회하며 1~2분 소요될 수 있습니다. 계속하시겠습니까?"
2버튼 [취소] / [검증](amber)완료 시 이상 유무 결과 다이얼로그로 전환
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
이 다이얼로그의 심화 초점은 검증 실행 안내(설계서에 기재됨)가 아니라, 검증 결과로 나열된 매장(카드사)별 행에서 개별 '락계좌 검증 제외' 토글을 켜고 끄는 로직이다. 제외는 이상 알림·집계에서만 빼는 설정으로 선정산 제외와 완전히 별개이며, 토글로는 이미 뜬 '이상'을 지울 수 없고 오직 재검증(스크래핑) 성공으로만 해소된다. 최종 판정·스크래핑 스케줄은 서버 전용이라 확인필요.
정책매장(카드사)별 락계좌 검증 제외 토글
토글 대상 단위
플랫폼 전체가 아니라 다이얼로그 표의 한 행(매장/카드사 단위)마다 켜고 끈다.한 플랫폼 안에 여러 매장·카드사가 있으면 행별로 개별 설정확정
제외로 켤 때 확인창 문구
제목 "락계좌 검증 제외"본문 "해당 매장(카드사)을 락계좌 검증에서 제외합니다. 이상 알림이 발생하지 않습니다."[확인] 버튼은 경고(amber) 스타일확정
다시 포함으로 끌 때 문구
제목 "락계좌 검증 포함"본문 "다시 검증 대상에 포함합니다. 다음 검증 시 락계좌 불일치면 이상으로 표시됩니다."확정
성공/실패 안내
성공 시 토스트 "락계좌 검증에서 제외되었습니다" / "…포함되었습니다".실패 시 서버 메시지 또는 "설정 변경 실패" 토스트확정
선정산 제외와의 관계
하단 고정 안내에 "선정산 제외와 별개 설정" 명시.이 토글은 락계좌 검증(모니터링) 대상에서만 빼는 것6대 개념의 '선정산 제외금액'과 무관확정
권한 없는 사용자
조회 전용(readOnly)이면 맨 오른쪽 '락계좌 검증 제외' 열 자체가 숨겨짐 — 상태 확인만 가능확정
데이터매장별 검증 상태 표시 규칙
상태값 5종
정상 / 이상 / 장애 / 스킵 / 검증 제외'이상'=락계좌 불일치, '장애'=스크래핑 실패로 판정 불가, '스킵'=이번 회차 미조회확정
제외 행 회색 처리 조건
제외 토글이 켜져 있거나 상태가 '검증 제외'면 행 배경을 회색으로.검증 대상에서 빠졌음을 시각적으로 구분확정
'스킵' 상태 추가 안내
상태가 스킵인데 제외되지 않은 행에는 사유 칸 아래에 amber로 "다시 검증하기를 실행해 주세요." 표시제외된 스킵 행에는 안내 안 뜸확정
사유(오류 메시지) 출처
각 행의 불일치·장애 사유 문구는 서버가 내려준 값을 그대로 노출. 없으면 "-".어드민 화면에서 편집 불가확정
최종 검증 시각 표기
머리말의 '최종 검증' 시각은 서버 포맷(yyMMdd HH:mm)을 yyyy.MM.dd HH:mm으로 변환해 표시.값 없으면 시각 라벨 자체를 숨김확정
플랫폼 이름 표기
내부 구분을 한글 라벨로: 여신협회 / 배달의민족 / 요기요 / 쿠팡이츠'여신협회'가 곧 카드 매출(카드사) 축확정
정책이상 해소 경계와 서버 전용 판정
이상은 토글로 못 지운다
하단 고정 안내 "이상 해소는 재검증(스크래핑) 성공으로만 가능".제외 토글은 '알림·집계에서 빼는' 것일 뿐, 이미 뜬 이상 판정 자체를 정상으로 바꾸지 않음확정
제외 시 사라지는 것
제외하면 락계좌 불일치 알림과 이상 집계에서만 빠진다.데이터 수집(스크래핑) 자체를 끄는 것과는 다른 별개 스위치가설
결과 다이얼로그 진입 경로
상위의 '플랫폼 락계좌 연결 검증' 실행 → 순차 조회 완료 후 이상 유무 결과를 안내 → 이 상세 다이얼로그에서 매장별 내역·제외 설정.이 상세창은 결과 확인 후 진입하는 심화 화면가설
정상/이상/장애 판정 기준
각 매장의 결제계좌가 우리 락계좌와 연결됐는지 대조하는 실제 판정 로직·스크래핑 스케줄은 서버 전용확인필요
'매출 회수'와 무관
이 화면의 '검증'은 락계좌 연결 상태 점검일 뿐, 어드민의 락계좌→모계좌 스윕(매출 회수)이나 정책상 과지급 회수와는 전혀 다른 개념확정

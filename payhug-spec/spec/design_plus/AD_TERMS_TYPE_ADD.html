약관 종류 추가 모달은 약관 관리 화면 상단 '종류 추가' 버튼에서 뜨는 별도 팝업이다. 신규 등록일 때만 컨텍스트 선택과 약관 코드 입력칸이 나타나며, 컨텍스트는 목록의 첫 항목이 미리 선택되고 '필수 동의 약관'은 기본 체크된 상태로 뜬다. 약관 코드는 타이핑하는 즉시 대문자로 강제 변환되고, 정렬 순서칸은 숫자만 받는다. 저장 전 코드·종류명을 반드시 채우게 막는다. 이 모달에서 만든 '종류'는 껍데기(분류)일 뿐, 실제 약관 문구(제목·본문·버전)는 이후 '개정' 단계에서 채운다.
설정모달이 열릴 때의 초기 상태
컨텍스트 미리 선택
'종류 추가'를 누르면 컨텍스트 선택칸에 등록된 컨텍스트 목록의 맨 첫 번째 항목이 자동으로 골라져 있다.사용자가 아무것도 안 고르고 넘어가도 첫 컨텍스트로 저장됨컨텍스트가 하나도 없으면 선택칸이 비어(0) 저장이 막힐 수 있음(확인 필요)확정
'필수 동의 약관' 기본 켜짐
필수/선택 체크박스가 기본으로 체크(필수)된 상태로 열린다. 선택 약관을 만들려면 사용자가 직접 체크를 해제해야 함.확정
정렬 순서 기본값
정렬 순서는 0으로 시작. 목록 노출 순서를 정하는 값.확정
정책이 모달에만 있는 입력 규칙
약관 코드 대문자 자동 변환
약관 코드칸은 소문자로 쳐도 입력 즉시 대문자로 바뀐다 (예: service → SERVICE).안내 예시값: SERVICE, PRIVACY코드는 시스템 식별용이라 통일 규칙으로 강제확정
약관 코드 입력칸은 '추가'에서만 노출
컨텍스트 선택칸과 약관 코드칸은 신규 추가일 때만 보인다. 같은 모달의 '종류 수정' 모드에서는 이 두 칸이 사라지고 종류명·순서·필수여부만 고칠 수 있음.즉 코드와 소속 컨텍스트는 한번 만들면 못 바꾸는 값확정
정렬 순서 숫자만 허용
정렬 순서칸은 숫자 외 문자를 걸러내며, 비우면 0으로 처리.확정
연결저장 검증과 저장 후 처리
필수 입력 순서
저장 시 종류명이 비면 '약관 종류명을 입력해주세요', 채워졌어도 약관 코드가 비면 '약관 코드를 입력해주세요' 경고를 띄우고 막는다.컨텍스트는 미리 선택돼 있어 별도 경고 없음확정
저장하면 종류만 생성 (문구는 없음)
이 모달은 약관의 '분류 껍데기'만 만든다. 제목·본문·버전·시행일 같은 실제 약관 문구는 저장되지 않으며, 만들어진 종류는 목록에서 '등록된 버전이 없습니다' 상태로 표시됨.실제 문구는 이후 '개정' 버튼으로 첫 버전을 붙여야 채워짐확정
저장 성공 후 동작
성공 시 '등록되었습니다' 안내 후 모달이 닫히고 목록이 새로고침됨. 저장 중에는 버튼이 '저장 중...'으로 바뀌며 중복 클릭 방지.확정

약관 컨텍스트(회원가입·계약 등 약관이 노출되는 맥락 묶음)의 이름·정렬순서를 고치는 수정 전용 모달. 신규 추가 모달과 껍데기는 같지만, 수정 모드에서는 코드 필드가 회색으로 잠겨 변경 불가하고 저장 시 서버로도 코드는 보내지 않는다. 이름만 필수값이며, 정렬순서는 숫자만 입력된다. 이 모달의 특수점은 코드 불변 규칙, 수정 대상 필드 축소, 코드별 색상 배지 매핑 세 가지다.
설정코드 불변 규칙 (수정 모드 전용)
코드 필드 잠금
수정 모드에서 코드 입력칸은 흐리게 비활성 처리되어 손댈 수 없다.신규 추가 때만 입력 가능코드는 약관 종류·버전이 컨텍스트를 참조하는 식별자라, 사후 변경 시 연결이 깨지는 것을 막는 잠금으로 해석확정
저장 시 전송 범위
수정 저장 시 서버로는 이름과 정렬순서만 전달되고 코드는 아예 실려 나가지 않는다.화면 잠금뿐 아니라 처리 단계에서도 코드는 제외확정
신규 추가 시 코드 자동 소문자화
코드 입력 시 자동으로 소문자로 변환된다(예: SIGNUP → signup).수정 모드에선 잠겨 있어 무의미, 신규 추가에만 적용확정
정책수정 가능 항목과 검증
필수값
이름이 비어 있으면 "컨텍스트 이름을 입력해주세요" 안내 후 저장 차단.수정 모드에선 이름만 필수 검증 대상 (코드 필수 검증은 신규 추가에서만 동작)확정
정렬순서 입력 제한
숫자 외 문자는 자동으로 걸러진다.빈 값이면 0으로 처리이 순서값이 컨텍스트 목록·필터 버튼 노출 순서를 결정확정
노출 여부(활성/비활성) 미노출
컨텍스트에는 활성 여부 값이 존재하나 이 수정 모달에는 조작 UI가 없다.이 화면에서는 비활성 전환 불가, 별도 처리 경로 필요 여부는 확인 필요확인필요
데이터데이터 출처와 배지 색상
값 출처
모달 열 때 목록에서 클릭한 컨텍스트의 코드·이름·정렬순서를 그대로 채워 넣는다.별도 상세 재조회 없이 목록 데이터를 재사용확정
약관 종류 수는 참고용 파생값
목록 표의 '약관 종류 수'는 해당 컨텍스트 코드에 걸린 약관 종류 개수를 화면에서 세어 보여주는 값.수정 모달에서 편집하는 항목 아님(읽기 전용 참고)확정
코드별 배지 색상 하드코딩
signup=하늘색, contract=보라색만 색이 지정돼 있고 그 외 코드는 회색 기본 배지로 표시.새 컨텍스트를 추가해도 이 두 코드가 아니면 전용 색이 안 붙음(색 추가는 코드 수정 필요)확정

입출금 계좌 등록은 선정산 전용계좌 등록과 '같은 모달 컴포넌트'를 계좌용도 값(SETTLEMENT/PRE_PAYMENT)으로 분기해 재사용한다. 이 화면(SETTLEMENT)만의 특수점은 (1) 은행 제한이 없다(하나은행 강제 미적용), (2) '계좌 출금 비밀번호' 입력·빠른조회 관련 요소가 아예 노출되지 않는다, (3) 통장사본 OCR·필수 첨부 규칙은 공통. 서비스정책서 화면 워크스루가 입력 필드에 '계좌 출금 비밀번호'를 적어둔 것은 코드와 불일치(확인 필요).
설정이 모달만의 분기 규칙 (입출금 계좌 = SETTLEMENT)
은행 제한
은행 제한 없음. 선정산 전용계좌(락계좌)에는 '하나은행만 등록 가능' 검증이 걸리지만, 입출금 계좌에는 그 검증이 적용되지 않아 어떤 은행이든 등록된다.이 강제 규칙은 계좌용도가 선정산 전용일 때만 작동확정
계좌 출금 비밀번호 필드
이 화면에는 노출되지 않음. 출금 비밀번호 입력칸·안내문('빠른조회로 입금내역 수집')은 선정산 전용계좌일 때만 뜬다. 입출금 계좌는 빠른조회 대상이 아니므로 비밀번호를 아예 받지 않고, 저장 시에도 비밀번호 값을 서버로 보내지 않는다.확정
모달 제목
"입출금 계좌 등록" — 계좌용도(입출금/선정산)와 진입 맥락(신규=등록/기존=수정)에 따라 제목이 자동 조합됨. 신규 진입은 미등록 서류 영역의 '입출금 계좌 등록' 버튼으로만 시작.확정
쿠콘·락계좌 검증 요소
입출금 계좌에는 쿠콘 등록/미등록 배지, 락계좌 검증 버튼이 표시되지 않음. 해당 요소는 모두 선정산 전용계좌 전용.확정
연결통장사본·OCR·저장 처리 (공통 로직 중 이 화면 적용분)
통장사본
신규 등록 시 통장사본 이미지 필수. 파일 미첨부면 등록 버튼 비활성 + '신규 등록 시 통장사본 파일은 필수입니다' 경고. 이미지 파일만 선택 가능.확정
OCR 자동 인식
통장사본을 고르면 OCR이 은행명·계좌번호·예금주를 자동으로 채움(수정 가능). OCR은 별도 분석 서버(계좌 분석 엔드포인트) 호출이라, 정산 저장용 백엔드와 출처가 다름.실패 시 '수동으로 입력해주세요' 안내만 뜨고 등록은 계속 가능확정
저장 경로
신규는 계좌 생성 요청(계좌용도 SETTLEMENT 포함해 전송), 기존 계좌 수정은 별도 수정 요청으로 갈라짐. 통장사본 파일이 있을 때만 함께 첨부.확정
데이터등록 완료 판정 & 설계서 불일치
'등록됨' 판정 기준
통장사본이 첨부된 계좌만 '입출금 계좌 등록 완료'로 인정. 인증 요청만 하고 통장사본을 안 붙인 계좌는 '미완료(통장사본 미첨부)'로 분류되어 삭제 대상 카드로 빠진다.확정
설계서 vs 코드 불일치
화면 워크스루(설계서)는 입력 필드에 '계좌 출금 비밀번호'를 포함시켜 놓았으나, 코드상 입출금 계좌 모달에는 비밀번호 필드가 없음. 설계서 3번 마커 문구 수정 필요.실제 입력: 은행명·계좌번호·예금주 3개뿐확인필요
라벨 명칭 혼재
같은 계좌를 두고 '입출금 계좌 등록'(버튼/모달), '입출금 전용계좌'(카드 배지), '입금 계좌'(서류 진행 단계)로 표기가 갈림. 노출 라벨 통일 필요.확인필요

종료(CLOSED) 문의는 답변 입력창이 사라지고 회색 안내 문구만 남는 잠금 상태다. 목록에서는 상태 필터를 서버에 넘겨 종료건만 불러오며, 종료 문의는 가맹점이 마지막으로 글을 남겼어도 NEW 뱃지가 뜨지 않는다. 다만 상세 패널 상단의 상태 드롭다운은 종료 상태에서도 자유롭게 다른 상태로 되돌릴 수 있어, 사실상 재오픈 경로가 열려 있다.
정책종료 상태의 답변 잠금
답변 입력창 노출 조건
종료가 아닐 때만 답변 입력 영역(텍스트창 + 전송 버튼)이 나타난다.종료 문의를 열면 입력창 자체가 렌더되지 않는다.확정
종료 시 안내 문구
입력창 대신 회색 바탕에 “종료된 문의입니다.” 한 줄만 표시.재개 버튼·경고 등 별도 액션 없음.확정
잠금 범위
화면 UI 차원의 잠금이다. 답변 등록 처리 함수 자체에는 종료 여부를 막는 방어 로직이 없어, 서버가 종료 문의의 답변 등록을 거부하는지는 화면만으로 알 수 없음.확인필요
데이터목록에서의 종료 문의 취급
종료 필터 동작
‘종료’ 탭 선택 시 상태값을 서버 조회 조건으로 전달해 종료건만 받아온다(전체 탭은 조건 없이 전량).카테고리 필터도 함께 서버로 전달.확정
NEW 뱃지 억제
마지막 발신자가 가맹점이면 제목 옆 빨간 NEW가 붙지만, 종료 문의는 예외로 NEW를 달지 않는다.종료건은 미응답으로 보이지 않게 처리.확정
종료 뱃지 스타일
목록·탭 카운트에서 종료는 회색(무채색) 뱃지로, 대기(주황)·처리중·답변완료(초록)와 시각적으로 구분.확정
최근 활동 시각
마지막 메시지 시각이 있으면 그 값, 없으면 접수 시각을 상대시간(‘n일 전’ 등)으로 표기.종료 전용 별도 시각 필드는 없음.확정
연결재오픈 경로
상태 드롭다운 제약 없음
상세 패널 상단 상태 선택 드롭다운은 종료 상태에서도 대기·처리중·답변완료로 되돌릴 수 있다(비활성화·확인창 없음).즉 종료는 최종 잠금이 아니라 되돌릴 수 있는 상태.확정
재오픈 시 화면 반영
상태를 종료 외 값으로 바꾸면 답변 입력창이 다시 나타나고 잠금이 해제된다(상태값 즉시 갱신 + 목록 재조회).가설
종료 전환의 부수효과
상태를 종료로 바꿀 때 가맹점 알림 발송·자동 안내 메시지 등 별도 처리가 있는지는 화면에 없어 확인 필요.확인필요

1:1 문의 목록에서 카테고리 칩 '기술'을 선택한 상태. 화면 자체 로직은 상위 목록과 동일하고, '기술' 필터는 표시 라벨·색과 조회 조건만 달라지는 변형이다. 특수 포인트는 (1) 카테고리 필터가 서버 재조회로 걸리고 검색은 클라이언트에서만 걸린다는 점, (2) 같은 칩 재클릭 시 전체로 해제되는 단일 토글, (3) 상단 상태 카운트가 '기술 필터가 적용된 목록' 기준으로만 집계된다는 점이다. 기술 문의에 특화된 별도 처리·경고·계산 규칙은 코드상 없다.
설정'기술' 카테고리 필터 동작
카테고리 5종 고정
일반 / 결제 / 정산 / 기술 / 계정 5개로 고정. '기술'은 보라색 계열 라벨로만 구분되고, 라벨·색 외에 별도 처리 분기는 없음확정
칩 재클릭 = 해제
카테고리 칩은 단일 선택.'기술'을 누르면 기술만 조회이미 켜진 '기술'을 다시 누르면 전체(ALL)로 해제됨 (동시에 여러 카테고리 선택 불가)확정
필터는 서버 재조회
카테고리·상태 필터를 바꾸면 목록을 서버에서 다시 조회(status·category를 조건으로 전달). 화면 안에서 거르는 방식이 아님확정
검색어는 클라이언트
상단 검색창(제목·가맹점명·작성자)은 이미 불러온 목록 안에서만 걸러줌. 즉 '기술+검색어'는 기술로 서버 조회한 결과 위에 검색어를 덧입히는 구조확정
탭 활성/포커스 시 재조회
이 탭이 활성화되거나 창 포커스가 돌아올 때 목록을 자동 재조회 → 다른 관리자가 처리한 내용이 반영됨확정
데이터목록 데이터·카운트·배지
상태 카운트 집계 범위
상단 상태 탭(대기/처리중/답변완료/종료)의 숫자는 현재 불러온 목록 기준으로 셈. '기술' 필터가 켜져 있으면 카운트도 기술 문의만 집계 → 전체 건수와 다르게 보일 수 있음확정
NEW 배지 규칙
제목 옆 빨간 NEW 배지는 마지막 발신자가 가맹점이고 + 상태가 종료가 아닐 때만 표시. 관리자 답변이 마지막이거나 종료되면 사라짐확정
최근 활동 시각
'최근 활동' 열은 마지막 메시지 시각을 쓰고, 없으면 접수 시각으로 대체. 방금 전/N분 전/N시간 전/N일 전, 그 이상은 날짜로 표기확정
총 건수 표기
헤더의 '총 N건'은 검색어 적용 전, 필터 적용된 목록 전체 건수확정
가맹점 연결
상세 패널의 가맹점명 클릭 시 해당 가맹점 상세로 이동(탭 모드에서만 새 탭). 문의는 특정 가맹점에 귀속됨확정
정책상세 패널 답변·상태 처리 (기술 문의도 동일)
답변 작성자 필수
답변 전송 시 관리자 로그인 정보가 없으면 등록 중단. 발신 주체가 기록되어 스레드에 관리자/가맹점 말풍선으로 구분 표시확정
종료 문의는 답변 불가
상태가 종료면 답변 입력창이 사라지고 '종료된 문의입니다' 안내로 대체. 답변하려면 상태를 되돌려야 함확정
상태 수동 변경
상세 패널 상단 드롭다운으로 대기/처리중/답변완료/종료를 관리자가 직접 전환. 답변 등록만으로 상태가 자동 전환되는 규칙은 이 화면 코드엔 없음확인필요
답변 후 처리
답변 등록되면 입력창 비우고 상세·목록을 다시 불러와 최신 스레드로 갱신확정
기술 특화 규칙 부재
'기술' 카테고리라고 해서 담당자 자동배정·SLA·외부계정/스크래핑 연동 같은 특수 처리는 코드상 없음. 정책적으로 기술 문의를 별도 취급할지는 미정확인필요

정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
좌측 정산 목록에서 배치 한 건을 클릭하면 우측이 채워지는 변형 상태. 이 상태 특유의 로직은 (1) 배치 클릭 시 배분집계·차감내역·이월액을 한 호출로, 원장을 뒤이어 또 한 호출로 가져오는 2단 조회, (2) 실 지급액·시스템이용료 건별 합산·납부 상대방 뱃지를 화면에서 직접 계산하는 것, (3) 미회수 차액 이월(다음 정산 차감) 안내 문구다. 최종 배분 산술값과 예상/확정 판정은 서버 전용.
연결배치 클릭 시 우측 데이터 출처
1단계 — 배분·차감·이월
배치를 클릭하면 해당 배치의 배분집계를 한 번에 조회한다.이 한 응답에 – 이해관계자 배분 목록현장결제(오프라인) 차감 내역·합계우리가게클릭비(광고비) 차감 내역·합계미회수 차액 이월액이 모두 함께 담겨 온다. 각 차감 표는 화면에서 별도로 다시 부르지 않는다.확정
2단계 — 수수료 원장
배분집계 조회가 끝나면 곧바로 같은 배치의 수수료 원장을 이어서 조회한다. 배분 요약과 원장은 출처가 서로 다른 두 조회이며, 원장이 로딩 중이면 요약이 먼저 그려진 뒤 원장 자리에 '로딩 중...'이 뜬다.확정
다른 배치 클릭 시
새 배치를 누르면 이전 배분·원장이 즉시 비워지고 다시 두 단계로 채워진다. 선택 행은 좌측에서 파란 세로바로 강조.확정
배치 목록 자체의 출처
좌측 목록은 조회 기간으로 받은 배치 전체이며, 상단 에이전시·가맹점 검색은 이미 받아온 목록을 화면에서 거르는 것(재조회 아님). 검색어는 가맹점명·가맹점ID·사업자번호에 걸린다.확정
계산이 화면에서 직접 계산하는 값
실 지급액
배치 헤더의 실 지급 = 총 금액 − 오프라인 차감 − 광고비 차감. 화면에서 즉석 계산하며, 차감이 하나라도 있을 때만 병기된다. 차감이 0이면 총 금액만 노출.확정
시스템 이용료 건별 합산
원장 아코디언 맨 위 '시스템 이용료(건별 합산)' 블록은 서버가 주는 게 아니라, 거래별 원장 중 시스템 이용료 항목만 참여자 단위로 화면에서 합산해 만든 요약이다. 'N건 합산' 개수는 시스템 이용료가 걸린 거래 수.확정
납부 → 상대방 뱃지
원장에서 배분액이 음수이면서 시스템 이용료·이체 수수료인 행에 '납부 → 받는 참여자' 뱃지를 붙인다. 상대방 이름은 같은 수수료 유형에서 양수 배분을 받는 참여자를 화면에서 모아 표시. – 가맹점이 대신 부담하는 수수료의 흐름을 보여주는 표기.확정
합계·소계
배분 요약 하단 합계, 원장 각 표 소계는 화면에서 배분액을 더한 값.확정
매출·원가·수익·VAT·순수익·배분액
원장 표의 각 산술값 자체는 서버 산출값을 그대로 표시. 확정 수수료율·최종 배분 계산식은 서버 전용이라 여기서 검증 불가.확인필요
정책미회수 차액 이월 (이 상태에서만 뜨는 경고)
노출 조건
이월액이 0보다 클 때만 배치 헤더 아래 노란 박스로 뜬다.확정
문구가 말하는 규칙
차액 정산(환수)이 당일 지급액을 초과하면 → 그날 지급액은 0원으로 처리하고, 회수하지 못한 나머지 금액을 다음 정산에서 차감한다.확정
개념 구분
여기 이월액은 미회수금(다음 정산으로 넘긴 차감분)이며, 어드민의 매출 회수(락→모 스윕)와 무관하다. 원인이 된 차액 환수는 과지급 회수 계열이라 이월액과 별개로 다뤄야 함.가설
데이터차감·배분 항목의 성격
현장결제 차감
현장카드·만나서결제 등 라이더/현장 수령 건. 주문번호·매장명·매출원·결제수단·차감액을 나열하며 매출에서 빼는 것이지 회수(스윕)가 아니다(C5 혼동 주의).확정
우리가게클릭비 차감
매출원·정산일·광고기간·광고비(−)·부가세로 표시되는 광고비 차감. 광고비와 부가세를 나눠 보여준다.확정
예상 뱃지
거래별 원장 헤더에 '예상' 뱃지가 붙는 건이 있다. 스크래핑 미확정 등으로 예상값 기반인 거래이며, 예상/확정 판정 기준·스크래핑 시각은 서버 전용.확인필요
기록용 배분 정렬
'기록용' 상태 배분은 실제 이체가 없는 행이라 배분 요약·엑셀 모두 맨 아래로 내린다. 상태는 이체완료·이체대기·이체실패·부채상계·기록용 5종.확정
배치 방식 뱃지
일반 선정산 외에 바로이체·이미지급(기록용) 배치가 좌측 목록에 뱃지로 구분된다. 바로이체 배치는 정상 정산 흐름을 건너뛴 즉시 지급 건.가설

## 1. 프레임 레이아웃 (3분할 고정 골격)

한 프레임 = **상단 메타바 + 좌측 목업(번호마커 오버레이) + 우측 설명패널(key note)**.
프레임 폭 1920px 고정. 좌측 contents 영역 1300px, 우측 Des_contents 500px, 사이 여백 20px.

### (1) 상단 메타바 `content/header` (1820px, 2행 표)

라벨 셀은 회색 배경(`#E5E5EA`), 값 셀은 흰색. **좌하단·우하단에도 동일 메타바가 반복**(하단 풋터로 한 번 더).
우측 끝에는 **Payhug 로고**가 2행 높이로 병합.

실제 값 예시(ST_MA / 메인 프레임 `2782:4125`):

| 필드 | 값 |
|---|---|
| **Page** | `가맹점 선정산 메인` |
| **Page ID** | `ST_MA` |
| **System** | `pc` |
| **Date** | `2026.06.21` |
| **Writer** | `최지원` |
| **Flow** | `페이허그 소개 > 로그인 후 > 가맹점 선정산 메인` |
| **Note** | `-` |

ST_AC / 계좌 내역 프레임 `2782:4650`:
- Page `가맹점 메인 > 계좌 내역` · Page ID `ST_AC` · System `pc` · Date `2026.06.21`
- Flow `페이허그 소개 > 로그인 > 가맹점 메인 > 계좌 내역` · Note `-`

→ **Page = 화면명**, **Page ID = ST_ 접두 코드**(ST_MA, ST_AC, ST_EP_LI, ST_AC_EX …),
**Flow = breadcrumb(> 로 연결)**, Note는 보통 `-`. 화면끼리는 `Page ID`로 상호참조([ST_AC_EX]으로 이동 식).

일부 프레임 우상단에 **보라 테두리 박스**가 떠 있다. 상단바에 `2026.07.20` `V.0.1.1`,
본문에 변경 bullet 1줄: `추가 선정산 18시 업데이트 UI 표시 추가`.
그리고 **본문 설명 안**에도 해당 신규 항목 옆에 **보라 알약형 배지 `V.0.1.1 추가`**를 인라인으로 붙여
"이번 버전에 새로 들어간 스펙"을 표시한다.

### (2) 좌측 목업 위 번호 마커 ①②③

- **메인 마커**: 채워진 **인디고/블루퍼플 원(●)**, 안에 흰 숫자 `1 2 3 4`. 컴포넌트명 `디스크립션 번호`(26×26).
- **서브 마커**: 같은 색 **작은 알약형 배지**에 `2-1` `3-4`처럼 하위번호. 주석 대상 요소 **바로 앞/위**에 얹음
  (예: `③-¹ 26년 6월 16일 (화)·오늘`, `③-² 488,086원`, `③-⁴ 계좌 입금 내역보기`).
- **연결선**: 컴포넌트명 `영역표시_화살표`. 카드/섹션 **좌측 세로에 얇은 보라 치수선(양끝 T캡)**을 세워
  그 마커가 **어느 영역 전체를 가리키는지 범위로 표시**. 단건 요소는 선 없이 배지만 얹음.
- 한 화면에 **여러 상태(state)를 세로로 나열**하되(정상/빈값/집계중 등), **번호 마커는 대표 상태에만** 달고
  아래 반복 상태에는 안 단다(메인 프레임: 위 카드엔 ①②③, 아래 "0원/집계중" 카드엔 마커 없음).

### (3) 우측 설명패널 `key note`

위→아래 3단:
1. **`key note` 헤더**(회색 바)
2. **더미데이터/운영이슈 메모**(빨강 글씨, 있을 때만) — 예: `· 더미 데이터 / · 6.16 선정산 제외액은 더미 데이터로 만약 16일에 계좌 이체했다는 가정`
3. **디스크립션 표**: 헤더행 `No | Name | Note`(회색), 이후 `넘버 디스크립션` 행 반복.
   - **No**(40px, 볼드) = 좌측 원마커 숫자와 1:1
   - **Name**(80px) = 요소 이름 짧게 (`뒤로가기`, `계좌 정보`, `계좌 내역`, `내역 더 불러오기`, `카드사별요약`)
   - **Note**(380px) = **불릿 중첩 리스트**로 상세 스펙. 하위번호 `3-1) 3-2)`가 그대로 좌측 서브마커와 대응.

폰트 Apple SD Gothic Neo 14px. 정책상 강조/이슈는 **빨강**, 신규는 **보라 배지**.

## 2. 디스크립션 문장 스타일 (사람 문체 특징)

### 핵심 규칙 (그대로 답습할 것)

- **개조식·명사 종결**. `~함/~됨/~이동/~표기/~노출`. 완결형 서술어("~합니다") 절대 없음. 마침표도 거의 안 씀.
- **하위번호 체계**: 요소는 `N-1) N-2)` 괄호닫기 번호, 그 아래 세부는 `-` 불릿, 더 깊으면 `a. b.` 또는 `Case1) Case2)`.
- **콜론 스펙 표기**: `필드 : 값/규칙` 형태로 좌우를 콜론으로 끊음. (`입금자명 (default : 페이허그)`, `default : 버튼 비노출`)
- **화면 이동은 대괄호 코드**: `[ST_AC_EX]으로 이동`, `미리 받은 돈[ST_EP_LI]으로 이동` — 대상 화면을 대괄호 Page ID로.
- **표기 규칙 관용구 반복**: `천단위 [,]콤마 표기`, `내림차순 정렬`, `[+] 표시`/`[-] 표시`, `? 아이콘 선택 시, 툴팁 노출`.
- **조건 분기는 부등호/케이스로**: `예상 수수료 > 실제 수수료`, `승인데이터O, 매입데이터O`, `Case3) 매입데이터만 있는 경우 (삼성카드, 해외카드 등등)`.
- **미완/추정 표시**: `개발 구현 현행화 예정`(구현 미확정), `파악안되는 차감액/입금액`, `(6.21 확인)` 날짜 각주. 오타·구어 그대로(`선전상 지급액`, `라밸문구`, `등등`).
- **길이**: Name은 2~6자. Note 한 불릿은 짧으면 4자(`YYYY.MM.DD`), 길면 한 줄에 조건+예외까지(`Case4) 프렌차이즈 등에서 수기매입 등으로 인해, 승인, 매입없이 돈만 들어오는 경우`).
- **줄바꿈**: `<br>`로 케이스 내부를 강제 개행해 `Case1) … / Case2) …`를 한 불릿 안에 쌓음.
- **"박스/테두리" 강조**: 전용 테두리 그리기보다 **색으로** 강조 — 빨강=이슈/더미/예외 정책, 보라 배지=신규 버전, 회색바=구획 헤더.

### 원문 인용 (그대로 붙여 쓸 톤)

1. `선택 시 히스토리 Back` / `메인에서 진입 시 메인으로 이동`
2. `3-1) 날짜 M.DD, 내림차순 정렬`
3. `3-2) 입금자명 (default : 페이허그)`
4. `선정산 대상 이체 금액인 경우 / 라벨 문구 : 미리 받는 돈`
5. `신용카드 : 승인데이터 기준` / `배달앱 : 정산 예정액 기준`
6. `[배달의 민족 차감액] 항목으로 처리 / a. 정산 예정액보다 입금액이 적은 경우 : 광고비, 깃발비용 등 선정산 대상액에서 제외 / b. 그외 파악안되는 차감액`
7. `Case4) 프렌차이즈 등에서 수기매입 등으로 인해, 승인, 매입없이 돈만 들어오는 경우`
8. `버튼 선택 시, 선정산 제외액 내역[ST_AC_EX]으로 이동`
9. `default : 버튼 비노출 / 리스트 10개 초과 시 : 버튼 노출 / 버튼 선택 시, 과거 입금 10개씩 내역 불러옴`
10. `면제인 경우 '면제' 표시` / `페이허그 수수료 · 채권 매입 수수료 건별 합산`
11. `계산식 = 카드 + 배달 매출액 / 수수료 등 차감하지 않는 순 매출액을 의미` (메인)
12. `개발 구현 현행화 예정 / 계약 완료시 당일 1회 노출 후 비노출` (2번째 줄 빨강)
13. (조건 분기) `카드 : 예상 수수료 > 실제 수수료` / `배달 : 예상 입금 예정금 < 실제 입금 예정금`

## 3. 화면당 항목 수 · 상태 표기

- **항목(No 행) 수: 화면당 3~5개**가 표준. 뒤로가기(1) → 정보/날짜(2) → 리스트 본문(3, 하위번호 대량) → 내역 더 불러오기(마지막).
  - 메인 ST_MA: **3항목**(가맹점 정보 / 계약 정보 / 계좌 입금 내역)
  - 계좌 내역 ST_AC: **4항목**(뒤로가기 / 계좌 정보 / 계좌 내역 / 내역 더 불러오기) — 3번에 3-1~3-6 하위 대량
  - 미리 받은 돈: **4항목**(뒤로가기 / 중요 정보 / 리스트 / 내역 더 불러오기)
  - 어제 배달 내역: **5항목**(뒤로가기 / 날짜 / 카드사별요약 / 어제 카드 내역 / 내역 더 불러오기)
- **하위번호는 대응 요소가 있을 때만**. 리스트 본문 항목이 가장 깊게(3~4단) 중첩.
- **상태/조건 표기 관용어**: `default :`, `~인 경우`, `~ 초과 시`, `~ 없을 경우 미노출`, `hidden`(빈값·집계중 상태는 마커 없이 목업만 추가).
- **공통 마지막 항목 `내역 더 불러오기`**는 세 화면에서 문구가 거의 동일(재사용 블록): `default : 버튼 비노출 / 리스트 10개 초과 시 : 버튼 노출 / 버튼 선택 시, 과거 입금 10개씩 내역 불러옴`.
- **색상 토큰**: 마커/서브마커/치수선 = 인디고 계열, 이슈·더미·예외정책 = 빨강(`#FF383C` accents/red), 신규 = 보라 배지, 헤더/라벨 = `#E5E5EA`.

## 3. "화면설계서 작성분" vs "원본만" 구분

- **화면설계서로 완성된 프레임: 0개.**
  전수 확인 결과 모든 프레임은 사이드바+본문만 있는 순수 UI 목업이다. 예시 스타일의 화면설계서에 있어야 할 요소 — 번호 콜아웃, 우측/하단 스펙 설명 패널, 필드/버튼 주석, 상태·정책 라벨 — 이 **어느 프레임에도 없다.**
- **원본만 존재: 프레임 18개(+조각 2개).**
  이들은 배포 UI(캐시노트/어드민 HTML)에서 임포트된 base 시안이며, 화면설계서의 "재료"에 해당한다.

> 결론: 태스크 #9 "화면설계서 실제 작성"은 **재료(원본 화면)만 깔린 상태**이고 주석·설계 레이어 작업은 시작되지 않았다. 착수 시 (a) 라이트/다크 중복·66215↔68812 중복 정리, (b) 미존재 3개 메뉴(약관·1:1문의·로그인) 원본 추가, (c) 각 원본에 스펙 주석 레이어 부착 순으로 진행하면 된다.

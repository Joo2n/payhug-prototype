key note
승인되지 않은 사업자(계약 진행·반려 등)의 메인 레이아웃. 상단 계약 현황 카드 아래 미리 받을 수 있는 금액(예상 0원)과 선정산 시작하기 CTA, 접이식 매출 조회 카드가 세로로 배치된다.
No이름설명
1미리 받을 수 있는 금액승인 화면의 '미리 받는 돈(실지급)'과 달리 예상 조회 합계. 초기 0원, 매출 조회 성공 시 합산되어 증가.
2선정산 시작하기초록 CTA. 클릭 시 계약 존재/상태를 확인해 계약 유도 모달·이미 신청 모달·계약 페이지 등으로 분기.
3보안 안내"다중 보안 시스템으로 계정 정보를 보호하고 있으니 안심하세요" 문구로 계정 입력 신뢰 확보.
4매출 조회 접이식 카드"배달앱 또는 카드 매출이 있으신가요?" 카드. 펼치면 계정 입력 폼(MC_DASH_INQUIRY)이 열림.
5저장 안 함 안내"계약 승인 전에는 매출 정보가 저장되지 않아요" — 예상 조회 전용임을 명시.
6상단 계약 현황 카드선택 사업자 상태에 따라 진행 스텝/반려·중지/완료 카드로 바뀜(MC_DASH_PROGRESS·REJECT).
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
미승인 사업자는 승인 사업자와 완전히 다른 레이아웃(예상 조회 중심 1컬럼)을 쓴다. 핵심 구분은 상단 금액이 '예상값'이며 저장되지 않는다는 점. 선정산 시작하기는 계약 여부/상태에 따라 여러 모달·페이지로 분기하는 진입 허브다. 예상 금액의 정의·수수료율은 정책 미확정.
연결레이아웃 분기
승인 여부 기준
승인완료 → 미리 받는 돈(실지급) 단일 카드미승인 → 예상 금액 + CTA + 매출 조회 카드 1컬럼확정
CTA 분기
선정산 시작하기 → 계약 미존재:계약 유도 모달 / 존재:이미 신청 모달 / 반려:계약 페이지 / 대기:승인 대기 모달확정
계산예상 금액
예상값·비저장
상단 금액은 조회 예상 합계, 승인 전 저장 안 함실제 지급액과 구분 필수(6대 개념)확정
수수료·차액 정의
예상액 수수료율(C1)·예상 지급 차액 정의(C4) 미확정확인필요

상태별 카드

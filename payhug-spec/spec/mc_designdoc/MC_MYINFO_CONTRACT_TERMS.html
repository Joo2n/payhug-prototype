key note
약관 동의 내역 항목을 클릭하면 뜨는 약관 전문 모달. 동의했던 약관 제목과 본문(조문) 전체를 읽기전용으로 표시한다.
No이름설명
1모달 헤더약관 제목(예: 선정산 서비스 이용약관)을 표시, X로 닫기.
2약관 본문제1조(목적)·제2조(정의) 등 조문 전체를 스크롤 영역에 표시. 내용이 없으면 '내용 없음'.
3선정산·수수료 정의제2조(정의)는 '선정산'(매출채권 조기 매입 후 대금 지급)만 정의 — '채권매입수수료'는 약관 정의어가 아니라 원장 라벨(MARGIN)로만 존재(확인필요).
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
이 모달의 본문은 서버에 저장된 약관 텍스트(termsContent)를 그대로 렌더링한다. 선정산의 법적 정의('매출채권을 회사가 매입하여 정산 예정일 이전에 대금을 지급')는 제2조에 있으나 '채권매입수수료'는 약관 정의어로 존재하지 않는다(원장 라벨 MARGIN뿐). 화면에 숫자로 안 나오는 수수료율의 실제 근거·표현이 약관 텍스트에 있는지 대조가 필요하다.

동의 내역 항목의 termsTitle·termsContent를 그대로 표시.별도 조회 없이 계약 상세에 포함된 약관 객체 사용.확정
정책수수료 용어 근거
채권매입수수료 정의
약관 제2조(정의)엔 '채권매입수수료' 정의 없음 — 원장 라벨(MARGIN)로만 존재.실제 요율 수치는 약관 본문에 포함되는지, 별도 특약인지 확인 필요(C1).확인필요
선정산 정의
'정산 예정일 이전에 대금 지급' — 지급 캘린더(매일/D+1/D+2, C2)와의 정합 확인 필요.확인필요

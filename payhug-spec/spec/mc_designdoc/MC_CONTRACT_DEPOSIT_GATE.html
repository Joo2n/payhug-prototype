key note
통장 업로드(4단계 입금계좌) 화면에 진입했으나 선정산 전용계좌(락계좌)가 아직 준비되지 않았을 때 뜨는 차단 모달. 입금받을 계좌 등록 전 전용계좌 등록·빠른조회 가입을 강제하는 진입 가드다.
No이름설명
1차단 모달뒤 업로드 화면은 흐리게 처리되고 닫을 수 없는 안내 모달이 뜬다. 신규 등록 흐름에서만 동작하고 수정 흐름(edit)에서는 뜨지 않는다.
2차단 사유 메시지두 경우로 갈린다. 전용계좌 등록 미완료 시 '먼저 선정산 전용계좌 등록을 완료해 주세요'. 등록은 됐으나 하나은행 빠른조회 미가입 시 '빠른조회 가입이 완료되어야 입금받을 계좌를 등록할 수 있어요'.
3전용계좌로 이동 버튼유일한 액션. 누르면 선정산 전용계좌 개설 단계(전용계좌 신청 화면)로 강제 이동한다. 모달 닫기(X)도 같은 이동으로 처리된다.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
이 게이트는 '입금받을 정산계좌(SETTLEMENT)'를 등록하기 전에 '선정산 전용 락계좌(PRE_PAYMENT)'가 등록·인증되고 빠른조회까지 가입돼 있어야 한다는 선후 관계를 강제한다. 프론트 가드는 보조 방어선이고 서버 게이트가 최종 차단선이다. 상태 조회 실패 시에는 프론트에서 막지 않고 통과시킨다.
연결게이트 판정 데이터
상태 조회 API
계좌 상태 조회(getBankAccountStatus, accountPurpose=PRE_PAYMENT)로 전용계좌 준비 여부를 읽는다.응답 필드: 등록완료 여부(registrationComplete), 빠른조회 가입 여부(fastInquiryEnabled) 등.확정
두 단계 조건
registrationComplete=false → '전용계좌 등록 먼저' 메시지.registrationComplete=true & fastInquiryEnabled=false → '빠른조회 가입 먼저' 메시지.확정
조회 실패 시
상태 조회가 에러나면 프론트는 가드를 강제하지 않고 통과. 최종 차단은 서버 게이트가 담당.확정
정책진입 선후 정책
전용계좌 → 입금계좌 순서
선정산 전용 락계좌(출금 전용) 등록·빠른조회 가입이 선행되어야 입금받을 정산계좌를 등록할 수 있다.전용계좌=PRE_PAYMENT(락계좌), 입금받을 계좌=SETTLEMENT(정산계좌)로 코드상 용도 분리 확정.확정
수정 흐름 예외
edit=true(계좌 수정)로 진입하면 게이트를 건너뛴다.확정
빠른조회 가입 강제 사유
빠른조회는 하나은행 락계좌에서 매출·잔액을 조회하기 위한 가입 절차로 추정. 미가입 시 선정산 운영이 불가하다는 정책 근거는 코드 밖에서 재확인 필요.확인필요

락계좌 등록(1원 인증)은 이미 성공한 상태에서 빠른조회 가입만 미완인 케이스를 처리하는 분기다. 빠른조회는 락계좌 입금내역을 PayHug가 자동 스크래핑/조회하기 위한 필수 인프라라, 미가입이면 계약 진행을 막는다. 재점검 API는 1원 인증을 다시 하지 않고 하나은행 조회(내부 코드 0101 추정)만 재시도하며, 비밀번호 오류였다면 새 비밀번호로 갱신 후 재조회한다.
연결빠른조회 재점검
재점검 API
recheckFastInquiry → /bank/fast-inquiry/check. userId·accountPurpose·(선택)accountPassword 전송. 1원 인증 재실행 없음.res.data.fastInquiryEnabled true면 done→성공 모달→upload-settlement. false면 fastInquiryMessage 갱신 후 재시도 유도.확정
비밀번호 오류 갱신
비밀번호 오류로 실패했으면 4자리 재입력 후 재점검 시 서버 비밀번호 갱신. /^\d{4}$/ 검증 통과 필수.확정
정책빠른조회 필수 정책
미가입 시 진행 차단
락계좌 입금내역 자동확인을 위해 하나은행 빠른조회 가입이 필수. 미가입이면 다음 계약 단계로 못 넘어감.확인필요: 빠른조회 가입 없이 운영이 수동 대체 가능한지, 재점검 시도 제한 정책 미기재.확인필요
빠른조회 용도
잔액·거래내역(입금내역) 조회 권한을 인터넷뱅킹·폰뱅킹 모두 '허용'으로 설정해야 PayHug가 락계좌 입금을 인식.내부 스크래핑/펌뱅킹 연동 코드는 노출 안 함 — 업무용어 '입금내역 자동확인'으로 표기.가설

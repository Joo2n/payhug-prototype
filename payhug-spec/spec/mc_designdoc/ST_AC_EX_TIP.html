key note
선정산 제외액 상세에서 거래 행의 밑줄 금액에 호버하면 뜨는 툴팁. 그 거래의 제외액이 어떻게 산출됐는지 매출액·카드수수료·제외액으로 분해해 보여준다.
No이름설명
1호버 트리거거래 행 오른쪽의 밑줄 처리된 실지급 금액이 트리거(cursor:help). 클릭 이동 없이 마우스 오버로만 툴팁이 열림.
2산출 3요소툴팁 내용: '매출액 (N월) : ...원 / 카드 수수료 (N월) : ...원 / 선정산 제외액 (N월) : ...원'. 매입일의 월을 괄호로 붙여 표기.
3검산 관계매출액 − 카드수수료 = 선정산 제외액 관계로 읽힘(예: 15,000 − 450 = 14,550). 본문에 없던 매출액·수수료를 이 툴팁에서만 확인.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
base(선정산 제외액 상세) 대비 새 데이터 로드 없이 이미 받은 행 데이터(sales, cardFee, amount)를 CommonTooltip으로 재구성해 보여주는 순수 표시 variant다. 추가 API 호출·라우팅이 없고, 월 라벨은 거래 date에서 파생한다. 세 값의 관계식이 제외액 산식을 드러내므로 수수료 구성·수수료율(C1) 검토의 단서가 된다.
연결툴팁 구성
데이터 소스
별도 호출 없음 — ExcludedPayoutItem의 sales·cardFee·amount를 그대로 사용월 라벨(N월)은 item.date의 월을 파싱해 각 줄에 부착트리거는 CommonTooltip(호버/포커스), 클릭 네비게이션 아님확정
계산산식·수수료
3요소 관계
매출액 − 카드수수료 = 선정산 제외액으로 표기됨(예: 15,000 − 450 = 14,550)페이허그(채권매입) 수수료 항목은 툴팁에 없음 → 제외액엔 미적용/면제로 보이나 미확정가설
수수료율 확인
카드수수료 값의 근거 요율이 C1(수수료율 병존)과 연결 — 임의 확정 금지'N월' 라벨이 매입월 기준인지 정산월 기준인지 표기 정합성 확인 필요확인필요

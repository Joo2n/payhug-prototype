사장님이 페이허그 고객센터와 1:1 문의를 주고받는 화면. 문의 목록(상태·카테고리 배지·미답변 건수)과 [문의하기] 버튼을 카드로 제공하고, 항목 클릭 시 대화 드로어가 열린다.
No이름설명
1사업자 선택 드롭다운다중 사업자 시 노출. 문의는 사업장 단위로 관리.
2문의 카드 헤더'1:1 문의' 제목 옆 총 건수와 'N건 미답변'(대기·처리중 합계) 빨간 배지, 우측 [문의하기] 버튼.
3문의 목록 행각 행에 상태 배지(대기/처리중/답변완료/종료), 카테고리 배지(일반/결제/정산/기술/계정), 제목, 메시지 건수, 최종 시각. 관리자 새 답변 시 NEW 배지.
4문의하기 버튼클릭 시 문의 작성 모달 오픈(카테고리·제목·내용 입력).
5빈 상태접수 문의 없을 때 '접수된 문의가 없습니다' 안내 표시.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
1:1 문의는 계약·계좌·정산 등 직접 수정 불가 항목의 유일한 변경·해명 창구다. 카테고리(정산·결제 등)와 실제 문의 제목들('지급 예정 금액과 실제 입금액 차이', '선정산 지급이 하루 늦어졌어요', '수수료가 생각보다…')이 미확정 3대 지뢰(예상 지급 차액 C4, 지급 캘린더 C2, 수수료율 C1)와 직결되어, 정책 미확정이 곧 CS 부하로 나타나는 지점이다.
연결문의 상태·카테고리
상태 값
PENDING=대기, IN_PROGRESS=처리중, ANSWERED=답변완료, CLOSED=종료.미답변 카운트=대기+처리중 합계.확정
카테고리
GENERAL=일반, PAYMENT=결제, SETTLEMENT=정산, TECHNICAL=기술, ACCOUNT=계정.내부 상수를 한글 라벨로 매핑 표시.확정
NEW 표시
마지막 발신자가 ADMIN이고 상태 ANSWERED면 NEW 배지.확정
정책문의 내용과 정책 지뢰 연계
정산 관련 문의 유형
'지급 예정 금액과 실제 입금액 차이'→예상 지급 차액 정의(C4).'선정산 지급이 하루 늦어졌어요'→지급 캘린더(C2).'수수료가 생각보다…'→수수료율(C1).정책 미확정이 반복 CS로 이어지는 근거.확인필요
계약 수정 창구
계좌·사업자 등 수정 불가 항목을 문의로 접수(예: '정산 계좌를 국민은행으로 변경').문의로 처리 가능한 변경 범위 정책 확인 필요.확인필요

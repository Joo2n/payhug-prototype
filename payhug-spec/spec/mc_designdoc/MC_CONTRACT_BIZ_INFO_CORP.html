key note
개인 정보 확인 화면의 법인사업자 변형. 상단에 '법인사업자' 배지가 붙고 개인용 7필드 아래에 법인 전용 4필드(법인등록번호·본점소재지·대표유형·사업자등록일)가 추가로 열린다.
No이름설명
1법인사업자 배지필드 영역 최상단에 진녹 톤 '법인사업자' 배지 표시. 개인 화면에는 없다.
2라벨 명칭 전환'상호'→'법인명(상호)', '성명'→'대표자명' 으로 라벨이 바뀐다.
3법인 추가 필드 4종기본 7필드 뒤에 법인등록번호, 본점소재지, 대표유형(단독/공동/각자), 사업자등록일(예: 20150325)이 추가로 표시·편집 가능.
4진위확인 파라미터 차이국세청 진위확인 시 법인 여부와 법인등록번호를 함께 전송. 등록 시에도 법인등록번호·본점소재지·대표유형·사업자등록일이 함께 저장된다.

법인 여부는 앞선 업로드 단계에서 사업자번호(중간자리)로 자동 판정되어 전달된다. 이 화면은 개인 base와 동일한 2단계(진위확인→등록) 흐름을 타되, 법인 전용 필드가 요청 페이로드에 추가된다. 대표유형은 '단독/공동/각자' 텍스트 입력값으로 받으며, 공동/각자대표의 서명 권한·계약 주체 처리는 정책 미확정 영역이다.
연결법인 전용 데이터
추가 전송 필드
진위확인: 법인 여부 true + 법인등록번호 함께 전송등록: 법인등록번호·본점소재지·대표유형·사업자등록일을 페이로드에 추가확정
법인 판정 출처
법인/개인 구분은 직전 업로드 화면에서 사업자번호로 자동 판정된 값을 이어받음(entity 파라미터)확정
정책대표유형 처리
대표유형 입력
'단독/공동/각자'를 자유 텍스트로 입력받음 — 선택형(드롭다운) 아님확인필요: 공동/각자대표일 때 계약 서명 주체·추가 서류 요구 여부확인필요
base 대비 차이
처리 흐름(진위확인→등록)·버튼·토스트는 개인과 동일차이는 배지 노출, 라벨 명칭, 법인 4필드 추가뿐확정

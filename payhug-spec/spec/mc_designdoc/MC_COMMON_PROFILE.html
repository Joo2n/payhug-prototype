key note
헤더 우측 프로필 영역(아이콘+사장님 이름)을 눌러 열리는 계정 메뉴 드롭다운이다. 사용자 이름을 다시 표시하고 내 정보 / 1:1 문의 / 로그아웃으로 이동한다.
No이름설명
1프로필 토글헤더 우측 프로필 아이콘+이름 버튼. 클릭 시 드롭다운 열림/닫힘. 바깥 클릭 시 자동 닫힘. 아이콘 하단 초록 체크는 인증(승인) 완료 표식.
2사용자 헤더패널 상단에 큰 프로필 아이콘 + 사장님 이름 재표시로 로그인 계정 확인.
3내 정보클릭 시 내 정보 화면(/my-info)으로 이동하며 드롭다운 닫힘. 등록 계좌·서류·계약 정보 확인 진입점.
41:1 문의클릭 시 1:1 문의 목록(/my-info/inquiries)으로 이동. 고객 문의 채널.
5로그아웃빨간색 항목. 클릭 시 드롭다운을 닫고 로그아웃 확인 모달을 띄움.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
프로필 드롭다운은 헤더 로컬 상태로 제어되며 표시 이름은 로컬 저장된 사용자 정보(user.name)를 그대로 읽는다. 메뉴는 내 정보·1:1 문의·로그아웃 3개로 고정이고, 로그아웃만 별도 확인 모달을 거친다. 프로필 아이콘의 초록 체크 배지는 계약/인증 승인 완료 상태를 암시하나, 미승인 계정에서 배지가 달라지는지 등 상태별 표시 정책은 코드로 확인되지 않는다.

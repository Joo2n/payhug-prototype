key note
비로그인 상태에서 선정산 신청/시작하기 CTA를 누르면 뜨는 로그인 유도 모달. 배경이 딤 처리되고 "로그인이 필요해요" 안내와 [닫기]·[로그인하기] 두 버튼을 제공한다.
No이름설명
1딤 오버레이랜딩 전체에 반투명 딤이 깔리고 중앙 모달만 활성화. 배경 스크롤·클릭이 차단된다.
2안내 문구제목 "로그인이 필요해요", 본문 "선정산 서비스는 로그인 후 이용하실 수 있습니다. 로그인 페이지로 이동하시겠습니까?". 선정산 실행은 인증 필수임을 알림.
3[로그인하기] 버튼클릭 시 로그인 후 대시보드로 복귀+선정산 모달 자동 오픈되도록 redirect 파라미터를 실어 로그인 페이지로 이동(/login?redirect=/dashboard?openModal=true).
4[닫기] 버튼모달만 닫고 랜딩에 그대로 머문다. 다른 페이지 이동 없음.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
이 모달은 base의 CTA 분기(인증 토큰 없음) 경로 중 첫 갈래로, 획득 퍼널에서 로그인 게이트 역할을 한다. 토큰이 있으면 이 모달 대신 계약 확인 분기(계약 완료→대시보드 / 미계약→계약 안내 모달)로 흐른다.
정책분기·리다이렉트
진입 조건
인증 토큰 부재 상태에서 선정산 신청/시작하기 클릭 시에만 노출토큰 존재 시엔 이 모달이 뜨지 않고 계약 확인 로직으로 진행확정
로그인 후 복귀
redirect=/dashboard?openModal=true로 설계 — 로그인 완료 후 대시보드에서 선정산 흐름을 이어감의도: 이탈 최소화(신청 의사를 로그인 뒤에도 유지)가설
모달 종류
공통 모달 컴포넌트 재사용(제목·본문·확인/취소)닫기=랜딩 잔류, 로그인하기=이동. 회원가입 경로는 이 모달에 없음(헤더 CTA로만)확정

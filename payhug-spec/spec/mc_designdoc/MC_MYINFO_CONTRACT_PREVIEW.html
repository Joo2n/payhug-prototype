증빙 서류·전자 계약서 항목의 [보기]를 눌렀을 때 뜨는 파일 미리보기 모달. 제목(예: 사업자등록증)과 함께 PDF는 iframe, 이미지는 확대 보기로 표시한다.
No이름설명
1모달 헤더파일 종류명(사업자등록증/신분증/통장사본/계약서명)을 제목으로 표시, 우측 X로 닫기.
2파일 뷰어확장자가 .pdf면 PDF 뷰어(iframe), 그 외는 이미지로 렌더링. 다운로드 URL은 클릭 시점에 서버에서 발급.
3배경 닫기모달 바깥(딤 영역) 클릭 시 닫힘. 최대폭 900px·높이 85vh.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
미리보기는 저장된 정적 URL이 아니라 [보기] 클릭 시점에 fetchAttachmentDownloadUrl(첨부ID)로 임시 다운로드 URL을 발급받아 연다. URL에 .pdf 포함 여부로 PDF/이미지 뷰어를 분기한다. 민감 서류(신분증·통장사본) 접근이므로 URL 만료·권한 정책 확인이 필요하다.

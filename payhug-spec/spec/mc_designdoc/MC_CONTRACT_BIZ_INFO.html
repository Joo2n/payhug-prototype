key note
사업자등록증 OCR 결과를 입력 필드로 채워 검토·수정한 뒤 국세청 진위확인을 거쳐 등록하는 화면. 개인사업자 기준 7개 필드가 자동 입력되며 사장님이 직접 고칠 수 있다.
No이름설명
12/5 진행바프로그레스바 2칸 채워진 상태(사업자등록증 단계 진행 중).
2제목/부제'사장님의 정보가 맞나요? / 사장님의 사업자등록 정보가 맞는지 확인해 주세요'.
3OCR 자동입력 힌트 토스트'OCR로 자동 입력되었어요 / 잘못 인식된 값이 있으면 직접 수정해주세요' 초록 말풍선. 진입 후 약 10초 뒤 자동으로 사라지고, X로 즉시 닫기 가능.
47개 입력 필드사업자등록번호·상호·성명·개업일자·사업장소재지·업태·종목. 전부 편집 가능한 입력창. 개업일자는 '예: 20150325' 형식 힌트.
5정보가 일치해요 버튼연두 CTA. 누르면 국세청 진위확인 → 사업자 등록 순으로 처리. 진행 중에는 '사업자 정보 확인 중...' → '등록 중...' 로딩 문구로 바뀌고 필드가 잠긴다.
6다시 첨부하기 버튼이전 업로드 화면으로 되돌아가 사진을 다시 촬영·선택.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
업로드 단계에서 저장된 임시 사진과 함께, 확정한 필드값으로 먼저 국세청 진위확인을 호출한다. 검증 결과가 정상(VERIFIED)이 아니면 국세청 메시지를 그대로 실패 사유로 노출하고 등록을 막는다. 검증 통과 후 사진 파일과 정보를 함께 등록하며, 이미 등록된 사업자번호는 중복 안내로 걸러낸다. OCR 값은 신뢰값이 아니라 사장님 확인·수정을 전제로 한 초안이다.
연결진위확인·등록 연동
2단계 처리
1) 국세청 사업자 진위확인 호출(사업자번호·대표자명·상호·개업일자, 법인 여부)2) 검증 정상 시 사진 파일 + 정보로 사업자 등록 호출검증 미통과 시 국세청 응답 메시지를 실패 사유로 노출하고 등록 중단확정
임시 사진 사용
업로드 단계에서 저장한 임시 사업자등록증 파일을 등록 시 첨부. 파일이 유실됐으면 '사진이 유실되었습니다. 다시 첨부해 주세요' 안내등록 성공 후 임시 파일 삭제확정
중복 처리
이미 등록된 사업자번호면 '이미 등록된 사업자 등록번호입니다' 로 치환해 안내(원 DB 오류문구는 숨김)확정
정책입력값·검증 정책
OCR 값 신뢰 수준
OCR 자동입력은 초안일 뿐 확정값 아님 — 사장님 검토·수정을 전제힌트 토스트 약 10초 자동 소멸확정
수정 모드 연동
수정 모드(edit=true)로 진입 시 등록 완료 후 해당 사업장의 계약 안내 화면(수정 모드)로 복귀신규 사업장 추가(addBusiness) 흐름이면 등록 후 락계좌 신청 화면으로 이동확정
필드 유효성
개업일자·필수값 형식 검증 규칙(자릿수·필수 여부)은 정책 문서에 미기재확인필요: 진위확인 실패 시 재시도 횟수 제한 여부확인필요

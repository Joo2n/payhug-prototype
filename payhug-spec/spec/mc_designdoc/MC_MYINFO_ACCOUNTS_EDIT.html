key note
연동 계정 관리에서 특정 플랫폼의 [변경]을 누르면 해당 행이 아이디·새 비밀번호 입력 폼으로 전환되는 변형. 다른 플랫폼 행은 조회 상태 그대로 유지된다.
No이름설명
1편집 전환 행선택한 플랫폼(예: 여신금융협회) 행만 조회 UI에서 입력 폼으로 바뀜. 아이디 입력칸에는 기존 아이디가 채워지고 비밀번호는 빈 상태.
2새 비밀번호 입력'새 비밀번호 입력' 플레이스홀더. '보안을 위해 저장된 비밀번호는 표시되지 않아요. 변경하려면 새 비밀번호를 입력해 주세요.' 안내.
3변경 저장 버튼아이디·새 비밀번호 모두 입력해야 활성. 저장→매출 조회로 검증까지 수행(저장 및 검증). 검증 성공 시 '변경되었습니다' 토스트.
4취소 버튼입력을 버리고 조회 상태로 복귀. 비밀번호 입력값 초기화.
5검증 중 로딩저장·검증 진행 중 해당 행에 '계정 변경 중...' 로딩 오버레이 표시, 입력 비활성.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
변경은 단순 저장이 아니라 저장 후 실제 매출 조회 API로 자격증명을 검증하는 2단계(저장→검증) 흐름이다. 카드(CARD)는 카드매출 조회, 배달앱은 배달매출 조회로 검증하며, 성공해야만 연결됨(verified) 처리된다. 검증 실패 시 '아이디 또는 비밀번호를 확인해 주세요' 오류로 되돌아간다.
연결저장·검증 처리
2단계 처리
1) saveExternalAccount로 계정 저장.2) CARD=카드매출 조회, 배달앱=배달매출 조회 API로 검증.둘 다 성공해야 연결됨 처리, 실패 시 오류메시지 반환.확정
버튼 라벨 분기
기존 연결 계정=‘변경 저장’, 미연결 신규=‘연결’.아이디·비밀번호 미입력 시 비활성.확정

비밀번호 재입력 강제
저장값 미표시 → 변경 시 항상 새 비밀번호 전체 재입력.부분 수정 불가.확정

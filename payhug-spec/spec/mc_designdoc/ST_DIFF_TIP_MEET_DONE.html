key note
base에서 만나서 결제 회수 행의 금액을 탭했을 때 뜨는 툴팁 상태. 회수가 이미 완료된 건이라 예정차감일과 실제차감일이 모두 날짜로 표시된다.
No이름설명
1회수 완료 툴팁만나서 결제 회수 행(예: −18,500원)의 밑줄 금액을 탭하면 표시. 내용은 예정차감일 / 실제차감일 두 줄이며 수수료 정보는 없다.
2차감일 실현실제차감일에 실제 날짜가 채워져 있으면 회수가 집행 완료된 상태. 예: 예정 2026.07.15 → 실제 2026.07.18.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
만나서결제 회수건(isOfflineRecovery=true)은 다른 차액 행과 달리 금액 툴팁에 수수료 대신 예정/실제 차감일을 보여준다. actualDeductionDate에 값이 있으면 '회수 완료' 상태로 실제 날짜를 렌더한다.

툴팁 내용
isOfflineRecovery=true → 예정차감일(scheduledDeductionDate), 실제차감일(actualDeductionDate)actualDeductionDate가 있으면 그 날짜를, 없으면 '회수 예정' 문구를 표기일반 차액 행과 툴팁 구조가 완전히 다름(수수료 3줄 대신 차감일 2줄)확정

만나서결제 회수 성격
현장(만나서)결제분은 선정산에서 제외 후 사후 처리되는 지연 회수 대상. 항상 차감(−).'과지급 회수'와 '선정산 제외' 성격이 혼재 — 차액 순액에 함께 합산되는 것이 타당한지 확인 필요.확인필요
예정 vs 실제 차감일
두 시각(예정/실제)을 혼동 금지. 실제차감일 = 실제 집행일.실제차감일과 상단 '반영일'의 관계(같은 배치인지) 표기 필요.확인필요

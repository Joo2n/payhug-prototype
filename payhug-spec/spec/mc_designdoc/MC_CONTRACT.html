key note
선정산 계약에 필요한 6종 서류·절차를 한눈에 보여주는 계약 진입 허브다. 진입 시 각 단계의 완료 여부를 서버에서 조회해 체크 표시하고, '준비 완료'를 누르면 아직 완료되지 않은 첫 단계로 자동 이동한다.
No이름설명
16단계 진행바상단 6칸 프로그레스바. 첫 칸은 항상 진한색, 2~5칸은 사업자·신분증·락계좌·입금계좌 완료 시 채워지고 마지막 칸(계약 동의)은 안내 화면에선 회색 고정.
2화면 제목/부제기본 모드는 '계약 전 사진을 준비해 주세요 / 미리 준비하면, 빠르게 신청할 수 있어요'. 수정 모드에선 문구가 바뀐다(MC_CONTRACT_EDIT).
36개 준비 항목 리스트1 사업자등록증 사진, 2 신분증 사진(주민등록증/운전면허증), 3 선정산 전용 계좌(락계좌) 통장사진, 4 입금 받을 계좌 통장사진, 5 플랫폼 계정 등록, 6 비대면 계약 동의. 완료 항목은 초록 체크박스로 표시.
4완료 체크 아이콘각 항목 완료 시 초록 사각 체크로 전환. 미완료면 번호가 든 원형 아이콘. 기본 안내 모드에서는 항목 클릭 불가(안내 목적).
5하나은행 통장사본 확인 안내'하나은행 앱 > 계좌설정 > 통장사본확인 > 이미지 저장' 경로 안내. 기본 모드에서만 노출, 수정 모드에서는 숨김.
6준비 완료 버튼연두색 CTA. 미완료 단계 중 첫 번째로 비어있는 단계로 이동(사업자→신분증→락계좌→입금계좌→플랫폼계정→계약). 모두 완료면 상황에 따라 계약동의/승인대기 모달로 분기.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
진입 즉시 사용자 ID 기준으로 6개 완료 상태를 병렬 조회한다(락계좌·입금계좌 존재, 사업자 존재, 신분증 존재, 계약서 작성 완료, 플랫폼 연동 ACTIVE 여부). '준비 완료'의 다음 이동 지점은 미완료 단계 순서로 결정되며, 계약서 작성이 완료됐고 계약 상태가 심사대기(PENDING)면 승인 대기 모달을 띄운다. 이 화면은 계약 온보딩의 상태 머신 허브 역할을 한다.
연결완료 상태 조회
진입 시 상태 조회
사용자 ID로 6종 상태를 병렬 조회: 락계좌 존재(PRE_PAYMENT), 입금계좌 존재(SETTLEMENT), 사업자 존재, 신분증 존재, 계약서 작성 완료, 플랫폼 연동 계정businessId가 없으면 사용자의 첫 사업장을 자동 선택해 조회확정
플랫폼 연동 완료 판정
연동 성공(ACTIVE) 계정이 1개 이상일 때만 5단계 완료로 처리. 실패/대기 행만 있으면 미완료로 간주확정
내부용어 대치
노출: '선정산 전용 계좌(락계좌)', '입금 받을 계좌' / 내부: PRE_PAYMENT·SETTLEMENT 계좌 구분화면 노출은 한글 업무용어 유지확정
정책다음 단계 분기
준비 완료 이동 규칙
미완료 단계 순서대로 이동: 사업자등록증→신분증→락계좌 신청→입금계좌→플랫폼 계정→비대면 계약모든 단계 완료 시: 계약서 작성 완료 상태면 승인대기 모달, 아니면 플랫폼 연동 완료 여부에 따라 약관/계정등록 화면으로 분기확정
편집 가능 조건
수정 모드(edit=true) 또는 계약 상태 PENDING이면 항목 클릭·수정 가능그 외에는 안내 전용(클릭 불가)확정
세션 정리
진입 시 '방금 등록됨' 임시 플래그(사업자/입금계좌/락계좌/신분증)를 세션에서 제거해 새 상태로 갱신가설

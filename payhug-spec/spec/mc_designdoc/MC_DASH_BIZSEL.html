key note
상단 사업자 카드를 누르면 열리는 사업자 목록 드롭다운. 등록된 여러 사업자를 상태 배지와 함께 보여주고, 선택 시 상태별로 분기하며 사업자 추가도 가능하다.
No이름설명
1사업자 목록등록 사업자 각각 사업자명 + 사업자번호 + 상태 배지로 나열. 배지: 승인완료(초록)·계약진행(노랑)·심사반려(빨강).
2선택 시 분기승인완료 → 해당 사업자 선택(정산 화면). 반려 → 선택 후 반려 카드. 진행/대기 → 계약서 작성 완료면 승인 대기 모달(MC_DASH_PENDING), 아니면 계약 페이지로 이동.
3사업자 추가목록 하단 "+ 사업자 추가". 클릭 시 사업자 등록(업로드) 플로우로 이동.
4선택 카드 토글상단 카드의 화살표가 위로 뒤집히며 드롭다운 열림/닫힘을 표시.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
base와 동일 데이터(fetchBusinesses)의 펼침 상태. 선택 사업자에 따라 전체 대시보드 데이터가 재조회되므로 이 드롭다운이 화면 컨텍스트 전환의 핵심 스위치다. 상태별 분기 로직이 계약/정산 진입을 가른다.

목록 데이터
사용자 소유 사업자 전체를 상태 배지와 함께 표시선택 변경 시 해당 사업자 기준으로 정산·계약 데이터 재조회확정
정책상태별 진입 분기
분기 규칙
승인완료 → 정산 메인반려 → 반려 카드진행/대기 + 계약서 작성완료 → 승인 대기 모달그 외 → 계약 진행 페이지확정
배지 용어
내부 상태(APPROVED/REJECTED/PENDING)를 승인완료/심사반려/계약진행으로 노출 변환확정

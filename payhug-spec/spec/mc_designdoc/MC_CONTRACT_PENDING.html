key note
모든 단계 완료·계약서 작성까지 끝난 사업자가 다시 진입했을 때 뜨는 '승인 대기 중' 안내 모달. 심사 진행 중임을 알리고 서류 수정 여부를 묻는다.
No이름설명
1승인 대기 모달제목 '승인 대기 중이에요', 본문 '해당 사업자는 계약이 완료되어 심사가 진행 중이에요. 서류를 수정하시겠어요?'.
2대시보드로 이동(취소)좌측 버튼. 모달 닫고 대시보드로 이동. 심사 결과를 기다림.
3서류 수정하기(확인)우측 연두 버튼. 수정 모드(edit=true)로 재진입해 서류를 교체할 수 있게 함(MC_CONTRACT_EDIT로 전환).
4트리거 조건계약서 작성 완료 + 계약 상태 심사대기(PENDING)일 때 '준비 완료'/재진입 시 자동 노출.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
이 모달은 계약서 작성이 완료됐고 계약 상태가 심사대기(PENDING)일 때 안내 허브에서 '준비 완료'를 누르거나 완료된 사업자로 재진입할 때 뜬다. 심사 중에도 서류 교체 경로를 열어주되, 사장님이 능동적으로 '서류 수정하기'를 선택해야 수정 모드로 전환된다. 심사 상태 PENDING의 후속 상태(승인/반려) 전이와 서류 수정이 심사에 미치는 영향은 정책 미확정이다.
정책노출 조건·분기
트리거
계약서 작성 완료 + 계약 상태 PENDING(심사대기)에서 모든 단계 완료 후 '준비 완료' 시 모달 노출확정
버튼 분기
'대시보드로 이동' → 대시보드, '서류 수정하기' → 수정 모드(edit=true)로 계약 안내 재진입확정
정책심사 상태
상태 전이
확인필요: PENDING 이후 승인/반려 상태값과 각 상태에서의 사장님 화면 안내(반려 사유 노출 등) 정책 미기재확인필요
내부용어 구분
여기서의 '승인/심사'는 계약 심사이며, 어드민의 '매출 회수'(락계좌→모계좌 스윕)나 정책의 '회수'(과지급 회수)와 무관확정

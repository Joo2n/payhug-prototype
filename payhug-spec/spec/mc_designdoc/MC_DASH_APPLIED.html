주소에 openModal 파라미터가 있고 이미 계약이 접수된 상태로 재진입했을 때 뜨는 안내(info) 모달. 중복 신청을 막고 계약 현황 확인을 유도한다.
No이름설명
1안내 모달"이미 계약 신청이 완료되었어요" 제목 + "이미 비대면 계약 동의 및 신청이 완료된 상태에요! 대시보드에서 계약 현황을 확인해 주세요." 본문.
2확인 버튼단일 확인 버튼. 클릭 시 모달만 닫히고 대시보드에 머무름(별도 이동 없음).
3배경 딤뒤 대시보드(미리 받는 돈 등)는 흐리게 처리되어 상호작용 차단.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
base 대비 차이는 계약 존재 여부 확인(checkContract) 결과 '이미 존재'일 때 뜨는 info 모달 한 장. 선정산 시작하기 등 진입 시 중복 계약을 방지하는 가드 역할.

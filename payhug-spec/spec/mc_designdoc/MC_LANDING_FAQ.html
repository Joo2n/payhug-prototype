랜딩 FAQ 섹션의 개별 문항을 클릭해 답변을 아코디언으로 펼친 상태. base 대비 해당 카드 배경이 연회색으로 바뀌고 화살표가 위로 향하며 하단에 줄바꿈 보존(pre-line) 답변 본문이 나타난다.
No이름설명
1아코디언 토글질문 카드 클릭 시 열림/닫힘 전환. 열리면 배경 #f6f8fa로 강조되고 우측 아이콘이 아래(▼)에서 위(▲)로 바뀐다. 각 문항 독립 토글(다중 동시 열림 가능).
2답변 본문 영역카드 하단에 흰 배경으로 답변이 펼쳐진다. 줄바꿈·번호목록·※ 주석을 원문 그대로 보존해 표시(pre-line). 표·링크 없는 순수 텍스트.
3정책성 답변 문항수수료·지급 시점·최소 5만원·선정산 중지 사유·매출액 차이 등 정책 민감 문항이 여기서 실제 노출된다. 문구가 곧 대외 정책 선언이 되므로 정합성 관리 대상.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
FAQ 펼침은 UI상 단순 토글이나, 답변 본문이 미확정 정책(지급 캘린더·수수료·최소금액)을 확정 어조로 서술하는 지점이라 검토 밀도가 가장 높다. base 화면에서 서술한 지뢰 저촉 문구가 실제 사용자에게 노출되는 순간이 이 상태다.

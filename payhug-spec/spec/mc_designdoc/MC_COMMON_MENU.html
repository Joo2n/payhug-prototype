key note
화면 폭이 좁을 때(모바일 뷰) 헤더 우측 햄버거 아이콘을 눌러 열리는 메뉴 드로어다. 데스크톱에서 상단에 펼쳐지는 알림·프로필·메뉴를 좁은 화면에서 세로 목록으로 대체한다.
No이름설명
1햄버거 토글헤더 우측 3줄 아이콘. 누르면 드로어가 열리고 아이콘이 X(닫기)로 바뀜. PC 넓은 화면에서는 숨겨지고 알림·프로필이 대신 노출.
2사용자 정보 헤더드로어 최상단에 프로필 아이콘 + 사장님 이름. 하단 구분선으로 메뉴 목록과 분리.
3주요 이동 메뉴대시보드 / 알림 / 내 정보 / 1:1 문의 4개 링크를 세로로 나열. 각 항목 클릭 시 해당 화면 이동 후 드로어 자동 닫힘.
4로그아웃 항목목록 맨 아래 빨간색 로그아웃. 누르면 드로어를 닫고 로그아웃 확인 모달을 띄움.
5딤 배경드로어 아래로 반투명 검정 딤. 딤을 누르면 드로어가 닫힘. 헤더(상단 64px) 아래 영역만 덮음.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
이 드로어는 반응형 분기 전용 화면으로, md 브레이크포인트 미만에서만 렌더링되고 데스크톱 폭에서는 나타나지 않는다. 스크린샷은 대시보드 원본이 캐프처되어 드로어 자체는 보이지 않으나, 코드상 로그인 상태일 때 대시보드·알림·내 정보·1:1 문의·로그아웃 항목으로 구성된다. 비로그인 상태에서는 로그인·시작하기 버튼만 노출되는 별도 분기가 있다.

key note
미승인 사업자 레이아웃에서 "배달앱 또는 카드 매출이 있으신가요?" 카드를 펼친 상태. 카드·배민·요기요·쿠팡이츠 계정을 입력해 미리 받을 수 있는 예상 금액을 조회한다.
No이름설명
1안내 배너"계약 승인 전에는 매출 정보가 저장되지 않아요. 지금은 예상 금액만 미리 확인할 수 있어요" 파란 배너로 예상 조회임을 명시.
2카드 매출 조회여신금융협회 계정(아이디/비밀번호) 입력 + "여신금융협회 바로가기" 링크. 조회 버튼으로 예상 매출 산출.
3배달앱 계정"배달앱 계정" 구분선 아래 배달의민족·요기요·쿠팡이츠 각각 아이디/비밀번호 입력 + 사장님 사이트 바로가기 링크.
4조회 버튼·상태각 항목 우측 조회 버튼과 상태 표시(미확인 / 정상 / 인증실패 / 일시 오류). 조회 성공 시 예상 금액이 합산됨.
5예상 금액 합산각 플랫폼 조회 결과가 상단 "미리 받을 수 있는 금액"에 누적 합산되어 반영.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
승인 전 예상 조회 전용 폼. 입력한 계정으로 카드/배달 매출을 스크래핑해 예상 금액을 합산하되 저장하지 않는다. 조회값은 예상값이며, 실제 지급액(미리 받는 돈)과 명확히 구분된다. 예상액 표기의 정의(예상 지급 차액 C4)는 정책 미확정.
연결조회 연동
조회 API
카드: 카드 매출 조회, 배달: 배달 매출 조회(플랫폼별)성공 시 예상 금액을 상위 합계에 누적, 실패 시 상태 표시만확정
저장 여부
승인 전에는 계정/매출 저장 안 함 — 예상 조회 전용승인 후 관리 모드에서는 계정 저장(연동 상태 표시)확정
계산예상 금액의 정의
예상값 성격
"미리 받을 수 있는 금액"은 조회 기반 예상값실제 지급액과 다를 수 있음(수수료·정산 시간 안내 문구 존재)확정
수수료·차액 근거
예상액 산출 수수료율 미확정(C1)예상 지급 차액 정의 미확정(C4) — 화면 예상 표기의 정책 근거 필요확인필요

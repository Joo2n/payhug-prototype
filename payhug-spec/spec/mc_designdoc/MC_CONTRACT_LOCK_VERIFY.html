(info 화면의 상태 전환 variant) 1원 입금 요청 성공 후, 락계좌 통장 적요에 찍힌 '페이허XXX'의 숫자 3자리를 입력해 계좌 소유를 확정하는 단계. 인증 성공 시 통장 파일과 함께 락계좌를 실제 등록한다.
No이름설명
1제목·안내 문구 전환'사장님의 정보가 맞나요?' → '1원 인증번호를 입력해주세요'로 바뀌고, 통장 적요 숫자 3자리 입력 안내로 교체.
2인증번호 입력 필드(3자리)신규로 나타나는 필드. 숫자만·3자리. '페이허XXX' 메모의 숫자를 입력. 3자리 미만이면 확인 버튼 비활성.
3기존 정보필드 잠금계좌주명·은행명·계좌번호·비밀번호가 disabled(흐림) 처리되어 수정 불가.
4인증번호 확인 버튼통장 파일 + 인증정보를 묶어 /bank/verify/confirm-and-register 호출. 성공하면 락계좌 등록 완료.
5다시 인증 요청하기info 단계로 되돌려 1원 인증을 재요청. 입력한 인증번호는 초기화.

info 화면의 verifyStep 상태만 'verify'로 바뀐 동일 컴포넌트다. 인증 확정 시 통장 원본파일(pendingPrePaymentFile) + verifyVal + 출금비밀번호를 FormData로 묶어 confirm-and-register로 전송해 락계좌를 등록한다. 등록 성공 후 서버 응답의 fastInquiryEnabled 값에 따라 분기: true면 완료, 아니면 fast_inquiry 단계(빠른조회 미가입 안내)로 넘어가 다음 진행을 막는다.

key note
매출 수집(스크래핑)에 사용하는 여신금융협회·배달앱 4개 플랫폼의 로그인 계정을 조회하고 연결 상태를 확인·변경하는 화면. 각 플랫폼별로 아이디(마스킹 비밀번호)와 연결 상태 배지를 카드로 나열.
No이름설명
1안내 배너'여신금융협회와 배달앱 계정 정보를 수정할 수 있어요. 비밀번호를 변경하셨다면 여기서 다시 저장 및 검증해 주세요.' 외부 플랫폼 비밀번호 변경 시 재검증 필요를 안내.
2사업자 선택 드롭다운사업자가 2개 이상일 때만 노출. 상호명·사업자번호로 대상 사업장 전환. 기본값은 계약 승인완료(APPROVED) 사업장.
3플랫폼 행 — 여신금융협회카드 매출 스크래핑용 계정. 아이디 표시, 비밀번호는 ••••••••로 마스킹. 회원가입 바로가기 외부링크 제공. 연결 상태 배지(연결됨).
4플랫폼 행 — 배달의민족/쿠팡이츠/요기요배달앱 3종 계정. 각 사장님 사이트 바로가기 링크. 연결됨/일시 오류/인증실패 상태를 색상 배지로 구분하고 실패 시 힌트 문구 노출.
5연결 상태 확인 버튼비밀번호 입력 없이 서버에 저장된 계정으로 재확인. 정상이면 성공 토스트, 실패면 '계정을 변경해 주세요' 안내 토스트.
6변경 버튼계정 변경 폼(아이디·새 비밀번호 입력)으로 전환. 저장된 비밀번호는 보안상 표시하지 않음.

연동 계정은 선정산의 원천인 카드·배달앱 매출 스크래핑의 핵심 자격증명이다. 화면은 저장된 아이디만 보여주고 비밀번호는 절대 노출하지 않으며, 연결 상태(ACTIVE/AUTH_FAILED/SCRAPING_ERROR)를 서버값 그대로 배지로 표시한다. 인증실패·일시오류 상태는 매출 미수집으로 직결되어 정산 지연의 원인이 되므로, 이 화면의 상태값과 정책 문서의 스크래핑 상태·기준일 정의가 정합해야 한다.

연결 상태 배지
ACTIVE=연결됨(녹색), AUTH_FAILED=인증실패(빨강), SCRAPING_ERROR/ERROR=일시 오류(주황), 계정없음=미연결(회색).일시 오류 시 서버 statusMessage 또는 '일시적인 오류입니다. 잠시 후 다시 확인해 주세요.' 힌트.인증실패 시 '아이디 또는 비밀번호를 확인해 주세요.' 힌트.확정

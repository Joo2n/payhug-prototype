key note
base에서 카드사 행을 누르면 열리는 카드사 단위 상세. 상단은 해당 카드사의 어제 매출액→차감액→미리 받는 돈 요약, 하단은 건별 승인 내역 리스트(더 불러오기)로 구성된다.
No이름설명
1카드사명 헤더상단 타이틀이 선택한 카드사명(KB카드)으로 바뀐다. 날짜 네비·반영시간 블록은 base와 동일하게 유지되고 좌우 화살표로 카드사 유지한 채 날짜 이동.
2차감액 분해어제 매출액 − 차감액 = 미리 받는 돈 구조. 차감액 하위에 회색으로 카드 수수료와 페이허그 수수료를 들여쓰기 표기(deduction = cardFee + payhugFee). 면제 대상이면 페이허그 수수료 자리에 면제.
3미리 받는 돈(카드사)이 카드사 몫의 미리 받는 돈을 파란색으로 강조(transferAmount = net − 페이허그 수수료). base 카드 블록의 해당 행 금액과 일치.
4미리 받은 돈 내역두꺼운 구분선 아래 건별 승인 내역. 각 행은 카드사명·승인일시·건별 미리 받는 돈·결제수단(신용/체크/기타). 승인 내역 없으면 '승인 내역이 없어요'. 행 클릭 → 카드 거래 상세.
5내역 더 불러오기10건씩 페이징(hasMore). 초록 버튼 클릭 시 다음 페이지 append, 로딩 중 '불러오는 중...'.

카드사별 상세는 fetchCardSettlement(bizNo, card, date, page)로 카드사 코드 단위 집계와 건별 리스트를 함께 받는다. 요약부 차감액은 카드 수수료 + 페이허그 수수료 2단으로만 분해되며, base 페이허그 블록의 전산 수수료·시스템 이용료·예상 차액은 여기 나타나지 않는다(카드사 단위엔 채권매입 수수료만 귀속).

key note
약관 동의 후 서버가 생성한 계약서 이미지(서명 전)를 전체화면 오버레이로 보여주는 2단계. 페이지별 이미지를 스크롤로 확인하고 '내용을 확인했습니다'로 서명 단계로 넘어간다.
No이름설명
1전체화면 오버레이 전환약관 화면 위에 전체화면 계약서 뷰어가 덮임. 상단에 '이전', 제목 '계약서 확인', 우측 '확대' 버튼.
2계약서 이미지 렌더서버가 반환한 페이지별 이미지를 세로로 나열. 하단에 현재/전체 페이지 표시(예: 1/3).
3확대 안내 배너글씨가 작을 때 우측 상단 '확대'를 누르라는 안내 배너를 상단에 노출(축소 상태일 때).
4이전 버튼약관 동의(1단계)로 되돌아감. 확대 상태는 해제됨.
5내용을 확인했습니다하단 고정 버튼. 누르면 서명·수수료율 입력(3단계)으로 전환.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
미리보기 이미지는 서버 계약서 생성 API의 응답이며, 사업자·대표자·주소·계좌·파트너(총판)·투자자 정보를 본문에 채워 생성한다. 이 단계에서는 서명·수수료율이 비어 있고, 응답의 서명 위치 정보로 다음 단계에서 서명 입력칸/수수료율 입력칸을 켤지 결정한다.
연결계약서 생성 입력값
본문 채움 데이터
사업자명·사업자번호·대표자·주소·은행/계좌/예금주·연락처를 사업자 상세·사용자 정보에서 채움.가입 경로(직계약/총판)에 따라 파트너·투자자·파트너체인·참여자 배열을 함께 전송.확정
참여자 조회
다음 단계 진입 시 사용자 기준 계약 참여자 정보를 조회해 총판/제휴/투자자 역할을 본문에 반영.확정
계산입력칸 활성 판정
서명/수수료 칸 켜기
생성 응답의 서명 위치 목록에서 서명 타입 존재 시 서명 입력칸, 텍스트 타입 존재 시 수수료율 입력칸을 3단계에서 활성화.즉 어떤 입력을 받을지는 서버 템플릿이 결정.확정

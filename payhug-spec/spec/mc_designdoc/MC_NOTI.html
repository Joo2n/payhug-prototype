헤더 알림 드롭다운의 더보기로 진입하는 전체 알림 목록 화면이다. 안 읽은 알림 개수와 모두 읽음 버튼을 제공하며, 현재 코드는 항상 받은 알림이 없습니다 빈 상태를 표시한다.
No이름설명
1상단 타이틀·네비좌측 뒤로가기(‹)와 알림 제목, 우측 홈 아이콘. 뒤로가기는 대시보드, 홈은 메인(/)으로 이동.
2안 읽은 개수카드 상단 안 읽은 알림 N개 표시. 현재 값은 0으로 하드코딩. 실제 카운트 연동 전 기본값.
3모두 읽음 버튼우측 회색 버튼. 안 읽은 알림을 일괄 읽음 처리하는 용도. 현재 클릭 핸들러·처리 로직 미구현.
4알림 목록 영역카드 본문에 알림 항목이 나열될 자리. 최소 높이가 지정돼 빈 상태에서도 카드 형태 유지.
5빈 상태 문구항목이 없을 때 중앙에 받은 알림이 없습니다. 안내. 실제 데이터 연동 전 고정 노출.

일반 카드/배달 차액 행 금액을 탭했을 때 뜨는 계산 근거 툴팁. 예상값·실제값·차액 세 줄로 부호까지 보여준다.
No이름설명
1일반 차액 툴팁카드 행(예: KB카드 +3,200원) 금액 탭 시 표시. 세 줄 구성: 예상 수수료 / 실제 수수료 / 예상 지급 차액.
2부호 있는 차액차액 줄은 부호와 함께(예: +3,200원) 노출. 예상 대비 실제가 낮아 환급되는 구조가 그대로 드러난다.
3배달 라벨 변형배달 건이면 같은 위치의 라벨이 예상 입금예정금 / 실제 입금예정금으로 바뀐다(카드는 예상/실제 수수료).
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
일반 차액 툴팁은 isCard 값에 따라 라벨만 바뀌고 구조는 동일하다. 예상값(estimated)·실제값(actual)·차액(amount)을 그대로 표기해 '예상 수수료율로 미리 지급 → 실제 정산 후 차액 보정' 원리를 건별로 보여준다.
계산툴팁 구성
카드 건
예상 수수료 {estimated}원 / 실제 수수료 {actual}원 / 예상 지급 차액 {부호}{amount}원예: 예상 15,000 · 실제 11,800 → 차액 +3,200확정
배달 건
라벨이 '예상 입금예정금 / 실제 입금예정금 / 예상 지급 차액'으로 전환isCard 플래그로 라벨만 스왑, 계산·표기 구조는 동일확정
정책정책 지뢰
예상 수수료율 (C1)
'예상 수수료' 값이 어떤 요율로 산정됐는지 미확정. 툴팁 첫 줄 값의 근거 요율 확정 필요.확인필요
차액 라벨 (C4)
'예상 지급 차액'이라는 라벨이 정의 미확정인 채 툴팁·상단·행에 반복 노출. 정의 확정 전 문구 확정 불가.확인필요

회원가입 마지막 입력 단계(3단계·마지막)로 로그인 비밀번호를 설정하는 화면이다. 새 비밀번호·확인 두 필드로 구성되며, 정책(8~16자·영문+숫자+특수문자)을 충족하고 두 값이 일치해야 가입이 완료된다.
No이름설명
1진행 단계(3단계)프로그레스 세 번째 점 활성화. 본인인증 성공 후 진입. (점 4개 중 4번째는 코드상 항상 비활성 — 실제 단계는 3개, 확인필요)
2제목/안내“비밀번호를 입력해 주세요 / 사장님의 소중한 정보를 보호하기 위해 필요해요”.
3새 비밀번호비밀번호 정책 검증 필드. 눈 아이콘으로 표시/숨김 전환. 미충족 시 조건 체크리스트/오류 문구 노출.
4비밀번호 확인동일 값 재입력. 일치 시 ‘비밀번호가 일치합니다’, 불일치 시 오류 안내.
5다음(가입 완료)정책 충족+일치 시에만 활성화. 누르면 가입 처리 후 자동 로그인되어 완료 화면으로 이동.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
비밀번호는 가맹점 웹 공통 정책(8~16자, 영문·숫자·특수문자 필수, 공백·한글 불가, 허용 특수문자 !@#$%^&*() 만)을 따르며 회원가입·재설정 화면이 동일 규칙을 공유한다. [다음]에서 본인인증으로 확정된 이름·CI·통신사·동의약관·유입코드를 묶어 가입 API에 전송하고, 성공 시 토큰·유저정보를 저장해 자동 로그인 상태로 완료 화면으로 넘어간다.
정책비밀번호 정책
필수 조건
길이 8~16자, 영문·숫자·허용 특수문자 각 1개 이상 포함.공백·한글·이모지 등 비ASCII 문자 불가, 허용 특수문자는 !@#$%^&*() 만.확정
입력 필터
비ASCII 문자는 저장하지 않고 제거, 16자 초과 시 잘라냄.한글 등 IME 조합 입력은 조합 종료 후 정책 필터 적용.확정
오류 우선순위
공백 > 허용되지 않은 특수문자 > 조건 미충족 순으로 문구 1개만 노출.확정
연결가입 처리
가입 요청
CI·통신사·전화번호·이름·비밀번호·동의약관ID·유입코드(파트너/투자자/영업/제휴/사업자/대리점)를 묶어 가입 API 호출.확정
자동 로그인
성공 응답의 토큰·유저정보를 저장 후 완료 화면으로 이동(별도 로그인 불필요).실패 시 서버 메시지를 오류 토스트로 상단 노출.확정

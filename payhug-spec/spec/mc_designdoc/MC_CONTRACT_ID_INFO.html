2제목/부제'사장님의 정보가 맞나요? / 추출된 신분증 정보가 맞는지 확인해 주세요'.
3신분증 종류(읽기전용)주민등록증/운전면허증 구분을 읽기전용 박스로 표시. 여기선 '주민등록증'.
4성명·주민등록번호·발급일자3개 편집 가능 입력창. 주민등록번호는 뒷자리 마스킹된 형태로 표시(예: 850312-1******).
5OCR 자동입력 힌트 토스트'OCR로 자동 입력되었어요 / 잘못 인식된 값이 있으면 직접 수정해주세요' 초록 말풍선, 약 10초 후 자동 소멸.
6정보가 일치해요 / 다시 첨부하기'정보가 일치해요' 누르면 신분증 등록 처리 후 완료 모달. '다시 첨부하기'는 업로드 화면으로 복귀.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
업로드 단계에서 주민번호 뒷자리를 검게 마스킹해 저장한 이미지와 함께, 확정한 필드값으로 신분증을 등록한다. 원본(뒷자리 노출) 이미지는 보관하지 않는 fail-closed 정책이 앞 단계에 적용되어 있다. 등록 성공 시 완료 모달을 띄우고 계약 안내 화면(수정 모드면 해당 사업장)으로 복귀한다.

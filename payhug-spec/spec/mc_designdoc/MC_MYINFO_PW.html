key note
페이허그 계정의 비밀번호를 변경하는 화면. 현재 비밀번호·새 비밀번호·새 비밀번호 확인을 입력하고, 변경 성공 시 자동 로그아웃 후 재로그인을 유도한다.
No이름설명
1현재 비밀번호본인 확인용 현재 비밀번호 입력. 눈 아이콘으로 표시/숨김 토글.
2새 비밀번호'영문, 특수문자, 숫자 조합 8자 이상' 정책. 입력 규칙 충족 여부를 실시간 검증·안내.
3새 비밀번호 확인재입력 일치 검증. 불일치 시 '비밀번호를 한번 더 입력해주세요' 등 안내.
4변경하기 버튼현재 비밀번호 입력+새 비밀번호 규칙 충족+확인 일치 시에만 활성(연녹색).
5변경 후 자동 로그아웃성공 토스트('다시 로그인해주세요') 후 1.5초 뒤 인증 정보 삭제·로그인 화면 이동.

비밀번호 변경은 이 클러스터에서 유일하게 직접 쓰기(변경) 가능한 항목이다. 클라이언트에서 비밀번호 정책(영문+특수문자+숫자 8자 이상)과 확인 일치를 검증한 뒤 서버(/user/change-password)로 전송하고, 성공 시 강제 로그아웃으로 세션을 재발급받게 한다. 연동 계정(외부 플랫폼) 비밀번호와는 전혀 다른 대상임에 주의.
연결변경 처리
제출 API
/user/change-password에 사용자ID·현재 비밀번호·새 비밀번호 전송.성공 시 입력 초기화, 실패 시 서버 메시지 토스트.확정
성공 후 세션
1.5초 후 clearAuth로 인증 삭제, 로그인 화면 이동(재로그인 강제).확정

복잡도 규칙
영문+특수문자+숫자 조합 8자 이상(usePasswordPolicyField).확인란 일치 필수.확정

여기는 페이허그 로그인 비밀번호 변경.여신협회·배달앱 계정 비밀번호는 연동 계정 관리에서 별도 관리(혼동 금지).확정

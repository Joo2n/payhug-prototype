key note
개설한 하나은행 출금전용 락계좌 통장 사진을 첨부하면 OCR로 계좌주명·은행명·계좌번호를 자동 추출해 다음 확인 단계로 넘기는 화면. 일반 입출금 통장이 아닌 출금전용 락계좌 통장을 올려야 함을 강하게 안내한다.
No이름설명
15단계 진행바 (3/5)계약 3스텝 내 통장 업로드 지점. 앞 3칸 완료 표시.
2출금전용 락계좌 경고 배너'출금만 가능' 배지와 함께 일반 입출금 통장이 아닌 출금전용 락계좌 통장을 반드시 첨부하라고 강조. 오첨부 방지 목적.
3통장 사진 첨부 영역클릭 시 파일 선택. 하나은행 통장 형태의 일러스트 플레이스홀더, 선택 후 미리보기 이미지로 대체.
4사진 첨부하기 버튼OCR 분석(FastAPI /ocr/analyze-account) 호출. 분석 중 전체화면 로딩('계좌 정보를 분석하고 있어요') 표시.
5OCR 실패 안내 모달이미지 유형 불일치·분석 실패 시 서버 메시지 또는 '잠시 후 다시 시도' 안내 모달. 다음 단계로 넘어가지 못함.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
통장 이미지를 FastAPI OCR로 분석해 계좌주명·은행명·계좌번호를 추출하고, 원본 파일은 IndexedDB(pendingPrePaymentFile)에 임시 저장한 뒤 확인 화면으로 쿼리 전달한다. 이 화면 자체는 락계좌를 등록하지 않으며, purpose=PRE_PAYMENT 태그만 붙여 다음 단계에서 하나은행 검증·1원 인증을 수행하게 한다.
연결OCR 분석·파일 전달
OCR API
getFastApiUrl('/ocr/analyze-account')로 통장 이미지 POST. 응답 status==='success' 시 account_holder·bank_name·account_number 추출.status==='error'거나 HTTP 실패 시 안내 모달, 진행 차단.확정
원본 파일 임시보관
savePendingFile('pendingPrePaymentFile', file)로 브라우저에 원본 보관. 다음 확인 화면에서 1원 인증 확정 시 함께 전송, 성공하면 삭제.가설: 페이지 이동 사이 파일 유실 방지를 위한 IndexedDB 사용.확정
다음 화면 이동
/contract/confirm-pre-payment?holder=..&bank=..&number=..&purpose=PRE_PAYMENT 로 OCR 결과를 쿼리로 전달. businessId·addBusiness·edit 승계.확정

출금전용 락계좌 통장 한정
'일반 입출금 계좌와 다르니 반드시 출금 전용 락계좌 통장 첨부'. 화면 카피로 강제하나 OCR이 계좌 종류(출금전용 여부)까지 판별하는지는 불명.확인필요: 잘못된 종류의 하나은행 통장을 올렸을 때 서버가 거르는 규칙 유무.확인필요

key note
프로필 드롭다운(또는 모바일 메뉴)에서 로그아웃을 누르면 뜨는 확인 모달이다. 실수 로그아웃을 막기 위한 2단계 확인이며, 확인 시 인증정보를 지우고 로그인 화면으로 이동한다.
No이름설명
1모달 제목·닫기상단에 로그아웃 제목과 우측 X(닫기) 버튼. X 또는 바깥 딤 영역을 누르면 모달만 닫히고 로그인 상태는 유지.
2확인 문구본문은 로그아웃 할까요? 한 줄. 되돌릴 수 없는 액션이 아니므로 경고성 문구 없이 단순 확인만 요청.
3취소 버튼회색 보조 버튼. 로그아웃을 중단하고 모달을 닫음. 현재 화면(대시보드) 유지.
4확인 버튼파란색 주 버튼. 저장된 인증 토큰·사용자 정보를 삭제하고 로그인 화면(/login)으로 이동.
5딤 배경뒤 화면을 어둡게 덮는 오버레이. 대시보드 카드가 비활성처럼 흐려짐. 딤 클릭 = 취소와 동일.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
로그아웃은 클라이언트 인증정보(토큰·사용자)를 지우고 로그인 화면으로 보내는 순수 프론트 동작으로, 서버 세션 만료 API 호출은 코드상 확인되지 않는다. 확인 모달은 헤더 컴포넌트 내부 상태로만 제어되어 데스크톱 프로필 드롭다운과 모바일 메뉴 양쪽에서 동일하게 재사용된다.

clearAuth()로 로컬 저장 인증정보 삭제 후 /login으로 라우팅.서버 측 세션·토큰 무효화 API 호출은 코드에 없음(클라이언트 정리만).가설

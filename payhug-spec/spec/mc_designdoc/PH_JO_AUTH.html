회원가입 2단계로 휴대전화번호를 입력받아 KCB 본인인증을 수행하는 화면이다. 인증 전 이미 가입된 번호인지 먼저 검사하고, 신규 번호만 통신사 본인인증 팝업으로 진행한다.
No이름설명
1진행 단계(2단계)프로그레스 두 번째 점 활성화. 1단계 약관 완료 후 진입. (점 4개가 렌더되나 4번째는 코드상 항상 비활성 — 실제 단계는 3개, 확인필요)
2제목/안내“본인 확인이 필요해요 / 본인의 휴대전화번호로 인증해 주세요”.
3휴대전화번호 입력숫자만 입력, 자동으로 000-0000-0000 형식으로 표기. 12자리 이상일 때만 인증 버튼 활성화.
4본인 인증 버튼누르면 ①가입 여부 확인 → ②KCB 인증토큰 발급 → ③통신사 본인인증 팝업 순으로 진행. 인증 성공 시 ‘인증 완료’로 라벨 변경.
5인증 결과 수신팝업에서 인증 성공 시 이름·CI·통신사 정보를 전달받아 저장하고, 완료 토스트 노출 후 3단계로 자동 이동.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
본인인증은 KCB(safe.ok-name.co.kr) 팝업 방식으로, 백엔드 콜백이 처리 후 부모창에 성공/실패 메시지를 전달하는 postMessage 구조다. 인증으로 실명·CI·통신사가 확정되며 이 값이 최종 가입 요청의 본인확인 근거가 된다. 인증 전 `/auth/check-phone`으로 중복 가입을 선차단한다.
연결본인인증 흐름
중복번호 선검사
인증 전 입력번호로 기가입 여부 조회.기가입이면 인증 진행 없이 ‘이미 가입된 번호’ 모달(PH_JO_AUTH_EXIST).확정
KCB 인증
인증토큰 발급 성공 시 별도 팝업(430×640)으로 통신사 본인인증 실행.팝업 차단 시 해제 안내 알림.확정
결과 전달
백엔드 콜백 처리 후 부모창으로 성공/실패 메시지 전달.성공: 이름·CI·통신사 수신 → 완료 토스트 → 3단계 이동. 실패: 재시도 안내.확정

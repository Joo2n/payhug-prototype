key note
세션(토큰)이 만료되어 강제 로그아웃된 뒤 로그인 화면으로 돌아온 상태. 상단에 세션 만료 안내 토스트가 뜬다.
No이름설명
1세션 만료 토스트화면 상단에 안내 토스트 "세션이 만료되어 다시 로그인해 주세요." 노출. 정보성(에러 아님) 안내다.
2진입 조건주소에 만료 사유 파라미터(reason=expired)가 붙어 재진입할 때만 토스트가 표시된다.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
API 호출이 인증 만료(401)를 받으면 인증정보를 정리하고 만료 사유 파라미터를 붙여 로그인 화면으로 강제 이동시킨다. 로그인 화면은 그 파라미터를 감지해 정보성 토스트를 1회 노출한다. 토큰 유효기간은 150분으로, 만료 시 이 플로우를 탄다.
연결만료 처리 흐름
401 감지·강제 로그아웃
공통 API 클라이언트가 응답 401을 받으면 인증정보(쿠키·스토리지)를 모두 정리.이후 만료 사유 파라미터(reason=expired)를 붙여 로그인 화면으로 이동.확정
토스트 노출 조건
로그인 화면 진입 시 주소의 만료 사유 파라미터를 확인해 정보성 토스트를 노출.토큰 유효기간 150분 경과가 대표 만료 트리거.확정
안내 등급
에러가 아닌 정보(info) 등급 토스트로, 재로그인만 유도한다.확정

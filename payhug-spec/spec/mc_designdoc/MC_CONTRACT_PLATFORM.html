key note
계약 마지막 단계로 매출 수집용 플랫폼 계정(여신금융협회·배민·쿠팡이츠·요기요)의 아이디·비밀번호를 등록하고 매출 조회로 연동을 검증하는 화면. 캡처는 2개 연결됨·2개 인증실패가 섞인 혼합 상태다.
No이름설명
1여신금융협회(연결됨)카드 매출 수집용. 아이디 채워지고 '연결됨' 배지, 버튼은 '재검증'. 회원가입 바로가기 링크 제공.
2배달의민족(연결됨)배민 매출 수집용. '연결됨' 배지·'재검증' 버튼. 배민 사장님 바로가기 링크.
3쿠팡이츠(인증실패)'인증실패' 배지. '매출 조회 중 일시 오류가 발생했어요' 메시지와 '다시 시도' 버튼. 일시 오류 유형.
4요기요(인증실패)'인증실패' 배지. '아이디 또는 비밀번호가 올바르지 않아요' 메시지와 '다시 시도' 버튼. 자격 오류 유형.
5저장·검증 버튼(행별)각 행에 아이디/비밀번호 입력 후 '저장 및 검증'. 상태에 따라 '재검증'/'다시 시도'로 라벨 변화, 처리 중 '저장 중→검증 중' 오버레이.
6다음 단계하단 CTA. 4개 중 최소 1개라도 연동 성공해야 활성화되어 다음(약관) 단계로 진행.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
플랫폼 계정은 매출 데이터 수집(스크래핑) 자격이며, 저장 후 실제 매출 조회를 돌려 연동 성공 여부를 판정한다. 저장된 계정 중 서버 연동상태 ACTIVE인 것만 '연결됨'으로 표시하고 나머지는 재인증 유도. '다음 단계'는 4개 전부가 아니라 1개 이상 연동되면 열린다.
연결저장·검증 흐름
두 단계 처리
행별로 계정 저장(saveExternalAccount) → 매출 조회로 검증. 카드는 카드매출 조회, 배달앱은 플랫폼명 기반 배달매출 조회.확정
연결 상태 판정
기존 저장분 로드 시 서버 연동상태 ACTIVE만 '연결됨(verified)'. 그 외는 '인증실패(failed)'로 두고 재인증 유도.확정
실패 메시지 유형
자격 오류: '아이디 또는 비밀번호가 올바르지 않아요'. 일시 오류: '매출 조회 중 일시 오류' 등 서버 메시지 표시.확정
플랫폼 목록·링크
4종 고정: 여신금융협회(카드)·배민·쿠팡이츠·요기요. 각 사장님 사이트/회원가입 바로가기 외부 링크 제공.확정
정책진행 조건·정책
다음 단계 활성 조건
4개 중 1개 이상 verified면 '다음 단계' 활성화. 전 플랫폼 필수는 아님.확정
최소 연동 요건
실제 선정산 심사/운영에 어떤 플랫폼이 필수인지(예: 카드 필수 여부), 1개 연동만으로 계약 진행이 정책상 충분한지 확인 필요.확인필요
자격증명 보관 정책
플랫폼 아이디/비밀번호를 저장해 반복 스크래핑에 사용. 저장·암호화·재검증 주기 등 보안 정책은 코드 범위 밖으로 확인 필요.확인필요
매출 수집 용어
'플랫폼 계정=매출 수집(스크래핑) 자격'. 화면 노출은 '연동/매출 수집'으로, 내부 스크래핑·조회 용어와 구분해 표기.가설

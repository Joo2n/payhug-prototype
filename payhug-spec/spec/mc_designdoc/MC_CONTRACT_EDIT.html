key note
계약 안내 허브의 수정 모드 변형(edit=true). 문구가 '등록된 서류를 수정할 수 있어요'로 바뀌고 각 항목이 클릭 가능한 링크(우측 화살표)로 전환되며, 하단 버튼은 '대시보드로 이동'이 된다.
No이름설명
1제목/부제 변경'등록된 서류를 수정할 수 있어요 / 수정할 항목을 선택해 주세요' 로 문구 전환.
2항목 클릭 활성화6개 항목 각 우측에 화살표(>)가 붙고 클릭 시 해당 단계의 업로드/등록 화면으로 이동해 재제출 가능.
3하나은행 안내 숨김기본 모드의 '하나은행 통장사본 확인' 안내 블록이 수정 모드에서는 노출되지 않는다.
4대시보드로 이동 버튼기본 모드의 '준비 완료' 대신 '대시보드로 이동' CTA. 수정만 하고 대시보드로 빠져나감.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
수정 모드는 edit=true 파라미터 또는 계약 상태 PENDING일 때 진입한다. 이미 심사가 진행 중인 계약도 서류 교체가 가능하도록 항목별 재진입 경로를 열어주며, 각 단계로 이동할 때 edit=true를 유지해 등록 완료 후 다시 이 수정 화면으로 되돌아온다. 심사 중 서류 변경이 심사 상태·재심사 트리거에 어떤 영향을 주는지는 정책 미확정이다.

수정 모드 진입

복귀 흐름

key note
입금받을 계좌(정산계좌) 통장 사진을 첨부하고 OCR로 계좌 정보를 자동 추출하는 화면. '입출금이 자유로운 일반 계좌'를 등록하도록 안내하며, 출금 전용 락계좌 오등록을 방지한다.
No이름설명
1진행 인디케이터5칸 중 4칸 초록. 4단계 입금계좌 단계.
2안내 문구'입금 받을 계좌 사진을 첨부해 주세요' — 정산금 수령 계좌 통장 첨부 요청.
3자유 입출금 계좌 안내 배너'정산 금액을 받을 계좌 / 입금과 출금이 자유로운 일반 계좌를 등록 / 출금 전용 락계좌가 아닌지 확인'. 계좌 종류 오등록 방지 가이드.
4통장 첨부 드롭존통장 형태 플레이스홀더 위 '클릭하여 사진 선택'. 클릭 시 이미지 파일 선택, 선택하면 미리보기로 대체된다.
5사진 첨부하기 버튼주 액션. 선택 파일을 OCR 분석 서버로 전송, 성공 시 추출값과 함께 정보 확인 화면으로 이동.
6분석 중 오버레이업로드 후 '계좌 정보를 분석하고 있어요' 전체 화면 로딩. 실패 시 안내 모달.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
통장 이미지를 OCR 서버(FastAPI /ocr/analyze-account)로 보내 예금주·은행·계좌번호를 추출한다. 원본 파일은 브라우저 임시 저장소에 저장돼 뒤 인증 단계까지 이어지고, 추출값은 URL 파라미터로 확인 화면에 전달된다. 이 화면은 게이트(전용계좌 선등록)를 통과해야 실제 사용 가능하다.
연결OCR·파일 처리
OCR 분석
첨부 이미지를 계좌 OCR 분석 API로 POST. 성공(status=success) 시 예금주·은행명·계좌번호 반환.확정
실패 처리
이미지 유형 불일치·서버 오류·연결 실패별로 각각 안내 모달. '잠시 후 다시 시도' 문구 케이스 별도 전달.확정
파일 임시 보관
OCR 성공 시 원본 파일을 브라우저 임시 저장소에 저장 후 확인/인증 화면으로 이어붙임.확정
확인 화면 전달
추출값을 URL 파라미터(holder/bank/number, purpose=SETTLEMENT)로 넘겨 정보 확인 화면으로 이동.확정
정책계좌 종류 정책
일반 입출금 계좌 강제
입금받을 계좌는 입출금 자유 일반 계좌여야 함. 출금 전용 락계좌 등록을 배너로 명시 차단 안내.확정
진입 게이트 종속
신규 흐름에서는 전용계좌(락계좌) 등록·빠른조회 선행이 필요하며, 미충족 시 게이트 모달로 차단됨(MC_CONTRACT_DEPOSIT_GATE).확정
OCR 오인식 방지 검증
락계좌/일반계좌를 OCR·시스템이 자동 판별하는지, 사용자 확인에만 의존하는지 정책 확인 필요.확인필요

key note
base 배달앱 행을 누르면 열리는 배달 플랫폼 단위 상세. 카드사별 상세와 골격은 같으나 차감액 분해에 플랫폼 차감액·광고비·페이허그 수수료 3단이 들어가고, 리스트에 만나서결제(음수) 건이 섞인다.
No이름설명
1플랫폼 헤더타이틀이 플랫폼명(배달의 민족)으로. 날짜 네비·반영시간은 base와 동일.
2차감액 3단 분해차감액 하위에 배달의 민족 차감액(플랫폼 수수료), 광고비, 페이허그 수수료. deduction = 배달사 차감액 + 광고비 + 페이허그 수수료. 카드보다 한 줄 많다.
3광고비 + 툴팁광고비는 adCost>0일 때만 노출, 라벨 옆 ? 툴팁(우리가게배민 등 배달앱 광고 이용료 차감). 이 툴팁 펼침 상태가 ST_MA_DELIV_TIP.
4미리 받는 돈(플랫폼)파란색 강조. transferAmount = netAll − 광고비 − 페이허그 수수료.
5주문 내역 리스트건별 주문: 매장명·주문일시·건별 미리 받는 돈·결제수단(바로결제/만나서 결제). 행 클릭 → 배달 주문 상세, 더 불러오기 10건 페이징.
6만나서결제 음수 표기만나서 결제 건은 선정산에서 차감되므로 금액을 흐린 회색 음수(-18,500원)로 노출(괄호 없이 차감으로 읽히게). 바로결제 건은 진한 검정.

fetchDeliverySettlement(bizNo, source, date, page)로 플랫폼 코드(BM/CPE/YO) 단위 집계+주문 리스트를 받는다. 카드와 달리 차감 구성에 플랫폼 수수료·광고비가 추가되고, 만나서결제(오프라인 수령)는 선정산 제외분이라 건별 금액이 음수로 내려와 리스트에서 차감으로 표현된다.

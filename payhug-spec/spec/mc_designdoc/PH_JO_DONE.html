key note
가입이 완료되어 자동 로그인된 상태의 환영 화면. 상단에 알림·프로필(가입자명)이 나타나고, 매출 조회를 시작하도록 유도하는 CTA를 제공한다.
No이름설명
1로그인 헤더가입 직후 자동 로그인 상태라 헤더에 알림 벨과 프로필(가입자 이름·인증 완료 배지) 노출.
2환영 일러스트매장+코인 일러스트로 가입 완료를 축하.
3환영 메시지“OOO님 환영해요! 페이허그 서비스를 이용할 수 있어요 / 내 매장 매출을 조회하고 선정산 서비스를 신청해 보세요”. 이름은 가입 시 URL 파라미터로 전달.
4매출 조회하기주요 CTA. 누르면 대시보드(매출)로 이동. 첫 액션을 선정산 신청 전 ‘매출 조회’로 유도.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
이 화면은 가입 API 성공 후 저장된 토큰으로 이미 인증된 상태에서 진입하며, 표시되는 이름은 완료 라우트의 name 파라미터에서 읽는다(없으면 ‘사장님’). CTA 목적지가 대시보드(매출 조회)라는 점에서, 가입 완료 ≠ 선정산 이용 시작이며 매출 연동·선정산 신청은 이후 단계임을 시사한다.

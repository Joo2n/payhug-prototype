key note
사업자등록증 사진을 첨부해 OCR로 분석하고 정보 확인 화면으로 넘기는 업로드 단계. 개인/법인 유형을 먼저 고르고, 최대 3장까지 한 번에 첨부할 수 있다.
No이름설명
11/5 진행바프로그레스바 1칸만 채워진 상태(계약 첫 단계).
2제목/부제'사업자등록증 사진을 첨부해 주세요 / 사장님의 사업자등록증 사진을 첨부해 주세요'.
3사업자 유형 선택'개인사업자 / 법인사업자' 라디오 2택. 기본값은 개인사업자 선택 상태.
4사진 첨부 영역'클릭하여 사진 선택' 점선 카드. 여러 장 선택 시 대표 미리보기 위에 '+N장' 배지 표시.
5최대 3장 안내'사업자등록증이 여러 장인 경우 한 번에 선택해 주세요 (최대 3장)' 안내 문구.
6사진 첨부하기 버튼파일 선택 전 비활성. 누르면 OCR 분석 실행, '분석 중...' 전체화면 로딩('사업자등록증을 분석하고 있어요') 노출 후 정보 확인 화면으로 이동.
정책 · 계산 로직 · 데이터 출처 코드 기반 심화 · 확정 / 가설 / 확인필요 표기
여러 장을 세로로 합쳐 하나의 이미지로 임시 저장한 뒤 다음 단계에서 등록에 사용한다. OCR 결과로 사업자번호 중간자리를 검사해 개인/법인을 자동 판정하고, 사장님이 고른 유형과 다르면 '유형 확인' 모달로 자동 보정한 뒤 정보 확인 화면으로 넘긴다. 유형 판정 로직이 사용자의 라디오 선택보다 우선한다.
연결OCR 분석·전달
이미지 처리
최대 3장을 세로 병합해 하나의 사업자등록증 임시 파일로 저장OCR 분석 성공 시 사업자번호·상호·대표자·주소·업태·종목·개업일 등을 다음 화면 파라미터로 전달(법인이면 법인등록번호 등 추가)확정
실패 처리
분석 실패·서버 오류 시 안내 모달('이미지 분석에 실패했습니다. 잠시 후 다시 시도해 주세요' 등)확정
정책개인/법인 자동 판정
유형 자동 보정
OCR 사업자번호 중간자리로 법인 여부 자동 판정 → 사용자가 고른 유형과 다르면 '사업자 유형 확인' 모달로 안내 후 자동 변경판정 결과가 라디오 선택보다 우선확정
판정 폴백
사업자번호 자릿수가 부족하면 OCR의 is_corporate 값으로 판정가설

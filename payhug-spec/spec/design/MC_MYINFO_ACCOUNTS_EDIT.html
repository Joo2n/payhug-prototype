key note
화면 성격  연동 계정 관리에서 특정 플랫폼 행의 [변경]/[연결하기]를 누르면 그 행만 입력 폼으로 바뀌는 인라인 상태 (별도 화면 아님) 데이터  캡처는 여신금융협회 행이 편집 상태 · 나머지 행(배민·쿠팡이츠·요기요)은 연결 표시 그대로 유지 핵심  저장하면 실제 매출 조회로 자격증명 검증 · 저장된 비밀번호는 마스킹만 표시
No이름설명
1진입 연결 행의 [변경] 또는 미연결 행의 [연결하기]를 누르면 그 행이 입력 폼으로 전환같은 화면 안 인라인 전환 — 다른 플랫폼 행은 그대로 유지
2입력칸 아이디 입력칸 : 입력창 안내문 "아이디"변경(연결됨)으로 진입하면 기존 아이디 미리 채워짐 · 연결하기(미연결)로 진입하면 빈칸비밀번호 입력칸 : 비어 있음, 입력창 안내문 "새 비밀번호 입력"둘 다 필수 — 하나라도 비면 저장 버튼 비활성, 눌러도 "아이디와 비밀번호를 모두 입력해 주세요."
3안내문구 입력칸 아래 회색 안내 (원문)"보안을 위해 저장된 비밀번호는 표시되지 않아요. 변경하려면 새 비밀번호를 입력해 주세요."
4버튼 [변경 저장] + [취소]저장 버튼 라벨 : 연결된 계정이면 "변경 저장", 미연결이면 "연결"[취소] : 입력 버리고 원래 표시(연결 정보 또는 미연결)로 복귀
5저장
검증		 저장 시 계정을 저장한 뒤 실제 매출 조회로 자격증명을 검증여신금융협회 = 카드 매출 조회 / 배달앱 = 해당 앱 매출 조회로 검증저장·검증 동안 입력칸이 흐려지고 비활성, 폼 위에 오버레이 "계정 변경 중..."상황별 토스트성공 → "○○ 계정이 변경되었습니다." (미연결이면 "연결되었습니다") → 목록 다시 불러오고 폼 닫힘실패 → 서버 메시지, 없으면 "아이디 또는 비밀번호를 확인해 주세요."오류 → "처리 중 오류가 발생했습니다."

화면 성격  정산 정책(수수료 배분 규칙) 상품을 만들고 관리하는 어드민 목록 데이터  현재는 예시(목업) 8개 상품 (ID 1~8) 기준 진입하면 자동으로 불러옴 (다른 탭 갔다 돌아오거나 창 포커스 복귀 시 다시 불러옴) 새로고침 버튼으로 수동 재조회

목록		 정렬 순서서버가 준 순서 그대로 나열 (화면에서 바꾸는 정렬·검색·필터 없음)카드 항목유형 뱃지 · 상품명 · 설명 · 우측 ID: 번호설명은 값이 있을 때만 상품명 아래 회색으로 표시상품명·설명에 박힌 수수료율(1% · 1.5% · 0.6%)도 예시 표기 — 정책 수수료율 아님(C1)3-1 유형 뱃지일반 = 초록 · 다우 = 보라펼침카드의 상품명 영역이나 펼침(∨)을 누르면 상세 펼침 [AD_PRODUCT_GENERAL]·[AD_PRODUCT_DAOU]한 번에 한 카드만 펼쳐짐 (다른 카드를 펼치면 이전 것 닫힘)상황별 문구불러오는 중 → "로딩 중..."상품이 하나도 없음 → "등록된 상품이 없습니다."

key note
화면 성격  모바일(태블릿 미만 폭) 전용 헤더 햄버거 드로어 — 넓은 화면에선 햄버거 숨김, 대신 로그인 시 알림 벨[MC_COMMON_NOTI_DD]·프로필[MC_COMMON_PROFILE] / 비로그인 시 로그인·시작하기 노출 데이터  로그인 여부는 저장된 인증 토큰 유무로 판정 · 프로필 이름은 저장된 로그인 정보의 이름 그대로(없으면 빈칸) 로드  진입 직후 로그인 판정 전엔 빈 헤더 바만 표시(깜빡임 방지) · 이후 로그인 여부로 드로어 내용 분기(로그인=프로필+메뉴 / 비로그인=로그인·시작하기) 캡처는 로그인 상태 대시보드의 좌측 크롭 — 우측 햄버거·알림·프로필이 잘려 안 보이고, 드로어 패널·백드롭·로그아웃 모달은 미캡처. 좌측 마커 2~5는 열렸을 때 예상 위치

1헤더바
햄버거		 화면 최상단 헤더 바 — 좌측 로고, 우측 햄버거 버튼햄버거는 태블릿 미만 폭에서만 노출 (넓은 화면에선 숨고, 로그인 시 알림 벨·프로필 / 비로그인 시 로그인·시작하기가 대신 나옴)로고 누르면 이동로그인 시 → 대시보드[MC_DASH] / 비로그인 시 → 랜딩 홈[MC_LANDING]햄버거 누르면 드로어 열림/닫힘 토글아이콘 전환 : 닫힘 = 3줄 햄버거 / 열림 = X(닫기)(예외) 메인 랜딩(/) + 비로그인일 땐 헤더가 초록 배경으로 바뀜햄버거·드로어 없이 [선정산 신청하기]·[로그인] 버튼이 바로 노출 (드로어 안 뜸)
2드로어
백드롭		 드로어는 헤더 바로 아래에서 아래로 펼쳐짐 (화면 좌우 꽉 채움, 흰 배경·그림자)뒤 배경은 반투명 검정 백드롭으로 덮임 (헤더 아래 영역)백드롭을 누르면 드로어 닫힘드로어 안 링크를 누르면 자동으로 닫힘

2플랫폼
현재상태		 플랫폼별 현재 상태카드·배달의민족·요기요·쿠팡이츠 4개 카드 고정 노출(항상 4장, 필터와 무관)
2-1 상태 뱃지(점+글자)
정상=초록 점 / 장애 발생 중=빨강 점 / 장기 장애=진한 빨강 점
상황별 본문 문구장애 중 → "미해소 N건" · "N일째 지속" · "최근 대상일 YYYY-MM-DD"
정상인데 과거 잔여 있음 → "최근 수집 정상" · "과거 미해소 잔여 N건 (최근 YYYY-MM-DD)"
정상·잔여 0 → "미해소 장애 없음"
정상/장애 발생 중/장기 장애 판정·'N일째 지속' 산정 기준은 서버값 그대로 표시 — 개발 확인 필요
3기간·필터 기간 프리셋(7개)오늘 · 어제 · 이번 주 · 지난 주 · 이번 달 · 지난 달 · 최근 3개월
현재 기간과 정확히 일치하는 프리셋은 파랑으로 강조 표시
입력 필드시작일 ~ 종료일 (달력 입력)
기본값(default : 오늘로부터 30일 전 ~ 오늘)
플랫폼 : 전체 플랫폼 / 카드 / 배달의민족 / 요기요 / 쿠팡이츠
상태 : 전체 상태 / 감지 (미해소) / 예상 정산 중 / 해소 (대사 대기) / 대사 완료
[조회] · [초기화] 버튼
[초기화] : 기간 기본값 복원 + 플랫폼·상태 '전체'로 되돌림
재조회 방식(중요)기간·상태 : 서버에 다시 물어 목록을 다시 불러옴(값 바꾸면 자동 재조회)
플랫폼 : 서버에 안 보냄 — 이미 불러온 목록에서 즉시 걸러짐
[조회] 버튼은 기간·상태가 이미 자동 재조회되고 플랫폼은 화면 필터라 사실상 중복 — 누르면 같은 요청을 다시 보낼 뿐
유효성시작일 > 종료일이면 [조회] 비활성 + 빨강 경고 "시작일은 종료일보다 이후일 수 없습니다."
눌러도 알림(alert)으로 막혀 실행되지 않음 / 달력 자체도 시작일 max=종료일, 종료일 min=시작일로 제한
불러오는 중 [조회] 라벨이 "조회 중..."으로 바뀌고 버튼 비활성
4요약카드 3장 : "전체 (기간 내)" · "감지 (미해소, 전체)" · "예상 정산 중 (전체)"
뱃지 색 : 전체=회색 · 감지(미해소)=빨강 · 예상 정산 중=주황
세 숫자 모두 서버가 준 전체 기준값 — 플랫폼 필터·화면 목록 행수와 무관(플랫폼을 골라도 안 줄어듦)
5장애
이력표		 표 항목(9열)대상일 · 플랫폼 · 사업자번호 · 장애 유형 · 상태 · 발생 · 예상 정산 · 해소 · 대사 완료
장애 유형 값 : API 오류 / 타임아웃 / 데이터 없음 / 주말 데이터 없음
5-1 플랫폼 뱃지 색
카드=연둣빛 초록(브랜드색) · 배달의민족=하늘 · 요기요=로즈(분홍) · 쿠팡이츠=주황
5-2 상태 뱃지 색
감지 (미해소)=빨강 · 예상 정산 중=주황 · 해소 (대사 대기)=파랑 · 대사 완료=진초록
시각 컬럼발생·예상 정산·해소·대사 완료 4개 : "YYYY. MM. DD. 오전/오후 HH:MM" 표기
값 없으면 "-"(미해소 건은 예상 정산/해소/대사 완료가 대부분 "-")
정렬·인터랙션정렬 기준 코드에 없음 — 서버가 준 순서 그대로 표시(대상일 뒤섞여 보임), 정렬 기준 개발 확인 필요
행에 마우스 올리면 배경 옅게 강조 / 단 행 클릭 이동 없음(조회 전용, 조치 버튼 없음)
상황별 문구로딩 → 스피너만 표시(문구 없음)
0건 → "조회된 장애 이력이 없습니다." (검색어 유무 분기 없이 단일 문구, 조회 실패 시에도 동일)

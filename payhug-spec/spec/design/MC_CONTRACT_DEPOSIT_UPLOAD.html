화면 성격   계약 4/5단계 입금계좌 등록 중 통장 사진을 올려 예금주·은행·계좌번호를 자동 판독(OCR)하는 화면 (모바일 웹) 데이터   업로드 박스 안 통장은 예시 목업(홍길동 님 · 계좌번호 000-000000-00000 · 급여 하나 통장 · 주식회사 하나은행) — 실제 계좌 아님 진입 동작   신규 등록 흐름 진입 시 선정산 전용계좌(락계좌) 준비 여부 자동 확인(서버에 요청 용도 PRE_PAYMENT) → 미완료면 게이트 모달[MC_CONTRACT_DEPOSIT_GATE] / 수정(edit=true) 흐름은 가드 제외
No이름설명
1진행·헤더 진행 표시 : 상단 막대 5칸 중 4칸 채움(초록), 마지막 5번째 칸 회색 → 4/5 단계
제목 : "입금 받을 계좌 사진을 첨부해 주세요" (앞 "입금"만 진한 초록 강조)
안내문 : "사장님 입금 받을 계좌 통장 사진을 첨부해 주세요"
2안내배너 좌측 ↔(양방향 화살표) 아이콘 + 라벨 "자유 입출금 계좌" + 우측 알약 "입출금 자유"
설명문 : "정산 금액을 받을 계좌입니다. 입금과 출금이 자유로운 일반 계좌를 등록해 주세요. 출금 전용 락계좌가 아닌지 확인해 주세요."
받을 계좌 = 입금계좌(자유 입출금), 앞 단계 선정산 전용계좌(락계좌)와 구분 — 출금 전용 락계좌를 잘못 등록하지 않게 하는 안내
3통장
업로드		 청록 실선 박스 안 통장 예시 목업 노출 (기본 상태 높이 고정)
예시값 : "홍길동 님" · 계좌번호 "000-000000-00000" · 과목 "급여 하나 통장" · "주식회사 하나은행" + 하단 회색 막대 3줄(거래내역 흉내) — 실제 계좌 아님
박스 위 오버레이 문구 : "클릭하여 사진 선택"
이미지 파일만 선택 가능(accept=이미지) — 카메라 촬영·앨범 선택 모두 열림(별도 촬영 강제 없음)
사진 고르면 예시 목업이 선택한 사진 미리보기로 교체(박스 높이 자동 확장)되고, 아래 [사진 첨부하기] 버튼 위치로 자동 스크롤
분석 중에는 파일 다시 선택도 잠김(입력 비활성)
4첨부
버튼		 버튼 라벨 : "사진 첨부하기"
파일 선택 전에는 버튼 비활성(연한 초록·클릭 불가), 사진을 고르면 활성(진한 초록)
누른 뒤 (OCR 자동 판독)버튼이 로딩 + "분석 중..."으로 바뀌고, 화면 전체에 "계좌 정보를 분석하고 있어요" 딤 오버레이성공 → 판독된 예금주·은행·계좌번호(용도 SETTLEMENT)를 들고 입금계좌 정보 확인 화면[MC_CONTRACT_DEPOSIT_INFO]으로 이동실패 시 안내 모달 (제목 "안내", 확인 버튼 하나)서버가 분석 실패 판정(이미지 유형 불일치 등) : "이미지 분석에 실패했습니다." (서버 메시지 있으면 그 문구 그대로)응답 자체 실패(HTTP 오류) : 서버 안내에 '잠시 후 다시 시도' 포함 시 그 문구 그대로, 없으면 "이미지 분석에 실패했습니다. 잠시 후 다시 시도해 주세요."서버 연결 끊김(네트워크) : "서버 연결에 실패했습니다. 잠시 후 다시 시도해 주세요."
5진입가드 화면 진입 시 선정산 전용계좌(락계좌) 준비 여부 자동 확인 (수정 흐름 edit=true는 가드 제외)
막히는 두 경우 (게이트 모달 본문이 갈림)락계좌 등록 미완료(registrationComplete=거짓) → "먼저 선정산 전용계좌 등록을 완료해 주세요."락계좌는 됐으나 하나은행 빠른조회 미가입(fastInquiryEnabled=거짓) → "선정산 전용계좌의 하나은행 빠른조회 가입이 완료되어야 입금 받을 계좌를 등록할 수 있어요. 빠른조회 가입 후 다시 시도해 주세요."게이트 모달 상세 → [MC_CONTRACT_DEPOSIT_GATE]상태 조회 자체가 실패하면 화면에서 강제로 막지 않음 (최종 차단은 서버 게이트가 담당)

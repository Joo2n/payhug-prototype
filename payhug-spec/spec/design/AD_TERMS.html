2컨텍스트
관리		 접힌 카드 "컨텍스트 관리 (N개)" — N = 전체 컨텍스트 수누르면 아래로 펼쳐지며 컨텍스트 목록 테이블 노출[AD_TERMS_CTX]기본은 접힘 상태
3컨텍스트
필터		 [전체] + 컨텍스트별 칩 (기본 전체)각 칩 옆 숫자 = 그 컨텍스트에 속한 약관 종류 수칩 목록은 서버에서 동적으로 불러옴 (고정 아님)누르는 즉시 목록이 걸러짐 (서버에 다시 묻지 않음)칩은 숫자가 0이어도 항상 노출 — 목록에서는 종류 0개인 컨텍스트 그룹만 빠짐(칩은 남음)
4약관 목록
(트리)		 3계층 구성① 컨텍스트 그룹 헤더 : 컨텍스트 뱃지 + "N개 종류"② 종류 카드 : 종류명 + 코드칩 + 필수/선택 뱃지 + [종류 수정][개정]③ 버전 테이블 : 각 종류 아래 버전 행들종류 카드 헤더종류명이 길면 …로 줄여서 표시[종류 수정] → 종류 수정 모달[AD_TERMS_TYPE_EDIT][개정] → 새 버전 등록 모달[AD_TERMS_REVISE_FIXED] (그 종류로 고정)4-1 컨텍스트 · 필수 뱃지 색컨텍스트 : 회원가입 = 하늘 · 전자계약 = 보라그 외 컨텍스트(마케팅 수신 등)는 색 미정의 → 회색 기본값종류 : 필수 = 주황 · 선택 = 회색상황별 문구불러오는 중 → "로딩 중..."약관 0건 → "등록된 약관이 없습니다."종류에 버전 없음 → "등록된 버전이 없습니다."로드 실패 → "데이터 로드에 실패했습니다."

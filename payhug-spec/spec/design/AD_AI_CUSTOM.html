No이름설명
1직접지정 [직접 지정] 알약이 켜져(흰 배경) 있음 켜면 1시간~7일 프리셋 7개가 화면에서 사라지고 시작 · 종료 일시 입력 2개가 대신 노출 다시 누르면 프리셋 방식으로 복귀
2일시입력 시작 일시 ~ 종료 일시 (달력 · 시각 선택 입력) 기본값 (default : 켠 시각 기준 현재-1시간 ~ 현재) 화면 예시 : "2026. 07. 20. 오후 08:55 ~ 2026. 07. 20. 오후 09:55" 시작이 종료보다 뒤여도 막지 않음 — 시작>종료 유효성 검증 없음(개발 확인 필요) 종료를 비워도 전송됨(종료 없음 허용) 직접 지정을 켠 채 시작 일시를 비우면 이 구간이 무시되고 기본 프리셋 기간(기본 1시간)으로 조회됨 — 개발 확인 필요 질문을 보낼 때 이 구간이 로그 조회 범위로 전송됨

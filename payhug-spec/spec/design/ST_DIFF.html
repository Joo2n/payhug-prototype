내역		 행 구조왼쪽 : 거래일(회색) + 거래처명(카드사·배달앱·만나서 결제 회수)거래처명이 길면 …로 줄여서 표시오른쪽 위 : 승인번호(카드) 또는 주문번호(배달·만나서결제) + 번호오른쪽 아래 : 차액 금액(밑줄, 올리면 툴팁) — 양수 + · 음수 − · 천단위 콤마만나서 결제 회수 (도메인)현장결제(만나서결제) 지연 회수분 → 매출 차감이라 음수(−)로 표시이 행만 금액 툴팁이 예정/실제 차감일을 보여줌(다른 행은 수수료 차액)상황별 문구내역 없음 → "반영된 차액 내역이 없어요."불러오는 중 → 페이지 로딩 화면(중앙)더 보기서버에서 페이지 단위로 나눠 내려줌 · 더 있으면 아래 [내역 더 불러오기] 버튼한 페이지에 몇 건씩인지는 코드에 없음 — 개발 확인 필요누르는 동안 "불러오는 중..."(버튼 비활성) · 기존 목록 아래에 이어붙임(다시 안 접힘)

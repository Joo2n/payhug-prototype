화면 성격  계약 신청 4단계(입금계좌) — 입금(정산받을) 계좌 정보를 확인하고 1원 인증을 시작하는 관문. 같은 라우트가 info → verify 2단계로 전환 [MC_CONTRACT_DEPOSIT_VERIFY] 데이터  세 칸 값은 앞 단계 통장 OCR 결과가 넘어온 것 — 캡처는 테스트값(김성호 / 하나은행 / 38099876543210) 넘어온 값이 세 칸에 미리 채워짐 (없으면 빈칸), 이 단계에서는 세 칸 모두 직접 수정 가능 참고 : 선정산 전용계좌(락계좌) 등록과 달리 비밀번호·하나은행 전용 제약·빠른조회 없음

화면 성격   통장 업로드 화면[MC_CONTRACT_DEPOSIT_UPLOAD] 진입 시 선정산 전용계좌가 준비 안 됐을 때 뜨는 게이트 모달 (에러형 · 확인 버튼 하나) 근거   약관 제8조④ — 전용계좌(락계좌)를 먼저 개설·연결해야 입금계좌 등록 가능 동작   뒤 화면 흐림·조작 불가, 딤 바깥을 눌러도·버튼을 눌러도 곧바로 락계좌 단계로 이동(현재 화면 대체·이 모달에 머무를 수 없음)
No이름설명
1딤 배경 뒤 통장 업로드 화면[MC_CONTRACT_DEPOSIT_UPLOAD]이 흐리게 깔림 (반투명 검정 딤)
딤 바깥 영역·확인 버튼 어느 쪽으로 닫아도 곧바로 락계좌 단계로 이동 — 업로드 화면으로는 돌아갈 수 없음(뒤로가기 불가)
2게이트
모달		 상단 빨간 × 아이콘(에러형 원형 배지) + 제목 "선정산 전용계좌 먼저 등록해주세요"
별도 닫기(X) 버튼·취소 버튼 없음
3사유문구 뜨는 사유 두 가지 (본문 문구가 갈림)락계좌 등록 미완료 : "먼저 선정산 전용계좌 등록을 완료해 주세요." (캡처 상태)락계좌는 됐으나 빠른조회 미가입 : "선정산 전용계좌의 하나은행 빠른조회 가입이 완료되어야 입금 받을 계좌를 등록할 수 있어요. 빠른조회 가입 후 다시 시도해 주세요."
4이동버튼 버튼(초록) : "선정산 전용계좌로 이동"
누르면 선정산 전용계좌(락계좌) 개설 화면[MC_CONTRACT_LOCK_APPLY]으로 이동현재 화면을 대체해 이동(뒤로가기로 이 게이트·업로드 화면으로 못 돌아옴)

화면 성격  계약 신청 1단계 · 사업자등록증 사진을 올려 서버가 판독(OCR)하는 화면 진입 맥락  신규 계약 말고도 사업자 추가·정보 수정 흐름으로 들어오기도 함 · 그 맥락(추가/수정 여부)은 다음 화면까지 그대로 이어짐 데이터  사장님이 직접 촬영·선택한 실제 파일 · 판독은 서버에서 수행
No이름설명
1진행
표시		 계약 신청 5단계 진행 막대 (막대 5칸)현재 1단계만 초록 · 나머지 4칸 회색
2헤더 제목 "사업자등록증 사진을 첨부해 주세요"'사업자등록증'만 진초록으로 강조안내문 : "사장님의 사업자등록증 사진을 첨부해 주세요" (회색)
3사업자
유형		 위 라벨 "사업자 유형" · 개인사업자 / 법인사업자 중 택1 (라디오)기본값(default : 개인사업자)고른 쪽 진초록 테두리 + 연초록 배경 + 진초록 글자, 안 고른 쪽 회색사진 분석 중에는 유형 변경 잠김(못 바꿈)여기서 고른 유형과 판독된 유형이 다르면 첨부 후 자동 보정됨 (5번 참고)
4업로드
영역		 사진 선택빈 박스 안 "사업자등록증" + 가운데 알약 "클릭하여 사진 선택"이미지 파일만 선택 가능 · 여러 장 한 번에 선택최대 3장 · 3장 넘게 고르면 앞에서 3장만 쓰고 초과분은 조용히 버림다시 고르면 이전 선택은 새 선택으로 대체됨선택 후 미리보기첫 장이 박스에 꽉 차게 보임 (위쪽 기준)2장 이상이면 우하단에 "+N장" 뱃지 (N=첫 장 뺀 나머지 수)선택되면 화면이 첨부 버튼 위치로 자동 스크롤안내문 : "사업자등록증이 여러 장인 경우 한 번에 선택해 주세요 (최대 3장)"
5첨부
버튼·결과		 하단 버튼 "사진 첨부하기"사진 1장 이상 선택 전에는 비활성 (연초록·못 누름)누르면 고른 이미지를 서버로 보내 사업자등록증 판독(OCR)처리 중버튼이 "분석 중..." + 로딩 표시로 바뀜전체 화면 덮개 문구 : "사업자등록증을 분석하고 있어요"성공판독값(상호·대표자·주소·업종·개업일 등) 담아 정보 확인 화면[MC_CONTRACT_BIZ_INFO]으로 이동사업자번호로 개인/법인 자동 판별 · 고른 유형과 다르면 '사업자 유형 확인' 모달 먼저 뜨고 이동실패 (안내 모달 · '확인' 버튼)판독 실패 → "이미지 분석에 실패했습니다." (서버 메시지 있으면 그 문구 우선)서버 오류 → "이미지 분석에 실패했습니다. 잠시 후 다시 시도해 주세요." (서버가 '잠시 후 다시 시도' 문구 주면 그 문구)연결 끊김 → "서버 연결에 실패했습니다. 잠시 후 다시 시도해 주세요."

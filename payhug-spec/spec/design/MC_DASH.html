화면 성격  로그인한 가맹점주 홈 — 선택한 사업자가 승인일 때의 메인(‘미리 받는 돈’ 카드). mobile web 데이터  예시(목업) — 김성호떡볶이 본점 / 미리 받는 돈 1,847,200원 / 어제 매출액 2,150,000원 로드  로그인 필수(미인증이면 화면 안 뜨고 로그인으로 회송) 진입 시 사업자 목록·계약 진행상태 자동 로드 · 사업자를 바꾸면 연동계정까지 다시 불러옴

2사업자
선택 카드		 선택한 사업자명(크게) + 계약상태 뱃지 + 사업자번호사업자번호는 하이픈 형식으로 표기 (예 123-45-67890)선택된 사업자가 없으면 "사업자를 선택하세요" 문구카드를 누르면 사업자 목록 드롭다운[MC_DASH_BIZSEL] 열림 (사업자 여러 개 등록 가능)2-1 계약상태 뱃지승인완료 = 초록 · 심사반려 = 빨강 · 그 외(심사대기 등) = 노랑 "계약진행"
3계약
완료 카드		 체크 아이콘 + "계약이 완료되었어요""등록된 계좌, 증빙 서류, 계약서를 확인할 수 있어요""계약 정보 상세 보기 →" 누르면 계약 정보 조회[MC_MYINFO_CONTRACT]로 이동승인 사업자별 최초 1회만 노출(자세히 [MC_DASH_DONE])
4미리
받는 돈		 오늘 날짜 라벨 : "26년 7월 20일 (월) ∙ 오늘""미리 받는 돈" = 오늘 실제 이체된 금액, 천단위 [,] 콤마 + "원"불러오는 중 → "조회 중..." · 이체 전 → 0원이체 시점(T+1·11:30 등) 지급 캘린더 미확정 — 화면은 서버값 그대로 표시, 산정 기준 개발 확인 필요(C2)아래 "어제 매출액 2,150,000원" (수수료 미차감 총매출)아직 집계 전이면 → "어제 매출액 집계중"카드 헤더/화살표 누르면 정산 상세[ST_MA]로 이동

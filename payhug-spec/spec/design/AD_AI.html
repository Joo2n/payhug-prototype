화면 성격  자연어로 서버 로그를 조회해 AI가 비즈니스 이슈를 분석해주는 읽기 전용 어시스턴트 (어드민 · 시스템 메뉴, 라우트 /log-analysis) 데이터  질문 전송 시 서버가 단계별 실시간 스트리밍으로 응답 — 답변 · 건수 · 원본 로그 · 쿼리는 전부 서버(AI) 산출값을 그대로 표시, 화면은 계산하지 않음 운영 이슈  대화 내역은 저장 안 됨 — 새로고침 · 이탈 시 전부 사라짐(휘발)

1헤더 제목 : "AI 모니터링 어시스턴트" 안내문 : "자연어로 서버 로그를 조회하고 비즈니스 이슈를 분석합니다" 초록 그라데이션 히어로 배너 안에 제목 · 안내문 · 기간조회가 함께 들어감 우상단 콘솔 아이콘 — 장식용(클릭 동작 없음), 좁은 화면에선 숨김
2기간조회 기본 조회 라벨 + 기간 프리셋 7개 알약 1시간 · 3시간 · 6시간 · 12시간 · 24시간 · 3일 · 7일 기본값 (default : 1시간) — 첫 진입 시 1시간이 선택됨 선택된 알약만 흰 배경으로 강조, 하나만 선택(단일) 맨 끝 [직접 지정] 알약 → 켜면 프리셋 7개를 숨기고 시작 · 종료 일시 입력을 노출 [AD_AI_CUSTOM] 질문을 보낼 때 이 기간이 로그 조회 범위로 함께 전송됨 프리셋 기간은 질문 보내는 그 순간의 현재 시각 기준으로 (현재-N시간 ~ 현재) 계산됨
3시작화면 대화 시작 전 안내 카드 (보낸 질문이 0건일 때만 노출) 제목 "무엇을 확인하시겠어요?" 안내문 "로그를 분석하여 비즈니스 이슈를 빠르게 파악합니다" 추천 질문 칩 4개 (고정) "오늘 하루 비즈니스 이슈 요약해줘" "이체 실패 건이 있었어?" "매출대금 회수 실패 내역 알려줘" "최근 스크래핑 오류 확인해줘" 칩 클릭 즉시 그 문구로 질문 전송(입력창을 거치지 않음) 질문을 한 번 보내면 카드가 사라지고 대화형(질문 · 답변) 화면으로 전환 [AD_AI_ANSWER]
4입력창 하단 고정 입력창 (스크롤해도 따라옴) 입력창 안내문 : "질문을 입력하세요..." Enter 전송 / Shift+Enter 줄바꿈, 입력이 길어지면 높이 자동 확장(한계 넘으면 스크롤) 전송 버튼 : 입력이 비었거나 응답 대기 중이면 비활성(흐리게) 응답 대기 중에는 입력창도 잠기고 버튼이 로딩 스피너로 바뀜 글자수 제한 없음

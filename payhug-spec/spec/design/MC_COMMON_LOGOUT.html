key note
화면 성격  가맹점 모바일웹 공통 헤더에 내장된 로그아웃 확인 모달 — 프로필 드롭다운/모바일 드로어의 [로그아웃]에서만 열림, 단독 페이지 아님 데이터  캡처(909_2)는 모달이 열리기 전 대시보드 홈 상태 — 모달 자체는 미렌더. 문구·버튼·삭제동작은 헤더 코드 원문 기준 운영이슈  세션 만료(401)로 인한 강제 로그아웃은 이 모달을 거치지 않고 인증정보만 지운 뒤 세션 만료 안내[PH_LO_EXPIRED]로 바로 이동(별도 플로우)
No이름설명
1열림
경로		 프로필/모바일 메뉴의 [로그아웃]을 누르면 화면 중앙에 확인 모달이 뜸데스크톱 : 우측 프로필 아이콘 → 드롭다운[MC_COMMON_PROFILE] 안 로그아웃 (빨강 글자)모바일 : 우상단 햄버거 → 드로어[MC_COMMON_MENU] 하단 로그아웃 (빨강 글자)누르는 즉시 그 메뉴는 닫히고 모달만 열림
2모달
헤더		 상단에 제목 + 닫기 버튼, 아래 옅은 구분선제목 : "로그아웃" (볼드)우측 X 닫기(옅은 회색·흐리게 표시) → 모달만 닫힘(로그아웃 안 됨)
3본문
문구		 확인 문구 한 줄만 표시문구 : "로그아웃 할까요?"
4하단
버튼		 버튼 2개 (우측 정렬)[취소] : 회색 버튼 → 모달만 닫힘마우스 올리면 배경색 진해짐[확인] : 파랑 버튼 → 로그아웃 실행 (누르는 즉시 실행, 로딩·되돌리기 없음)마우스 올리면 더 진한 파랑확인 시 저장된 인증정보 전부 삭제 — 쿠키(토큰·사용자)·브라우저 저장값(사용자)·세션 저장값(토큰·사용자)서버에 로그아웃 요청은 없음 — 브라우저 저장 인증정보만 지움 (서버 세션 만료 처리 여부는 개발 확인 필요)삭제 후 로그인 화면[PH_LO]으로 화면 전환

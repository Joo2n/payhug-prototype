화면 성격  1원 입금 후 인증번호 입력 단계 (같은 페이지에서 정보 확인 → 인증으로 상태 전이) 데이터  위 계좌 필드(계좌주명·은행명·계좌번호·출금비밀번호)는 이 단계에서 잠금(수정 불가) · 흐리게 표시 캡처  이 캡처는 인증 단계가 아니라 '정보 확인' 화면에서 비밀번호 미입력으로 막힌 '안내' 모달 순간 — 인증번호 입력 화면 자체는 캡처에 없음. 아래 rows는 코드 기준 서술
No이름설명
1단계 전환
헤더		 제목이 "1원 인증번호를 입력해주세요"로 바뀜부제 : "통장에 입금된 1원의 적요(메모)에서 숫자 3자리를 입력해 주세요"상단 진행 막대는 정보 확인 단계와 동일(2칸 초록 고정)
2잠긴
필드		 계좌주명·은행명·계좌번호·출금 비밀번호 모두 잠김(수정 불가) · 흐리게(반투명) 표시
3인증번호
입력		 새 입력칸 "인증번호 (숫자 3자리)" 나타남 (부드럽게 슬라이드)가운데 정렬 큰 글씨 · 숫자 3자리만 입력 (숫자 외 문자 자동 제거) · 진입 시 자동 포커스입력창 안내문 : "통장 적요의 숫자 3자리"아래 설명 : 통장에 "페이허XXX" 형태로 입금된 메모에서 숫자만 입력
4하단
버튼		 [인증번호 확인] · 3자리 미만이면 비활성 (로딩 중에도 비활성)누르면 계좌 등록 완료 시도 → 성공 시 등록 완료 모달 "등록 완료" / "선정산 전용 계좌 인증 및 등록이 완료되었습니다." → 확인 시 다음 단계(정산 통장 업로드)로 이동단, 하나은행 빠른조회 미가입이면 완료 대신 빠른조회 가입 안내[MC_CONTRACT_LOCK_FASTINQ]로 막힘확인 중 문구 "인증 확인 중..."[다시 인증 요청하기] → 정보 확인 단계[MC_CONTRACT_LOCK_INFO]로 되돌아가고 입력한 인증번호 지움
5안내
모달		 막는 안내 (모달, 제목 "안내", 확인 버튼)인증번호 빈칸 → "인증번호를 입력해주세요."통장 사진 유실 → "통장 사진이 유실되었습니다. 다시 첨부해 주세요."서버 확인 실패 → "인증번호 확인에 실패했습니다. 다시 시도해 주세요." (서버 메시지 있으면 그 문구)이 캡처에 뜬 모달 = 정보 확인 단계의 "락계좌 출금 비밀번호 4자리를 입력해주세요." (인증 단계 문구 아님)

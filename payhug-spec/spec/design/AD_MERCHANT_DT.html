화면 성격  가맹점 1곳의 계약·서류·계약서·정산 상품·수수료·부채·이체를 모두 관리하는 종합 상세. 어드민(ADMIN·PAYHUG)만 편집, 파트너는 조회 전용 데이터  예시(목업) — 김성호떡볶이 본점 · 승인완료 · 정산 활성 기준 진입 시 자동 로드(가맹점·정산 배정·상품 목록·서명 현황 병렬 조회), 승인+정산활성이면 최상단에 예상정산 경고 배너 전체 높이 캡처 — 15개 섹션 전부 표시 · 수수료율·"매일 11:30" 지급일 근거 미확정(C1·C2), 개업일 "2021.-0.5-"는 목업 포맷 오류
No이름설명
1예상정산 아직 실제 매출이 들어오지 않은 날은 요일별 평균 매출로 정산 금액을 미리 예측해 해당 날짜에 정산 처리한다는 예고 배너다. 예상 정산 금액은 순지급액 × 할인율로 산출하며, 대상 요일·평균 매출·수수료·마지막 실제 데이터 수신일을 함께 보여 준다. 실제 데이터가 늦어질 때만 노출된다.
2헤더·
액션		 상호명과 함께 승인완료·정산활성·이관·수수료면제·회수전용 등 현재 상태 뱃지, 담당자, 같은 대표의 여러 사업자 전환 버튼이 놓인다. 우측 액션은 가맹점 승인/반려, 수동 이체, 과거 매출 데이터 수집, 비밀번호 초기화, 하드리셋으로 상태와 권한에 따라 노출이 달라진다.
3담당·
투자자		 소개 파트너는 담당자와 별개로 계약서의 파트너 체인·직인 생성 근거가 된다. 담당자는 내부 관리 배정, 투자자는 승인 전제 조건으로 매칭 후 매출 건전성 검증이 끝나야 가맹점을 승인할 수 있다. 이미 승인된 뒤 파트너를 바꾸면 계약서 반영을 위해 재서명 요청이 필요하다.
4기본
정보		 상호명·사업자번호·대표자·사용자·휴대폰(통신사)·업종·업태·개업일·주소 등 가맹점 원장 정보를 조회하고 수정하는 영역이다. 계약·정산의 기준이 되는 기본 신원 정보를 담는다.
5계정·
증빙		 플랫폼별(여신금융협회 카드·배민·쿠팡이츠·요기요) 로그인 계정 연결 상태, 락계좌 연동 상태(정상/이상/장애/스킵), 데이터 수집·선정산 포함 토글을 관리한다. 정산계좌 불일치·수집 오류·인증 실패 같은 경고가 계정별로 뜬다. 오른쪽 증빙 서류에서는 사업자등록증·신분증·선정산 전용계좌(통장사본) 미리보기와 하나은행 빠른조회·쿠콘 계좌 등록 상태, 락계좌 검증을 확인한다.
6계약·
서명		 현재 유효한 선정산 서비스 이용계약서의 서명일·PDF 미리보기·다운로드와 재서명 요청을 제공한다. 서명 현황은 본사·소개 파트너·가맹점 각각의 서명 완료 일시와 전원 완료 여부를 보여 주고, 약관 동의 이력에는 동의 일시가 남는다.
71:1
문의		 가맹점이 올린 문의를 최근순으로 모아 보여 주며, 미답변 건수와 상태(대기/처리중/답변완료/종료)·분류(정산/계정/기술) 태그로 구분한다. 정산 금액·계좌 변경 등 실제 문의가 이 화면에서 바로 파악된다.
8특이·
메모		 운영자가 남기는 내부 메모 영역으로, 일반·정산·계약·리스크 분류별로 작성·필터하고 핀 고정할 수 있다. 작성자와 일시가 기록되어 정산 판단·리스크 이력을 팀이 공유한다.
9정산
설정		 세 개의 토글로 정산 동작을 제어한다. 정산 실행 설정은 매일 자동 정산 실행 여부(실행 시각 표기), 수수료 면제는 켜면 수수료를 차감하지 않음, 회수 전용은 정상 선정산 지급 대신 회수만 진행하는 모드다. ※ '매일 오전 11:30 자동 실행'은 화면 고정 문구 — 실제 지급 캘린더(D+N) 근거 미확정(C2).
10상품
배정		 카드·배달 등 거래 유형별로 적용 중인 정산 상품(수수료 정책)과 배정일을 보여 준다. 표준 채권매입·배달 정산·시스템 이용료·이체 수수료처럼 항목별 요율이 나열되며, 하단에서 거래 유형과 상품을 골라 새 상품을 배정한다. ※ 표시 요율(표준 채권매입 1.0%·배달 0.604%·시스템 0.11% 등)은 서버 표시값 — 수수료율 근거 미확정(C1).
11카드
수수료		 카드사마다 개별 수수료율을 직접 수정(0~10%)하고, 카드사별로 선정산 포함/제외를 토글한다. 수수료율은 스크래핑으로 자동 갱신되나 씨티카드 등 미지원 카드사는 수동 관리한다. 이 요율로 승인 단계의 예상 수수료를 계산하고, 매입 확정 시 실제 수수료와의 차액은 자동 정산된다.
12차액
정산		 예상 수수료로 먼저 선정산을 지급한 뒤, 매입이 확정되어 실제 수수료가 확인되면 그 차액을 다음 선정산에서 환급(+) 또는 추가 차감(-)한다. 대기 건과 예정 금액, 이번 달 누적, 전체 누적 금액을 보여 주고 매출 내역·차액 이력으로 이동할 수 있다.
13평균
매출		 최근 3~6개월 매출로 카드·배달·전체의 일평균 매출·수수료율·건수와 카드/배달 비중, 카드사별 매출 비중, 배달 플랫폼별(배민·요기요·쿠팡이츠) 상세와 요일 히트맵을 요약한다. 실제 데이터가 없는 날의 예상 정산액 산출 근거가 되며 재계산할 수 있다.
14락계좌
입금		 플랫폼 락계좌로 하루 2회 자동 수집된 입금 내역을 기간별로 조회한다. 현재 잔액·인출가능액·빠른조회 상태와 플랫폼별 입금 합계, 기간 총 입금액, 개별 거래(입금/출금/잔액/분류)를 보여 주며, 페이허그가 선정산금을 모계좌로 회수(스윕)한 출금도 함께 표시된다. 엑셀 다운로드를 지원한다.
15이관
부채		 타 시스템에서 넘어온 가맹점의 기존 부채를 등록·관리한다. 부채를 등록하면 정산 모드가 회수 모드로 전환되어 정산은 정상 계산하되 가맹점 이체는 생략하고, 락계좌에서 잔여 부채만큼만 회수해 상환한다. 최초·잔여·누적 회수 금액과 진행률·회수 이력을 보여 주며, 회수가 끝나면 일반 모드로 전환하며 선정산을 중단한다.

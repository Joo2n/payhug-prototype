화면 성격  계약 신청 3단계(선정산 락계좌) — 출금 전용 락계좌 통장 사진을 첨부하는 단계 (모바일 웹) 첨부 → 계좌정보 자동 분석(OCR) → 정보 확인 화면[MC_CONTRACT_LOCK_INFO]으로 이동 데이터  첨부 전 통장 삽화는 예시(더미) — 홍길동 님·000-000000-00000·과목 선정산 전용·하나은행 진행  계약 5단계 중 3단계 (진행바 5칸 중 3칸 채움)
No이름설명
1진행바 계약 신청 진행 표시 — 가로 5칸 중 앞 3칸이 초록으로 채워짐현재 3단계(선정산 락계좌) 진행 중, 나머지 2칸은 회색되돌리기·건너뛰기 등 조작 없음 (진행 상태 표시 전용)
2헤더 제목 : "출금 전용 계좌 사진을 첨부해 주세요""출금 전용" 부분만 짙은 초록으로 강조안내문 : "사장님의 선정산 전용 계좌 통장 사진을 첨부해 주세요"
3락계좌
안내박스		 자물쇠 아이콘 + "하나은행 출금 전용 락계좌" + 알약 뱃지 "출금만 가능"안내 문구 : "선정산금이 입금되는 전용 계좌입니다. 일반 입출금 계좌와 다르니 반드시 출금 전용 락계좌 통장을 첨부해 주세요."일반 입출금 계좌와 다른 계좌임을 강조 — 라벨 원문 '출금 전용 락계좌'·'선정산 전용 계좌' 그대로 고수
4통장
첨부영역		 테두리 영역 전체가 파일 선택 버튼 — 누르면 기기 사진/파일 선택창이 열림이미지 파일만 선택 가능 (accept 이미지 전용), 파일 크기·형식 추가 제한 없음파일 선택 전 기본 통장 삽화 위에 "클릭하여 사진 선택" 문구가 반투명 오버레이로 겹쳐 표시기본 삽화의 통장 정보(홍길동 님 · 계좌번호 000-000000-00000 · 과목 선정산 전용 · 하나은행)는 예시(더미)파일을 고르면 그 자리에서 미리보기 이미지로 교체 (삽화·문구 사라짐)선택 직후 아래 [사진 첨부하기] 버튼으로 화면이 부드럽게 스크롤분석 중에는 선택창 잠김 (다시 고를 수 없음)
5사진
첨부하기		 버튼 라벨 : "사진 첨부하기"파일 선택 전에는 비활성 (연한 초록 · 클릭 불가)파일 선택 후 활성 (진한 초록)누르면 계좌정보 자동 분석(OCR) 시작 — 버튼이 스피너 + "분석 중..." 으로 바뀌고 비활성분석 요청에는 통장 파일만 전송분석 성공 시 예금주·은행명·계좌번호를 자동 추출해 정보 확인 화면[MC_CONTRACT_LOCK_INFO]으로 이동용도값 선정산 전용계좌(PRE_PAYMENT)와 추출값을 다음 화면 주소로 넘김, 원본 파일은 임시 저장(다음 화면에서 재사용)사업장 추가·계약 수정 등으로 진입한 경우 그 맥락(사업장·수정 여부)을 다음 화면까지 그대로 이어 전달
6분석중·
실패안내		 분석 중에는 전체 화면을 어둡게 덮고 마스코트 로딩 + "계좌 정보를 분석하고 있어요" 표시실패 안내 (모달 제목 "안내" · 빨강 X 아이콘 · 버튼 "확인")이미지 유형 불일치 등 서버 실패 → 서버 메시지 그대로, 없으면 "이미지 분석에 실패했습니다."'잠시 후 다시 시도' 안내가 온 경우 → 그 문구 그대로 표시그 외 분석 실패 → "이미지 분석에 실패했습니다. 잠시 후 다시 시도해 주세요."서버 연결 실패 → "서버 연결에 실패했습니다. 잠시 후 다시 시도해 주세요."[확인] 또는 바깥 영역을 누르면 모달 닫힘 (같은 화면 유지, 재시도 가능)

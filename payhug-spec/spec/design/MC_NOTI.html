key note
화면 성격  가맹점 인앱 알림 센터(모바일 웹) — 서비스 이벤트 알림을 한 곳에 모아 보여주는 전체 목록 화면 데이터  알림 조회 API 미연동 — 목업이 아니라 실제 미구현. 어떤 계정으로 들어와도 항상 빈 상태로만 렌더됨 운영이슈  안 읽은 개수 0 하드코딩 · [모두 읽음] 클릭 처리 부재 · 알림을 그려 주는 화면 구성 자체 없음 → 로딩/에러/목록 상태 분기 전무 참고  데스크톱 헤더의 알림 벨을 누르면 뜨는 요약 드롭다운은 공용 헤더 컴포넌트 안에 있고(별도 화면 아님), 같은 빈 상태 "받은 알림이 없습니다."를 보여주며 [더보기] → 이 목록[MC_NOTI]로 이동. 모바일엔 벨이 없어 햄버거 메뉴 > "알림"으로 진입. 카카오 알림톡과 인앱 알림은 별개 채널이며 인앱 알림 정책 미확정

로고 클릭 → 로그인 시 대시보드[MC_DASH]로 이동
모바일 폭에서는 우측 햄버거 메뉴만 노출 — 알림 벨·프로필은 데스크톱 전용이라 이 화면(모바일)엔 벨 없음
이 알림 화면 진입 경로(모바일) : 햄버거 메뉴 > "알림"
헤더 아래 페이지 제목 영역
좌측 [< 뒤로가기](좌향 꺾쇠) → 대시보드[MC_DASH]로 이동
제목 : "알림"
우측 [홈] 아이콘 → 랜딩 홈[MC_LANDING](/)로 이동
2안읽은
카운트		 카드 좌상단 "안 읽은 알림 N개" 표시 (숫자만 진초록 볼드)
현재 문구 : "안 읽은 알림 0개"
값이 0으로 고정(하드코딩) — 실제 안 읽은 개수 미반영, 알림 조회 미연동 / 카운트 산출 기준 개발 확인 필요
3모두읽음
버튼		 카드 우상단 [모두 읽음] 버튼 (회색 배경·회색 글자)
눌러도 아무 반응 없음 — 클릭 처리 미연결 / 읽음 표시·카운트 갱신 등 동작 미구현
4목록영역
(빈상태)		 카드 하단 알림 목록 영역 — 항상 빈 상태 하나만 노출
상황별 문구
빈 상태 : "받은 알림이 없습니다." (가로 가운데 정렬 · 카드 위에서 내려 배치 — 세로 정중앙은 아님)
로딩/에러/목록 있음 분기 없음 — 알림을 한 건씩 그려 주는 화면 구성 자체가 없어 어떤 경우에도 항목이 채워지지 않음

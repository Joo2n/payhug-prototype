사업자
선택		 왼쪽 뒤로가기 버튼 → 직전 화면으로 복귀가운데 제목 "계약 정보"사업자가 2개 이상일 때만 사업자 선택 드롭다운 노출옵션 표기 : "상호명 (000-00-00000)" — 사업자번호 하이픈 표기기본 선택(default) : 계약 승인된 사업자 · 없으면 목록 첫번째사업자 1개면 드롭다운 숨김상황별 문구불러오는 중 → 페이지 로딩 표시조회 실패 → 빨강 박스에 오류 문구 + 밑줄 [다시 시도] (오류 메시지 없으면 "데이터를 불러올 수 없습니다.")
2계약

3신분증
종류		 신분증 종류 · 회색 박스로 읽기전용(입력·수정 불가)값은 앞 단계에서 넘어온 종류로 결정 — 주민등록증 / 운전면허증 두 가지만 (type 값이 ID_CARD면 주민등록증, 아니면 운전면허증)type 값 없이 들어오면 기본 주민등록증으로 표시이 화면은 주민등록증 표시 (운전면허증 케이스는 [MC_CONTRACT_ID_INFO_DRIVER])
4정보
입력칸		 입력 필드 (수정 가능)성명 · 주민등록번호 · 발급일자 3칸 — OCR 추출값이 미리 채워짐, 직접 고쳐 쓸 수 있음자리수·형식·필수 검증 없음(자유 입력) · 빈 값이어도 전송 막지 않음 · 발급일자는 구분기호 없는 8자리 그대로(예: 20180712)표시값이 뒷자리 마스킹본(850312-1******) — 이 상태로 두면 마스킹 문자가 그대로 서버 전송됨 · 원본 수집 시점·전송값 개발 확인 필요
5OCR
안내툴팁		 OCR 자동입력 안내 툴팁 · 입력칸 아래 초록 말풍선(위 화살표)문구 : "OCR로 자동 입력되었어요" / "잘못 인식된 값이 있으면 직접 수정해주세요"진입 시 자동 노출 → 10초 뒤 자동으로 사라짐 · 우측 X로 즉시 닫기 가능
6하단버튼
·완료		 하단 버튼[정보가 일치해요] (초록) : 화면의 신분증 정보 + 앞 단계 첨부사진을 함께 서버에 등록누르는 동안 "처리 중..."으로 바뀌고 버튼 비활성(중복 전송 방지)성공 시 등록 완료 모달 — "신분증 정보 등록에 성공했습니다."모달은 [확인]·배경 어느 쪽을 눌러도 계약 화면[MC_CONTRACT]로 이동(수정모드면 해당 계약으로 복귀)[다시 첨부하기] (흰색) : 직전 화면(신분증 촬영)으로 되돌아감차단·오류 문구(알림창)로그인 정보 없음 → "로그인 정보가 없습니다. 다시 로그인 해주세요."(로그인으로 이동)첨부사진 유실 → "신분증 사진이 유실되었습니다. 다시 첨부해 주세요."(이전 화면 복귀)등록 실패 → 서버 메시지 우선, 없으면 "신분증 등록에 실패했습니다." · 통신 예외 → "신분증 등록 중 오류가 발생했습니다."

화면 성격  회원가입 마지막 완료·환영 화면 (라우트). 가입 성공 후 이동해 오는 화면 — 이 화면 코드엔 서버 조회·인증 로직 없음(정적). '자동 로그인 상태'는 앞 가입 플로우 가정이라 개발 확인 필요 데이터  표시할 실데이터 없음 — 인사말 이름만 앞 화면에서 넘긴 ?name 값 사용, 없으면 "사장님". 캡처는 예시값 "홍길동" 로드  진입 시 준비 대기 문구(Suspense 대체) : "로딩 중..." — 이름 값 읽는 짧은 순간만 노출, 준비되면 본문 표시 금액·정산 표기 전혀 없음 — 수수료율·지급일 등 미확정 지뢰 라벨 이 화면엔 없음

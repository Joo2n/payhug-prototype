1헤더·진행 상단 로고 Payhug — 누르면 랜딩 홈으로 이동 [MC_LANDING]진행 점 4개 중 2번째가 현재 단계 (현재 점만 길쭉하게 강조)1·2번째 = 진한 초록(지나온·현재) · 3번째 = 회색(다음 = 비밀번호 설정)4번째 점은 어느 단계에서도 켜지지 않음 — 코드상 단계는 3개뿐, 4단계인지 완료 표시인지 개발 확인 필요
2안내 문구 제목 "본인 확인이 필요해요"부제 "본인의 휴대전화번호로 인증해 주세요"
3번호 입력 라벨 "휴대전화번호"입력창 안내문 : "숫자만 입력"숫자 입력 시 하이픈 자동 삽입 (010-0000-0000 · 3-4-4 형태)하이픈 포함 최대 13자 · 숫자 11자리까지만 반영키보드 Enter로도 인증 시작 (번호 12자 이상 & 아직 인증 전일 때)
4인증 버튼 버튼 [본인 인증]번호 12자 미만이면 눌리지 않음 (연한 초록·비활성)인증 완료 후 라벨이 [인증 완료]로 바뀌고 다시 못 누름빈 값 방어 알림 "휴대전화번호를 입력해 주세요." — 버튼 비활성·Enter 조건 탓에 실사용선 거의 도달 안 함(방어 코드)
5인증 진행 중복 확인누르면 먼저 이미 가입된 번호인지 서버에 확인 (check-phone)이미 가입돼 있으면 → 이미 가입 안내 모달 [PH_JO_AUTH_EXIST]본인인증 팝업새 번호면 본인인증 창(KCB)이 별도 팝업(430×640)으로 열림KCB 본인인증 도입은 정책 근거 없음 — 가설, 정책 확인 필요팝업 차단 시 알림 "팝업 차단을 해제해 주세요."토큰 발급 실패 시 알림 "본인인증 토큰 발급 실패: …" (뒤에 서버 사유 메시지 덧붙음)요청 중 오류 시 알림 "본인인증 요청 중 오류가 발생했습니다."인증 결과성공 → 상단 초록 토스트 "본인인증이 완료 되었어요"(3초) 후 비밀번호 설정(3단계)로 자동 진행인증 결과로 이름·CI·통신사 값이 함께 넘어와 가입 처리에 사용실패 → 알림 "본인인증에 실패했습니다. 다시 시도해 주세요." 후 이 화면 유지

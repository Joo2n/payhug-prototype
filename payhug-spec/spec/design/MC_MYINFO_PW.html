2현재
비밀번호		 라벨 "현재 비밀번호" · 입력창 안내문 : "현재 비밀번호를 입력하세요"현재 쓰는 비밀번호를 그대로 입력 (정책 체크리스트·조건 안내 없음)이 칸은 새/확인 칸과 달리 글자수 제한·공백·한글 걸러내기가 없음 — 입력한 값이 그대로 저장됨세 입력창 공통 동작 (입력창 컴포넌트 자체 기능)오른쪽 눈 아이콘으로 입력값 가림/보임 전환 (기본은 가림 ●●●)Caps Lock이 켜진 채 입력하면 위에 "Caps Lock이 켜져 있습니다" 말풍선 표시 (칸을 벗어나면 사라짐)한글은 조합이 끝나기 전까지 입력에 반영되지 않음
3새
비밀번호		 라벨 "새 비밀번호" · 입력창 안내문 : "비밀번호 입력"입력 필터 (새 비밀번호·확인 칸 공통)공백·한글·이모지는 저장되지 않고 걸러짐 (출력 가능한 영문·숫자·특수문자만 남음)최대 16자까지만 입력됨 (초과분은 잘림)공백을 치면 "비밀번호에 공백을 사용할 수 없습니다."가 약 2.2초 떴다 사라짐비밀번호 정책 (충족해야 변경 가능)8~16자 · 영문 포함 · 숫자 포함 · 특수문자 포함허용 특수문자는 ! @ # $ % ^ & * ( ) 만 · 그 외 문자·공백·한글 불가입력 상태별 문구 (입력창 아래 인라인)비었을 때(기본) → "영문, 특수문자, 숫자 조합 8자 이상" (회색 안내)입력 시작하면 체크 항목 4개(8~16자 · 영문 포함 · 숫자 포함 · 특수문자 포함)가 뜨고, 충족한 항목은 초록 체크로 바뀜빨강 안내문은 허용 안 되는 특수문자일 때 또는 입력창을 벗어난 뒤에만 뜸허용 안 되는 특수문자 입력 시 → "사용 가능한 특수문자: ! @ # $ % ^ & * ( )" (빨강)입력창을 벗어났는데도 조건 미충족이면 → "영문, 숫자, 특수문자를 포함한 8~16자로 입력해주세요." (빨강)모두 충족 → "사용 가능한 비밀번호입니다." (초록·테두리 초록)
4새 비번
확인		 라벨 "새 비밀번호 확인" · 입력창 안내문 : "새 비밀번호를 한번 더 입력하세요"위 새 비밀번호와 같은지만 확인 (정책 체크리스트는 반복 안 함)입력 필터는 새 비밀번호 칸과 동일 (공백·한글 걸러짐 · 16자 제한)상태별 문구비었을 때(기본) → "비밀번호를 한번 더 입력해주세요." (회색)일치 → "비밀번호가 일치합니다." (초록·테두리 초록)불일치 → "비밀번호가 일치하지 않습니다." (빨강·테두리 빨강)허용 안 되는 특수문자 → "사용 가능한 특수문자: ! @ # $ % ^ & * ( )" (빨강)공백 입력 시 → "비밀번호에 공백을 사용할 수 없습니다." (빨강, 약 2.2초 노출)

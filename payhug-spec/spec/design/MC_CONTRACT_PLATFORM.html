3계정 입력
· 저장검증		 진입 로딩사업장 확인·기존 계정 불러오는 동안 로딩 스피너 표시 (전용 문구 없음)플랫폼마다 아이디 · 비밀번호 입력 (비밀번호는 가림 처리)입력창 안내문 : "아이디" / "비밀번호" · 글자수 제한 없음아이디·비밀번호를 모두 입력해야 버튼 활성 (공백만은 미입력 취급)진입 시 기존 등록 계정 자동 불러옴 — 아이디가 채워진 채로 표시연동 성공(활성) 계정 → 연결됨 · 그 외 → 인증실패로 프리필저장·검증 버튼 (상태별 라벨)처음 → "저장 및 검증" · 연결됨 → "재검증" · 실패 → "다시 시도"누르면 저장 → 검증 2단계로 진행 (매출 조회로 실제 로그인 검증)진행 중 입력·버튼 흐리게 잠김 + 안내 "계정 저장 중..." → "연결 검증 중..."아이디·비번을 다시 고치면 상태가 '미확인'으로 되돌아감검증 실패 문구 (버튼 위 빨강)프리필 실패에 서버 사유 없으면 기본 "매출 연동 인증이 완료되지 않았어요. 다시 인증해 주세요."캡처의 "매출 조회 중 일시 오류가 발생했어요" · "아이디 또는 비밀번호가 올바르지 않아요" = 서버 사유(예시·목업)

1모달
헤더		 상단에 약관 제목 + 오른쪽 [X] 닫기모달 제목은 별도 제목 필드 · 목록의 약관명과 다를 수 있음화면 가운데 흰 카드, 뒤 배경은 반투명 검정으로 덮임
2본문 약관 전문 스크롤 영역서버가 준 약관 원문을 줄바꿈 그대로 표시
3확인 하단 [확인] 버튼누르면 해당 약관에 동의 처리(체크)되고 모달 닫힘이 동의로 모든 약관(필수·선택)이 다 체크되면 [모두 동의]도 자동 켜짐전문 끝까지 스크롤하지 않아도 바로 [확인] 가능
4닫기 [X] 또는 바깥 어두운 영역 클릭 → 동의 없이 그냥 닫힘카드 안쪽을 눌러도 닫히지 않음확인을 눌러야만 동의됨 (닫기만으로는 체크 안 됨)

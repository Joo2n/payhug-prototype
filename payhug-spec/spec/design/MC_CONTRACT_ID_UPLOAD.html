처리		 버튼을 누르면 화면 전체 딤 위에 로딩 "신분증을 분석하고 있어요" 표시사진을 서버로 보내 신분증 정보를 자동 인식 (종류 · 이름 · 주민번호 · 발급일 추출)인식은 서버 OCR가 수행 · 정확도·실패 사유 문구는 서버 응답에 의존(개발 확인 필요)서버가 돌려준 마스킹 이미지(주민번호 뒷자리 검게 가림)만 저장 · 원본 사진은 보관하지 않음마스킹 이미지 없으면 진행 중단(fail-closed) → 안내 모달 "신분증 이미지 처리에 실패했습니다. 다시 촬영해 주세요."성공 시 정보 확인 화면[MC_CONTRACT_ID_INFO]으로 이동 (종류 · 이름 · 주민번호 · 발급일 넘김)이동 대상은 항상 같은 확인 화면 — 운전면허증으로 인식되면 그 화면이 운전면허증 모드[MC_CONTRACT_ID_INFO_DRIVER]로 표시 (종류 판정·분기는 이 화면 아닌 다음 화면 몫, 여기선 종류값만 넘김)재등록 진입·businessId 값이 있으면 그대로 이어붙여 전달상황별 오류 안내 모달 (제목 "안내" · 버튼 "확인")분석 실패 → "이미지 분석에 실패했습니다." (서버가 보낸 사유 문구가 있으면 그 문구)서버 응답 오류 → "이미지 분석에 실패했습니다. 잠시 후 다시 시도해 주세요."연결 실패 → "서버 연결에 실패했습니다. 잠시 후 다시 시도해 주세요."

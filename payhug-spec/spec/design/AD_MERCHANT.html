No이름설명
1헤더 제목 "가맹점 관리" 와 안내문"가맹점 승인, 수수료 정책 설정 및 관리를 수행합니다."우측 상단 [부채 가맹점 등록] 버튼(주황)관리자(ADMIN·PAYHUG) 권한에서만 노출누르면 부채 가맹점 등록 모달[AD_MERCHANT_LEGACY]맨 오른쪽 총 N개 가맹점 표시 (예 총 14개)검색·상태필터와 무관하게 전체 가맹점 수 (좁혀도 줄지 않음)
2예상정산
배너		 목록 위 빨강 배너 — 예상정산 대상이 1건 이상일 때만 노출 (0건이면 배너 자체가 사라짐)왼쪽에 빨강 깜빡이는 점문구 : "{정산일} 정산에서 {매출일} 매출이 예상 데이터로 처리 예정 — N개 가맹점" (캡처 예 : 2026-07-20 정산에서 2026-07-18 매출 · 2개 가맹점)정산일·매출일·'예상 데이터 처리' 산정 기준 개발 확인 필요 (예상매출·지급 캘린더 미확정)
3상태
필터		 전체 · 심사대기 · 승인 · 반려 · 미등록 5개 탭, 각 탭 옆에 건수기본값(default : 전체)누른 탭만 초록으로 강조 · 목록을 그 계약상태로만 좁힘 (서버에 다시 묻지 않음)탭 옆 건수는 전체 기준 집계 — 검색어를 넣어도 건수는 안 줄고 목록만 줄어듦계약상태 뱃지가 승인인 행은 목록에 10개 보이지만 [승인] 탭 건수·필터는 6개만 잡음 — 내부 '승인' 상태가 둘로 갈려 한쪽만 집계·필터됨 · 개발 확인 필요각 탭 → [AD_MERCHANT_PENDING] · [AD_MERCHANT_APPROVED] · [AD_MERCHANT_REJECT] · [AD_MERCHANT_NONE] (전체=기본 화면)
4검색 가맹점명 · 사업자번호 · 대표자명 · 사용자명으로 검색일부만 입력해도 찾아줌 · 입력 글자수 제한 없음입력하는 즉시 목록이 걸러짐 (서버에 다시 묻지 않음) · 지우면 전체 복원입력창 안내문 : "가맹점명, 사업자번호, 대표자명, 사용자명으로 검색"
5가맹점
목록		 정렬 순서 (위에서부터 · 토글 없음)① 계약 승인 + 정산 활성② 계약 승인 + 정산 비활성③ 그 외(미승인)표 항목# · 가맹점명 · 사업자번호 · 대표자 · 사용자 · 계약상태 · 계약 진행 · 정산 · 담당 · (마지막 칸 = 마우스 올림 액션, 컬럼명 없음)번호는 정렬·검색 후 위에서부터 다시 매겨짐사업자번호는 형식에 맞춰 표기 · 없으면 "-" / 대표자·사용자 없으면 "-"가맹점명 옆 뱃지 : 사업자 2개 이상이면 "N개 사업자"(파랑), 예상정산 대상이면 "예상정산"(빨강·깜빡이는 점)사업자 미연결 미등록 행은 흐리게 표시행에 마우스 올리면 배경색이 진해짐 (누를 수 있다는 표시)5-1 계약상태 뱃지심사대기=주황 · 승인=초록 · 반려=빨강 · 미등록=회색5-2 계약 진행승인 완료 → "완료" 텍스트(초록)진행 중 → 막대(주황) + 완료수/전체수(회색, 예 3/6)모든 단계 완료(6/6)면 막대·숫자 초록미등록·정보 없음 → "-"막대에 마우스 올리면 단계별 체크 툴팁 : 사업자 · 신분증 · 락계좌 · 정산계좌 · 플랫폼 · 계약동의계약상태가 승인인데도 완료 텍스트 대신 6/6 막대로 뜨는 행이 섞임 (내부 '승인' 상태가 둘로 갈려서) · 개발 확인 필요툴팁 '정산계좌' 라벨은 정책 표기(입금계좌/전용계좌)와 충돌 — 개발·정책 확인 필요5-3 정산 뱃지활성=초록 · 비활성=회색활성/비활성을 무엇으로 판단하는지는 개발 확인 필요상황별 문구불러오는 중 → "로딩 중..."검색 결과 없음 → "검색 결과가 없습니다."데이터 없음 → "가맹점이 없습니다."

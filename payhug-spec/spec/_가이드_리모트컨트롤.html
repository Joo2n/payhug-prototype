📱 Remote Control 가이드

데스크톱에서 도는 Claude Code 작업을 폰에서 리모컨처럼 보고 승인하기 · 초보용 · 2026.07.21
한 줄 요약 — 컴퓨터는 계속 작업하고, 자리를 비워도 폰으로 알림을 받아 폰에서 바로 승인하면 세션이 이어집니다.
⚠️ 앱 버튼·메뉴 이름은 iOS/Android·버전에 따라 조금 다를 수 있어요. 정확한 글자보다 순서·개념을 따라오시면 됩니다. 막히면 저에게 물어보세요.

🤔 왜 쓰나요?

  • 로컬 컴퓨터에서 오래 걸리는 작업(대량 분석·생성 등)을 돌리는 중
  • 자리를 비웠는데, 중간에 "이거 승인해 주세요"가 뜨면 컴퓨터로 돌아가야 함 😫
  • Remote Control을 켜면 → 그 순간 폰에 알림이 오고, 폰에서 답하면 컴퓨터 세션이 알아서 계속 진행 🎉

1 준비물 (딱 2개)

① 폰에 Claude 앱 설치
앱스토어/플레이스토어에서 "Claude" (제작사 Anthropic) 검색 → 설치
② 컴퓨터와 같은 계정으로 로그인
지금 이 Claude Code에서 쓰는 것과 동일한 계정으로 앱에 로그인해야 연결됩니다.
계정이 헷갈리면 터미널에 /status 를 쳐서 확인할 수 있어요.
계정이 API 키가 아니라 claude.ai 구독 계정이어야 Remote Control이 됩니다. 안 되면 터미널에 /login 으로 claude.ai 로그인.

2 켜는 법

방법 A — 지금 이 세션에 바로 붙이기 (가장 쉬움)

지금 대화하는 입력창에 그대로 입력:
/remote-control

방법 B — 새 세션으로 시작

터미널에서:
claude --remote-control
※ 이 세션 입력창에서 실행하려면 앞에 ! 를 붙여 ! claude --remote-control 처럼 칠 수 있어요.
✅ 켜지면 화면에 연결용 링크(URL) 또는 QR 코드가 나타납니다. 이걸 폰으로 여는 게 다음 단계예요. (QR이 바로 안 보이면 스페이스바를 눌러보세요.)

3 폰 연결 + 알림 켜기

① 세션 열기 — 아래 중 편한 방법 하나
  • QR 스캔: 폰 카메라(또는 앱 QR 스캔)로 터미널의 QR 촬영 → 세션 자동 열림 (제일 확실)
  • 앱에서 찾기: Claude 앱 하단 "Code" 탭 → 내 세션(녹색 점=온라인) 선택
  • URL 열기: 터미널에 뜬 링크를 앱/브라우저에 붙여넣기
② 푸시 알림 켜기 (중요!)
앱 설정(Settings) → 알림(Notifications)에서 "승인/작업 필요 시 알림" 계열 항목을 ON
보통 "Push when actions required" / "Push when Claude decides" 같은 이름
③ 폰 시스템 알림 허용
iOS: 설정 → 알림 → Claude → 알림 허용 ON
Android: 설정 → 앱 → Claude → 알림 → 허용

4 평소 사용 흐름

  • 컴퓨터 세션이 작업하다가 승인이 필요해짐
  • → 폰에 푸시 알림: "승인이 필요합니다"
  • → 알림 탭 → 폰에서 내용 확인 → 답 입력(예: 승인/approve) 또는 버튼 탭
  • → 컴퓨터 세션이 그 답을 받아 계속 진행 ✅
핵심: 실제 작업은 컴퓨터에서 돌고(파일·MCP 다 씀), 폰은 모니터링 + 승인만 합니다.

5 문제 해결 체크리스트

푸시가 안 와요

  • 앱 설정에서 "승인 필요 시 알림"이 ON인지
  • 폰 시스템에서 Claude 알림이 허용인지
  • 앱을 완전히 닫았다가 다시 열기 (알림 토큰 갱신)
  • 컴퓨터·폰 모두 인터넷 연결 확인

연결이 끊겨요

  • 컴퓨터 터미널이 계속 켜져 있어야 함 (닫으면 세션 종료)
  • 오래(약 10분+) 오프라인이면 종료 → 다시 claude --remote-control
  • 회사 WiFi·방화벽이 막을 수 있음 → 개인 WiFi로 시도

- 위 "회수"는 전부 **자금 이동(스윕/부채상환)**이며, merchant/05 #56 만나서결제 "회수"·merchant/08 "회수 완료" 알림·정책의 '과지급 회수'와 **다른 개념**. KPI 라벨 "매출 회수"가 두 개념을 혼동시킴 → analysis 제안 "매출대금 회수(스윕)" vs "회수건 관리" 분리 필요.

**계좌 라벨 매핑 주의(원칙7)**: merchant/06 등록 계좌 UI 라벨(선정산 전용계좌/입출금 전용계좌)과 계약 용어(전용계좌=락계좌 / 입금계좌)의 대응 방향이 미확정 — 임의 매핑 금지(§3 #129). 계좌 개념 자체는 금액 6개념과 무관.

**계약 용어 ↔ 6개념 매핑 미확정**: 계약 2개념(과정산금=초과입금 반환 / 미정산금=부족입금 회수) ↔ 운영 6개념 ↔ Figma 용어(과정산금/미정산금/미수금액/미수금) 3중 분열(§5 K5). 임의 매핑 금지.

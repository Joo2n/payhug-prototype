## A. 화면 개요

- **목적**: 가맹점(사장님)이 접수한 1:1 문의를 처리하는 고객 대응 인박스다. 어드민은 이 화면에서 문의를 목록으로 조회하고, 행을 열면 상세 드로어에서 메시지 스레드를 확인해 답변을 등록하며 문의 상태를 관리한다.
- **진입·권한**:
  - 좌측 메뉴에서 `/inquiries`로 바로 들어온다. 어드민 로그인이 필요하며, 화면 전체가 `AdminLayout`으로 감싸져 있다. `code 01_admin app/inquiries/page.tsx:186`
  - 가맹점 상세 화면의 `1:1 문의` 위젯에서 `전체보기`를 눌러도 이 화면으로 진입한다. `code 01_admin components/MerchantInquiries.tsx:60`
  - 답변을 등록하려면 먼저 `getAdminUser()`로 현재 관리자 식별값(`adminUserId`)을 확보해야 하고, 값이 없으면 답변 전송이 중단된다. `code 01_admin app/inquiries/page.tsx:140`
- **주요 상태 변형(캡처된 케이스)** — `01_IA.md` A-09 근거:
  - 목록 기본 화면은 `node 951:2`이고, 상태 필터는 대기 `node 956:2` · 처리중 `node 960:2` · 답변완료 `node 964:2` · 종료 `node 968:2`로 나뉜다.
  - 카테고리 필터는 일반 `node 972:2` · 결제 `node 978:2` · 정산 `node 983:2` · 기술 `node 985:2` · 계정 `node 990:2`으로 캡처돼 있다.

## D. 미확정 지뢰 관련

- 이 화면(1:1 문의 인박스)에는 **수수료율(C1) / 지급 캘린더(C2) / 예상 지급 차액(C4)** 라벨·계산이 **직접 나타나지 않는다**(해당 없음).
- 다만 카테고리 `정산(SETTLEMENT)`·`결제(PAYMENT)` 문의 본문에서 위 값들이 화제로 다뤄질 수 있으나, 이 화면은 값을 계산·표시하지 않고 텍스트 스레드만 렌더한다. 답변 문구 작성 시 3대 지뢰 값을 임의로 확정해 안내하지 않는다.
- 6개 개념(미지급금·선정산 제외금액·바로이체·과지급·미회수금·환급) 역시 이 화면에서 계산·표기되지 않는다. 어드민 `매출 회수`(락계좌→모계좌 스윕)와 정책 `회수`(과지급 회수)의 구분도 이 화면 범위 밖.

- **진입·권한**:
  - 라우트 `/`. `AdminLayout`으로 래핑, 사이드바 "홈" 링크가 이 화면을 연다. `code 01_admin components/AdminLayout.tsx:465-467`

## D. 미확정 지뢰 관련

- **수수료율 (C1)**: 이 화면은 수수료를 **금액**으로만 표시하며 **율(%)은 노출하지 않는다.** 단 "선정산 수수료"를 매입/시스템/이체 3분할로 병기(app/page.tsx:211)하는데, 이 3분할이 C1의 병존 수수료율 구조와 매핑되는지는 미확정 → **임의 매핑·값 채택 금지**. "수수료 산정 현황"의 "확정률"은 **건수 비율**(actualFeeCount/totalFeeCount)이지 수수료율이 아님(혼동 금지).
- **지급 캘린더 (C2)**: 데이터 조회 범위가 오늘−7 ~ 어제(오늘−1)로 고정(useDashboardData.ts:56-61). 지급일(D+1/D+2/매일) 로직은 이 화면에 표시되지 않으며, 종료일 "어제" 채택 근거는 미확정 → **캘린더 값 임의 확정 금지**.
- **예상 지급 차액 (C4)**: 이 화면의 "예상 수수료(매입대기)"·"차액 반영/대기"는 **어드민 내부의 차액정산(수수료 확정 전/후, adjustment)** 개념으로, 가맹점 노출 라벨 "예상 지급 차액"(C4)과 **다른 개념·다른 라벨**이다. 두 개념을 동일시하지 말 것.
- **개념 구분 주의**: 이 화면의 "차액"은 수수료 차액정산(refund/deduct 네팅)이며, 어드민의 '매출 회수'(락계좌→모계좌 스윕)와도, 정책의 '회수'(과지급 회수)와도 다른 개념이다.

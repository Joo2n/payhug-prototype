## A. 화면 개요
- **목적**: 가맹점 선정산 지급에 앞서, PayHug가 지급 재원으로 쓰는 **모 계좌(입금이체 PG)의 실시간 가용 잔액**을 확인하는 운영 화면이다. 기간별 **입·출금 원장**을 함께 조회하고, 쿠콘 시스템 밖에서 들어온 입금은 **외부 입금**으로 직접 기록해 장부상 잔액과 실제 잔액을 맞춘다(대사, reconcile). (헤더 "모 계좌 잔액 조회 / 가맹점 지급 전 모 계좌의 가용 잔액과 입·출금 내역을 확인합니다." `code 01_admin app/account-balance/page.tsx:173`)
- **진입·권한**: 관리자 전용 화면이다. 로그인한 사용자의 `getAdminUser().userType`이 `ADMIN` 또는 `PAYHUG`일 때만 본문이 렌더되고, 그 외에는 "이 페이지는 관리자만 접근할 수 있습니다." 안내로 접근을 차단한다 (`code 01_admin app/account-balance/page.tsx:66-69, 133-143`).
- **주요 상태 변형(캡처된 케이스)** — `01_IA.md` A-08 node 목록 근거:
  - `node 944:2` — 기본(잔액 히어로 + 잔액 대사 카드 + 입·출금 원장).
  - `node 1058:2` — 외부 입금 등록 모달(빈 폼).
  - 코드상 추가 파생(미캡처): 잔액 대사의 3가지 상태(일치 / 차이 발생(잔액 과다) / 확인 필요(잔액 과소)), 원장 로딩·빈 상태, 외부 입금 건에 한한 원장 행 삭제, 삭제 확인(confirm) 다이얼로그.

## D. 미확정 지뢰 관련 (해당 시)
- **수수료율(C1)**: 이 화면에는 **나타나지 않음**. 원장은 타 화면(정산현황·정산)에서 이미 계산된 지급/회수 금액을 결과로 표시할 뿐, 수수료율·이체수수료(300원)를 이 화면에서 산정하지 않음.

- **예상 지급 차액(C4)**: 이 화면에는 **나타나지 않음**. ⚠️ **혼동 주의** — 이 화면의 "잔차 / 차이(확인 필요) / 미기록 외부 입금(추정)"은 모 계좌 **잔액 대사 residual**(현재 잔액 vs 원장 예상 잔액)이며, 가맹점 화면의 **예상 지급 차액**(C4, 정의 미확정)과는 **다른 개념**이다. 두 라벨을 같은 것으로 매핑하지 말 것.
- **⚠️ 용어 충돌 주의 — "매출 회수"(원칙6)**: 이 화면의 category `COLLECTION` = "매출 회수"는 방향이 **IN(모계좌로 입금)**으로, **어드민 매출 회수(락계좌→모계좌 스윕)**를 가리키는 것으로 추정된다. 이는 정책 문서의 **'회수'(가맹점에게 과지급된 금액을 되찾는 처리, `02 §4`)**와 **전혀 다른 개념**이다. 어드민 매출 회수(자금 이동)와 정책 회수(과지급 회수)를 절대 하나로 합치지 말 것. (코드 라벨과 정책 용어의 명칭 충돌 — 개념 확정은 C 참조)

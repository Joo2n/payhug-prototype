## A. 화면 개요

- **목적**: 한 가맹점의 운영 전반을 한 화면에서 관리한다. 구체적으로는 계약 심사(승인·반려), 서류·계좌·플랫폼 계정의 등록·수정, 담당자·소개파트너·투자자 배정, 정산 상품 배정과 정산 실행·수수료 면제·회수 전용 설정, 그리고 카드사 수수료율·차액정산·락계좌 입금내역·이관부채 관리까지 이 화면에서 처리한다.
- **진입·권한**:

## D. 미확정 지뢰 관련

- **수수료율(C1)** — 이 화면 핵심. ① 카드사별 수수료 관리(MerchantCardFees): 인라인 `0~10%` 자유입력(`code components/MerchantCardFees.tsx:99`), "기본값 초기화"의 기준값 미명시. ② 예상정산 배너 '할인율%'(`discountRatePct`). ③ 안내문구 "시티카드 제외 스크래핑 자동 업데이트". **어느 후보값(1% / 0.604% / 0.6+0.11+0.1% / 0.25%)도 임의 채택 금지.**
- **지급 캘린더(C2)** — 정산 실행 토글 설명 "매일 오전 11시 30분 자동 실행 중"(`code app/merchants/[id]/page.tsx:2211`)이 유일한 스케줄 표기. 계약 "매일" vs D+1 vs D+2 매핑 미확정 — 문자열 그대로 두고 확정 금지.
- **예상 지급 차액(C4)** — "예상 지급 차액"이라는 라벨은 이 화면에 직접 등장하지 않으나, ① 예상정산 배너의 '예상 정산 금액'(예상값), ② 카드수수료 '차액' 정산(정산적용−실제) 라벨이 병존. 둘은 별개 개념 — C4('예상 지급 차액') 정의(02 §1 미확정)와 혼동 금지. '차액 정산'(수수료 매입 확정 차액)은 C4가 아님을 명시.

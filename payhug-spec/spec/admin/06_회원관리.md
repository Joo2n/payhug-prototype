## A. 화면 개요

- **목적**: 선정산에 참여하는 회원(가맹점이 아닌 투자자·파트너 등)을 등록·수정·비활성화·삭제하고, 각 회원의 프로필(사업자등록증·직인·사업자정보)을 관리하는 화면이다. 회원 유형은 투자자·페이허그·파트너·제휴사·영업·영업조직·관리자 7종이다. 각 회원이 가진 추천코드(referralCode)와 상위 회원(parentUserId) 체인은 가맹점 가입 URL의 귀속, 그리고 하위 도메인의 수수료 배분 구조와 연결된다. 다만 **이 화면 자체는 수수료율이나 정산 금액을 계산·표시하지 않고, 회원 등록과 귀속 관계 설정만 담당한다.**

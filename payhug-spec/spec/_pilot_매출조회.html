No이름설명

2검색 가맹점명 · 사업자번호 · 대표자명으로 검색 일부만 입력해도 찾아줌 · 입력 글자수 제한 없음 입력하는 즉시 목록이 걸러짐 (서버에 다시 묻지 않음) 검색어를 지우면 전체 목록으로 복원 입력창 안내문 : "가맹점명, 사업자번호, 대표자명으로 검색"
3가맹점
목록		 정렬 순서 (위에서부터) ① 계약 승인 + 정산 활성 가맹점 ② 계약 승인 + 정산 비활성 ③ 계약 미승인 표 항목 번호 · 가맹점명 · 사업자번호 · 대표자 · 주소 · 계약상태 · 정산 · (마우스 올리면 나오는 버튼) 번호는 정렬·검색 후 위에서부터 다시 매겨짐 주소가 길면 …로 줄여서 표시 행에 마우스를 올리면 배경색이 진해짐 (누를 수 있다는 표시) 3-1 계약상태 뱃지 승인 = 초록 · 대기 = 회색 · 거절 = 빨강 3-2 정산 뱃지 활성 = 초록 · 비활성 = 회색 활성/비활성을 무엇으로 판단하는지는 개발 확인 필요 상황별 문구 불러오는 중 → "로딩 중..." 검색 결과 없음 → "검색 결과가 없습니다." 가맹점이 하나도 없음 → "등록된 가맹점이 없습니다."

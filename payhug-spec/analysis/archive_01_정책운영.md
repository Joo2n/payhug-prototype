#### 핵심 내용 (확정 — 화면 정의 기준)

**메인 페이지 금액 구조 (A~I 체계)**
```
전일 거래액 (A)
카드/배달사 차감 (B)
C = A - B
선정산 적용 제외 (D)
선정산 적용 (E = C - D)
페이허그 수수료 (F)          ← 화면 표기: F = E × f, f = 1.0%
G = E - F
전일예상의 오차 조정 (H)      ← 예시 +2,638 (카드사 Refund 건별 합계)
과거 선정산 제외 입금 (I)     ← 예시 +12,900 (제외 사유: "만나서 결제")
계좌 입금액 = G + H + I
```
- 입금일 기준 조회(과거 일자 선택 시 해당일 내역 출력)
- H 상세 화면: 거래일/승인번호/정산주체(카드사)/적요(Refund)/금액 건별 리스트
- I 상세 화면: 거래일/승인번호/정산주체/**제외 사유**(예: 만나서 결제)/금액 — 과거 제외건이 실제 입금되면 지급하는 구조
- D(선정산 제외) 상세 화면: 제외 거래별 카드사(배달앱)명 / 거래액 / 수수료 / 순액 출력

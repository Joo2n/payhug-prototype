### TP-2  미지급·과지급이 두 축에서 서로 다른 뜻

| | |
|---|---|
| 분류 | 용어 |
| 상태 | 확정 |
| 정한 사람 | 대표 조현준 |
| 언제 | 2026-08-28 (대표 미팅 메모 2번) |
| 근거 | `terms_briefing_0831.md` §7-1 대조표 · `meeting_20260828.md` §2 |

**내용** — 같은 낱말이 두 축에서 다른 것을 가리킨다.

| | 투자자 축 | 내부(가맹점) 축 |
|---|---|---|
| 누가 누구에게 | 플랫폼 → 투자자 락계좌 | 페이허그 → 가맹점 |
| 미지급 | 락계좌에 덜 넣은 것 | 선정산 때 덜 준 것 |
| 과지급 | 락계좌에 더 넣은 것 | 선정산 때 더 준 것 |
| 손해 보는 쪽 | 투자자 | 가맹점 |

한 채권에서 두 축이 동시에 벌어질 수 있다. 가맹점에 정상 지급했는데 플랫폼이 락계좌에 덜 넣으면 내부 축은 움직이지 않고 투자자 축만 미지급이 선다.

**닿는 곳** — 용어 해설 문서의 미지급금·과지급금 카드. 어느 축인지 표시가 없으면 값의 방향을 읽을 수 없다.

**연결** — TP-1 · TP-3 · TP-4 · 02 §2 · 02 §4

### TP-64  기간 집계 — PSA · PSM · PSMR · PSD · PSC

| | |
|---|---|
| 분류 | 산식 |
| 상태 | 확정 |

**내용** — 일별 배치가 만든 하루치 레코드를 기간만큼 이어 붙인다. 기간을 가르는 열쇠는 **정산예정일**이며 매출일도 선정산일도 아니다.

```
PSA  = 기간 내 SAD-1 합
PSM  = 기간 내 SMD-1 합
PSMR = PSM ÷ PSA
PSD  = Σ(Api × Dpi) ÷ PSA
PSC  = 기간 내 EC 합
④ 투자실행금액 대비 ty수익율 = PSMR × 365 ÷ PSD
⑤ 투자자산   대비 ty수익율 = (④ × PSA) ÷ (PSA + PSC)
```

`PSD`는 일별 `SDD-1`을 단순 평균하는 것이 아니라 기간 내 채권 전건을 한 번에 놓고 다시 가중평균한다.

### TP-65  ⑤의 분모 `PSA + PSC` 처리

| | |
|---|---|
| 분류 | 산식 |
| 상태 | 대기 |
| 정한 사람 | — (대표 회신 대상) |

**내용** — 분모 두 항의 성격이 다르다. `PSA`는 기간 동안 나간 돈을 더한 값이고 `PSC`는 기간 동안의 잔액을 더한 값이라, 그대로 더하면 현금 쪽이 상대적으로 작게 잡힌다.

정의서 안에서도 갈린다 — 배치 산출 목록은 `평균순현금`을 적었는데 `PSC`는 `EC들의 합`으로 정의돼 있다.

| 갈래 | 분모 |
|---|---|
| (A) 원문 그대로 — `PSC` = 기간 EC 합 | 합 기준 |
| (B) 평균 잔액끼리 — `PSA × PSD ÷ 일수` + `PSC ÷ 일수` | 평균 기준 |
| (C) 분모를 기준일 잔액으로 | 잔액 기준 |

같은 실적이 갈래에 따라 1%p 넘게 벌어진다.

**닿는 곳** — 투자 수익 화면 `Ty수익율 › 투자자산 대비`, 엑셀 `투자수익_현황`, 제안서에 실리는 수익률 지표.

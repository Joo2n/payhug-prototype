# 가맹점 선정산 UI 요구사항

## 1. 기본 설계 원칙

가맹점은 다음 질문에 바로 답을 얻을 수 있어야 한다.

1. 오늘 얼마를 받는가?
2. 어떤 매출이 반영됐는가?
3. 무엇이 차감됐는가?
4. 왜 예상 금액과 실제 금액이 다른가?
5. 추가로 받을 금액이 있는가?
6. 이전 지급분에서 조정될 금액이 있는가?
7. 지급은 언제 완료되는가?
8. 현재 데이터는 언제 업데이트됐는가?

- 현재 반영 매출액
- 선정산 반영 금액
- 플랫폼 수수료
- 카드 수수료
- PayHug 수수료
- 이체수수료
- 플랫폼 환급금
- 추가 지급 예정액
- 이전 지급 조정금액
- 선정산 미반영 금액
- 최종 지급 예정액
- 지급 상태
- 최종 업데이트 일시

## 5. 가맹점 노출 용어

| 내부 용어 | 가맹점용 |
|---|---|
| 미회수금 | 이전 지급 조정금액 |
| 과지급 | 이전에 추가 지급된 금액 |
| 선정산 제외금액 | 이번 선정산 미반영 금액 |
| 자체 플랫폼 환급 | 플랫폼 환급금 |
| 바로이체 미지급 | 추가 지급 예정금액 |
| 대사 불일치 | 정산 확인 중 |
| 회수 | 다음 지급액 조정 |
| 스크래핑 오류 | 데이터 확인 중 |

## 6. 화면 상태별 문구

### 매출 수집 중
현재 매출 내역을 확인하고 있습니다.

### 일부 수집
일부 매출이 아직 반영되지 않았습니다.

### 매입 지연
플랫폼 또는 카드사의 매입 확인이 지연되고 있습니다.

### 지급 예정
선정산 금액이 산정되었으며 지급을 준비하고 있습니다.

### 지급 완료
선정산 지급이 완료되었습니다.

### 추가 지급 예정
정산 내역 확인 결과 추가 지급 예정 금액이 있습니다.

### 이전 지급 조정
이전 정산 내역 변경으로 다음 지급액에서 조정될 금액이 있습니다.

### 선정산 미반영
이번 선정산에 반영되지 않은 금액이 있습니다.

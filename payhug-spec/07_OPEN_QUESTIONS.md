# 미확정 및 미팅 협의사항

> 이 문서가 미팅 내용을 담는 가장 중요한 문서다.
> Claude Code는 이 문서의 질문을 임의로 확정하지 않는다.

## 1. 지애 매니저와 확인할 내용

### 용어

- 미지급금과 선정산 제외금액은 다른 개념인가?
- 과지급과 미회수금은 발생액과 잔액으로 구분하는가?
- 자체환급분은 플랫폼 자체 환급을 의미하는가?
- 바로이체 대상금액과 바로이체 미지급의 정확한 차이는 무엇인가?

### 매출대사 엑셀

- 각 칼럼의 정의
- 금액 출처
- `+ / -` 의미
- 지급·차감·회수 방향
- 자동·수동 처리 구분
- 완료 여부 확인 위치
- 마지막 시트 자체환급 리스트의 사용 목적
- 결산자료 및 매출내역 필터 기준

### 플랫폼 예외

- 우리가게클릭비 일반 비용과 프로모션 환급 분리 가능 여부
- 하나의 항목에 혼합된 경우 세부 처리 또는 순액 처리 여부
- 가게배달 음수 발생 원인
- 환급 미지급 8건의 플랫폼·품목·원인
- 수동이체 후 완료 기록
- 쿠팡이츠 과지급 재대사 기간
- 카드 미정산금과 플랫폼 과지급의 합산 관리 여부

### 회수

- 회수건 생성 주체
- 자동 생성 여부
- 회수 우선순위
- 차기 지급 상계 여부
- 부분·분할 회수 여부
- 회수 완료 검증 기준
- 회수 실패·보류·취소 처리

## 2. 정규 매니저와 확인할 내용

### 가맹점 UI

- 요청 UI가 가맹점 화면만인지 운영 어드민도 포함인지
- 예상 지급 차액 정의
- 메인 화면 필수 항목
- 상세 화면 필수 항목
- 환급과 회수 별도 노출 여부
- 내부 사유 공개 범위
- 플랫폼별 상세와 합산 화면 필요 여부
- 완료된 조정 이력 조회 여부

### 알림톡

- 실제 사용 중인 템플릿
- 필수 발송 케이스
- 전체 발송과 조건부 발송 기준
- 플랫폼별 개별 발송 또는 합산
- 환급·추가 지급·회수 알림 여부
- 링크 이동 화면
- 이미지형 템플릿 필요 여부
- API 테스트 일정과 기획 전달 마감일

## 3. 팀장 또는 책임자와 확정할 내용

- 바로이체 입금예정일 당일 지급 원칙
- 익일까지 지급 허용 여부
- 주말·공휴일 기준
- 회수금과 추가 지급금 상계 가능 여부
- 회수 어드민 1차 개발 범위
- 자동 회수 포함 여부
- 가맹점 UI와 알림톡 개발 범위
- 최종 정책 승인자

## 5. 문서 정합성 검토에서 발견된 확정 필요 사항 (2026-07-15)

- "추가 지급"이 3가지 의미로 혼용: ① 당일 산식 합산 항목(03) ② 별도 미래 지급분(바로이체 등) ③ 과지급의 가맹점 노출 문구(05 §5) — 의미 확정 필요
- 미지급금의 가맹점 노출 용어가 05 §5 매핑 표에 없음
- 취소·환불·추가 매입·프로모션 환급은 02 용어집에 정의 없음
- "이전 지급 조정금액"(05 메인)이 미회수 잔액인지 당회 상계액인지 미정
- 가게배달 음수(04 §2)·쿠팡이츠 정산 출금(04 §5)의 화면·알림톡 노출 방식 미정의
- "지급 실패" 상태의 화면 문구 부재 (알림톡 케이스에는 존재)
- 플랫폼 환급 vs 자체환급분이 가맹점 용어에서 "플랫폼 환급금" 하나로 합쳐짐 — 동일 개념인지 확정 필요

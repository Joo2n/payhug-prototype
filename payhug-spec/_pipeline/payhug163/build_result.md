## 조판 규격

- 골격(메타바·표·keynote)은 신규 생성. Apple SD Gothic Neo 로드 불가 → `Noto Sans KR`로 동일 치수 재현.
- 표·keynote는 오토레이아웃 중첩(셀 폭 고정 + 텍스트 HEIGHT) → 행 높이 자동.
- 화면 자산은 텍스트 미수정, 이동 + `rescale`만(웹 화면 0.55배, 운영 안내본 0.7배).

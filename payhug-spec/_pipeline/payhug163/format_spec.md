## 4. 폰트 — 필수 주의

- 원본 텍스트 = **Apple SD Gothic Neo** (Bold 14/16 · Regular 14).
- 이 환경에서 Apple SD Gothic Neo는 **로드 불가**(`loadFontAsync` 실패 확인).
- → clone한 텍스트의 `characters`를 바꾸려면 **`Noto Sans KR`로 폰트 재구성 후 교체**.
  - 대응: Bold → `Noto Sans KR / Bold`, Regular → `Noto Sans KR / Regular`, 크기 동일 유지.
- Noto는 Apple SD보다 자간이 넓음 → 텍스트 노드는 `textAutoResize = 'HEIGHT'` + 폭 고정(`resize`)으로 오버플로 방지.
- 화면 목업(사용자 제작 캡처·프레임)은 **텍스트를 건드리지 않고 clone만** — 폰트 재구성 불필요.

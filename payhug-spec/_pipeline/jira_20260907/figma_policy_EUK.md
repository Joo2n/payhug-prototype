### 대조 결과 — 「양수 = 차감」이 뒤집혔는가

| 비교 대상 | 판정 |
|---|---|
| `77:329` (정책 8/15) vs `77:328`·`85:342` (어드민 화면 8/15·8/17) | **일치.** 둘 다 `실제 − 예상`, 양수 = 차감, 음수 = 환급. 어드민 화면 캡션이 정책과 정반대라는 의심은 **성립하지 않는다** |
| `77:329` (정책 8/15) vs `5:44` (정책 7/18) | **표기상 정반대.** `5:44` 는 음수 = 차감, 양수 = 지급 |
| 어드민 `거래 수수료 차액` vs 가맹점 앱 `예상 지급 차액` | **부호 규약이 반대다.** 아래 「현행 어드민 코드 대조」와 C4 절 참고. 두 라벨이 서로 다른 앱에 나란히 살아 있다 |

`5:44` 는 뺄셈 순서를 「**예상** 수수료와 **실제** 수수료 차액」 = `예상 − 실제` 로 잡은 것으로 읽을 수 있다. 그렇게 읽으면 실제가 예상보다 클 때 음수가 되고 차감이므로, 경제적 결과는 `77:329` 와 같아진다. 다만 `5:44` 는 뺄셈 순서를 명시하지 않았고 결과 라벨도 `예상 지급 차액` 으로 `77:329` 의 `거래 수수료 차액` 과 다르다. 어느 쪽이 유효한지 **`확인 필요`** 로 남긴다. 두 해석은 아래와 같이 갈린다.

| 해석 | `5:44` 의 차액 정의 | `77:329` 와의 관계 |
|---|---|---|
| 해석 A | 예상 − 실제 | 부호 표기만 반대, 처리 결과는 동일. 나란히 존재 가능 |
| 해석 B | 실제 − 예상 | 처리 결과까지 정반대. 8/15 가 7/18 을 뒤집은 것 |

`1%` 가 가맹점 계약률이고 `0.6%` 가 이해관계자에게 배분되는 몫이라는 해석이 가능하다. 그러나 `22:263` 화면은 채권매입 열의 참여자 배분 합계(2,908+773+850=4,531)를 그대로 「배분」으로 표기할 뿐, 가맹점에게 1% 를 떼고 그중 0.6% 만 배분한다는 문장이 어디에도 없다. **`확인 필요`.**

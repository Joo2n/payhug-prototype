## Duration 용어에 대하여

위키백과에서 Duration을 검색하면, "투자자금의 평균회수기간을 뜻한다."고 나와.
즉, Duration은 평균이라는 개념이 이미 들어가 있어. 그래서 Weighted Mean Duration (WMD)이나 Weighted Average Duration은 적절한 용어가 아닌 것 같고, 그냥 "Duration"이 적정한 용어 같아. Duration이라는 용어가 생소할 것 같아서 "투자자금 weighted 금융일수"라는 뜻으로 "w금융일수"라는 변수를 사용했는데, 그냥 "Duration" 또는 "D"라고 쓰는 게 오히려 혼선을 없애는데 도움되겠다는 생각이 이제와서 들기도 해.

단, 샘플일자의 Duration인지 정산금채권의 Duration인지 구분이 필요할 것이야.

기존의 용어정의에서는 샘플일자의 Duration을 w금융일수로 표기하고 정산금채권의 Duration을 D라고 표기했어. 예컨대, 투자자금중 30%는 회수기간이 2일이고, 50%는 회수기간이 3일이고, 20%는 회수기간이 4일이라면, 그 투자자금의 평균회수기간(Duration)은 30%x2일 + 50%x3일 + 20%x4일 이 되겠지. 그래서 w금융일수(=Duration) = Ai/Σ Ai가 비중이니까, 특정일의 Duration (즉, 현재 용어로서는 특정일의 w 금융일수)= Di(해당일의 각 정산금채권의 듀레이션) x  Ai/Σ Ai 의 합 = Σ Ai x Di / Σ Ai로 표기한 것이야

## PSC 와 투자자산 대비 수익율 유도

PSC는 사용자가 선택한 Period에 속하는 샘플(S) 일자들의 순현금(EC)의 합을 나타내는 변수이고, 그 자체로는 의미가 없지만,
'PSA+PSC'는 사용자가 선택한 Period에 속하는 각 샘플(S) 일자들의 '투자실행금액(A) + 순현금(EC) = 투자자산' 들의 합계가 되.
EC에서의 투자수익은 발생하지 않으니, '사용자가 선택한 Period에 속하는 각 샘플(S) 일자'들의 일별 '투자자신에서 발생한 수익'의 합 = '사용자가 선택한 Period에 속하는 각 샘플(S) 일자'들의 일별 '투자실행금액 대비 ty수익율 x 투자실행금액(A)'의 합 ≒  이미지2의 ④ x PSA이고,
'사용자가 선택한 Period에 속하는 각 샘플(S) 일자'들의 일별 투자자산의 합 = 해당 Period에 속하는 각 샘플(S) 일자의 'A + EC'의 합 = PSA + PSC
따라서,   '사용자가 선택한 Period에 속하는 투자자산대비 수익율' = ' 사용자가 선택한 Period에 속하는 각 샘플(S) 일자들의 일별 투자자신에서 발생한 수익의 합' / '사용자가 선택한 Period에 속하는 각 샘플(S) 일자들의 일별 투자자신의 합' =   (이미지2의 ④ x PSA)/(PSA + PSC)

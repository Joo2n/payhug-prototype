# 반올림 자리 규칙

기준일 2026-08-27 · 조회기간 2026-08-21 ~ 08-27

## 규칙 둘

### 1. 비율·일수 — 소수 6자리

소수 일곱째 자리에서 반올림해 **여섯째 자리까지** 남긴다. 다음 계산에는 이 6자리 값을 넣는다.
화면은 지금대로 소수 2자리까지 보이되, 보이는 값이 아니라 6자리 값으로 계산한다.

대상 — `wD` `wD(d-1)` `PwD` `MR(d-1)` `PMR` `Y_{MR,d−1}` `PY_{MR}` `wPY_{MR}` `Y_r` `LR` · 가중치 `A_i ÷ ΣA_i`

예외는 없다. `MR(d-1)` · `PMR` 도 끊는다.

```
wD(d-1)  원값 3.105802684513  →  계산에 쓰는 값 3.105803  →  화면 3.11일
PMR      원값 0.033991602832  →  계산에 쓰는 값 0.033992  →  ④ 에 넣는 값
```

6자리는 백분율 표기 기준이다 — `PMR = PM ÷ PA × 100` 을 끊는다. 비율 그대로 끊으면 백분율로 4자리만 남는다.

### 1-1. `PwD` 는 채권 경로

```
PwD = ( Σ A_i × D_i ) ÷ PA        i 는 조회기간 안 채권 전부
```

조회기간 안 채권을 한 뭉치로 모아 한 번에 낸다. 6자리로 끊은 `wD(d-1)` 을 다시 가중하지 않는다.
분자 `Σ A_i × D_i` 는 원 단위 정수라 중간에 끊는 자리가 없다.

### 2. 금액 — 원 단위, 끊는 곳을 하나로

원 아래는 남기지 않는다. 6자리 규칙은 금액에 적용하지 않는다.
**중간에 원 단위로 끊는 횟수를 줄인다** — 나눠 계산해 더하지 말고 한 줄로 낸다.

```
상환액 B(d-1) = 순지급액 − 차감액                     ← 이 길
              ≠ A(d-1) + M(d-1)                     ← 이 길은 중간에 두 번 끊는다
```

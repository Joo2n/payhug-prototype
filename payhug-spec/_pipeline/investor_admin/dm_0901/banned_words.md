# 산출물에 쓰지 않는 말

기획자가 반려한 낱말이다. 대표·기획자가 읽는 산출물(워드·HTML·엑셀)에 나오면 안 된다.
새 산출물을 낼 때마다 `verify_banned.py` 가 이 목록으로 검사한다.

## 쓰지 않는 말과 대신 쓸 말

| 쓰지 않는다 | 대신 | 근거 |
|---|---|---|
| `낱개` · `낱건` | `ID가 i인 대상정산금채권` | 대표 원문 14행 `Ai = ID가 i인 대상정산금채권의 …` |
| `재료` | `계산에 넣는 값` | 대표 원문에 없음 |
| `하루로 모으기` · `기간으로 모으기` | `하루 합계` · `조회기간 합계` | |
| `어디에 연결되나` | `화면 표시값 대조` | |
| `몫` · `이 테스트 케이스 몫` | 그 자리에서 무엇을 가리키는지 그대로 씀 | |
| `화면 값` | `화면 표시값` | |
| `갈려 나온다` · `갈려` | `~로 나온다` | 커밋 전 판의 말투 |
| `상수` | 분류 제목을 두지 않음 | 프로그래밍 낱말 |
| `이 글자는` | 주어를 용어 이름으로 | |
| `~자리` · `~꼴` (지시 대상이 흐릴 때) | 무엇을 가리키는지 그대로 씀 | |
| `투자금액` | `투자실행액` (투자 자산 화면) · `투자실행금` (투자 수익 화면) | 화면 열머리 실측 |
| `연회전수익률` | `연환산수익률` | 기획자 지시 2026-09-02 |
| `PTY자산` | `투자자산 대비 ty수익율` | 대표 원문 54행 · `PTY` 는 원문에 0회 |
| `w` · `S` · `Ty` 낱글자 단독 | `w금융일수` · `입금부족률` · `ty수익율` | 낱글자는 원문에 없음. `입금부족률` 은 화면 확정 라벨(2026-09-04) |
| `미결` · `확인필요` · `확인 필요` | 그 표시를 두지 않음 | 작업 진행 상태는 산출물에 넣지 않음. **「미확정」은 다름 — 미확정 3대 때문에 붙인 것이라 지운다** |

## 어투

| 하지 않는다 | 예 |
|---|---|
| 값 뒤에 대시로 설명을 붙임 | `16.34% — 카드사 70건만 놓고 낸 값이라 …` |
| 대시로 같은 말을 두 번 함 | `A입니다 — 즉 A라는 뜻입니다` |
| 문장을 종결하지 않고 가운뎃점으로 나열하고 끝냄 | `낱개 D_i · 하루 wD_{d−1} · 기간 PwD 로 갈려 나온다` |
| 마크다운 표시가 리터럴로 찍힘 | `**자기가 가중한 값 바로 앞**` · 백틱 |
| 값이 없는 칸을 `—` `-` `N/A` 로 채움 | 비운다 |
| 「~했습니다」식 수행보고·변경이력체 | 현재 상태만 서술 |

## 문장 규칙

설명은 완결된 문장으로 쓴다. `~다` · `~이다` · `~로 적는다` 로 끝낸다.

대표 정의서(`ceo_definitions.md`)의 말투를 뼈대로 삼고 바뀐 기호만 갈아 끼운다. 대표가 쓰는 말은 이렇다.

```
- 금융일수 = 선정산일로부터 정산예정일까지의 한편넣기 일수
- Ai = ID가 i인 대상정산금채권의 순지급액 x (1- 유동화투자자의 할인율)
- 표본집합: 선정산일이 D-20부터 D-11인 기간에 속하는 대상정산금채권들의 집합
- Σ AD-1i = 정산예정일이 전일자(D-1)인 모든 대상정산금채권의 '…'의 합
- 투자 실행금(PSA) = 정산예정일이 위 선택한 기간에 해당하는 투자실행금들 합계
```

## 근거 없는 글자를 만들지 않는다

대표 원문 · 화면 라벨 · 기호 정본(`symbol_rule_0901.md`) 셋 어디에도 없는 글자를 새로 만들지 않는다.
과거에 `TA` `EX` `AC` `NP` `F` `U` `OV` `PTY자산` 을 지어내서 전부 물렸다.

## 기계 검사가 이 표를 읽는 법

`verify_banned.py` 는 낱말을 제 안에 적어 두지 않고 위 표에서 읽는다. 표를 고치면 검사가 따라온다.

| 표에 적힌 것 | 검사 방식 |
|---|---|
| 「대신」 칸에 백틱 낱말이 있다 | 그 낱말이 나오는 자리를 전건 잡는다 |
| 「대신」 칸에 「그 자리에서」·「제목」이 들어 있다 | 제목·열 이름·라벨·단독 칸에 선 것만 잡는다. 문장 안은 둔다 |
| 「쓰지 않는다」 칸에 「단독」이 붙어 있다 | 그 칸이 통째로 그 글자일 때만 잡는다 |
| 「쓰지 않는다」 칸이 물결표로 시작한다 | 기계로 가르지 못해 수동 항목으로 센다 |
| 「대신」 칸의 백틱 낱말 | 대체어라 그 자리는 잡지 않는다 |

가려내는 자리는 대표 정의서 원문과 글자가 같은 대목, `quote`·`orig`·`ceo_source` 필드, 「기존 표기」·「옛 표기」 칸,
출처를 단 따옴표 인용, `<q>`·`<blockquote>` 안이다. 「미확정」은 표에 없어 잡히지 않는다.

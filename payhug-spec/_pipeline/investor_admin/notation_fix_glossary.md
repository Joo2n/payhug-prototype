## 2. 아래첨자 규약

| 자리 | 표기 |
|---|---|
| HTML | `B<sub>D−1,&thinsp;i</sub>` · `A<sub>i</sub>` · `A<sub>p,&thinsp;i</sub>` — 하이픈은 `−`(U+2212) |
| 마크다운 | `B_{D-1,i}` · `A_i` · `A_{p,i}` |
| 파이썬 식별자 | 손대지 않는다 |
| 앵커 id `sym-AD1i` | 손대지 않는다 — 기계 식별자 |

`symbol_glossary.json` 의 `symbol` 값도 마크다운 표기로 옮겼다. `restructure_glossary.py` 의 `sym_id()` 가 영숫자만 남기므로 앵커 id 는 `A(D-1)i` 시절과 같은 `sym-AD1i` 를 그대로 낸다.

손대지 않은 기호 — `PSA` `PSM` `PSD` `PSMR` `PSC` `EC` `W` `S` `Σ` `i` `D` `③④⑤⑥`.

`D`(현재일자) ↔ `D_i`(금융일수) 글자 충돌은 대표 회신 대기라 글자를 바꾸지 않고 표기만 갈랐다.

### 렌더 경로

`build_glossary.py` 에 `subs()` 를 넣었다. `inline()` 끝(교차참조 링크를 건 뒤) · 서술 코드펜스 · 카드 제목 · 목차 항목 · 목차 기호 칩. `alt` · `aria-label` · 검색키는 태그를 못 넣으므로 `flat()` 으로 표시만 걷는다. 검색키에 `A_i` 와 `Ai` 를 함께 넣어 두 표기 모두로 찾힌다.

## 3. 인용 보호 장치 (추가 5)

### 조판에서 가른다

`blocks()` 가 코드펜스 앞의 라벨을 보고 원문 인용 펜스를 가른다. 라벨이 `원문`으로 시작하고 `:` 로 끝나거나 `원문이 화면 수정 지시도 함께 달아 두었다.` 인 경우다.

| 블록 | 클래스 | 아래첨자 |
|---|---|---|
| 원문 인용 | `<pre class="calc quote">` | **걸지 않는다** |
| 문서 서술 | `<pre class="calc">` | 건다 |

배포본 실측 — 인용 37 · 서술 86. 인용 블록 안 `<sub>` 0건 · 밑줄 표기 0건. CSS 는 인용 블록에 왼쪽 4px 띠만 준다.

### 빌드가 세운다

`check_quote()` 가 인용 블록 각 줄을 `ceo_definitions.md` 와 글자 그대로 대조한다. `←n번 이미지` 주석과 `…` 줄임은 걷고 8자 이상 조각이 원문에 없으면 `SystemExit` 으로 빌드를 세운다.

음성 시험 — 인용 블록의 `Ai = ID가 i인 대상정산금채권의…` 를 `A_i = …` 로 바꿔 넣으니 빌드가 `!! 원문 인용 블록이 원문과 다르다 1줄` 로 멈췄다(rc=1). 되돌린 뒤 정상 빌드.

### 교체 시점의 보호 구간

| | 보호 구간 |
|---|---|
| P1 | 라벨이 「원문…:」인 코드펜스 37곳 |
| P2 | `「…」` 안 |
| P3 | `sym-XXXX` 앵커 id |
| P4 | 백틱·펜스 한 줄이 `ceo_definitions.md` 의 12자 이상 부분문자열일 때 |
| P5 | 평문 아래첨자 토큰이 「원문」이 든 줄에 있을 때 · 표기 흔들림 기록 줄 통째로 |

P4 예외 — `| 산식 |` 행은 문서가 다시 적은 산식이라 원문과 글자가 같아도 교체 대상이다.
라벨이 「원문」으로 시작해도 마침표로 끝나는 펜스 4곳(`원문에 순지급액의 정의문이 없다…` · `원문에 투자자산이라는 낱말의 정의문은 없다…` · `원문에 가맹점 단위 산식은 없다…` · `원문이 정한 절차는 이렇다.`)은 문서가 스스로 적은 블록이라 교체했다.

## 4. 낱말 교체

`ceo_definitions.md` 의 「만기」는 0건이다. 원문은 예외 없이 `정산예정일이 전일자(D-1)인` · `정산예정일이 위 선택한 기간에 해당하는` 관형절로 쓴다.

| 쓰임 | 바꾼 것 |
|---|---|
| 모집단 — `어제 만기가 돌아온 채권들` | `정산예정일이 어제인 채권들` |
| 모집단 — `고른 기간에 만기가 돌아온 채권들` | `정산예정일이 고른 기간에 든 채권들` |
| 모집단 — `그날 만기가 돌아온 채권` | `정산예정일이 그날인 채권` |
| 모집단 명사 — `전일자 만기` · `어제 만기분` | `전일자 도래분` |
| 모집단 명사 — `선택 기간 만기` · `기간 만기분` | `기간 도래분` |
| 날짜 — `만기에 100원을 받으니` · `만기까지 두는지` | `정산예정일에` · `정산예정일까지` |
| 기간 길이 — `만기가 짧을수록` · `채권의 만기를 더 무겁게` | `금융일수가 짧을수록` · `채권의 금융일수를 더 무겁게` |
| `플랫폼별 평균만기` · `그 가맹점의 평균만기` | `플랫폼별 w금융일수` · `그 가맹점의 w금융일수` |
| 계약 매핑표 행 이름 `투자 원금` | `투자 실행액` (원문 낱말) |

`채권 원리금` 은 이 조 파일에 0건이라 손댈 것이 없었다.
`조달이자형` · `대출 이자형` 은 이 조 파일에 0건이고 지시대로 손대지 않았다.
`투자자산` 은 `ceo_definitions.md` 에 1건 있는 원문 낱말이라 손대지 않았다.

카드 이름도 따라 바뀌었다 — `A_{D-1,i}` 의 한국어 이름이 `전일자 만기 채권 1건분 투자실행금` → `전일자 도래분 채권 1건분 투자실행금`. 검산 엑셀은 `SBD-1` `SAD-1` `SMD-1` `SDD-1` 넷에만 이름을 달아 출처 간 이름 대조는 갈리지 않는다.

### `Duration` 표기 제거 — 정본 표기 단일화

「`w금융일수` = `Duration` = `가중평균만기`」 서술을 3블록에서 걷었다. 대표가 2026-08-31 회의 00:44:30 에서 개명 권한을 넘겨(「그 이름은 바꿔도 돼, 내가 마음대로 붙인 이름이야」) 정본 표기를 `w금융일수` 하나로 세운 것이다. 지운 자리에 새 설명을 넣지 않았고, 살아남은 것은 가중치 사실과 출처뿐이다.

| 원고 줄 | 지운 것 | 남은 것 |
|---|---|---|
| 1237~1239 | 블록 제목 `금융 일반 용어로는 Duration` · `세계 공통 금융용어 Duration, 한국어로 가중평균만기와 같은 것이다` · `표준 지표다` | 블록 제목 `가중치` · `가중치는 투자액(= 선정산대금) 이다.` `확정` (조현준 `정산주기.xlsx` 2025년 365일 실측) |
| 2379~2381 | 같은 제목 · `w금융일수 = Duration(가중평균만기).` | 같은 제목 · 가중치 문장 · 플랫폼별 실측 4값 · 값의 범위 |

`정산주기.xlsx` 는 일수 도수분포 실측 문서이므로 이제 실측값(2.0 · 3.4 · 4.7 · 6.2일)과 가중치의 출처로만 붙어 있다. 걷어낸 것은 잘못 붙어 있던 출처이고, 용어 동일성 자체는 대표 구두 근거(2026-08-31 회의 00:43:33 · 00:44:30)로 성립한다.

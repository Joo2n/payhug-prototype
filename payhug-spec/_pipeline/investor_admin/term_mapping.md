# 화면 기준 용어 매핑 — 산출 기록

대상: `payhug-investor-admin/glossary.html` · `_pipeline/investor_admin/glossary_manuscript.md`
기준 자료: `ceo_definitions.md` (대표 정의 원문) · `invest-assets.html` · `invest-profit.html` 실물 라벨

숫자·산식·판정은 손대지 않았다. 바뀐 것은 이름·배치·안내 셋뿐이다. 할인율 `0.11% 예정` 단서, C1·C2·C4 미확정, 6대 개념 분리 원칙 모두 그대로다.

## §1. 매핑표

문서 최상단에 `§0 화면에서 본 이름으로 찾기`를 새로 두었다. `§1 전체 그림`보다 앞이다. 열은 다섯이다 — `화면에서 보는 이름` · `어느 화면 · 어느 자리` · `대표님 정의 원문` · `이 문서에서는` · `한 줄 뜻`.

### 1-1. 고정 13행 (대표님께 보낸 나열 그대로)

|---|---|---|---|

## §2. 층위 분리

카드를 두 층으로 갈랐다. 기준은 **그 이름이 화면에 뜨느냐**다. 뱃지·필터·검색 세 곳에 같은 축을 넣었다.

| 층위 | 뜻 | 개수 |
|---|---|---|
| `화면 용어` | 화면에 라벨 또는 값으로 실제로 뜬다 — 독자가 찾는 것 | 28 |
| `계산 재료` | 화면에 안 뜨고 산식·정의 안에서만 쓰인다 | 22 |

**`계산 재료` 22건**
`정산금채권` · `정산금채권 ID` · `플랫폼ID` · `매출일자` · `선정산일` · `순지급액` · `효력기간` · `대상정산금채권` · `Ai` · `채권매입수수료` · `회수되지 않은 순지급액` · `Di` · `미지급금` · `과지급금` · `SLi` · `SAi` · `표본집합` · `투자수익율 (일별 배치 · 하루치)` · `순현금 (일별 배치 · 자정 시점)` · `PSMR` · `PSD` · `PSC`

지적된 중간 계산 기호 7개(`Ai` `Di` `SLi` `SAi` `PSMR` `PSD` `PSC`)는 전부 이쪽이다. `AD-1i` · `DD-1i` · `Api` · `Dpi` · `MD-1i` · `BD-1i`는 단독 카드가 없고 상위 카드 산식 안에서 풀린다.

**판정이 갈렸던 것**

| 카드 | 판정 | 근거 |
|---|---|---|
| `PSD` | 계산 재료 | 일별 표 합계 행에 값이 뜨기는 하나, 그 자리의 라벨은 `W금융일수`다. `PSD`라는 이름은 화면에 없다 |
| `투자수익율 (일별 배치 · 하루치)` | 계산 재료 | 율 자체는 안 뜨고 연 환산한 `Ty수익율`로만 보인다 |
| `순현금 (일별 배치 · 자정 시점)` | 계산 재료 | 자정 잔액은 화면에 없고 `PSC`의 재료로만 쓰인다 |
| `금융일수` | 화면 용어 | 두 화면 각주 `용어 안내` 첫 줄에 정의가 실제로 떠 있다 |
| `유동화투자자의 할인율` | 화면 용어 | 각주 `Ty수익율: 할인율 × (365 / w금융일수)`와 `배분 요율 0.11%`로 뜬다 |
| `유동화투자자` | 화면 용어 | 사이드바 프로필 `투자자` 배지, 가맹점 화면 필터 `채권매입업체`가 이것이다 |

**필터** — 상단에 `층위` 칩 두 개(`화면 용어 28` · `계산 재료 22`)를 추가했다. 기존 출처 칩 5종과 AND로 걸린다. 검색 인덱스는 카드 본문 전체를 훑으므로 부제로 내린 기호(`SB` `SA` `PSA` 등)도 그대로 걸린다.

## §3. 이름 규칙과 근거

### 3-1. 규칙

**`용어 (어느 계통 · 어느 집계 단위)`** 하나로 통일했다. 계통은 셋이다.

| 꼬리표 | 언제 만들어지나 | 어디에 뜨나 |
|---|---|---|
| `투자 자산 · 잔액` | 화면을 조회하는 그 순간 계산 | `invest-assets.html` 두 표 |
| `일별 배치 · 하루치` | 매일 자정 배치가 D-1치로 한 줄 기록 | `invest-profit.html` 일별 표 각 행 |
| `투자 수익 · 기간 합계` | 고른 기간만큼 하루치를 더해 계산 | `invest-profit.html` 현황 카드 |

기호(`SB` `SA` `SM` `SMR` `SD` `EC` `PSA` `PSM`)와 원문 번호(`④` `⑤` `⑥`)는 이름에서 빼고 카드 제목 옆 **부제**로 내렸다.

적용 범위는 카드 제목 · 읽는 순서 칩 · 화면 역방향 색인 칩 · 검색 인덱스 넷이다. 본문 산문 안의 교차링크는 문장 흐름을 지키려고 종전 약칭을 그대로 뒀다 — 클릭하면 같은 카드로 간다.

### 3-3. 판단 근거

| 결정 | 근거 |
|---|---|
| 괄호에 기호가 아니라 **계통·단위**를 넣는다 | 독자가 화면을 보고 찾는다. 화면에는 `SB`도 `PSA`도 없고 `상환액` `투자실행금`만 있다. 기호는 원문을 대조할 때만 필요하므로 부제 자리가 맞다 |
| 계통을 셋으로 못 박는다 | 대표 정의 원문이 이미 세 계통으로 갈라 쓴다 — 조회 시점(1번 이미지), 자정 배치(2번 이미지 전반), 기간 합산(2번 이미지 후반). 새 축을 만든 것이 아니라 원문 구조를 이름에 드러낸 것 |
| `④` `⑤` `⑥`을 이름 앞에서 뺀다 | 원문이 참조한 이미지가 문서에 없어 번호만으로는 어느 자리인지 못 짚는다. 실제 화면 라벨(`투자실행금액 대비` · `투자자산 대비`)이 앞에 오는 편이 찾기 쉽다. 번호는 부제로 남겨 원문 대조는 유지 |
| 소문자 `w` · `ty`를 유지한다 | 화면 표기는 `W` · `Ty`지만 카드 이름 규칙이 「대표 정의서 표기 그대로」다. 검색은 대소문자를 가리지 않아 `W금융일수`로 쳐도 걸리고, 매핑표가 화면 표기 → 카드 이름을 이어 준다 |
| `투자 실행금` → `투자실행금` (띄어쓰기 정리) | 원문이 같은 값을 `투자 실행금(PSA)`과 `투자실행금(SAD-1)` 두 표기로 쓴다. 띄어쓰기 차이가 다른 개념으로 읽히는 함정이 되므로 화면 표기(`투자실행금`)로 맞췄다. 원문 표기는 매핑표 `대표님 정의 원문` 열과 카드 안 원문 인용 블록에 그대로 남아 있다 |
| `투자 실행액`은 그대로 둔다 | 갈리는 이름이 아니라 개명 대상이 아니다. 원문 표기가 곧 카드 이름이다 |

## §4. 대표 정의 전수 대조

`ceo_definitions.md`의 정의 불릿은 45개다(1번 이미지 19 · 2번 이미지 26).

### 4-1. 누락 — 0건

45개 전부 문서에 있다. 단독 카드가 없는 것은 상위 카드 산식 안에서 풀린다.

| 원문 항목 | 어디에 들어갔나 |
|---|---|
| `D = 현재일자` | `표본집합` 카드 — 원문 인용·기호 풀이·미결(조회 시각이냐 배치 실행일이냐) |
| `Σ BD-1i` · `MD-1i` | `상환액` · `투자수익` 카드 산식 |
| `AD-1i` · `DD-1i` | `투자실행금 (일별 배치 · 하루치)` · `w금융일수 (일별 배치 · 하루치)` 카드 |
| `Api` · `Dpi` | `PSD` 카드 |
| `평균순현금` | `순현금 (일별 배치 · 자정 시점)` 카드 — 원문이 배치 산출 목록에만 적고 산식을 안 준 항목으로 등재 |
| `투자 실행액의 비중` · `순현금의 비중` | `비중` 카드 (두 산식 모두 인용) |
| 배치 서술 · 기간 선택 서술 | 6단계 · 7단계 머리글과 `검색대상기간` 카드 |

### 4-2. 초과 — 대표 정의에 없는데 문서에 있는 카드

**정의문 없이 이름·구절로만 원문에 등장하는 것 — 13건**
`정산금채권` · `매출일자` · `선정산일` · `정산예정일` · `순지급액` · `유동화투자자` · `정산금채권 재양도 합의서` · `효력기간` · `채권매입수수료` · `회수되지 않은 순지급액` · `쿠콘 가상계좌` · `미지급금` · `과지급금`
→ 출처 표기: 대표 정의 원문 구절 + 운영 어드민(`payhug-admin-web`)·Figma 정산채권DB 대조. 카드마다 `이 값은 어디서 오나` 블록에 소재를 적어 두었다.

**원문에 이름조차 없는 것 — 5건**

| 카드 | 출처 |
|---|---|
| `자산 구분` | 스토리보드 슬라이드 3·4 (현황표 첫 열) |
| `보관` | 스토리보드 슬라이드 3 (현황표 마지막 열) |
| `가맹점별 투자금액` | 스토리보드 슬라이드 3 · 현행 `invest-assets.html` 가맹점별 표 |
| `기준일자` | 현행 화면 헤더 · 스토리보드(표마다 다른 날짜) — 소재 `추적 중` 유지 |
| `검색대상기간` | 현행 `invest-profit.html` 화면 컨트롤. 산출 서술만 원문에 있고 라벨은 화면 것 |

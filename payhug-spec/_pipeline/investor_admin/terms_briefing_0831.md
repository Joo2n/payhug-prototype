# 1. 먼저 갈라야 하는 두 가지 — 정산주기와 금융일수

숫자가 비슷해서 붙여 읽기 쉬운데, 재는 대상이 다르다.

| | 정산주기 | 금융일수 |
|---|---|---|
| 재는 것 | 플랫폼이 매출일로부터 며칠 뒤에 정산금을 주기로 했는가 | 투자자 돈이 며칠 묶여 있는가 |
| 단위 | 영업일 | 달력일 |
| 시작점 | 매출일(결제일) | 선정산일 = 결제일 다음날 |
| 끝점 | 플랫폼 입금일 | 락계좌 입금일 = 정산예정일 |
| 값 | 플랫폼과의 약속이라 고정 | 요일·공휴일에 따라 매일 달라짐 |
| 주인 | 플랫폼 | 투자자 |

## 1-1. 카드가 2영업일인데 금융일수도 2.0인 이유

`확정` 두 숫자가 비슷하게 나온 것은 우연이다. 만드는 과정이 완전히 다르다.

카드(van) 정산주기는 2영업일이다. 매출일 다음날 가맹점에 선정산금이 나가고, 그 순간부터 카드사 돈이 락계좌에 들어올 때까지가 투자자 자금이 묶인 구간이다. 요일별로 이렇게 갈린다 (`정산주기.xlsx` 시트 `정산주기` E33:G39).

| 결제일 | 선정산일 | 락계좌 입금일 | 금융일수 |
|---|---|---|---|
| 일 | 월 | 화 | 1 |
| 월 | 화 | 수 | 1 |
| 화 | 수 | 목 | 1 |
| 수 | 목 | 금 | 1 |
| 목 | 금 | 다음주 월 | 3 |
| 금 | 토 | 다음주 화 | 3 |
| 토 | 일 | 다음주 화 | 2 |

한 주 합 = 1+1+1+1+3+3+2 = **12일**, 7로 나누면 **1.714일**.

여기에 2025년 달력을 얹는다. 2025년은 수요일이 53회, 나머지 요일이 52회다. 요일별 값을 그대로 곱하면 한 해 합계 **625일**, 365로 나누면 **1.712일**.

실제 시트의 카드사 금융일수 합계는 **736일**이다(`Q6:Q370` 합). 차이 **111일**은 금·토가 아닌 공휴일 19일이 만든다. 연휴 앞뒤로 **36개 날짜**의 금융일수가 늘어난다.

736 ÷ 365 = **2.016438일**. 이것이 카드사 연평균 금융일수다.

2025년 카드 금융일수 분포 (365일 실측, `Q6:Q370`)

| 금융일수 | 일수 | 어디서 나오는가 |
|---|---|---|
| 1일 | **189** | 일·월·화·수 결제분 209일 중 공휴일에 안 밀린 것 (20일이 밀려 나감) |
| 2일 | **53** | 토 결제분 52일 중 47일 + 연휴 끝자락에서 넘어온 6일 |
| 3일 | **96** | 목·금 결제분 104일 중 93일 + 연휴 끝자락에서 넘어온 3일 |
| 4일 이상 | **27** | 연휴에 걸린 것. 최댓값 **10일** — 10/2(목) 결제분이 10/13(월)에 들어온다 |

값이 밀린 매출일은 아홉 구간 36일이다.

```
01/23~01/29 (7)   02/27~03/02 (4)   05/01~05/05 (5)
05/30~06/02 (4)   06/04~06/05 (2)   08/13~08/14 (2)
10/01~10/08 (8)   12/23~12/24 (2)   12/30~12/31 (2)
```

즉 **2영업일이라는 정산주기와 2.016일이라는 금융일수는 다른 대상을 잰 다른 숫자다.** 카드사는 언제나 2영업일을 지켰고, 금융일수는 그 2영업일이 달력 위 어디에 떨어지느냐로 1일이 되기도 10일이 되기도 한다.

`확인 Q1`

## 3-2. 하루치 순지급액

`가설` 정의서에 일별 규모가 적혀 있지 않아 현황 **투자실행액 1,523,100,000** 에서 거꾸로 잡았다.

```
투자실행액(잔액) = 하루치 투자실행금 × w금융일수
1,523,100,000 ÷ 2.7504068549 = 553,772,616   ← 하루치 투자실행금
553,772,616 ÷ (1 − 0.0011)   = 554,382,437   ← 하루치 순지급액
```

이 관계를 말로 풀면 이렇다. 매일 5.54억이 새로 나가고 평균 2.75일 묶여 있으면, 어느 시점에 잔액을 세도 늘 15.23억이 나가 있다.

# 4. 정의서 1번 이미지 — 조회 시점 현황

## 4-1. 유동화투자자의 할인율

**대표님 정의 원문**
> 유동화투자자의 할인율 = 0.11% 예정
> (8/28) 투자자 할인율 = (채권매입)수수료율. 내부 용어이며 외부에는 `할인율`로 표기

**내 말로 푼 뜻**
투자자가 정산금채권을 액면보다 싸게 사들이는 그 할인 폭. 액면 1,000원짜리 채권을 998.9원에 사고 만기에 1,000원을 받으니, 그 1.1원이 투자자 몫이 된다. 이자를 따로 받는 구조가 아니라 **싸게 사는 방식으로 수익을 만드는 구조**로 읽었다.

**산식**
```
채권매입수수료 = 순지급액 × 할인율
투자실행금     = 순지급액 × (1 − 할인율)
```

**예시 숫자**
```
카드 채권 1건, 순지급액 360,348,584원
채권매입수수료 = 360,348,584 × 0.0011 = 396,383원
투자실행금     = 360,348,584 × 0.9989 = 359,952,201원
```

**확인할 것**
`채권매입수수료` 라는 낱말은 2번 이미지 `MD-1i` 정의에만 나오고 1번 이미지에는 정의가 없다. `순지급액 × 할인율` 로 읽었다. `확인 Q4`

## 4-2. 순지급액

**대표님 정의 원문**
정의 없음. `투자 실행액` `Ai` `SAi` `BD-1i` `AD-1i` 다섯 자리에서 쓰이지만 뜻을 적은 줄이 없다.

**내 말로 푼 뜻**
`가설` 정산금채권의 액면. 정산예정일에 락계좌로 들어와야 할 금액.

그런데 두 가지로 읽힌다.

| 읽는 법 | 뜻 | 따라오는 결론 |
|---|---|---|
| (가) | 가맹점에 실제로 이체한 선정산 금액 | 투자자가 359,952,201원을 넣고 가맹점은 360,348,584원을 받는다. 차액 396,383원을 누가 채우는지 별도 설명이 필요 |
| (나) | 플랫폼이 락계좌에 넣을 정산금 총액 | 투자자는 액면을 할인 매입한 것이고, 그 액면과 가맹점 지급액의 차이는 페이허그 몫 |

**확인할 것**
어느 쪽인가. (가)라면 0.11% 차액의 출처가 필요하고, (나)라면 가맹점 화면의 `순지급액`과 투자자 화면의 `순지급액`이 다른 값이 된다. `확인 Q5`

## 4-3. 정산금채권 · 정산금채권 ID · 플랫폼ID

**대표님 정의 원문**
> 각 정산금채권의 ID = 가맹점ID & 플랫폼ID & 매출일자(YYYYMMDD)
> 플랫폼ID: 각 카드사, 각 배달플랫폼에 페이허그가 할당한 ID
> (8/28) 정산금채권 = 돈 주는 곳은 모두 플랫폼. 특정 플랫폼이 특정 가맹점에게 서로의 약속으로 정산예정일에 주기로 한 돈, 그 권리. 정식 용어는 정산금채권
> (8/28) 정산금채권 단위 = 특정 일자 · 특정 가맹점(ID)에 대해 특정 플랫폼이 지급할 돈

**내 말로 푼 뜻**
"9월 11일에 김성호떡볶이가 A카드사로 판 매출을 A카드사가 나중에 주기로 한 돈" 이 한 덩어리가 채권 1건이다. 세 값을 붙이면 이름이 된다.

**산식**
```
ID = 가맹점ID & 플랫폼ID & 매출일자
```

**예시 숫자**
```
M-1024 & CARD-01 & 20250911
   가맹점 M-1024 이 2025-09-11 에 CARD-01 로 낸 매출의 정산금채권
   순지급액 360,348,584원 · 선정산일 2025-09-12 · 정산예정일 2025-09-15 · 금융일수 3일
```

**확인할 것**
ID에 결제 건별 구분이 없다. 같은 날 같은 가맹점의 같은 플랫폼 매출은 몇 건이든 **1건으로 뭉친다**로 읽었다. 카드사가 여럿이면 `플랫폼ID`가 갈리므로 카드 안에서는 카드사 단위로 쪼개진다. `확인 Q6`

## 4-4. 대상정산금채권

**대표님 정의 원문**
> 대상정산금채권: 가맹점ID가 '유동화투자자와 정산금채권 재양도 합의서 체결한 가맹점'의 ID이면서, 선정산일자가 상기 합의서상의 효력기간에 해당하는 정산금채권
> (8/28) 정산금채권 중 투자자(나)에게 속하는 것. 매입 단위는 가맹점. 가맹점당 투자자 1명, 투자자 1명 : 가맹점 다수

**내 말로 푼 뜻**
전체 정산금채권 중에서 **로그인한 그 투자자가 돈을 댄 것만** 골라낸 묶음. 거르는 조건이 두 개다.

1. 가맹점 조건 — 그 투자자와 재양도 합의서를 쓴 가맹점인가
2. 날짜 조건 — 그 채권의 **선정산일**이 합의서 효력기간 안에 드는가

날짜 조건이 매출일이 아니라 선정산일 기준인 점이 중요하다. 8월 31일 매출은 9월 1일이 선정산일이라, 합의서가 9월 1일 발효면 8월 31일 매출도 들어온다.

**예시 숫자**
```
합의서 효력기간 2025-09-01 ~ 2026-08-31
매출일 2025-08-31 · 선정산일 2025-09-01  → 대상 (선정산일이 기간 안)
매출일 2026-08-31 · 선정산일 2026-09-01  → 비대상 (선정산일이 기간 밖)
```

**확인할 것**
없음. `확정`

## 4-5. 투자 실행액

**대표님 정의 원문**
> 투자 실행액: '유동화투자자와 정산금채권 재양도 합의서 체결한 가맹점들의 순지급액들 중 회수되지 않은 순지급액 합계' × (1 − 유동화투자자의 할인율)

**내 말로 푼 뜻**
지금 이 순간 나가 있고 아직 안 돌아온 돈. 매일 새로 나가고 매일 일부가 돌아오니 잔액처럼 움직인다.

**산식**
```
투자실행액 = Σ(미회수 순지급액) × (1 − 할인율)
```

**예시 숫자**
```
미회수 순지급액 합계 1,524,777,255원
× 0.9989 = 1,523,100,000원
```

**확인할 것**
`회수되지 않은` 의 뜻. 사내에서 `회수`는 이미 두 가지로 쓰인다.

| 자리 | 회수의 뜻 |
|---|---|
| 사내 정책 (`02_TERMS` §4) | 가맹점에 과지급한 돈을 되받는 처리 |
| 어드민 `매출 회수` | 락계좌에 모인 돈을 모계좌로 쓸어담는 처리 |
| 정의서 이 자리 | **플랫폼 정산금이 아직 락계좌에 안 들어온 상태**로 읽었다 |

세 번째 뜻으로 읽은 것이 맞는가. 맞다면 문서에서는 `미도래` 같은 다른 낱말로 갈라 쓰는 편이 안전하다. `확인 Q7`

## 4-6. 순현금

**대표님 정의 원문**
> 순현금: 조회시점 현재의 '유동화투자자에게 할당된 쿠콘제공 가상계좌'의 현금잔액
> (8/28) 쿠콘 가상계좌의 현 잔액. 현재는 페이허그 가상계좌 1개. 법적으로는 페이허그용으로 개설된 쿠콘 명의의 케이뱅크 계좌. 투자자별 케이뱅크 계좌 1개씩 제공 예정

**내 말로 푼 뜻**
채권으로 나가 있지 않고 계좌에 놀고 있는 돈. 투자자산 중 아직 일을 안 하는 부분.

**예시 숫자**
```
순현금 105,300,000원
```

**확인할 것**
두 가지가 갈린다.

1. 시점 — 1번 이미지는 `조회시점 현재`, 2번 이미지 `EC`는 `전일자 마감시점(자정)`. 현황 화면은 실시간 잔액, 일별 배치는 자정 잔액으로 서로 다른 값이 저장된다로 읽었다. `확인 Q8`
2. 계좌 분리 — 지금은 페이허그 가상계좌 1개뿐인데, 투자자별 계좌가 생기기 전까지 투자자 A의 순현금을 어떻게 가려내는가. `확인 Q9`

## 4-7. 비중

**대표님 정의 원문**
> 투자 실행액의 비중 = 투자실행액 / (투자실행액 + 순현금)
> 순현금의 비중 = 순현금 / (투자실행액 + 순현금)

**내 말로 푼 뜻**
투자자 돈 전체를 100으로 놓고, 그중 몇 %가 채권으로 나가 있고 몇 %가 현금으로 남아 있는가.

**산식·예시 숫자**
```
분모 = 1,523,100,000 + 105,300,000 = 1,628,400,000
투자실행액 비중 = 1,523,100,000 ÷ 1,628,400,000 = 93.5335% → 93.5%
순현금 비중     =   105,300,000 ÷ 1,628,400,000 =  6.4665% →  6.5%
합계 100.0%
```

**확인할 것**
분모 `투자실행액 + 순현금` 에 이름이 없다. 화면에서는 `투자자산`으로 부르고 있다. 이 낱말을 정식 용어로 삼는 것이 맞는가. `확인 Q10`

## 4-8. 금융일수

**대표님 정의 원문**
> 금융일수 = 선정산일로부터 정산예정일까지의 한편넣기 일수 (예, 선정산일 = 260827, 정산예정일 = 260808 이면 금융일수 = 1)

**내 말로 푼 뜻**
투자자 돈이 묶여 있는 달력일 수. 시작은 선정산일(가맹점에 돈이 나간 날), 끝은 정산예정일(플랫폼 돈이 락계좌에 들어오는 날).

`한편넣기` 는 양쪽 끝 중 **한쪽만 세는 방식**으로 읽었다. 즉 뺄셈 한 번이다.

**산식**
```
금융일수 = 정산예정일 − 선정산일
선정산일 = 결제일 + 1일 (달력일)
정산예정일 = 결제일 + N영업일 (플랫폼 정산주기)
```

**예시 숫자**
```
2025-09-11(목) 카드 결제
  선정산일   2025-09-12(금)
  정산예정일 2025-09-15(월)   ← 9/12, 9/15 두 영업일
  금융일수   15 − 12 = 3일

2025-10-02(목) 카드 결제
  선정산일   2025-10-03(금)
  정산예정일 2025-10-13(월)   ← 10/3~10/9 추석 연휴, 10/10·10/13 두 영업일
  금융일수   13 − 3 = 10일
```

**확인할 것**
① 정의서 예시가 성립하지 않는다. `선정산일 260827, 정산예정일 260808` 이면 정산예정일이 선정산일보다 19일 앞이다. **260828의 오타**로 읽었고 그러면 `28 − 27 = 1` 이 맞는다. 2번 이미지 예시(`20260824 → 20260826 이면 2`)도 같은 방식이라 일관된다. `확인 Q1`

② 끝점이 `정산예정일`인가 `실제 입금일`인가. 엑셀은 `락계좌 입금일` 열로 잡았고, 정의서 2번 이미지에서는 표 열 이름을 `입금일`에서 `정산예정일`로 바꾸라고 적혀 있다. 둘을 같은 것으로 보되, **플랫폼이 예정일보다 늦게 넣으면 그 지연은 금융일수에 안 잡힌다**로 읽었다. `확인 Q11`

③ 락계좌에 들어온 뒤 투자자 쿠콘 가상계좌로 옮겨지기까지의 구간은 금융일수 밖이다. 그 구간이 하루 이상이면 실제 자금 구속 기간이 금융일수보다 길어진다. `확인 Q12`

## 4-9. Ai · Di · w금융일수

**대표님 정의 원문**
> w금융일수 = Σ Ai × Di / Σ Ai
> Ai = ID가 i인 대상정산금채권의 순지급액 × (1 − 유동화투자자의 할인율)
> Di = ID가 i인 다상정산금채권의 금융일수

**내 말로 푼 뜻**
금액으로 가중한 평균 금융일수. 큰 채권의 기간이 평균을 더 많이 끌어당긴다. 100원짜리 10일과 10,000원짜리 2일을 그냥 평균 내면 6일이지만, 실제로 돈이 묶인 체감은 2일 쪽에 훨씬 가깝다. 그 왜곡을 없애려고 금액으로 가중한다.

할인율은 모든 채권에 같은 비율로 곱해지므로 분자·분모에서 약분된다. 순지급액으로 가중해도 결과가 같다.

**산식**
```
w금융일수 = Σ(Ai × Di) ÷ Σ Ai
```

**예시 숫자** — 2025-09-16 조회시점 미회수 16건

| 플랫폼 | 건수 | 투자실행금 합 | 금융일수 |
|---|---|---|---|
| 카드 | 1 | 359,952,201 | 1 |
| 배민 | 4 | 455,124,864 | 4·3·2·2 |
| 쿠팡이츠 | 5 | 273,074,915 | 5·5·4·3·3 |
| 요기요 | 6 | 152,545,296 | 6·6·6·5·4·6 |
| 합계 | **16** | **1,240,697,276** | — |

```
Σ(Ai × Di) = 3,542,844,365
w금융일수  = 3,542,844,365 ÷ 1,240,697,276 = 2.8555일
```

**확인할 것**
`다상정산금채권`은 `대상정산금채권`의 오타로 읽었다. 그리고 이 자리의 모집단이 8장에서 다시 문제가 된다. `확인 Q13`

## 4-10. ty수익율

**대표님 정의 원문**
> ty수익율 = 유동화투자자의 할인율 × (365 / w금융일수)

**내 말로 푼 뜻**
0.11%는 한 번 회전할 때 버는 몫이다. 회전이 빠르면 1년에 여러 번 벌 수 있으니, 1년에 몇 번 도는지를 곱해 연 단위로 환산한 것. `ty` 는 **연환산(to year)** 표시로 읽었다.

**산식**
```
ty수익율 = 할인율 × 365 ÷ w금융일수
```

**예시 숫자**

| 기준 | w금융일수 | 계산 | ty수익율 |
|---|---|---|---|
| 카드만 | 2.016438 | 0.0011 × 365 ÷ 2.016438 | 19.91% |
| 배민만 | 3.350685 | 0.0011 × 365 ÷ 3.350685 | 11.98% |
| 쿠팡이츠만 | 4.747945 | 0.0011 × 365 ÷ 4.747945 | 8.46% |
| 요기요만 | 6.164384 | 0.0011 × 365 ÷ 6.164384 | 6.51% |
| **전체 가중평균** | **2.750407** | 0.0011 × 365 ÷ 2.750407 | **14.60%** |

한 가지 주의점을 적어 둔다. **플랫폼별 ty수익율을 구성비로 단순 가중평균하면 16.54%가 나와 14.60%와 어긋난다.** 나눗셈이 끼어 있어 평균의 순서를 바꾸면 값이 달라지기 때문이다. w금융일수를 먼저 가중평균하고 그다음에 365를 나누는 순서가 정의서 산식이고, 이 순서가 맞는다.

**확인할 것**
분자가 `할인율 0.11%` 인가 `할인율 ÷ (1−할인율) = 0.110121%` 인가. 2번 이미지의 `SMRD-1` 은 투자수익 ÷ 투자실행금이라 후자가 되고, 1번 이미지는 전자다.

```
0.0011      × 365 ÷ 2.750407 = 14.5978%
0.00110121  × 365 ÷ 2.750407 = 14.6139%
```
차이 0.016%p. `확인 Q14`

## 4-11. S입금부족율 · SLi · SAi · 표본집합 · D

**대표님 정의 원문**
> S입금부족율 = Σ SLi / Σ SAi
> SLi = 표본집합에 속하는 ID가 i인 대상정산금채권의 미지급액 – 과지급액
> 표본집합: 선정산일이 D-20부터 D-11인 기간에 속하는 대상정산금채권들의 집합
> D = 현재일자
> SAi = 표본집합에 속하는 ID가 i인 대상정산급채권의 순지급액 × (1 − 유동화투자자의 할인율)

**내 말로 푼 뜻**
"플랫폼이 락계좌에 넣기로 한 돈 중 실제로 얼마가 덜 들어왔나"를 비율로 잰 것. 투자자 입장의 부도율에 해당한다.

최근 것을 쓰지 않고 `D-20 ~ D-11` 이라는 **지나간 10일 구간**을 표본으로 삼은 이유는, 그 구간 채권은 이미 정산예정일이 지나 미지급·과지급이 확정됐기 때문으로 읽었다.

**산식**
```
S입금부족율 = Σ(미지급액 − 과지급액) ÷ Σ(순지급액 × (1 − 할인율))
```

**예시 숫자**
```
D = 2025-09-16
표본집합 = 선정산일 2025-08-27 ~ 2025-09-05  (10일 × 4플랫폼 = 40건)

Σ SAi = 553,772,616 × 10 = 5,537,726,160
미지급액 합계 4,431,000
과지급액 합계   555,000
Σ SLi = 4,431,000 − 555,000 = 3,876,000

S입금부족율 = 3,876,000 ÷ 5,537,726,160 = 0.069993% → 0.07%
```
읽는 법 — 락계좌에 들어와야 할 돈 1억원당 69,993원이 덜 들어왔다.

**확인할 것**
① 표본 하한 `D-11` 이 플랫폼 최대 금융일수를 못 덮는다.

| 플랫폼 | 최대 금융일수 | 선정산일 D-11 채권의 정산예정일 | 판정 가능 |
|---|---|---|---|
| 카드 | 10 | D-1 | 가능 |
| 배민 | 11 | D | 당일 |
| 쿠팡이츠 | 12 | D+1 | 미도래 |
| 요기요 | 13 | D+2 | 미도래 |

연휴가 낀 구간에서는 배달앱 채권 일부가 아직 도래하지 않은 채 표본에 들어와, 미지급도 과지급도 아닌데 미지급으로 잡힐 수 있다. 하한을 **D-14**로 내리면 요기요 최대 13일까지 덮는다. `확인 Q15`

② `SLi` 는 음수를 허용하는데(미지급 − 과지급 그대로), 2번 이미지의 상환액·투자수익은 `max(0, 미지급금 − 과지급금)` 으로 음수를 0에서 자른다. 같은 양을 두 자리에서 다르게 다루는 것이 맞는가. `확인 Q16`

③ 1번 이미지는 `미지급액 · 과지급액`, 2번 이미지는 `미지급금 · 과지급금` 이다. 같은 것으로 읽었다. `확인 Q17`

## 5-0. 배치가 도는 조건

**대표님 정의 원문**
> 매일 자정일 지나면, 배치 작업으로, 유동화투자자별로 '정산예정일이 전일자인 정산금채권의 ID들' 추출하고, 상기 각 대상정산금채권별로 선정산일자 검색하고, 아래와 같이 전일자(D-1) 대상정산금채권의 상환액(SBD-1), 투자실행금(SAD-1), 투자수익(SMD-1), 투자수익율(SMRD-1), w금융일수(SDD-1), ty수익율, 평균순현금 산출해 DB 업데이트

**내 말로 푼 뜻**
매일 자정 이후, **어제 만기가 온 채권만** 골라 그날 하루치 실적을 확정하고 저장한다. 골라내는 열쇠는 `정산예정일 = 어제` 다. 채권을 고른 다음에 각각의 선정산일을 되짚어 금융일수를 계산한다.

## 5-1. 상환액 SBD-1

**대표님 정의 원문**
> 전일자(D-1) 대상정산금채권의 상환액(SBD-1) = Σ BD-1i
> Σ BD-1i = 정산예정일이 전일자(D-1)인 모든 대상정산금채권의 '순지급액 - max(0, 미지급금-과지급금)'의 합

**내 말로 푼 뜻**
어제 실제로 락계좌에 들어와 투자자에게 돌아온 돈. 원래 들어와야 할 액면에서 덜 들어온 만큼을 뺀 값이다.

`max(0, …)` 는 **음수는 0으로 본다**는 뜻이다. 즉 덜 들어왔으면 그만큼 깎고, 더 들어왔으면 깎지 않는다.

**산식**
```
BD-1i   = 순지급액 − max(0, 미지급금 − 과지급금)
SBD-1   = Σ BD-1i
```

**예시 숫자**

전액 정상 입금인 경우
```
SBD-1 = 554,382,437 − 0 = 554,382,437원
```

카드 채권에서 500,000원이 덜 들어온 경우
```
미지급금 500,000 · 과지급금 0
max(0, 500,000 − 0) = 500,000
카드 상환액 = 360,348,584 − 500,000 = 359,848,584
SBD-1      = 554,382,437 − 500,000 = 553,882,437원
```

카드 채권에 500,000원이 더 들어온 경우
```
미지급금 0 · 과지급금 500,000
max(0, 0 − 500,000) = 0
카드 상환액 = 360,348,584 (초과 500,000은 잡히지 않음)
SBD-1      = 554,382,437원
```

**확인할 것**
초과로 들어온 500,000원은 산식 어디에도 잡히지 않는다. 이 돈은 (가) 순현금으로 남는가 (나) 다음 회차 미지급과 상계되는가 (다) 페이허그가 플랫폼에 돌려주는가. `확인 Q19`

## 5-2. 투자실행금 SAD-1

**대표님 정의 원문**
> 전일자(D-1) 대상정산금채권의 투자실행금(SAD-1) = Σ AD-1i
> Σ AD-1i = 정산예정일이 전일자(D-1)인 모든 대상정산금채권의 '순지급액 x (1 - 유동화투자자의 할인율)'의 합
> AD-1i = 정산예정일이 전일자(D-1)이면서 ID가 i인 대상정산금채권의 순지급액 x (1- 유동화투자자의 할인율)

**내 말로 푼 뜻**
어제 만기가 온 그 채권들을 살 때 투자자가 실제로 낸 돈. 1번 이미지의 `투자실행액`이 지금 나가 있는 **잔액**이라면, 여기 `투자실행금`은 하루치 **흐름**이다. 이름이 한 글자 차이라 붙여 읽기 쉬우나 성격이 다르다.

**산식**
```
SAD-1 = Σ(순지급액 × (1 − 할인율))
```

**예시 숫자**
```
SAD-1 = 554,382,437 × 0.9989 = 553,772,616원
```

**확인할 것**
`투자실행액`(잔액)과 `투자실행금`(하루 흐름)을 이름으로 갈라 쓰는 것이 맞는가. `확인 Q20`

## 5-3. 투자수익 SMD-1 · MD-1i

**대표님 정의 원문**
> 전일자(D-1) 대상정산금채권의 투자수익(SMD-1) = Σ MD-1i
> MD-1i = 정산예정일이 전일자(D-1)이면서 ID가 i인 대상정산금채권의 채권매입수수료 - max(0, 미지급금-과지급금)

**내 말로 푼 뜻**
어제 확정된 하루 벌이. 채권을 싸게 산 그 차액에서, 덜 들어온 만큼을 뺀다. 덜 들어온 금액이 수수료보다 크면 **투자수익이 음수가 된다**.

**산식**
```
MD-1i = 채권매입수수료 − max(0, 미지급금 − 과지급금)
SMD-1 = Σ MD-1i
```

**예시 숫자**

전액 정상 입금
```
SMD-1 = 609,821원
```

카드 채권 500,000원 미입금
```
카드 투자수익 = 396,383 − 500,000 = −103,617원
SMD-1        = 609,821 − 500,000 = 109,821원
```

미입금 700,000원까지 커지면
```
SMD-1 = 609,821 − 700,000 = −90,179원  (하루 전체가 손실)
```

**확인할 것**
없음. `확정`

## 5-4. 투자수익율 SMRD-1

**대표님 정의 원문**
> 전일자(D-1) 대상정산금채권의 투자수익율(SMRD-1) = Σ MD-1i / Σ AD-1i

**내 말로 푼 뜻**
어제 굴린 돈 대비 어제 번 돈. 연환산하기 전의 **한 회전 수익률**이다.

**산식**
```
SMRD-1 = SMD-1 ÷ SAD-1
```

**예시 숫자**
```
SMRD-1 = 609,821 ÷ 553,772,616 = 0.110121%
```

여기서 짚어 둘 점 — **0.110121%는 할인율 0.11%와 같지 않다.** 분자는 액면에 0.11%를 곱한 값인데 분모는 액면이 아니라 액면의 99.89%이기 때문이다.

```
0.0011 ÷ 0.9989 = 0.00110121
```
미입금이 0인 한 이 값은 어느 날 어느 기간을 잡아도 **항상 0.110121%로 고정**된다.

**확인할 것**
4-10의 `확인 Q14`와 같은 자리다.

## 5-5. w금융일수 SDD-1 · DD-1i

**대표님 정의 원문**
> 전일자(D-1) 대상정산금채권의 w금융일수(SDD-1) = (Σ AD-1i x DD-1i) / Σ AD-1i
> DD-1i = 정산예정일이 전일자(D-1)이면서 ID가 i인 대상정산금채권의 금융일수
> 금융일수 = 선정산일로부터 정산예정일(=전일자)까지의 한편 넣기 일수 (예, 선정산일이 20260824면이고 정산예정일이 20260826이면, 2)

**내 말로 푼 뜻**
어제 돌아온 돈들이 평균 며칠씩 묶여 있었는지. 1번 이미지의 w금융일수와 산식 모양은 같고 모집단만 다르다.

**산식**
```
SDD-1 = Σ(AD-1i × DD-1i) ÷ Σ AD-1i
```

**예시 숫자** — D-1 = 2025-09-15
```
359,952,201 × 3 = 1,079,856,603
113,781,216 × 4 =   455,124,864
 54,614,983 × 5 =   273,074,915
 25,424,216 × 6 =   152,545,296
합계             = 1,960,601,678

SDD-1 = 1,960,601,678 ÷ 553,772,616 = 3.5404일
```

월요일이라 목요일 카드 매출(금융일수 3일)이 들어오면서 평균이 연평균 2.75일보다 크게 나왔다. 요일에 따라 하루치 w금융일수는 크게 흔들린다.

**확인할 것**
`20260824면이고` 는 `20260824이고`의 오타로 읽었다. 예시 자체는 `26 − 24 = 2`로 성립한다.

## 5-8. 배치 산식 사이의 항등식

`가설` 정의서에 문장으로 적혀 있지는 않으나, 세 산식을 이어 붙이면 이 관계가 항상 성립한다.

```
BD-1i = 순지급액 − L                (L = max(0, 미지급금 − 과지급금))
AD-1i = 순지급액 − 채권매입수수료
MD-1i = 채권매입수수료 − L

BD-1i − AD-1i = 채권매입수수료 − L = MD-1i
```

말로 옮기면 **상환액 = 투자실행금 + 투자수익**.

예시로 확인
```
D-1 하루치   553,772,616 + 609,821 = 554,382,437  = SBD-1
한 주치     3,876,408,312 + 4,268,747 = 3,880,677,059 = 상환액 합계
```

미입금이 있어도 깨지지 않는다.
```
카드 500,000원 미입금
359,952,201 + (−103,617) = 359,848,584 = 카드 상환액
```

`확인 Q22`

## 6-1. 투자실행금 PSA

**대표님 정의 원문**
> 투자 실행금(PSA) = 정산예정일이 위 선택한 기간에 해당하는 투자실행금(SAD-1)들 합계

**내 말로 푼 뜻**

**산식·예시 숫자**
```
PSA = 1,273,677,018 + 781,335,048 + 663,002,582 + 604,621,048 + 0 + 0 + 553,772,616
    = 3,876,408,312원
```

## 6-2. 투자수익 PSM

**대표님 정의 원문**
> 투자수익(PSM) = 정산예정일이 위 선택한 기간에 해당하는 투자수익(SMD-1)들 합계

**산식·예시 숫자**
```
PSM = 1,402,587 + 860,415 + 730,107 + 665,817 + 0 + 0 + 609,821
    = 4,268,747원
```

## 6-3. PSMR

**대표님 정의 원문**
> PSMR = PSM / PSA

**내 말로 푼 뜻**
기간 전체의 한 회전 수익률.

**산식·예시 숫자**
```
PSMR = 4,268,747 ÷ 3,876,408,312 = 0.110121%
```
미입금이 없으면 하루치 SMRD-1과 같은 값이 나온다.

## 6-4. PSD · Api · Dpi

**대표님 정의 원문**
> PSD = (Σ Api x Dpi) / PSA
> Api : 정산예정일이 위 선택한 기간에 해당하는 모든 각 대상정산금채권의 '순지급액 x (1 – 유동화투자자 할인율)'
> Dpi: 정산예정일이 위 선택한 기간에 해당하는 모든 각 대상정산금채권의 금융일수

**내 말로 푼 뜻**
기간 전체의 금액가중 평균 금융일수. 일별 SDD-1을 단순 평균하는 것이 아니라 채권 28건을 한 번에 놓고 다시 가중평균한다.

**산식·예시 숫자**
```
Σ(Api × Dpi) = 9,338,825,862 (28건 누계)
PSD = 9,338,825,862 ÷ 3,876,408,312 = 2.4091일
```

이 주는 공휴일이 없어 이론값 2.409144일과 정확히 일치한다. 2025년 연평균 2.750407일보다 짧은 것은 그만큼 공휴일 몫이 빠졌기 때문이다.

## 6-5. ④ 투자실행금액 대비 ty수익율

**대표님 정의 원문**
> 투자실행금액 대비 ty수익율(이미지의 ④) = PSMR x 365 / PSD

**내 말로 푼 뜻**
채권에 실제로 나간 돈만 분모로 놓고 잰 연환산 수익률. 계좌에 놀고 있는 현금은 안 센다.

**산식·예시 숫자**
```
④ = 0.00110121 × 365 ÷ 2.4091 = 16.6840% → 16.68%
```

---

## 6-6. PSC · ⑤ 투자자산 대비 ty수익율

**대표님 정의 원문**
> 투자자산 대비 ty수익율 (이미지의 ⑤) = (이미지의 ④ x PSA) / (PSA + PSC)
> PSC = 위 선택한 기간의 EC들의 합

**내 말로 푼 뜻**
놀고 있는 현금까지 분모에 넣어 잰 연환산 수익률. ④보다 반드시 낮게 나오고, 그 낮아진 폭이 현금이 얼마나 놀았는지를 보여 준다.

**산식·예시 숫자**
```
PSC = 105,300,000 × 7일 = 737,100,000
⑤   = 16.6840% × 3,876,408,312 ÷ (3,876,408,312 + 737,100,000)
    = 16.6840% × 0.84025
    = 14.0184% → 14.02%
```

**확인할 것**
분모의 두 항이 성격이 다르다. `PSA`는 7일 동안 나간 돈을 더한 값이고, `PSC`는 7일 동안의 잔액을 더한 값이다. 그대로 더하면 현금 쪽이 상대적으로 작게 잡힌다.

두 가지로 읽힌다.

| 읽는 법 | 분모 | 결과 |
|---|---|---|
| (가) 원문 그대로 | PSA + PSC = 4,613,508,312 | ⑤ = 14.02% |
| (나) 평균 잔액끼리 | (PSA×PSD÷7) + (PSC÷7) = 1,334,117,980 + 105,300,000 | ⑤ = 15.46% |

어느 쪽인가. `확인 Q24`

## 6-7. ② 상환액

**대표님 정의 원문**
> 상환액 (이미지의 ②) = 위 일별로 마감후 배치작업으로 업데이트하는 DB에서, 정산예정일이 해당 표의 입금일("정산예정일"로 변경 필요)에 해당하는 SBD-1

**내 말로 푼 뜻**
일별 표의 각 행에 그날의 SBD-1을 그대로 가져다 놓는다. 새로 계산하지 않는다. 그리고 표의 열 이름 `입금일`을 `정산예정일`로 바꾼다.

**예시 숫자**
```
2025-09-15 행의 상환액 = SBD-1(2025-09-15) = 554,382,437원
```

**확인할 것**
열 이름 교체는 `확정`으로 두었다. 다만 이 결정으로 **`정산예정일`이 곧 락계좌 실제 입금일**이라는 등식이 확정된다. 4-8의 `확인 Q11`과 이어진다.

## 6-8. ⑥ 투자실행금액 대비 ty수익율

**대표님 정의 원문**
> 투자실행금액 대비 ty수익율 (이미지의 ⑥) = (이미지의 ④ / 이미지의 ③) x 365 / 이미지의 ⑤

**내 말로 푼 뜻**
글자 그대로 읽으면 성립하지 않는다.

- ④는 이미 `PSMR × 365 ÷ PSD` 로 연환산이 끝난 값인데, 여기에 다시 365를 곱한다
- ⑤ 역시 연환산이 끝난 백분율인데 그것으로 나눈다
- ③이 어느 칸인지 앞에 정의가 없다

**내가 읽은 방식**
⑥은 ④와 이름이 같으나 **표가 다르다**. ④는 `현황` 표의 기간 집계값이고, ⑥은 `일별 투자수익` 표의 행 단위 값으로 읽었다. 그러면 ⑥ 산식 안의 ③·④·⑤는 일별 표의 세 열을 가리킨다.

| 마커 | 일별 표의 열 | 기호 |
|---|---|---|
| ③ | 투자실행금 | SAD-1 |
| ④ | 투자 수익 | SMD-1 |
| ⑤ | w금융일수 | SDD-1 |

이렇게 넣으면
```
⑥ = (SMD-1 ÷ SAD-1) × 365 ÷ SDD-1
   = SMRD-1 × 365 ÷ SDD-1
```
이 되어 5-6의 전일자 ty수익율 산식과 **글자 하나까지 같아진다**.

**예시 숫자** — 2025-09-15 행
```
⑥ = (609,821 ÷ 553,772,616) × 365 ÷ 3.5404 = 11.3529% → 11.35%
```

**확인할 것**
이 읽기가 맞는가. 맞다면 ④라는 번호가 `현황` 표(기간 집계)와 `일별` 표(행 단위) 두 곳에서 서로 다른 것을 가리키게 되므로, 문서에서는 번호 대신 기호로 적는 편이 안전하다. `확인 Q25`

# 7. 미지급·과지급 — 같은 단어가 두 뜻

2026-08-28 미팅에서 정리된 대로, 투자자 어드민의 미지급·과지급과 사내 운영의 미지급·과지급은 **방향도 당사자도 다르다**.

## 7-1. 두 축 대조

| | 투자자 축 (정의서) | 내부 축 (사내 정책 `02_TERMS`) |
|---|---|---|
| 누가 누구에게 | 플랫폼 → 투자자 락계좌 | 페이허그 → 가맹점 |
| 미지급 | 플랫폼이 락계좌에 **덜 넣은 것** | 선정산 때 가맹점에 **덜 준 것** |
| 과지급 | 플랫폼이 락계좌에 **더 넣은 것** | 선정산 때 가맹점에 **더 준 것** |
| 손해 보는 쪽 | 미지급이면 투자자 | 미지급이면 가맹점 |
| 쓰이는 산식 | `SLi` · `BD-1i` · `MD-1i` | 회수·상계·차감 |

같은 채권 한 건에서 두 축이 동시에 벌어질 수 있다. 예를 들어 가맹점에는 정상 지급했는데 플랫폼이 락계좌에 덜 넣으면, 내부 축은 아무 일도 없고 투자자 축만 미지급이 잡힌다.

## 7-2. 부호 방향 예시

```
카드 채권 1건 · 순지급액 360,348,584 · 수수료 396,383 · 투자실행금 359,952,201

[정상]        락계좌 입금 360,348,584
              미지급 0 · 과지급 0 · L = 0
              상환액 360,348,584 · 투자수익 +396,383

[투자자 축 미지급]  락계좌 입금 359,848,584 (500,000 부족)
              미지급 500,000 · 과지급 0 · L = 500,000
              상환액 359,848,584 · 투자수익 −103,617

[투자자 축 과지급]  락계좌 입금 360,848,584 (500,000 초과)
              미지급 0 · 과지급 500,000 · L = 0
              상환액 360,348,584 · 투자수익 +396,383
              초과 500,000의 처리는 산식에 없음
```

## 7-3. 사내 6대 개념과의 관계

사내 정책은 여섯 개를 절대 합치지 않는 것을 원칙으로 두고 있다. 정의서 용어와의 관계는 이렇게 읽었다.

| 사내 개념 (`02_TERMS`) | 정의서 용어와의 관계 | 판정 |
|---|---|---|
| 미지급금 | **다른 것.** 사내는 페이허그가 가맹점에 못 준 돈, 정의서는 플랫폼이 락계좌에 덜 넣은 돈 | `확인필요` |
| 선정산 제외금액 | 정의서에 대응 용어 없음. 애초에 채권이 만들어지지 않으므로 대상정산금채권에 들어오지 않는다 | `가설` |
| 바로이체 | 정의서에 대응 용어 없음. 가맹점 지급 경로 문제라 투자자 축과 무관 | `가설` |
| 과지급 | **다른 것.** 사내는 가맹점에 더 준 돈, 정의서는 플랫폼이 락계좌에 더 넣은 돈 | `확인필요` |
| 미회수금 | 정의서 `투자 실행액`의 `회수되지 않은` 과 낱말이 겹치나 뜻이 다르다. 사내는 과지급 잔액, 정의서는 아직 만기가 안 온 채권 | `확인필요` |
| 환급 | 정의서에 대응 용어 없음. 플랫폼 환급은 순지급액을 계산할 때 이미 들어간 것으로 읽었다 | `가설` |

**확인할 것**
투자자 축과 내부 축에 서로 다른 이름을 붙일 것인가, 아니면 같은 이름을 쓰되 화면·문서마다 어느 축인지 표시할 것인가. `확인 Q26`

# 8. 같은 이름 다른 값 — w금융일수와 ty수익율의 모집단

가장 크게 갈리는 자리라 따로 뺐다.

## 8-1. 두 개의 w금융일수

`w금융일수`라는 같은 이름이 두 산식에 나오는데, 모아 놓는 채권 묶음이 다르다.

| | 1번 이미지 (현황) | 2번 이미지 (일별·기간) |
|---|---|---|
| 모집단 | 대상정산금채권 = **아직 회수 안 된 것** | 정산예정일이 그 기간인 것 = **만기가 온 것** |
| 성격 | 지금 나가 있는 잔액의 구성 | 지나간 기간에 돌아온 흐름의 구성 |
| 기호 | `Ai` `Di` | `AD-1i` `DD-1i` / `Api` `Dpi` |

두 모집단은 값이 다르다. 만기가 긴 채권일수록 잔량에 더 오래 머무르기 때문에, 잔액을 찍어서 평균을 내면 만기가 긴 쪽이 과하게 잡힌다.

2025년 365개 날짜를 전부 계산해 보면 이렇게 벌어진다.

| 기준 | w금융일수 | ty수익율 (할인율 0.11%) |
|---|---|---|
| 만기 도래분 (2번 이미지) 연평균 | **2.7504** | **14.60%** |
| 미회수 잔량 (1번 이미지) 금액가중 | **4.0322** | **9.96%** |

4.6%p 차이다. 어느 쪽을 화면의 `ty수익율`로 쓰느냐에 따라 투자자에게 제시하는 수익률이 달라진다.

## 8-2. 어느 쪽이 실제 수익률인지 검산

`가설` 산식과 무관하게, 1년 동안 실제로 번 돈을 실제로 나가 있던 돈으로 나누면 다음과 같다.

```
연간 채권매입수수료 = 609,821 × 365 = 222,584,665원
평균 투자실행액                    = 1,523,100,000원
실제 연환산 수익률 = 222,584,665 ÷ 1,523,100,000 = 14.61%
```

**14.61%는 만기 도래분 기준 w금융일수 2.7504로 계산한 14.60%와 일치한다.** 미회수 잔량 기준 4.0322로 계산한 9.96%와는 맞지 않는다.

즉 `ty수익율 = 할인율 × 365 ÷ w금융일수` 라는 산식이 실제 수익률을 맞히려면, 여기 들어가는 w금융일수는 **만기 도래분 기준**이어야 한다.

## 8-3. 확인할 것

1번 이미지 현황 표의 `w금융일수` 열과 `ty수익율` 열을 어느 모집단으로 계산할 것인가.

| 안 | w금융일수 | ty수익율 | 장점 | 단점 |
|---|---|---|---|---|
| (가) 미회수 잔량 | 4.03 | 9.96% | `투자실행액`과 같은 채권 묶음이라 열끼리 앞뒤가 맞음 | 실제 수익률과 4.6%p 어긋남 |
| (나) 만기 도래분 | 2.75 | 14.60% | 실제 수익률과 일치 | 같은 행의 `투자실행액`과 다른 묶음에서 나온 값 |
| (다) 둘 다 표기 | 4.03 / 2.75 | 9.96% / 14.60% | 정확 | 열이 늘고 읽기 어려움 |

`확인 Q13` `확인 Q27`

### 5-2. 1차분 전량 폐기 사유 — 뷰포트 87px 편차

1차 32프레임 검수 중 고정 배치 요소가 아래로 87px 모자란 자리에 놓인 것을 발견했다.

- 모달 배경(`inset:0`)이 43px 위로 치우침

| 1440×620 | 1440×533 |
| 1440×689 | 1440×602 |

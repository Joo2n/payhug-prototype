## §1 세 구조 정의와 현금흐름표

채권 1건 · 순지급액(액면) `F` = 1,000,000원 · 투자자 몫 할인율 `d` = 0.11% · 통 요율 `r` = 1.00% / 0.81%.
입금부족 `S` = 0 으로 놓는다(부족액은 세 구조에 같은 방식으로 붙어 비교를 흐리지 않는다).

### 구조 정의

| | 전제 | 투자자가 t0 에 내보내는 돈 | 페이허그 몫이 붙는 자리 |
|---|---|---|---|
| **A** | 투자자가 페이허그 수수료까지 선불하고 만기에 액면 전액 회수 | `F × (1 − d)` | t0 · 투자자 지출에서 갈라져 나감 |
| **B** | 투자자는 실제 지급액만 내고, 페이허그 몫은 만기 회수분에서 뗀다 | `F × (1 − r)` | 만기 · 회수분에서 갈라져 나감 |
| **C** | 정의서의 `할인율`이 통 요율이다 (`d = r`) | `F × (1 − r)` | 없음 |

### 현금흐름 — 통 요율 1.00%

| | 투자자 지출 | 가맹점 수령 | 만기 회수 | 투자자 수익 | 페이허그 수익 |
|---|---|---|---|---|---|
| A | 998,900 | 990,000 | 1,000,000 | **1,100** | 8,900 |
| B | 990,000 | 990,000 | 991,100 | **1,100** | 8,900 |
| C | 990,000 | 990,000 | 1,000,000 | **10,000** | 0 |

### 현금흐름 — 통 요율 0.81%

| | 투자자 지출 | 가맹점 수령 | 만기 회수 | 투자자 수익 | 페이허그 수익 |
|---|---|---|---|---|---|
| A | 998,900 | 991,900 | 1,000,000 | **1,100** | 7,000 |
| B | 991,900 | 991,900 | 993,000 | **1,100** | 7,000 |
| C | 991,900 | 991,900 | 1,000,000 | **8,100** | 0 |

읽는 법 세 가지.

- A와 B는 투자자 수익이 같다(`F × d` = 1,100). 다른 것은 **투자자가 얼마를 굴리느냐**다. A는 998,900을 굴려 1,100을 벌고, B는 990,000(991,900)을 굴려 같은 1,100을 번다. 같은 수익이면 원금이 작은 B가 수익률이 높다.
- A에서만 **투자자 지출 > 가맹점 수령** 이다. 그 차액 8,900(7,000)이 정확히 페이허그 몫이다. 오늘 드러난 "투자자가 냈다고 계산되는 돈이 가맹점에 실제로 나간 돈보다 크다"는 현상은 **A의 정상 동작이거나, A가 아닌데 A로 계산한 오류**다. 둘을 가르는 것이 §5 질문이다.
- C만 투자자 수익이 자릿수로 다르다(10,000 / 8,100 대 1,100). 페이허그가 이 채권에서 버는 것이 0이 되는 구조라, 페이허그 수익이 다른 축(시스템이용료·이체수수료)에만 남는다.

## §2 정의서 산식 4개 × 구조 3개 성립 판정표

산식은 `ceo_definitions.md:14`(`Ai`) · `:36`(`AD-1i`) · `:34`(`BD-1i`) · `:38`(`MD-1i`) 원문 그대로.
판정 기준 — 산식이 낸 값이 그 구조의 **실제 현금흐름과 같은 금액**이면 `성립`, 다르면 `불성립`. 차액을 원 단위로 병기한다(위 1.00% / 0.81%).

| 산식 | 원문 | 구조 A | 구조 B | 구조 C |
|---|---|---|---|---|
| `Ai` | `순지급액 × (1 − 할인율)` | **성립** — 998,900 = 투자자 지출 | **불성립** — 998,900 vs 실제 990,000 / 991,900 (+8,900 / +7,000) | **성립** — 990,000 / 991,900 = 투자자 지출 |
| `AD-1i` | `순지급액 × (1 − 할인율)` | **성립** — `Ai` 와 동일식, 만기 도래분 | **불성립** — 같은 사유 (+8,900 / +7,000) | **성립** |
| `BD-1i` | `순지급액 − max(0, 미지급금−과지급금)` | **성립** — 1,000,000 = 만기 회수 | **불성립** — 1,000,000 vs 실제 991,100 / 993,000 (+8,900 / +7,000) | **성립** — 1,000,000 = 만기 회수 |
| `MD-1i` | `채권매입수수료 − max(0, 미지급금−과지급금)` | **불성립** — 10,000 / 8,100 vs 실제 수익 1,100 (+8,900 / +7,000) | **불성립** — 10,000 / 8,100 vs 실제 수익 1,100 (+8,900 / +7,000) | **성립** — 10,000 / 8,100 = 실제 수익 |
| **항등식** `BD−AD = MD` | — | **불성립** — 좌변 1,100 · 우변 10,000 / 8,100 | **불성립** — 좌변 1,100 · 우변 10,000 / 8,100 | **성립** — 좌변 = 우변 = 10,000 / 8,100 |
| 성립 수 | | **3 / 4** | **0 / 4** | **4 / 4** |

### 항등식이 걸리는 자리 — 구조와 무관한 대수 조건

```
BD-1i − AD-1i = (F − S) − F(1−d) = F·d − S
MD-1i         = 채권매입수수료 − S
∴ 항등식 성립 ⟺ 채권매입수수료 = F × d     (= 순지급액 × 할인율)
```

이 조건은 A·B·C 어느 구조를 골라도 같다. 구조가 항등식을 깨는 것이 아니라 **`채권매입수수료`라는 낱말이 무엇을 가리키느냐**가 깬다.
C에서만 항등식이 저절로 성립하는 이유도 이것이다 — C는 `d = r` 이라 두 해석이 한 값으로 겹친다.

### 보조 판정 — A′ (구조 A + `채권매입수수료 := 순지급액 × 할인율`)

D-31 이 `채권매입수수료 = 순지급액 × 할인율`, 할인율은 정산상품에 배정된 투자자 몫으로 못박은 판이다.

| 산식 | A′ 판정 |
|---|---|
| `Ai` · `AD-1i` | 성립 — 998,900 |
| `BD-1i` | 성립 — 1,000,000 |
| `MD-1i` | 성립 — 1,100 = 실제 투자자 수익 |
| 항등식 | 성립 — 좌변 = 우변 = 1,100 |

A′는 4/4로 성립하고 Ty수익율도 13.21%로 정상 범위에 남는다. 대가는 **낱말 하나가 두 값을 가리키는 것**이다.

| `채권매입수수료`가 서 있는 자리 | 값 | 근거 |
|---|---|---|
| 가맹점 계약 서명 화면 — 가맹점이 직접 입력 | 통 요율 (예시 표기 `예: 1.0`) | `payhug-merchant-web/components/ContractSignInput.tsx:195` 라벨 `채권매입 수수료율` · `:198` `계약서의 수수료율 항목에 적용` · `:210` `placeholder="예: 1.0"` |
| 운영 어드민 선정산 현황 — 가맹점에서 실제로 빠지는 금액 | 2,524,087 (순지급액 대비 0.8111% · 대상액 대비 0.9096%) | `payhug-admin-web/app/page.tsx:212` `매입 … + 시스템 … + 이체 …` · 실측 |
| 세금계산서 발행 탭 엑셀 열 | 같은 원천값 `marginFee` | `payhug-admin-web/app/settlement/overview/TaxInvoiceTab.tsx:129` |
| 투자자 어드민 프로토타입 (A′) | 순지급액 × 0.11% | `daily_ledger.py:301` `fee = fl(D(g['net']) * RATE)` |

같은 이름이 0.81%와 0.11%를 동시에 가리키면, 투자자 화면의 `투자수익` 열과 운영 화면의 `매입` 칸이 같은 채권에서 7.4배 갈린다.

### 잔차 2,457,392 의 정체 — 제외분인가 후속 차감 항인가

`T − 선정산수수료 − 선정산지급액` = 277,482,424 − 2,522,909 − 272,502,123 = **2,457,392**.

지급액 항등식 (`payhug-admin-web/types/settlement.ts:286-289` JSDoc · 화면 산식 문자열 `app/settlement/overview/PreSettlementTab.tsx:80-95`):

```
지급액 = 대상액 − 수수료(실차감 기준) + adjustmentTotal + carryForwardTotal
         − offlineDeductionTotal − adDeductionTotal + (refundAdditionTotal + cpcRefundTotal)
```

| 항 | 성격 | 투자자 노출과의 관계 |
|---|---|---|
| `adjustmentTotal` 지급액 산식용 수수료 차액 (취소 환수 포함) | 후속 차감 | 채권 액면과 무관 |
| `carryForwardTotal` 미회수 이월 | 후속 가산 | 채권 액면과 무관 |
| `offlineDeductionTotal` 오프라인 차감 | 후속 차감 | 가맹점 부담 |
| `adDeductionTotal` 플랫폼 차감(광고비·조정) | 후속 차감 | 가맹점 부담 |
| `refundAdditionTotal` · `cpcRefundTotal` 플랫폼 환급 | 후속 가산 | 가맹점 귀속 |

이 항들은 **선정산대상액이 확정된 뒤에 가맹점 지급 단계에서 붙는다.** 제외분(바로이체·이미지급)은 이미 `T` 안에서 걸러졌다.
투자자가 산 채권은 `T` 기준이므로, 이 2,457,392가 투자실행액을 깎을 근거는 없다. **④의 잔차는 오차가 아니라 성격이 다른 항목이다.**

**앵커가 요율보다 15배 큰 문제다.** 통 요율 확정값이 0.81%인지 1.00%인지 정해지지 않아도, 앵커를 `선정산대상액`으로 옮기는 것만으로 오차의 89%가 사라진다.

## §4 프로토타입 현재 전제와 영향 범위

### 현재 전제 = A′

| 확인 지점 | 코드 | 뜻 |
|---|---|---|
| 투자실행액 | `daily_ledger.py:219` `ai = ri(unit * SCALE)` · 주석 `Ai = 순지급액 x (1 - 할인율)` | 앵커 = 순지급액. 선정산대상액 개념 없음 |
| 순지급액 역산 | `daily_ledger.py:222` `net = ri(D(ai) / (D(1) - RATE))` | 액면 = 투자실행금 / 0.9989 |
| 채권매입수수료 | `daily_ledger.py:301` `fee = fl(D(g['net']) * RATE)` · `RATE = 0.0011` | **투자자 몫 0.11%.** 통 요율 축 없음 |
| 상환액 | `daily_ledger.py:304` `p = fee - g['ded']` · `:305` `repay = g['ai'] + p` | `BD = AD + MD` 로 항등식을 코드가 강제 |
| 시뮬레이션 채권 1건 | `build_app.py:1995-2002` `simBond()` — `A = floor(amt×(1−r))` · `fee = floor(amt×r)` · `B = amt − ded` · `M = fee − ded` | 같은 A′ |

**페이허그 수수료 축은 원장 어디에도 없다.** 선정산제외액·선정산대상액·시스템이용료·이체수수료도 없다.
원장이 아는 것은 `순지급액` 한 축이고, 그것을 0.11%로만 가른다. 결과적으로 원장은 **가맹점이 실제로 얼마 받는지를 한 번도 계산하지 않는다.**

전 구간 실측 — 채권매입수수료 5,176,160 / 투자실행액 4,700,503,303 = 0.1101%. 0.81%의 흔적이 0건이다.

## §5 대표님께 물어야 하는 것

> 유동화투자자가 채권 1건에 실제로 내보내는 돈이 `순지급액 × (1 − 0.11%)`(페이허그 수수료까지 투자자가 선불하고 만기에 액면 전액을 회수)인지 아니면 가맹점이 실제로 받는 `순지급액 × (1 − 채권매입수수료율)`(페이허그 몫은 만기 회수분에서 차감)인지, 그리고 그 답에 따라 `MD-1i` 의 `채권매입수수료`가 투자자 몫 0.11%를 가리키는지 가맹점이 실제로 부담하는 통 요율 0.81%를 가리키는지.

P1 14건 중 **수치가 어긋나는 6건**을 검산한다. 나머지 8건(CI-01·CI-02·CI-03·CI-04·CI-07·CI-08·CI-14·CI-18)은 정의문·라벨·질문 목록이 대상이라 숫자 검산 대상이 아니고, §1 표의 대조로 판정이 끝난다. 단 CI-14는 각주 문구가 표기값과 자기모순이라 CI-13 안에서 함께 검산했다.

### CI-13 · 투자자산 대비 Ty수익율 — 1.09%p 과대, 1.49배

화면·엑셀 표기 `3.32%`. 대표 정의 ⑤로 계산하면 `2.24%`.

```
④ 투자실행금액 대비 = PSMR × 365 / PSD
  PSMR = PSM/PSA = 1,375,880 / 1,250,800,000 = 0.110000%
  PSD  = 11.3
  ④    = 0.0011 × 365 ÷ 11.3 = 3.5531%   → 3.55%   (화면 일치)

⑤ 대표정의 = (④ × PSA) / (PSA + PSC)
  PSA = 1,250,800,000            (기간 7일 투자실행금 합)
  PSC = Σ EC = 7 × 105,300,000 = 737,100,000   (기간 7일 순현금 합)
  ⑤   = 3.5531% × 1,250,800,000 / 1,987,900,000 = 2.2356%  → 2.24%

⑤ 화면 실제 = ④ × 투자실행액 / 투자자산
     = 3.5531% × 1,523,100,000 / 1,628,400,000 = 3.3233%  → 3.32%
```

**어긋남의 성격**: 분자는 기간 실적(7일 누계 1,250,800,000), 분모 스케일은 기준일 스냅샷 잔액(1,523,100,000/1,628,400,000). 기간량과 시점량을 한 비율에 섞었다. 대표 정의는 분모도 기간 합(`PSA + PSC`)으로 잡는다.

괴리 **1.09%p**, 배수 **1.49배**. 수익율 지표이므로 그대로 제안서에 실리면 투자 수익성을 절반 가까이 부풀려 말하는 셈이 된다.

덧붙여 엑셀 각주(CI-14)대로 `투자자산 총액 기준`을 곧이곧대로 계산하면 `1,375,880 ÷ 1,628,400,000 × 365 ÷ 11.3 = 2.7292%` → 2.73%. **표기값 3.32% · 각주식 2.73% · 대표정의 2.24% 가 삼자 불일치**다.

### CI-11 · 투자수익 — 차감항 전면 부재

```
화면        투자수익 = 투자실행금 × 0.11%
            1,250,800,000 × 0.0011 = 1,375,880   (표기값과 오차 0, 7행 전건)
대표정의    Mi = 채권매입수수료 − max(0, 미지급금 − 과지급금)
```

화면 값은 `max(0, 미지급금−과지급금) = 0` 인 경우에만 성립한다. 미지급금·과지급금은 저장소 전건 0건(`과지급금` 0 · `미지급금`은 6대 개념 나열 문장 2건뿐)으로, **차감 자체가 데이터 모델에 없다.**

기준금액도 다르다. 채권매입수수료의 기준을 순지급액으로 잡으면:

```
순지급액 = 투자실행금 ÷ (1 − 0.0011) = 1,252,177,395
순지급액 × 0.11% = 1,377,395     (화면 1,375,880 대비 +1,515원)
```

**파급**: ④의 첫 항 `PSMR` 이 실현수익율이라는 점(ceo L50)이 여기 걸린다. 지금은 부족액이 0이라 `PSMR = 1,375,880/1,250,800,000 = 0.110000%` 로 할인율과 정확히 같아, 엑셀 각주 `Ty수익율 = 할인율 × (365÷W)` 가 우연히 맞는다. **부족액이 1원이라도 발생하면 `PSMR < 할인율` 이 되어 각주 산식이 즉시 깨진다.**

## §3 비중 쟁점 결론

**결론: 같은 지표가 아니다. 다른 지표 둘이 `비중` 이라는 한 이름을 쓰고 있다. 화면 구조를 뜯을 필요는 없다.**

근거 3가지.

1. **대표 정의의 비중은 이미 화면에 있고 값도 맞다.** `invest-assets.html` 현황표 2행 + KPI 카드 캡션이 `투자실행액 93.5% / 순현금 6.5% / 합계 100.0%` 로, `ceo L27~28` 과 분모·행 구성·값이 정확히 일치한다. 지시문이 우려한 "2행 구성이 없고 16행만 있다"는 상황이 아니다.

2. **가맹점별 16행 비중은 분모가 다른 별개 지표다.** 분모는 투자실행액(1,523,100,000)이지 투자자산(1,628,400,000)이 아니다. `app.html` 코드(`ratios(mrows, exec)`)와 엑셀 각주(A22)가 둘 다 그렇게 명시한다. 대표 정의는 이 축을 규정하지도, 금지하지도 않는다 — **단순 미언급**이다.

3. **대표 정의의 비중은 [1번 이미지] 지표군(투자실행액·순현금·w금융일수·S입금부족율·ty수익율·비중)에 속한다.** 이는 현황표의 행·열 구성 그 자체다. 가맹점별 표는 같은 화면의 다른 표이고, 대표 정의 원문에 그 표를 가리키는 문장이 없다.

## §5 대표 정의만으로 안 풀리는 것

각 항목은 대표 회신이 있어야 닫힌다. 질문문만 존댓말로 두고 사실 서술은 문서체로 적는다.

### Q-1. 채권매입수수료의 기준금액과 요율은 무엇입니까 — 할인율 0.11%와 같은 값입니까

대표 정의는 `투자수익 Mi = 채권매입수수료 − max(0, 미지급금−과지급금)` 이라 적으면서 **채권매입수수료 자체를 정의하지 않는다.** 산출물에서 확인되는 근거는 둘로 갈린다.

- 재양도합의서 제8조(16건 전건) — `채권매입수수료 / 산정 기준: 정산금채권 양수액 / 요율: _______ %` (공란)
- 대표 정의 — `유동화투자자의 할인율 0.11%` 를 **순지급액**에 적용

두 값이 동시에 0.11%일 수는 없다. 대표 정의의 상환액·투자실행액 산식이 아귀가 맞으려면:

```
상환액 − 투자실행금 = 순지급액 × 할인율        (부족액 0일 때)
투자수익 = 채권매입수수료 = 양수액 × r = 순지급액 × (1−할인율) × r
∴ r = 할인율 / (1 − 할인율) = 0.0011 / 0.9989 = 0.110121%
```

채권매입수수료율 r 은 0.110121%로, 0.11%와 다른 값이 된다.

**두 요율이 별개 값입니까, 아니면 채권매입수수료의 기준금액이 양수액이 아니라 순지급액입니까?** CI-11·CI-12·CI-18이 이 회신에 걸린다.

### Q-2. 금융일수 예시 2건이 원문 안에서 서로 어긋납니다 — 어느 쪽이 맞습니까

- ceo L19 — `선정산일 = 260827, 정산예정일 = 260808 이면 금융일수 = 1`
- ceo L43 — `선정산일이 20260824이고 정산예정일이 20260826이면, 2`

L43은 편면산입(`26 − 24 = 2`)으로 계산이 맞는다. L19는 정산예정일(0808)이 선정산일(0827)보다 앞서고, 그 차이로 1이 나오지도 않는다. 오탈로 보이나 임의로 고칠 수 없다.

**L43 기준으로 확정해도 됩니까?** `glossary.html` 질문 A-5(`한편 넣기 일수는 어느 셈법입니까?`)가 여기 걸리고, CI-09의 각주 문구가 이 회신에 따라 정해진다.

### Q-3. 가맹점별 투자자산 표의 `비중` 열을 존치합니까

대표 정의의 비중은 투자실행액:순현금 2행 구성이다(§3). 가맹점별 16행 비중은 분모가 투자실행액이라 다른 지표이고, 대표 정의에 언급이 없다. 셋 중 하나를 골라야 한다.

1. 존치하되 열 이름을 분리 (예: `투자실행액 대비 구성비`)
2. 분모를 투자자산으로 통일 — 이 경우 16행 합계가 100.0% → 93.5%가 되고 증명서 PDF 합계행도 바뀐다
3. 폐기

증명서 PDF 16건·엑셀 1·Figma 2프레임이 함께 걸린다(CI-19).

### Q-4. ⑥ 지표의 ③이 무엇이고, ④와 이름이 같은 것이 맞습니까

ceo L57 — `투자실행금액 대비 ty수익율 (이미지의 ⑥) = (이미지의 ④ / 이미지의 ③) x 365 / 이미지의 ⑤`

- **③이 정의되지 않았다.** 원문에 ①·③의 정의문이 없다.

### Q-5. 조달이자형(연 12%) 산식 카드를 유지합니까

`request_register.md` D-1이 `산식 2모델 병기 — 매출 배분형(0.11%) / 대출 이자형(연 12%)` 을 결정 사항으로 올려 두었다(대표 정의 수신 전 결정). 대표 정의는 채권매입수수료 기반 1모델만 제시하고 조달이자형을 언급하지 않는다.

**D-1을 유지합니까, 대표 정의에 맞춰 1모델로 접습니까?** 화면 11개·Figma 2프레임이 걸린다(CI-26). 회신 전까지 삭제하지 않는다.

### Q-6. 0.11%의 화면 표기를 `예시` 에서 `예정` 으로 올립니까

- 대표 정의 — `유동화투자자의 할인율 = 0.11% 예정`
- 현행 화면 — `수익 산정 기준 (예시)` · `산식·요율은 예시이며, 개별 계약 조건에 따라 확정됨.`

# 투자자 어드민 계산식 기호 사전

대표 정의서 산식에 나오는 기호 28건을 **기호 → 한국어 용어명 → 뜻 → 원문 근거** 네 축으로 편 것이다. 산식만 있고 그 안의 `Ai`·`Di`·`Σ`가 무엇인지 그 자리에 없어 독자가 막히던 것을 메우려고 만들었다.

| 무엇 | 어디 |
|---|---|
| 기호·산식의 근거 | `_pipeline/investor_admin/ceo_definitions.md` — 대표 정의서 원문 |
| 기계 판독용 | `_pipeline/investor_admin/symbol_glossary.json` |
| 반영 대상 | `glossary.html` 재조판 · `glossary_manuscript.md` |

**먼저 알아 둘 것**

- 할인율 0.11%는 원문이 '0.11% 예정'으로 적은 값이다. 확정값이 아니다.
- 채권매입수수료의 범위(투자자 몫만이냐 통 전체냐)가 원문에 없다 — M(D-1)i 이하 수익률 전부가 여기에 걸린다.
- ③④⑤⑥이 가리키는 화면 자리가 확정되지 않았다 — 원문이 참조한 이미지가 문서에 없다.

**한국어 용어명을 어떻게 붙였나** — 대표 정의서에 이름이 있으면 그것을 그대로 쓴다. 이름이 없으면 정의문에서 유도한 이름을 쓰고 `문서 명명`으로 표시한다. 지어냈다는 사실을 감추지 않는다.

`문서 명명` = 대표 정의서에 이름이 없어 정의문에서 유도한 것. 근거는 §2에 건별로 적었다.

**같은 것을 가리키는 다른 표기가 있는 기호 11건** — 원문은 아래첨자를 평문으로 붙여 `SAD-1`·`AD-1i`로 쓰고, 문서는 읽기 쉽게 `SA(D-1)`·`A(D-1)i`로 괄호를 넣는다. 여기에 더해 문서가 아래첨자를 통째로 떼고 `SA`·`SB`·`SM`·`SMR`·`SD`로 줄여 쓰는 자리가 있는데, **이 짧은 형태는 원문에 없다.** 건별 표기는 §2 각 항목의 `같은 것을 가리키는 다른 표기` 줄에 있다.

## 2. 기호별 상세

### 산식 문법

산식을 읽는 문법. 값이 아니라 '어떻게 읽으라'는 표시다.

#### `Σ` — 합계 기호(시그마)

| 필드 | 내용 |
|---|---|
| 한국어 용어명 | **합계 기호(시그마)** (문서 명명) |
| 뜻 | 뒤에 붙은 것을 조건에 맞는 만큼 하나씩 전부 더한 값. 무엇을 더하는지는 뒤에 오는 기호가 정한다. |
| 단위 | 더하는 대상의 단위를 그대로 따른다 |
| 산식 | `Σ Xi = X1 + X2 + … (모집단에 속하는 모든 i)` |
| 대표 정의서 원문 | 없음 — 원문이 뜻을 적은 문장이 없다 |
| 첨자인가 | 값이 아니다 — 더하는 대상의 단위를 그대로 따른다 |
| 영문 약자 출처 | 원문에 근거 없음 |
| 이름을 붙인 근거 | 원문이 Σ를 쓰기만 하고 뜻을 적은 문장이 없다. 수학 표준 기호명을 그대로 옮겼다. |
| 쓰이는 화면 용어 | `투자 실행액` · `w금융일수` · `S입금부족율` · `상환액` · `투자실행금` · `투자수익` · `PSD` · `PSC` |
| 주의 | 원문에서 Σ가 쓰인 자리: w금융일수 · S입금부족율 · SB(D-1) · SA(D-1) · SM(D-1) · SMR(D-1) · SD(D-1) · PSD. |

#### `i` — 채권 일련번호(첨자)

| 필드 | 내용 |
|---|---|
| 한국어 용어명 | **채권 일련번호(첨자)** (문서 명명) |
| 뜻 | 금액도 날수도 아니다. '몇 번 채권이냐'를 가리키는 이름표 자리다. 그 자리에 실제로 들어가는 값은 정산금채권 ID다. |
| 단위 | 첨자 (값이 아니다) |
| 산식 | `i ∈ { 대상정산금채권의 ID }` |
| 대표 정의서 원문 | `각 정산금채권의 ID = 가맹점ID & 플랫폼ID & 매출일자(YYYYMMDD)` |
| 첨자인가 | 첨자다 — 값이 아니라 '몇 번 채권이냐'를 가리킨다 |
| 영문 약자 출처 | 원문에 근거 없음 |
| 이름을 붙인 근거 | 원문에 i를 단독으로 정의한 문장이 없다. 언제나 「ID가 i인 대상정산금채권」 꼴로만 나오므로 그 쓰임에서 이름을 유도했다. |
| 쓰이는 화면 용어 | `정산금채권 ID` · `대상정산금채권` · `플랫폼ID` · `매출일자` |
| 주의 | Ai · Di · SLi · SAi · Api · Dpi · B(D-1)i 등 끝에 i가 붙은 기호는 전부 '채권 1건분'이라는 뜻이다. i가 없으면 합계다. |

#### `D` — 현재일자

| 필드 | 내용 |
|---|---|
| 한국어 용어명 | **현재일자** (원문 명명) |
| 뜻 | 오늘 날짜. 표본 구간(D-20 ~ D-11)과 전일자(D-1)를 세는 기준점이다. |
| 단위 | 날짜 |
| 산식 | `D = 오늘` |
| 대표 정의서 원문 | `D = 현재일자` |
| 첨자인가 | 아니다 — 값이다 |
| 영문 약자 출처 | 원문에 근거 없음 |
| 쓰이는 화면 용어 | `표본집합` · `S입금부족율` · `기준일자` · `일별 배치` |
| 주의 | 대문자 D 단독은 현재일자, 끝에 i가 붙은 Di는 금융일수다. 글자는 같아도 다른 것이다. 아래첨자 D-1은 전일자를 뜻한다. |

| 필드 | 내용 |
|---|---|
| 한국어 용어명 | **화면 항목 번호** (문서 명명) |
| 뜻 | 대표 정의서가 첨부 이미지의 어느 칸을 가리키는지 짚으려고 붙인 번호다. 기호도 첨자도 아니고 '그 이미지의 몇 번째 항목'이라는 뜻이다. |
| 단위 | 화면 항목 지시 번호 (값이 아니다) |
| 산식 | — |
| 대표 정의서 원문 | `투자실행금액 대비 ty수익율 (이미지의 ⑥) = (이미지의 ④ / 이미지의 ③) x 365 / 이미지의 ⑤` |

| 이름을 붙인 근거 | 원문이 「이미지의 ④」 꼴로만 쓰고 번호 체계에 이름을 붙이지 않았다. |
| 쓰이는 화면 용어 | `상환액 (일별 배치 · 하루치)` · `투자실행금` · `투자수익` · `w금융일수` · `ty수익율 › 투자실행금액 대비` · `ty수익율 › 투자자산 대비` · `ty수익율 (일별 표 · 행 단위)` |
| 주의 | 미확정. 같은 번호가 두 곳을 가리킨다. 현황 카드 기준으로는 ②=상환액, ④=투자실행금액 대비 ty수익율, ⑤=투자자산 대비 ty수익율이다. 그런데 그대로 ⑥의 산식에 넣으면 '수익률 ÷ 금액 × 365 ÷ 수익률'이 되어 성립하지 않는다. 일별 표의 열 번호(②상환액 ③투자실행금 ④투자 수익 ⑤w금융일수 ⑥ty수익율)로 읽으면 맞아떨어진다. 원문이 참조한 이미지 두 장이 문서에 없어 확정할 수 없다. |

### 채권 1건분

채권 한 건에서 바로 나오는 값. 투자자 어드민 모든 숫자의 출발점이다.

#### `Ai` — 채권 1건분 투자실행금

| 필드 | 내용 |

| 단위 | 채권 1건분 · 금액(원) |

## 4. 영문 약자 출처 — 전건 `원문에 근거 없음`

대표 정의서는 기호를 쓰기만 하고 **어느 글자가 무엇의 머리글자인지 적은 문장이 하나도 없다.** 추측으로 채우지 않고 전건 `원문에 근거 없음`으로 둔다.

| 글자 | 나오는 기호 | 판정 | 원문으로 확인되는 사실만 |
|---|---|---|---|
| `A` | `Ai` `SAi` `A(D-1)i` `Api` `SA(D-1)` `PSA` | 원문에 근거 없음 | 붙은 자리가 전부 `순지급액 x (1 - 할인율)` 계열이다 |
| `D` | `Di` `D(D-1)i` `Dpi` `SD(D-1)` `PSD` | 원문에 근거 없음 | 붙은 자리가 전부 금융일수 계열이다. 단, 단독 `D`만은 원문이 `현재일자`로 명시했다 |
| `B` | `B(D-1)i` `SB(D-1)` | 원문에 근거 없음 | 붙은 자리가 상환액 계열이다 |
| `M` | `M(D-1)i` `SM(D-1)` `SMR(D-1)` | 원문에 근거 없음 | 붙은 자리가 투자수익 계열이다 |
| `R` | `SMR(D-1)` `PSMR` | 원문에 근거 없음 | 붙으면 금액이 아니라 율이 된다 |
| `L` | `SLi` | 원문에 근거 없음 | 입금부족액 자리에만 쓰인다 |
| `S` | `SLi` `SAi` `SB` `SA` `SM` `SMR` `SD` `S입금부족율` | 원문에 근거 없음 | 두 갈래로 갈려 쓰인다 — 표본집합 표시와 하루치 집계 표시 |
| `P` | `PSA` `PSM` `PSMR` `PSD` `PSC` | 원문에 근거 없음 | P가 붙은 기호 5개가 **전부** '선택한 기간' 집계에만 쓰인다 |
| `p` | `Api` `Dpi` | 원문에 근거 없음 | 위 P계열과 같은 기간 범위를 가리킨다 |
| `E` `C` | `EC` | 원문에 근거 없음 | 자정 시점 현금 잔액 자리에만 쓰인다 |
| `w` | `w금융일수` | 원문에 근거 없음 | 산식이 금액 가중평균이다 |
| `t` `y` | `ty수익율` | 원문에 근거 없음 | 산식이 365를 곱해 1년치로 늘려 잡는다 |

오른쪽 열은 **원문에서 관찰되는 쓰임**이지 머리글자 판정이 아니다. 둘을 섞어 읽지 말 것.

## 6. 그 밖의 표기 — 연산자 4건

기호 사전 28건에는 안 들어가지만 산식에 같이 나오는 것들이다. 산식을 훑을 때 이것까지 있어야 빈칸이 없다.

| 표기 | 한국어 | 뜻 | 대표 정의서 원문 | 나오는 자리 |
|---|---|---|---|---|
| `max(0, X)` | 0과 X 중 큰 값 | X가 음수면 0으로 눌러 버린다. 덜 받은 경우만 깎고 더 받은 경우는 안 건드리려는 장치다. | `‘순지급액 - max(0, 미지급금-과지급금)’` | `B(D-1)i` · `M(D-1)i` |
| `x` | 곱하기 (원문 표기) | 대표 정의서가 곱셈에 쓴 기호다. 수학 기호 ×가 아니라 알파벳 소문자 x다. | `Ai = ID가 i인 대상정산금채권의 순지급액 x (1- 유동화투자자의 할인율)` | `원문 전 12곳` |
| `&` | 이어 붙이기 | 세 조각을 순서대로 이어 붙여 하나의 이름표를 만든다는 뜻이다. 논리 AND가 아니다. | `각 정산금채권의 ID = 가맹점ID & 플랫폼ID & 매출일자(YYYYMMDD)` | `정산금채권 ID` |

## 7. 헷갈리기 쉬운 쌍

이름이나 철자가 비슷한데 값이 다른 것들이다. 재조판할 때 여기가 가장 많이 틀린다.

| 헷갈리는 쌍 | 무엇이 다른가 |
|---|---|
| Ai  ↔  SA(D-1) · PSA | 같은 개념의 다른 단위. Ai는 채권 1건분, SA(D-1)은 하루치 합계, PSA는 기간 합계다. |
| SAi  ↔  SA(D-1) | 철자가 거의 같은데 다른 것. SAi는 표본집합 채권 1건분, SA(D-1)은 전일자 만기 채권 하루치 합계다. |
| D  ↔  Di  ↔  D-1  ↔  Dpi | D는 현재일자(날짜), Di·Dpi는 금융일수(날수), D-1은 아래첨자로 어제를 뜻한다. |

| ty수익율 (다섯 자리) | 잔액식·하루치식·④·⑤·⑥ 다섯 곳에 같은 이름이 뜬다. 분자와 분모가 각각 다르다. |

## 8. 재조판할 때 쓰는 법

1. **산식이 나오는 자리마다 그 산식에 쓰인 기호를 바로 옆에 편다.** `§0` 매핑표 행이 최우선이다 — 독자가 문서에서 처음 산식을 보는 자리이고, 지금은 `w금융일수 = Σ Ai x Di / Σ Ai`만 덩그러니 있어 거기서 막힌다.
2. 병기 형식은 한 벌로 통일한다. 예 — `Ai` 채권 한 건을 산 값(채권 1건분 투자실행금) · `Di` 그 채권이 묶인 날수(금융일수) · `Σ` 전부 더한 값.
3. 병기한 기호마다 이 사전 항목으로 가는 **앵커 링크**를 건다. 앵커 id는 `sym-` + 기호를 영숫자로만 남긴 것을 권한다 — `Ai` → `sym-Ai`, `SB(D-1)` → `sym-SBD1`, `Σ` → `sym-sigma`, `③④⑤⑥` → `sym-circled`.
4. **한국어 용어명을 빼지 말 것.** 사용자가 막힌 지점이 정확히 그것이다 — 기호는 있는데 그게 한국말로 무슨 용어인지가 없었다.
5. `문서 명명` 16건은 **지어낸 이름임을 화면에 표시**한다. 감추면 원문에 있는 이름과 구별이 안 된다.
6. 숫자와 산식 자체는 바꾸지 않는다. 설명만 붙인다. 할인율 `0.11% 예정` 단서는 그대로 둔다.
7. 역방향 점검 — 산식에 나오는데 이 사전에 없는 기호가 있으면 그건 누락이다. §6 연산자까지 포함해 훑는다.

### 2-1 · 16:45 · ty수익률 위=예상치 · 아래=실적치

| | |
|---|---|
| 이미지 근거 | **못 붙임** (`F0BTV39NT5X` · `F0BTV3B5T9P` 판독 불가) |
| 뒤집히는가 | **아니다.** 3차 미팅에서 이미 확정된 것과 같다 |
| 우리 것 | `termsdoc_seed.json` no.16 note · no.32 note 에 「투자 자산 메뉴 최상단 값은 예상치, 투자 수익 메뉴 일별 표의 값은 실적치다 (3차 미팅 확정)」로 들어 있다 |
| 새로 붙는 것 | **대수 항등식이 문장으로 처음 나왔다** — 「투자수익률은 할인율 − max(0, 미지급금−과지급금)/투자실행액 이므로 미지급−과지급이 0이면 할인율이 되므로 같다」 |

**도출 과정** — 원문의 `SMR_{d-1} = Σ M / Σ A`, `M = 채권매입수수료 − max(0, 미지급금−과지급금)`, `A = 순지급액 × (1 − r)` 을 놓고, 원장이 `채권매입수수료 = 순지급액 × r` 로 두었으므로

```
SMR = Σ(순지급액 × r − max(0,L)) / Σ(순지급액 × (1 − r))
```

DM 의 「할인율 − max(0,L)/투자실행액」이 되려면 분자 첫 항이 `Σ A × r` 이어야 한다. 실제 분자 첫 항은 `Σ 순지급액 × r` 이라 **`1/(1−r)` 배 차이**가 난다. `r = 0.11%` 에서 배율은 `1.0011`, 곧 `SMR` 이 `0.11%` 가 아니라 `0.110121%` 로 떨어진다. **DM 문장은 근사식이고 우리 원장은 엄밀식이다.** 근사·엄밀 어느 쪽을 정본으로 삼을지는 발화되지 않았다.

**파급** — 화면·용어해설 전 파일에 `예상치` · `실적치` 낱말이 **0건**이다(`glossary.html` 0 · `invest-assets.html` 0 · `invest-profit.html` 0 · `certificate.html` 0). 원고 `termsdoc_seed.json` 에만 5건·3건 있다. 두 `ty수익율` 이 왜 다른 값인지 화면에서 읽히지 않는다.

### N-1 · 표본 합의 표기 `Σ_{i}^{S}`

원문 — 「모두 표본이 맞고 **표본의 합은 S가 빠지고 시그마 i부터 S까지로 통계식으로 된다**」

**어긋나는 자리** — 우리는 표본 합을 `Σ SL_i` · `Σ SA_i` 로 적는다(원고 no.11 formula `S입금부족율 = Σ SL_i / Σ SA_i` · 기호 사전 `SL_i` · `SA_i` · 검산 엑셀 `산식` 시트). DM 규칙대로면 `Σ_{i}^{S} L_i / Σ_{i}^{S} A_i` 가 된다.

**따라가면 생기는 파급** — `SL_i` · `SA_i` 두 기호가 사전에서 사라지고 `L` · `A_i` 에 표본 첨자만 붙는 꼴이 된다. 기호 사전 29개 중 2개 삭제·2개 개정, 원고 no.11 · no.12 · no.15 세 항 개정, 화면 4종의 `S입금부족율` 툴팁, 엑셀 `산식` 시트가 전부 흔들린다.

**당장 따라가지 않는 이유** — 원문 인용 자리는 한 글자도 못 고친다(`verify_ceo_quotes.py` 가 48건 부분문자열 대조). 원고 `quote` 필드는 `SLi` · `SAi` 그대로 남아야 하는데 우리 서술 표기만 `Σ_{i}^{S}` 로 바꾸면 같은 항 안에서 두 표기가 갈린다. **표기 전환은 §6 Q 로 물은 뒤에 한다.**

## §5. `duration` · `가중평균 만기일` 을 어떻게 실을 것인가

### 5-1. 지금 상태

`verify_crossscreen.py:231`

```python
BANNED = ('Duration', '가중평균만기', '평균만기', '만기')
```

거는 자리 둘.

| 검사 | 대상 |
|---|---|
| `용어 해설 · 대출 어휘 0건` | `glossary.html` |
| `화면에 대출 어휘 없음 (D-23)` | `app.html` · `invest-assets.html` · `invest-profit.html` · `invest-profit--weekly.html` · `invest-profit--monthly.html` · `certificate.html` |

실측 — 일곱 파일 전부 `만기` 0건 · `Duration` 0건. `app.html` 의 소문자 `duration` 5건은 토스트 지속시간이라 걸리지 않는다.

같은 파일 주석이 이미 이렇게 적혀 있다 — 「대표가 **「엄밀히는 공식 영어는 듀레이션」·「가중 평균 만기해서 웨이티드의 W 를 붙인 것」** 이라고 직접 말했다(00:43:33·00:44:30) … 대표가 같은 자리에서 「그 이름은 바꿔도 돼, 내가 마음대로 붙인 이름」이라며 개명 권한을 넘겼다」.

곧 **판정 근거는 이미 잡혀 있고, DM 16:41 은 같은 말을 글로 다시 준 것**이다. 뒤집을 것은 없다. 바뀌는 것은 하나다 — 이제 대표 표현이 **글로 남았으므로 인용할 수 있다.**

### 5-2. 두 안

| | 안 A · 지금대로 0건 유지 | 안 B · 각주 한 자리만 뚫는다 |
|---|---|---|
| 정본 표기 | `w금융일수` | `w금융일수` (같음) |
| 화면 | `만기` 0건 | `만기` 0건 (같음) |
| 용어해설 `w금융일수` 카드 | 언급 없음 | **각주 1블록** — 「공식 용어는 duration, 대표 표현은 가중평균 만기일」 + 출처 |
| 얻는 것 | 검사가 단순하다 | 투자자가 `duration` 을 알고 물었을 때 대조 가능. 대표가 자기 낱말을 못 찾는 일이 없다 |
| 잃는 것 | 대표가 쓴 낱말이 산출물 어디에도 없다 | 금지어 검사를 정밀화해야 한다 |

**안 B 를 택한다.** 근거 셋.

1. **대표 본인 발화가 근거 C 다.** 3차 미팅 00:43:33 · 00:44:30 과 DM 16:41 두 자리다.
2. **금지 취지가 「대출 어휘 배제」다.** 검사 이름이 `대출 어휘 0건` 이다. 막으려는 것은 이 상품이 대출로 읽히는 것이지, 금융 일반 용어를 아예 못 적게 하는 것이 아니다. **출처를 병기한 각주 한 줄은 대출로 읽히지 않는다.**
3. **`만기` 를 통짜로 막으면 원문 인용도 막힌다.** DM 15:37 원문에 「전일자 **만기** (지급예정일)」가 들어 있다. 이 DM 을 인용할 자리가 생기면 지금 규칙으로는 못 싣는다.

**바꾸지 않는 것** — 화면 6종은 지금 그대로 `BANNED` 전량 0건이다. 각주는 용어해설에만 둔다.

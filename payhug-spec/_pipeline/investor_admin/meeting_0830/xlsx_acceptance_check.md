## ⑤ → ⑥ 사슬

`기간집계!B17` 수식 문자열을 그대로 읽었다.

```
=IF(COUNT(입력!C18)=0,"미확정",B13/입력!C18*연일수/B16)
```

- `B13` = ④ ✔
- `입력!C18` = ③ (빈 칸) ✔
- `B16` = ⑤ ✔ — **⑥ 이 ⑤ 셀을 실제로 참조한다**
- `연일수` = 이름정의 → `입력!C4` = 365 ✔

`입력!C18` 이 비어 있는 동안 `COUNT` 가 0 이라 문자열 「미확정」을 내고, ③ 이 정해져 숫자가 들어가는 순간 세 항이 모두 살아난다. 갈아 끼울 자리는 `입력!C18` 한 칸, `입력!C19` 한 칸 — 둘뿐이다.

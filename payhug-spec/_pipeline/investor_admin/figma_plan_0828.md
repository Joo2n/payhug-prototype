## 3. 모노 폰트 — 조치 완료

### 3-1. 문제

레포 원본 스택(`assets/base.css:55`)은 Chrome에서 **Menlo**로 해석된다(50자 421.44px = advance 8.43). Figma에는 Menlo가 없어 캡처 노드가 `hasMissingFont` 상태가 되고, ⓐ 텍스트 속성 쓰기가 전면 차단되며 ⓑ 대체 폰트 폭이 Chrome 실측 폭을 넘겨 숫자 셀이 `11.3` → `11…` 로 말줄임된다.

스택별 Chrome 해석 실측(14px, 자당 advance):

| 지정 | 자당 폭 | 판정 |
|---|---|---|
| 스택 전체 | 8.43 | Menlo와 동일 |
| `Menlo` | 8.43 | 사용 가능 |
| `SFMono-Regular` · `SF Mono` | 6.31 · 6.36 | 없음 — 비례폰트로 대체 |
| `Monaco` · `Courier New` | 8.40 | 사용 가능 |
| `Roboto Mono` | 6.48 | 이 맥에 없음 |

Figma 렌더와 Chrome 렌더 픽셀 대조(`3234:2`, 1440×815) — 전체 4.65%, 합계행 셀 11.60%, 4행 셀 10.23%. 0 글리프 형태가 다르다(Chrome 슬래시 0 / Figma 평 0).

### 3-2. 채택안

**Figma 내장 구글폰트 `Roboto Mono`로 스테이징 사본에서만 교체.** `prep_fig.py`에 편입되어 재동기화에도 살아남는다.

- `_fig/assets/base.css`의 `--font-mono` → `'Roboto Mono', ui-monospace, Menlo, monospace`
- 각 화면 `<head>`에 구글폰트 링크 주입(`display=block`)
- **원본 레포 무변경.** 쓰기는 `_fig/` 안에서만

**조정자 지시와의 차이 — woff2 파일 자체 호스팅 대신 구글폰트 CDN 링크를 쓴다.** 파일 내려받기는 사용자 승인 사항이라 에이전트 판단으로 하지 않는다. 레포가 이미 `Noto Sans KR`을 같은 방식(`fonts.googleapis.com` 링크)으로 싣고 있어 기존 방식과 어긋나지도 않는다. 대가는 캡처 시점 네트워크 의존이며 §3-4로 막는다. 자체 호스팅으로 가려면 사용자가 woff2 내려받기를 승인해야 한다.

`Menlo.ttc`를 `~/Library/Fonts`에 설치하는 B안은 **하지 않는다**(사용자 기기 변경).

### 4-1. 87px 보정 — 유효

### 4-2. 스크립트

- 셀렉터 지정 없음. `capture.js`가 문서 전체를 잡는다. 화면설계서 파이프라인의 `#root` 규칙은 다른 계통이라 옮기지 않는다.
- 해시 3파라미터(`figmacapture` · `figmaendpoint` · `figmadelay`) 형식 유효.
- 8903 서버는 **`_fig` 를 루트로** 띄워야 한다(`run_import_0828.sh serve`).
- `captureId`는 `generate_figma_design` 산출물이라 쓰기 라운드에서 발급된다.

### 4-3. 프레임 높이

프레임 높이 = `max(문서 높이, 사이드바 고유 높이)`. 사이드바는 `position: fixed; height: 100%` 라 문서 높이에 안 잡히고 뷰포트를 따라간다. `prep_fig.py heights`가 측정 때만 `height: auto`로 풀어 고유 높이(533)를 읽는다. 사이드바가 없는 `login`(503)·`index`(1701)는 이 바닥이 붙지 않는다.

산출물 `fig_heights.json`. 값은 콘텐츠 변동을 그대로 따라가므로 **캡처 직전 재산출이 필수다.** 이 세션 중에만 `invest-assets`가 1576 → 1406으로 움직였다.

### 4-4. 전처리 — `prep_fig.py`

```
sync      레포 → _fig 동기화 + CSS 패치(모노 폰트 · 시트 말줄임)
measure   value 필드 기하 측정 → fig_meas.json
apply     capture.js·폰트 링크 주입 + input → 텍스트 노드 치환
verify    스테이징 준비 상태 확인
fontgate  --font-mono 가 Roboto Mono 로 해석되는지 실측
heights   프레임 높이 산출 → fig_heights.json
all       sync → measure → apply → verify
```

대상 32화면(구 32화면 − `coocon--confirm` + `acquisition--doc`). `invest-profit--datepicker`는 `HOLD`로 제외.

`value` 필드 최근 실측 **20필드 / 9화면**. 직전 라운드는 17필드 / 8화면이었고 비밀번호 계열 변경으로 늘었다. 이 값은 매 `measure`마다 다시 잡힌다.

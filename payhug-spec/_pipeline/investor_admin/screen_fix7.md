## 2 — 용어 안내 섹션 (지시 1과 정면으로 갈린 자리)

**지시가 서로 어긋난다.** 1번은 "용어 박스 4줄은 슬라이드에 실재하니 남겨라", 2번은 "`app.html` 안의 용어 안내 성격 섹션을 통째로 제거하라". 같은 블록이다.

**택한 해석** — 2번이 `app.html` 로 범위를 못 박았고, 1번의 ⚠는 전수 색출 과정에서 스토리보드 각주를 싸잡아 지우지 말라는 방어다. 둘 다 문자 그대로 지키는 배치는 하나뿐이다.

| 자리 | 처리 | 근거 |
|---|---|---|
| `app.html` 투자 자산 | 제거 | 지시 2 (`app.html` 명시) |
| `app.html` 투자 수익 | 제거 | 지시 2 + 슬라이드 7·8·9 에 각주 없음 |
| `invest-profit*.html` 정적 4종 | 제거 | 슬라이드 7·8·9 에 각주 없음 |
| `invest-assets*.html` 정적 5종 | **유지** | 슬라이드 3·4·5·6 에 실재. Figma 임포트 원본이라 스토리보드와 1:1 |

→ **통합본과 정적 투자 자산 화면이 이 한 블록만큼 달라진다.** 한쪽으로 통일하려면 아래 한 줄이면 된다.

- 전부 없애려면 — `fix12_static.py` 의 `invest-profit` 분기에 걸린 `용어 안내 제거` 정규식을 `invest-assets` 에도 걸고 재실행
- 통합본에도 되살리려면 — `build_app.py` 의 `FORMULA_BLOCK` 옆에 `TERMS_BLOCK` 을 만들어 투자 자산 섹션 `{FORMULA}` 뒤에 끼운다

## 3 — FAB(화면·상태 이동 도크) 제거

우하단 `● 화면 · 상태` 도크를 CSS·마크업·핸들러·초기화까지 전량 제거.

| 제거 대상 | 자리 |
|---|---|
| `.dock` `.dock-toggle` `.dock-panel` `.dock-states` `.dock-hint` CSS 5블록 | build_app.py CSS |
| `<div class="dock">…</div>` | CHROME_HTML |
| `ACT['dock-toggle']` `ACT['dock-state']` `updateDock()` · `refresh()` 안 호출 · `init()` 안 호출 · `dock-screen` change 분기 | JS |

**딥링크는 유지** — `#invest-assets/page2` `#contracts/empty` 등 `#화면/상태` 는 그대로 동작한다(Figma 캡처 동선).

### 도달 불가가 된 상태 2건 — 실동선 없음, 사유

| 상태 | 왜 못 만들었나 |
|---|---|
| `invest-assets/empty` | 투자 자산 화면에는 조회 필터가 없다(스토리보드 슬라이드 3 — 기준일 표기와 표 둘뿐). 빈 상태를 만들려면 없는 필터를 새로 지어야 해서, 근거 없는 UI 추가가 된다 |

**대체 도달 경로는 살아 있다.** 두 상태 모두 정적 화면 파일이 따로 있고 랜딩 `index.html` 목록에서 눌러 들어간다 — `invest-assets--empty.html`(index.html:187) · `contracts--empty.html`(index.html:301). 통합본에서는 딥링크 `#invest-assets/empty` · `#contracts/empty`.

**결정 필요** — 투자 자산·계약기록에 조회 필터를 넣을지. 넣으면 두 빈 상태가 필터로 자연히 도달하고, 안 넣으면 딥링크·정적 파일 진입만 남는다.

## 11 — 서명 대기 목록

- `전체 선택` · `선택 해제` 신설. 계약기록과 같은 `.list-tools` 묶음, 카드 머리 오른쪽.
  `전체 선택`은 미서명분이 없거나 이미 전건 선택이면 비활성, `선택 해제`는 선택 0건이면 비활성.
- **행 클릭 선택** — `.sign-row` 에 `data-act="aq-row"` · `role="checkbox"` · `tabindex="0"` · `aria-checked`.
- **이중 토글 방지** — 체크박스는 자기 `data-act="aq-chk"`, 계약서 링크는 `data-act="aq-doc"`(KEEP_DEFAULT, 새 창 기본 동작 유지). `closest()` 가 가장 가까운 `data-act` 를 잡으므로 행 토글과 겹치지 않는다.
- **키보드** — `keydown` 에서 `[data-act="aq-row"]` 의 Space·Enter 를 받고, 다시 그린 뒤 같은 행으로 포커스를 되돌린다.
- 서명 완료 행은 `data-act` 를 붙이지 않아 클릭·포커스 대상이 아니다.
- 가맹점 표의 행 클릭 제거와 방향이 다른 이유 — 저기는 **목적지**가 없어서 뺐고, 여기는 **선택**이라 넣는다.

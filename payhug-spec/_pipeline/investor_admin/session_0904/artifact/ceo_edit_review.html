PEC 가 왜 순현금 × 일수인가

EC 는 날짜마다 하나씩 있는 값이다. 원문이 그렇게 적었고 대표님 수정 8번도 같은 말을 한다.

원문 32행 매일 자정일 지나면, 배치 작업으로 … 평균순현금 산출해 DB 업데이트 원문 45행 전일자(D-1) 순현금 (EC) = 전일자 마감시점(자정) 현재 … 현금 잔액 원문 55행 PSC = 위 선택한 기간의 EC들의 합
PEC = EC08-20 + EC08-21 + EC08-22 + EC08-23 + EC08-24 + EC08-25 + EC08-26 = 20,000,000 × 7 = 140,000,000 예시 원장은 잔액이 매일 같다고 두었다

「그냥 순현금」은 EC 하나다. PEC 는 그것을 조회기간만큼 더한 것이다. 실제 서비스에서는 날마다 잔액이 달라 곱셈이 아니라 덧셈이 된다.

Σ 가 어디에 있나

④와 ⑤ 둘 다 Σ 가 있다. 재료를 만드는 줄에만 있고 산식 줄에는 이름으로 감춰져 있다.

재료 PA = Σ Ai i ∈ P 179,916,643 PM = Σ Mi i ∈ P 62,977 PD = Σ( Ai × Di ) ÷ PA i ∈ P 3.093802 PEC = Σ ECd d ∈ P 140,000,000 ④ PYa = ( PM ÷ PA × 100 ) × 365 ÷ PD 4.129577% ⑤ PYt = PYa × PA ÷ ( PA + PEC ) 2.322416%

⑤ 줄에서 채권 2,240건은 이미 PA 하나로 뭉쳐 있다. 「이 채권 대 순현금」을 2,240번 하는 것이 아니라, 채권 덩어리 대 현금 덩어리를 한 번 나눈다.

어떻게 아나배치가 매일 DB 에 적는 것조회 때 하는 것
PA그 날 도래한 채권의 투자실행금 합 (원문 32행 SAD-1)조회기간 7일치를 더한다 (원문 47행)
PEC그 날 자정 계좌 잔액 (원문 45행 EC)조회기간 7일치를 더한다 (원문 55행)

순현금은 「채권을 다 더하고 남은 나머지」가 아니다. 채권과 별개로 계좌에서 읽는 값이다. 두 값이 서로 반대로 움직이는 것은 채권이 만기되면 현금으로 들어오기 때문이지, 한쪽을 다른 쪽에서 빼서가 아니다.

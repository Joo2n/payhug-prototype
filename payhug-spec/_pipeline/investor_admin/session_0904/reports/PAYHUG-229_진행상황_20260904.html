1. **대표님 워드 수정본 검토 (13곳)**

    * 대표님께서 9/3 정리본에 변경 추적으로 13곳을 고쳐 보내주셨고, 대부분 「관찰된」 이라는 낱말을 붙여 예상치와 실측치를 가르는 수정이었음
    * 11곳은 그대로 채택
        * 첨자 r·a·t 의 뜻을 「예상 수익률」 「투자실행금 기준 관찰된 값」 「투자자산 기준 관찰된 값」 으로
        * r 은 「계약된 할인율」, L 은 「입금부족액」 으로 이름 변경
        * Y 는 값이 아니라 「연환산」 을 뜻하는 접두어라 이름 짓는 규칙 표로 이동
        * EC 는 「마감시점」 잔액으로, 투자자산 산식의 i 는 「대상정산금채권」 으로 명시
    * 2곳은 우리 정의를 유지하고 대표님께 되물을 예정

        * 가중평균 금융일수 D 의 모집단을 「표본에 속하는」 으로 고치신 것 → 표본이 무엇이냐에 따라 값이 13.21% / 13.05% / 12.98% 로 갈려 확인이 필요함
    * 대표님께서 새로 제안하신 「포트폴리오정산금채권」 이라는 이름은 1차 최종에 반영하지 않고 「대상정산금채권」 을 유지 (추후 논의)

2. **투자자산 대비 ty수익률(⑤) 분모 문제 발견 및 교정**

    * 문제 : ⑤ = ④ × PA ÷ (PA + PEC) 에서 PA 와 PEC 가 서로 다른 방식으로 센 값이라 더할 수 없음
        * PEC 는 조회기간 각 날의 순현금을 날마다 한 번씩 더한 값이라 「금액 × 일수」 성격
        * PA 는 그 기간에 정산예정일이 온 채권의 투자실행액을 채권마다 한 번만 더한 값이라 「금액」 만 있고 묶여 있던 일수가 빠져 있음
        * 그 결과 채권 비중이 투자자산 화면의 80% 가 아니라 56% 로 나오고, ⑤ 가 2.32% 로 낮게 계산됨
    * 검증 : 결론을 주지 않은 도출, 결론 반박 시도, 원장 숫자 독립 재계산 세 갈래로 교차검증한 결과 셋 다 같은 결론
        * 현행 산식은 금융일수가 1일일 때만 성립하고, 원장의 평균 금융일수는 3.09일이라 채권 쪽이 약 3분의 1 로 작게 잡힘
        * 은행의 일평잔·대출 원일수 계산과 같은 구조로, 채권도 「투자실행액 × 금융일수」 로 세어야 순현금과 같은 자로 잰 것이 됨
    * 교정 : ⑤ = PM × 365 ÷ ( Σ( Aᵢ × Dᵢ ) + PEC ) , i 는 정산예정일이 조회기간 안인 대상정산금채권
        * 가중평균으로 쓰면 ④ × Σ( Aᵢ × Dᵢ ) ÷ ( Σ( Aᵢ × Dᵢ ) + PEC ) 이고, Σ( Aᵢ × Dᵢ ) 는 PD 의 분자라 새 기호 없이 표현됨
        * 기본 조회기간(8/20~8/26) 기준 채권 비중 79.9%, ⑤ 3.30% (기존 2.32%)
        * 대표님 원문 기호로는 PSA 자리를 PSA × PSD 로 바꾸는 것과 같음
    * 21:50 대표님께 DM 으로 문제와 교정안을 설명드렸고, 대표님 확인 전까지 화면의 「미확정」 배지는 유지

3. **기호 표기 규칙 통일 → 「투자자어드민 기호정리표_V1.0」 확정**

    * 산식마다 Σ 로 풀어 쓴 것과 이름으로 접은 것이 섞여 있어(예: PD 분자는 Σ, 분모는 PA) 규칙 셋으로 통일
        * 정의 줄은 「이름 = Σ 낱건, 범위 조건」 으로 한 번 풀어 쓴다 (PA = Σ Aᵢ, i ∈ P)
        * 다른 산식에서 그 합을 쓸 때는 이름으로만 쓴다 (PMR = PM ÷ PA)
        * 한 산식 안에서는 풀면 다 풀고 접으면 다 접는다 (PD = Σ( Aᵢ × Dᵢ ) ÷ Σ Aᵢ)
    * 개념 행(A·L·M·B·MR·D)에 첨자 없는 일반형 산식을 추가해 기본 개념부터 읽히도록 함
    * 워드·HTML·아티팩트 세 벌이 같은 내용인지 독립 검토 두 번 통과, 원고 검사기 137건 전건 통과
    * 파일명을 「투자자어드민 기호정리표_V1.0」 으로 통일해 기획 채널에 공유 (23:01)

        * 로그인 화면을 어드민 프론트 로그인(PayHug Admin · 관리자 로그인 · 아이디/비밀번호 · 안내 상자)과 동일하게 되돌림

## 1차 최종 결정사항 (9/4 기준)

`이 기준으로 1차 티켓을 마무리하고, 아래 「확인 중」 항목은 후속 티켓 또는 이 티켓의 2차 라운드에서 다룬다`

1. **용어·기호 : 「투자자어드민 기호정리표_V1.0」 으로 확정**

    * 기준일은 d, 조회기간은 P 하나로 통일하고 하루 단위(d−1) 기호는 두지 않음 (일별 표의 한 행은 P 가 1일인 경우)
    * ty수익률은 Y 접두로 통일 : 투자 자산 화면은 예상치 Y_r , 투자 수익 화면은 관찰된 값 PY_a(투자실행금 기준) · PY_t(투자자산 기준)
    * 가중평균 금융일수는 D (기간은 PD), 입금부족률은 LR, 순현금은 EC (기간 합은 PEC)
    * 산식 표기는 「정의 줄은 Σ 로 풀고, 조립 산식은 이름으로, 한 산식 안에서는 혼용하지 않는다」 규칙으로 통일
    * 대표님 워드 수정 13곳 중 11곳 채택, 2곳(Σ Aᵢ 누계 · D 표본)은 확인 중

2. **투자자산 대비 ty수익률(⑤) 산식**

    * 합의안 : ⑤ = PM × 365 ÷ ( Σ( Aᵢ × Dᵢ ) + PEC ) — 채권도 순현금과 같이 「금액 × 묶인 일수」 로 세어 분모를 맞춤
    * 문서(V1.0)·프로토타입·엑셀은 이 산식으로 반영, 기본 조회기간 값 3.30%
    * 대표님 확인 전까지 화면의 「미확정」 배지는 유지하고, 승인되면 배지를 제거하는 것으로

3. **프로토타입(프론트)**

    * 화면 구조·기능은 8/28 확정한 PPT 그대로이며 이번 변경은 컬럼명·툴팁 텍스트뿐
    * 시연본(payhug-investor-prototype)은 투자자에게 보이는 7개 메뉴로 확정, 시뮬레이션·엑셀 미리보기·문서 페이지는 내부 통합본에만 둠
    * 로그인은 기존 어드민 프론트 로그인 화면을 그대로 사용

4. **피그마**

    * 제안서 첨부용 페이지는 시연본과 같은 24개 화면 + 눌렀을 때의 상태 화면(추가 중)으로 구성
    * 쿠콘 상세·시뮬레이션·엑셀 서식·로그인 프레임은 두지 않음

5. **다음 단계**

    * 「포트폴리오정산금채권」 용어 도입 여부 (대표님 9/4 제안, 1차 최종에는 미반영)

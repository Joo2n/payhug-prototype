## 3번 산식

```
PY_t = PY_a × (PA × PD) ÷ (PA × PD + PEC)
     = PM × 365 ÷ ( Σ(A_i × D_i) + PEC )        i 는 정산예정일이 P 안인 채권
```

- `PA × PD = Σ(A_i × D_i)` 는 `PD` 의 분자 그대로다(원문 51행 `PSD = (Σ Api x Dpi) / PSA`). 새 기호가 없다.
- 현행 `PY_a × PA ÷ (PA + PEC)` 는 이 식에서 `PD = 1` 일 때만 같다. 원장은 `D_i` 2~7일, `PD` 3.09일이라 채권 항이 1/3.09 로 줄어 비중이 0.799 → 0.562 로 내려간다.
- 투자자산 화면과 같은 「원」 단위로 보이려면 양쪽을 P 의 일수로 나눈다: `PA·PD ÷ |P|` = 79,518,062(일평균 투자실행액) · `PEC ÷ |P|` = 20,000,000(원문 32행 「평균순현금」). 비 값은 같다. 이때 새 기호는 P 의 일수 `|P|` 하나다.
- 정확한 꼴은 날마다의 잔량을 더한 것이다: `Σ_{t∈P} A(t) + PEC`, `A(t) = Σ A_i, 선정산일_i ≤ t < 정산예정일_i`. 날짜 첨자 `t` 와 하루 잔량 `A(t)` 두 기호가 새로 필요하다. `d` 를 첨자로 못 쓰는 이유: 기호표가 `d` 를 「기준일 하나」 상수로 확정했고 투자자산 화면의 `Σ A_i, 정산예정일 > d` 가 그 상수에 걸려 있다. 같은 글자를 ⑤ 에서 달리는 첨자로 쓰면 같은 식이 한 화면에서는 고정 집합, 다른 화면에서는 움직이는 집합을 뜻한다. `PEC` 는 이 충돌을 「P 안 각 날」이라는 문장으로 피했고(원문 55행), 채권 항도 같은 문장 또는 별도 글자로 적어야 한다.
- 두 꼴의 차이는 P 경계 효과다. `PA × PD` 는 만기가 P 안인 채권의 묶인 날수를 P 밖 날짜까지 모두 세고, P 끝에 아직 안 들어온 채권은 세지 않는다. 이번 주는 −1.40%(원·일) · `PY_t` −0.009%p 라 소수 둘째 자리 표기(3.30% vs 3.31%)에서 한 눈금 갈린다.

## 결론

⑤ 의 분모 `PA + PEC` 는 원 단위 회전액에 원·일 단위 잔액 적분을 더한 것이라 「조회기간의 투자자산」이 아니며, 채권 비중을 0.80 이 아닌 0.56 으로 낸다.
채권 항에 금융일수를 곱한 `PA × PD`(= `PD` 의 분자)로 바꾸면 새 기호 없이 `PEC` 와 같은 종류가 되고, 비중 0.799 · ⑤ 3.30%(상수 EC) 로 투자자산 화면의 80/20 과 맞는다.
나머지 산식(`D`·`LR`·`Y_r`·`PD`·`PMR`·`PY_a`)에는 같은 종류의 단위 혼입이 없다.

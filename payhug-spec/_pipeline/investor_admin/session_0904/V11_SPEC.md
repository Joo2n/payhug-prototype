# 투자자어드민 기호정리표 V1.1 명세 — d 는 오늘

V1.0 표 셋의 골격을 그대로 두고 아래만 바꾼다. 첨자는 `i` 와 `r`·`a`·`t` 뿐이고 날짜 첨자는 없다.

## 전제

| 항목 | 정의 |
|---|---|
| `d` | 오늘. 화면을 보는 날. 산식에는 조건 문장으로만 들어간다 |
| 배치 | 매일 자정, 정산예정일이 그날인 채권을 회수 처리한다. 그래서 오늘 낮에 보이는 상태는 **어제 마감 시점**이다 |
| `P` | 조회기간. 어제까지이고 오늘은 포함하지 않는다. 일별 표 한 행은 P 가 1일 |
| `i` | 대상정산금채권 하나. 어느 채권을 셀지는 각 산식의 조건 문장이 정한다 |

## 표 1 이름 짓는 규칙 (V1.0 그대로 + 띄어쓰기)

| 분류 | 의미 | 예시 |
|---|---|---|
| 접두 P | 조회기간을 뜻한다 | PA PD PY_a |
| 접두 Y | 연환산을 뜻한다 ( × 365 ÷ 금융일수 ) | Y_r PY_a PY_t |
| 아래첨자 | 그 값을 가르는 것 하나만 넣는다 | A_i Y_r PY_a |
| 첨자 i | 대상정산금채권 하나의 ID | A_i D_i |
| 첨자 r | 예상 수익률을 나타낼 때 쓴다. Y_r 는 연환산 예상 수익률 | Y_r |
| 첨자 a | 투자실행금 기준 관찰된 값을 나타낼 때 쓴다. PY_a 는 조회기간에서 관찰된 투자실행금 기준 연환산 수익률 (P 는 조회기간) | PY_a |
| 첨자 t | 투자 자산 기준 관찰된 값을 나타낼 때 쓴다. PY_t 는 조회기간에서 관찰된 투자 자산 기준 연환산 수익률 | PY_t |

## 표 2 전체 기호

| 분류 | 개선 | 기존 | 용어 이름 | 산식 |
|---|---|---|---|---|
| | d | D | 오늘 | 화면을 보는 날. 조회기간 P 는 어제까지 |
| | r | | 계약된 할인율 | 0.11% 예정 |
| | D | wD | 가중평균 금융일수 (Duration) | D = Σ( A_i × D_i ) ÷ Σ A_i |
| | A | | 투자실행금 | A = 순지급액 × ( 1 − r ) |
| | M | | 투자수익 | M = 채권매입수수료 − max( 0, L ) |
| | B | | 상환액 | B = 순지급액 − max( 0, L ) |
| | L | | 입금부족액 | L = 미지급금 − 과지급금 |
| | MR | | 투자수익율 (Margin) | MR = M ÷ A |
| 채권 한 건 | D_i | | 금융일수 | 선정산일로부터 정산예정일까지의 한편 넣기 일수. 08-24 선정산 · 08-26 정산예정이면 2 |
| 채권 한 건 | A_i | | 투자 실행액 | A_i = 순지급액_i × (1 − r) |
| 채권 한 건 | L_i | | 입금부족액 | L_i = 미지급금_i − 과지급금_i |
| 채권 한 건 | 채권매입수수료_i | | 채권매입수수료 | 채권매입수수료_i = 순지급액_i × r |
| 채권 한 건 | M_i | | 투자수익 | M_i = 채권매입수수료_i − max(0, L_i) |
| 채권 한 건 | B_i | | 상환액 | B_i = 순지급액_i − max(0, L_i) |
| 투자 자산 | Σ A_i | | 투자 실행액 | Σ A_i. i 는 정산예정일이 d 이후인 채권 (어제 마감까지 회수되지 않은 채권. 오늘 정산예정 채권은 오늘 밤 배치 전이라 포함) |
| 투자 자산 | EC | | 순현금 | 어제 마감시점 쿠콘 가상계좌의 현금 잔액 |
| 투자 자산 | Σ A_i + EC | | 투자자산 | Σ A_i + EC. i 는 정산예정일이 d 이후인 대상정산금채권. 어제 마감 시점의 자산 |
| 투자 자산 | D | wD | 가중평균 금융일수 | i 는 대상정산금채권 전체 |
| 투자 자산 | LR | | 입금부족률 | LR = Σ L_i ÷ Σ A_i. i 는 선정산일이 d 의 20일 전부터 11일 전까지인 채권 |
| 투자 자산 | Y_r | | 예상 연환산 수익률 | Y_r = r × 365 ÷ D |
| 투자 수익 | PA | | 조회대상기간의 투자실행금 | PA = Σ A_i   i ∈ P |
| 투자 수익 | PM | | 조회대상기간의 투자수익 | PM = Σ M_i   i ∈ P |
| 투자 수익 | PB | | 조회대상기간의 상환액 | PB = Σ B_i   i ∈ P |
| 투자 수익 | PMR | | 조회대상기간의 투자수익율 | PMR = PM ÷ PA |
| 투자 수익 | PD | PwD | 조회대상기간의 가중평균 금융일수 | PD = Σ( A_i × D_i ) ÷ Σ A_i   i ∈ P |
| 투자 수익 | PEC | | 조회대상기간의 누적 순현금 | P 안 각 날 마감시점 EC 를 더한 값 |
| 투자 수익 | PY_a | PY_MR | 조회대상기간의 투자실행금액 대비 연환산 수익률 | PY_a = PMR × 365 ÷ PD |
| 투자 수익 | PY_t | wPY_MR | 조회대상기간의 투자 자산 대비 연환산 수익률 | PY_t = PM × 365 ÷ ( Σ( A_i × D_i ) + PEC )   i ∈ P  =  PY_a × Σ( A_i × D_i ) ÷ ( Σ( A_i × D_i ) + PEC ) |

「i ∈ P」는 정산예정일이 P 안인 채권.

## 표 3 기호 변경내역

| 변경점 | 기존 | 개선 |
|---|---|---|
| w 삭제 | wD PwD wPY_MR | D PD PY_t |
| d−1 제거 | A_d−1 M_d−1 B_d−1 MR_d−1 wD_d−1 EC_d−1 Y_MR,d−1 | 조회기간 P 를 1일로 잡아 대신한다 |
| d 재정의 | D 현재일자 · D−1 전일자 | d 오늘 하나. 산식에는 조건 문장으로만 |
| 미회수 조건 | 정산예정일이 d 보다 뒤 | 정산예정일이 d 이후 (오늘 정산예정 채권은 오늘 밤 배치 전이라 미회수) |
| EC 시점 | d 마감시점 | 어제 마감시점 |
| 관찰된 연환산 수익률 기호 변경 | PY_MR wPY_MR | PY_a PY_t |
| ⑤ 분모 | PA + PEC | Σ( A_i × D_i ) + PEC. PEC 는 P 안 각 날의 EC 를 더한 값이고 Σ( A_i × D_i ) 는 P 에 정산된 채권마다 투자실행액 × 금융일수를 더한 값이라 둘 다 금액 × 일수다 |

## 표 4 내부 용어와 투자자 화면 용어 (신설)

| 내부 용어 | 투자자 화면 | 툴팁 |

| 대상정산금채권 | 보유 채권 | |

| 예상 ty수익률 (Y_r) | 예상 연환산 수익률 | 계약된 할인율 기준 예상치 |
| 투자자산 대비 ty수익률 (PY_t) | 투자 자산 대비 연환산 수익률 | |

| 투자 실행액 · 순현금 · 투자자산 · 가중평균 금융일수 · 입금부족률 | 같음 | |
| 기호 (A_i PA PD PY_a …) | 화면에 쓰지 않음 | 툴팁에서만 |

## 원장·화면에 따라오는 것

| 자리 | 지금 | 바꿀 것 |
|---|---|---|
| 원장 `ASOF` 08-27 | 오늘로 해석 | **어제(마감 스냅샷 날)** 로 해석. 오늘은 08-28 이고 화면에 표시하지 않는다 |
| 원장 미회수 조건 `due > ASOF` | 정산예정일 > 08-27 | 그대로 (= 정산예정일 ≥ 오늘 08-28) |
| 원장 `LAST_DUE` = ASOF − 1 (08-26) | 일별 표 마지막 행 08-26 | `LAST_DUE = ASOF` (08-27). 기본 조회기간 08-21~08-27 |
| 순현금 `CASH` 2천만 | 시점 없음 | 08-27 마감 (= 어제 마감) |
| 투자 자산 화면 「기준일 2026-08-27」 알약 | 있음 | 제거 (실제 프론트에 없음) |
| 툴팁 「선정산일이 기준일 20일 전 ~ 11일 전」 | | 「선정산일이 오늘 기준 20일 전 ~ 11일 전」 |
| 엑셀 제목 「기준일 2026-08-27」 | | 「어제 마감 2026-08-27」 또는 실물 엑셀 형식 확인 |

### 유의점

| 항목 | 내용 |
|---|---|
| 제목 옆 상태 배지 | 새 상태 5건은 `STATE_META`(1193~1236)에 없어 `DERIVE` 가 `default` 를 내고 배지가 뜨지 않습니다. 기존 상태 프레임처럼 배지를 달려면 `build_app.py` `STATE_META`·`DERIVE` 에 항목을 더해야 하며, 이 분석은 파일을 고치지 않습니다 |
| 낱장·통합본 표기 차이 | 가맹점·계약기록 페이지 줄 — 낱장은 1쪽이어도 `1` 버튼을 그리고(`merchants.html:229~233`) 통합본은 `pageBar` 가 1쪽이면 비웁니다. 동결본과 기존 낱장을 나란히 두면 이 차이가 보입니다 |
| 툴팁 프레임 검사 | `figma_map_investor.json` `verification.hidden_tooltip_panel_leak: 0` 검사는 숨은 패널이 새지 않는지 봅니다. 툴팁 열림 프레임은 패널 1개가 의도적으로 보이므로 검사에서 예외 처리가 필요합니다 |

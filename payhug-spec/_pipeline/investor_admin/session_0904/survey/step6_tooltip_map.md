## 5. (나) 바꿀 문면 제안

행의 꼴은 `기호 | 용어명 · 산식(또는 값)` 입니다. 왼쪽 칸이 기호, 오른쪽 칸이 용어명과 산식 또는 값입니다(`.tip-row` 는 좌우 두 칸 flex, `assets/base.css:509`). 머리글은 `기호 · 용어명 · 산식` 한 줄입니다. 「대표 DM …」 행과 「미확정 · 대표 재전달 대기」 행은 글자 그대로 둡니다. 한 툴팁 안에서 같은 기호는 한 번만 풉니다. HTML 조판은 `subscript.py` 규약대로 `PY_a` → `PY<sub>a</sub>`, `PY_t` → `PY<sub>t</sub>`, `Y_r` → `Y<sub>r</sub>`, `A_i` → `A<sub>i</sub>`, `순지급액_i` → `순지급액<sub>i</sub>` 입니다.

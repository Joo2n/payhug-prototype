시뮬 로직 블록은 두 주소가 바이트 일치(14,648자)이며 세 벌 실행 raw 값도 동일하다. 아래는 양쪽 공통.

## 한 줄 결론

**된다. 단 ⑤는 못 쓴다.** 1억·유휴 20/25/30% 세 벌이 실제로 돌아가고 값이 갈린다.
그런데 ⑤ 투자자산 대비 ty수익율이 조회기간 길이에 끌려다닌다(7일 1.07% → 88일 0.11%, ④는 4.81% 고정).

## 2. 1억 · 유휴 20~30% 가능 여부

### 1억 — 입력은 되나 한 칸으로는 안 된다

「자금 1억」에 해당하는 칸이 없다. 순현금에만 1억을 넣으면 투자자산이 179,912,000원이 되고 유휴 비중 55.6%다.
투자자산 1억을 만들려면 역산해 4행에 나눠 넣어야 한다.

```
목표 투자실행액 E  →  미회수 채권 순지급액 합 = E ÷ (1 − 할인율)
E = 80,000,000  →  80,088,098원   (4행에 30,433,477 / 35,238,763 / 9,610,572 / 4,805,286)
```

### 유휴자금 비율 — 그런 칸이 없다

`유휴`·`아이들` 문자열이 배포 2주소·글로서리 통틀어 **0건**이다. 대응물은 **순현금**이고, 대표 정의서 [1번]의
`순현금의 비중 = 순현금 / (투자실행액 + 순현금)` 이 회의의 「아이들 머니 20~30%」와 같은 자리다.

**원 단위만 받는다.** 20%를 넣으려고 `20`을 치면 순현금 20원으로 먹힌다(실측: 투자실행액 비중 100.0%).
결과 화면·엑셀에는 비중이 `80.0% / 20.0%`로 나온다. 넣을 때만 % 입력구가 없다.

### 실행 게이트가 min/max를 안 본다 — 결함

브라우저는 빨간 테두리를 띄우는데 `simCanRun()`(`app.html:2409-2418`)은 할인율이 `0 < r < 100`인지만 본다.

| 친 값 | 브라우저 | 실행 버튼 | 결과 |
|---|---|---|---|
| 할인율 `6` (max 5) | 무효 | 살아 있음 | ① 720.39% · ④ 757.44% · ⑤ 160.36% |
| 미지급률 `150` (max 100) | 무효 | 살아 있음 | 투자수익 −59,952,000원 · ④ **−18,015.28%** |
| 순현금 `-5000000` (min 0) | 무효 | 살아 있음 | ⑤ 38.76%가 ④ 4.81%를 8배 추월 |

## 6. ⑤ 수식 교체 지점

### 지금 화면이 쓰는 것 — 대표 정의서 원문 그대로다

```js
var ECD = simDays(SIM.from, SIM.to) + 1;   // 조회 일수
var PSC = SIM.cash * ECD;                  // 순현금 × 일수
var TY5 = TY4 * PSA / (PSA + PSC);
```
`payhug-investor-admin/app.html:2384-2386` · 생성기 `build_app.py:2028-2030`

옮기다 틀린 게 아니라 **원문 산식대로 넣으니 값이 이상해진 것**이다.

### 증상 — 조회기간만 늘리면 ⑤가 0으로 수렴한다

| 조회기간 | ECD | PSA | PSC | ④ | ⑤ |
|---|---|---|---|---|---|
| 08-21~08-27 | 7일 | 39,956,000 | 140,000,000 | 4.81% | **1.07%** |
| 08-14~08-27 | 14일 | 39,956,000 | 280,000,000 | 4.81% | 0.60% |
| 08-01~08-27 | 27일 | 39,956,000 | 540,000,000 | 4.81% | 0.33% |
| 06-01~08-27 | 88일 | 39,956,000 | 1,760,000,000 | 4.81% | **0.11%** |

PSA는 만기 도래 채권을 1회씩 더한 **스톡**이고 PSC는 잔액 × 일수인 **유량**이라 단위가 다르다.
기간이 길어지면 PSC만 선형으로 불어나 ⑤를 깎는다. 순현금이 음수면 분모가 줄어 ⑤가 ④를 추월한다(실측 38.76% vs 4.81%).

이미 등재돼 있음 — `glossary_manuscript.md:1538-1553` 「유량 계통에 같은 이름의 다른 값이 있다」.

| 세 벌에서 ④·W·S·PSA·PSM이 안 변함 | 유휴는 미회수 채권·순현금만 건드린다. 기간 내 4행을 같이 바꾸면 ⑤ 1.07% → 1.75%로 움직인다 |
| 1행만 남으면 `삭제` 0개 | `n > 1` 조건. 실제 어드민 `page.tsx:288`과 같은 규칙 |
| 1행만 남기고 실행 시 0원·0.00일 | 남은 1행이 `기간 내`라 미회수가 없어서 나오는 정상값. 0 나누기 가드 있고 콘솔 에러 0건 |
| 임의 기간에서 엑셀 버튼 무반응 | `disabled`로 바뀐다(실측). 실물 없는 기간을 조용히 내려주지 않는 의도된 처리 |

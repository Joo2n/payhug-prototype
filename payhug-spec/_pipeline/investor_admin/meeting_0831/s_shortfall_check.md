## 2. 우리 구현 — 방식1 로 구현돼 있다

`daily_ledger.py` 252–256행.

```python
def shortfall(rows):
    """S입금부족율 = Σ SLi / Σ SAi — 표본집합 채권에서만 센다."""
    sa = sum(r['ai'] for r in rows)
    sl = sum(r['unpaid'] - r['over'] for r in rows)
    return (D(sl) / D(sa) * 100) if sa else D(0)
```

분자·분모를 각각 전부 더한 뒤 한 번 나눈다. 하루 단위로 자르는 자리가 함수 안에 없다. **(가) 구현.**

표본은 249행에서 잘린다. 자르는 축은 **선정산일(`adv`)** 이다.

```python
SAMPLE  = (ASOF - timedelta(days=20), ASOF - timedelta(days=11))   # S 표본집합 구간
_SAMPLE = [r for r in RECEIVABLES if SAMPLE[0] <= r['adv'] <= SAMPLE[1]]
```

### 항목 1 — 방식 판정

`daily_ledger.shortfall` 을 **인공 표본으로 직접 부른다.** 분모가 다른 두 묶음(SA 10,000 / SL 100 · SA 30,000 / SL 200)을

행동으로 본다.

이어 방식1 의 정의적 성질을 세 축에서 판정한다. **조각을 분모로 가중해 합치면 전체와 같다** —
가맹점 8조각 · 선정산일 10조각 · 홀짝 2조각. 단순평균이면 성립하지 않는다.

### 항목 2 — 표본 구간

`SAMPLE` 양끝이 `ASOF-20` · `ASOF-11` 인가 · 폭이 열흘인가 · 자르는 축이 선정산일인가.

문언은 네 곳에서 본다 — `ceo_definitions.md` 원문 · 화면 원천 6파일(`app.html` · 시연본 · 낱장 4종) ·

분자·분모 각각 `=SUMPRODUCT(…)`, `AVERAGE` 0건).

### 항목 3 — 판별 축은 raw 6자리다

### Q1. 표본을 자르는 축이 선정산일인 것이 맞나

원문 [1번] 은 `표본집합: 선정산일이 D-20부터 D-11인 기간` 이라 선정산일 축이다.
그런데 회의에서 대표가 설명한 KPI 개념은 **정산예정일** 축이다.

```
조현준 (00:20:33): 어제 상환 예정일인 것 중에 99%가 들어왔는지 100%가 들어왔는지 98%가 되는지
                   그걸 알고 싶은 거야.
조현준 (00:21:37): 어제가 정산 돼야 될 금액이 입금돼야 될 금액이 플랫폼으로부터 입금돼야 될 금액이
                   100만 원인데 실제로 들어온게 … 101만 원이더라.
```

선정산일 `D-20 ~ D-11` 은 금융일수 1~13일을 더하면 정산예정일이 `D-19 ~ D+2` 로 흩어진다.
아직 도래하지 않은 채권이 표본에 섞인다. 정산예정일 축으로 자르면 이 원장에서 값이
`0.074428%` → `0.071879%` 로 바뀐다.

`D-11` 이라는 11일 버퍼가 「정산예정일이 다 지나가기를 기다리는 장치」로 읽히지만 원문에 그 설명이 없다.
**물어야 할 것** — 표본을 자르는 날짜가 선정산일인가 정산예정일인가. 선정산일이라면 `D-11` 버퍼의 근거가 무엇인가.

### Q2. 사용자가 고른 기간이 S 의 표본을 바꾸나

원문 [1번] 의 표본집합은 `D` 하나로 고정(`D-20 ~ D-11`)이고 화면 기간 필터와 무관하다. 현행 화면도 고정이다.
그런데 회의 00:25:24 는 다르게 읽힐 여지가 있다.

```
조현준: 예를 들어서 투자자가 최근 일주일치를 한 보고 싶어 혹은 최근 한 달치를 보고 싶어 뭐 이런 걸 정하잖아.
        그럼 최근 일주일 최근 한 달치 하는게 피리오드야. 그지?
        그러면 그 피리어드를 전체를 했을 때 어 입금 부정률이 몇 %인지를 알고 싶은 거거든.
```

이 문답의 주제는 `P` 접두의 뜻이고, 대표가 든 예시가 입금부족률이다. 「기간을 고르면 그 기간의 입금부족률」로
읽으면 S 가 기간 필터를 따라야 하고, 「합산 규칙의 예시일 뿐」으로 읽으면 고정이 맞다.

### 16:45 — 근사식과 원식을 나란히

「투자수익률은 할인율 -max(0, 미지급금-과지급금)/투자실행액 이므로 미지급-과지급이 0이면 할인율이 되므로 같다.」

이 식을 원식으로 풀면 분모가 순지급액이 아니라 투자실행액이라 `1/(1-할인율)` 배만큼 갈린다.
**어느 쪽이 정본인지는 판정하지 않는다.** 두 값을 나란히 뒀다.

| 기간집계 | 항목 | 값 |
|---|---|---|
| `B21` | (가) 대표 근사식(%) = (할인율 − 차감합/PSA) × 100 | 0.037655 |
| `B22` | (나) 원식 PSMR(%) = PSM / PSA × 100 | 0.037716 |
| `B23` | (나) − (가) (%p) | 0.000060 |
| `B24` | (나) / (가) (배) — 실측 | 1.001606 |
| `B25` | 1 / (1 − 할인율) (배) — 이론 | 1.001101 |
| `B26` | 차감합 Σ max(0, 미지급−과지급) | 133,169 |
| `B27` | **차감합 0 일 때 (가)(%)** | **0.110000** |
| `B28` | **차감합 0 일 때 (나)(%)** | **0.110121** |

## 5. XML 금지어 판정 신설

셀 값만 보면 정의된 이름·시트 이름·데이터 유효성·주석에 숨은 것을 못 잡는다.
`banned_xml()` 이 워크북 zip 의 XML 조각 전건을 읽는다. openpyxl 이 한글을 숫자 문자 참조
(`&#47564;&#44592;`)로 쓰기 때문에 **먼저 되돌린 뒤** 본다 — 안 그러면 그냥 못 찾고 통과한다.

보는 낱말 셋 — `만기` · `가중평균만기` · `Duration`(대소문자).

| 예외 자리 | 못 박은 수 | 실측 |
|---|---|---|
| 조어 `만기 도래` | 8 | 8 |
| 파일명 `platform_duration.py` (출처 표기) | 5 | 5 |

**개수까지 못 박았다.** 하나라도 늘면 FAIL 이다. 잔여 금지어 0건.

같은 판정을 `verify_cycle_xlsx.py` 에도 걸었다. 정산주기_정리 워크북은 예외 자리가 0이어야 하고,
0 이 아니면 FAIL 이다. 판정기는 `audit_xlsx_check.banned_xml` 하나를 가져다 쓴다 — 기준을 두 벌 두지 않는다.

이 과정에서 `읽는 법` 기호 규칙 `w` 줄의 「공식 용어로 duration」을 뺐다. 대표 DM 16:41 의
말이지만 그 낱말은 우리가 안 쓰기로 한 쪽이라 예외를 만들지 않고 `w금융일수 = 가중평균금융일수` 로 적었다.

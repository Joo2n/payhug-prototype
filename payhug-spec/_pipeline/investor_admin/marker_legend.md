# 대표 정의서 번호 마커 대응표

출처: 사용자가 대표님께 보낸 용어 정의 요청 원문(2026-08-27) + 스토리보드 화면 캡처 2장의 번호 마커.
용도: `ceo_definitions.md`의 `이미지의 ③④⑤⑥` 참조를 실제 값에 연결한다. **이 표가 없으면 대표 산식을 적용할 수 없다.**

## 핵심 — 한 이미지 안에 표가 둘이고 번호도 두 벌이다

2번 이미지(투자 수익 화면)는 `현황` 표와 `일별 투자수익` 표가 각각 1번부터 다시 센다.
대표 산식의 번호가 어느 표 것인지는 **그 산식이 등장하는 문맥**으로 갈린다.

## 2번 이미지 — 투자 수익 화면

### 현황 표 (기간 집계)
| 번호 | 항목 |
|---|---|
| 1 | 검색대상기간 |
| 2 | 투자실행금 |
| 3 | 투자수익 |
| 4 | ty수익율 — 투자실행금액 대비 |
| 5 | ty수익율 — 투자자산 대비 |

### 일별 투자수익 표 (행 단위)
| 번호 | 항목 |
|---|---|
| 1 | 입금일자 (대표 지시: `정산예정일`로 변경) |
| 2 | 상환액 |
| 3 | 투자실행금 |
| 4 | 투자 수익 |
| 5 | w금융일수 |
| 6 | 투자실행금액 대비 ty수익율 |

## 대표 산식 대응 (전건 해소)

| 대표 정의서 원문 | 대응 | 풀어 쓰면 |
|---|---|---|
| `투자실행금액 대비 ty수익율(이미지의 ④) = PSMR × 365 / PSD` | **현황 4** | 기간 집계 수익률 |
| `투자자산 대비 ty수익율(이미지의 ⑤) = (이미지의 ④ × PSA) / (PSA + PSC)` | **현황 5**, 내부 ④ = 현황 4 | 기간 집계, 분모에 순현금 기간 합 포함 |
| `상환액(이미지의 ②)` | **일별 2** | 행 단위 |
| `투자실행금액 대비 ty수익율(이미지의 ⑥) = (이미지의 ④ / 이미지의 ③) × 365 / 이미지의 ⑤` | **일별 6**, 내부 ④③⑤ = 일별 4·3·5 | (투자수익 ÷ 투자실행금) × 365 ÷ w금융일수 = 행 단위 수익률 |

### 왜 ④와 ⑥이 같은 이름인가
둘 다 `투자실행금액 대비 ty수익율`이다. **④는 기간 전체를 한 번에 계산**하고, **⑥은 하루치를 계산**한다. 같은 지표의 집계 단위가 다르다. 동명이의가 아니라 같은 지표다.

## 해소된 문의 문항
- **Q-1 이미지 2장 누락** — 이 표로 대체 해소. 재송부 없이 산식 적용 가능
- **Q-4 ⑥이 ④와 동명** — 동명이의가 아니라 집계 단위 차이. 해소

## 남는 것
`⑤`의 분모 `PSC`가 **기간 동안 EC들의 합(유량)** 이라는 점은 원문에 명시돼 있다. 현재 화면은 기준일 잔액 1개(스톡)로 계산해 `3.32%`가 나오고, 대표 정의대로면 `2.24%`다. **화면 쪽 오류로 확정** — 정정 대상.

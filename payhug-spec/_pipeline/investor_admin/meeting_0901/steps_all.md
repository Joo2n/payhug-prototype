### 3-2. 세 갈래 산출 계통

값 138개가 세 계통에서 나온다.

같은 화면의 옆 칸끼리 모집단이 다르다. 현황 표 한 행에서 `금액`은 미회수 2,240건, 바로 옆 `W금융일수`는 전체 61,760건이다. 정의서에서 「회수되지 않은」이라는 한정이 투자 실행액 줄에만 붙어 있고 w금융일수가 쓰는 대상정산금채권에는 붙어 있지 않은 것이 그 근거다. 화면 툴팁이 `대상정산금채권 전체 (발생 기준)` · `61,760건` 으로 이 갈림을 드러내지만, **두 칸이 다른 모집단이라는 사실 자체는 어느 산식에도 적혀 있지 않다.**

### 3-3. 비율·일수를 다음 계산에 넣는 자리

`Ty수익율` 의 분모는 표기 W 가 아니라 소수 6자리에서 끊은 W다(`dm_0901/rounding_rule_0901.md` 규칙 1).

```
6자리  3.039607  →  0.11 × 365 ÷ 3.039607 = 13.208944%  →  13.21%
표기   3.04      →  0.11 × 365 ÷ 3.04     = 13.207237%  →  13.21%
```

현황 행은 두 길 다 13.21% 로 떨어지지만 가맹점별 행은 갈린다 — 청춘포차 신촌점 `14.89 ↔ 14.87` · 바다마루 횟집 `15.72 ↔ 15.75` · 한강커피 잠원점 `15.95 ↔ 15.93`. 화면과 원장은 6자리 쪽이다. 일별 표 `Ty수익율`(⑥)도 같은 규칙이라 ⑤ 열의 6자리 값으로 나눈다. 화면은 6자리 값을 보여 주지 않아 화면에 뜬 두 칸만으로는 되짚을 수 없다.

`MR(d−1)` 과 `PMR` 도 예외 없이 끊는다. 끊는 자리는 백분율 표기 기준 6자리다. `MR(d−1) = M(d−1) ÷ A(d−1) × 100` 을 끊고 그 6자리 값에 365 를 곱한다. 비율 그대로 끊으면 백분율로 넉 자리만 남아 ④ 가 `3.992465%`, ⑤ 가 `2.245603%` 로 밀린다.

### 3-4. PwD 두 갈래

합계 행 `W금융일수 3.11(가중평균)`과 수익 현황 `④ 3.99%` 의 분모가 같은 PwD 다.

| 경로 | 값 | 어디가 쓰나 |
|---|---|---|
| 일별 **6자리 W** 를 투자실행금으로 가중 | **3.107588일** | 화면 · `ledger_facts.json weekWRaw` |
| 건별 `( Σ Aᵢ × Dᵢ ) ÷ PA` | 3.107588일 | 검산 엑셀 `기간집계!B12` |

소수 6자리까지 같다. 일별 W 를 2자리로 끊어 가중하면 3.108481일이 나오고, 그 잔차 0.000893일이 ⑤ 표기를 `2.24% ↔ 2.25%` 로 뒤집는다. 대표 정의서 원문 `PSD = (Σ Api x Dpi) / PSA` 은 건별 쪽이고, 6자리 규칙 아래서 두 경로가 만난다.

### 3-5. 상환액 — 한 줄로 낸다

`② 상환액` 은 `( Σ 순지급액ᵢ ) − ( Σ max(0, Lᵢ) )` 한 줄로 낸다(`dm_0901/rounding_rule_0901.md` 규칙 2). `③ + ④` 로 되짚는 길은 `반올림(순지급액 × 0.9989)` 과 `절사(순지급액 × 0.0011)` 두 곳에서 원 단위로 끊는다.

화면은 한 줄 쪽 값을 싣는다. 합계 행에서 `상환액 − 투자수익 = 투자실행금` 이 원 단위로 닫히지 않고 17원이 남는다 — 상환액을 한 줄로 내기로 한 대가다.

### 3-6. 손검산 두 줄

주어진 산식대로 두 줄을 손으로 풀었다.

```
② 상환액      = ( Σ 순지급액ᵢ ) − ( Σ max(0, Lᵢ) )
채권매입수수료  = ⌊ Σ 순지급액ᵢ × 0.11% ⌋
④ 투자수익     = 채권매입수수료 − ( Σ max(0, Lᵢ) )
⑥ ty         = (④ ÷ ③) × 365 ÷ ⑤
```

## 4. (다) 이어짐이 끊긴 자리

층을 여섯으로 놓고 잰다.

| 층 | 무엇 |
|---|---|
| L0 | 가맹점 매출 |
| L1 | 채권 낱건 — 가맹점·플랫폼·선정산일·정산예정일·`Dᵢ`·순지급액 |
| L2 | 낱건 파생 — `Aᵢ` · 채권매입수수료ᵢ · `Lᵢ` · `Mᵢ` · `Bᵢ` |
| L3 | 하루 — `A(d−1)` · `M(d−1)` · `wD(d−1)` |
| L4 | 기간 — `PA` · `PM` · `PwD` · `PMR` |
| L5 | 화면 칸 — 3.99% · 2.24% · 3.04일 · 13.21% |

「이 값이 저 값으로 간다」가 실제 숫자로 적힌 자리.

| 이음매 | `calc` · `final_terms` | `termsdoc` · `용어정의서` | `steps_all` |
|---|---|---|---|
| L0 → L1 | 없음 | 없음 | 없음 |
| L1 → L2 | 산식만 | 산식만 | 산식만 |
| L2 → L3 | 산식만 (`A(d-1) = Σ Aᵢ (i ∈ d−1)`) | 산식만 | 모집단 수까지 (하루 320건 · `Σ 순지급액 180,169,120원`) |
| L3 → L4 | 산식만 (「7일치를 더한다」) | 없음 | **값 전량** (`08-21 25,941,773` … `08-27 26,521,983` 7개 · `M(d−1)` 7개 · `wD(d−1)` 7개) |
| L4 → L5 | **값 있음** (①~⑤ 다섯 줄) | 항목 45개 분산 · 이음 문장 없음 | **값 있음** (6단계 · 중간값 포함) |
| 가맹점 축 ↔ 기간 축 | 없음 | 없음 | **없음** — 가맹점별 표는 미회수 잔량(280건/7,720건) 기준, 기간 표는 흐름(320건/일) 기준. 두 축이 만나는 칸이 0개 |

가장 크게 벌어진 이음매는 L3 → L4 다. `steps_all.json` 만 7일치 값을 전부 적고, 나머지 넷은 「7일치를 더한다」 한 줄로 넘어간다.

두 번째는 기호 계열 갈림이다. 같은 값에 두 이름이 붙어 있어 문서를 옮겨 타면 이어짐이 끊긴다.

| 기간 투자수익 | `PSM` | `PM` | `PSM` |

## 6. (마) 설명 문장이 뜻을 나르는가

`termsdoc_seed.json` 은 필드로 갈라 놓았다. `plain` 이 「무엇인가」, `note` 가 「어떻게 정했나」다.

| 필드 | 보기 | 갈래 |
|---|---|---|
| 5항 `plain` | 「채권 한 건을 투자자가 산 값이다. 그 채권의 순지급액에서 할인율만큼 깎은 금액이다」 | 무엇인가 |
| 5항 `note` | 「…3차 미팅에서 대표가 직접 정정했다」 | 어떻게 정했나 |
| 4항 `note` | 「3차 미팅에서 대표가 같은 값을 금액 구성비라 말해 원천이 갈린다. 어느 쪽 값도 새로 채택하지 않았다」 | 어떻게 정했나 |
| 6항 `note` | 「4차 미팅에서 대표 확인을 받는다」 | 어떻게 정했나 |

`용어정의서_20260901.docx` 는 `note` 를 싣지 않는다. 경위 낱말 실측 — `확정했`·`정정했`·`회의에서`·`미팅에서`·`대표 DM`·`재확인`·`채택하지` 전부 0곳, `미확정` 4곳뿐이다. 갈래가 지켜졌다.

`final_terms.json` `vars[].plain` 30항 가운데 「우리가 어떻게 정했나」로 새는 자리 셋.

| 항 | 문장 | 무엇이 문제인가 |
|---|---|---|
| `Yr` | 「분모는 소수 둘째 자리로 끊은 `wD` 를 쓴다 — 화면 두 칸(3.04 · 13.21%)이 서로 되짚어지게 하기 위해서다」 | 값의 뜻이 아니라 표기 결정 이유 |
| `B(d-1)` | 「정의대로 `Σ(순지급액ᵢ − max(0, Lᵢ))` 로 내면 하루 −12 ~ +13원 갈리는데… 화면은 A + M 을 쓴다」 | 정의 대신 두 산식의 갈림 서술 |
| `채권매입수수료ᵢ` | 「기존 운영 어드민에서 쓰던 용어라 따로 영문 기호를 두지 않는다」 | 기호 배정 사유 |

문장 자체가 깨진 자리 하나.

| 자리 | 실제 문자열 |
|---|---|
| `final_terms.json` `vars[]` `투자자산` 의 `plain` · `final_terms.fragment.html` · 배포 `final-terms.html` · `용어기호정리.docx` | `채권과 현금을 합친 것. 화면 「합계」 행이다. 두 항뿐이라` |

「두 항뿐이라」에서 문장이 끊긴다. 네 산출물에 그대로 실렸다.

마크다운이 그대로 새어 나온 자리.

| 자리 | 곳수 | 실제 문자열 |

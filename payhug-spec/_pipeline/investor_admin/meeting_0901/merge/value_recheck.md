### 뿌리 ① `wD` 의 모집단 — 갈림이 가장 크다

### 뿌리 ⑤ 낱개 `Mᵢ` 의 재료가 정의돼 있지 않다

`Mᵢ = 채권매입수수료ᵢ − max(0, Lᵢ)` 인데 `vars` 29항에 **`채권매입수수료ᵢ` 항이 0건**(E6).

상환액 두 길의 진단 폭 「−5 ~ +7원」은 실측 「−12 ~ +13원」보다 좁다.

## 판별력 시험

원고 사본 하나를 한 자리씩 틀리게 만들어 자식 프로세스로 돌렸다. 실물은 건드리지 않는다.

| 변조 | 기대 FAIL | 결과 종료코드 | 새로 난 FAIL |
|---|---|---|---|
| `calc` PA 179,970,919 → 179,970,918 | B2 | 1 | `B2` |
| `calc` ③ 3.991318% → 3.991319% | B7 | 1 | `B7` `C4` |
| 검산 연환산 7,183,211 → 7,183,212 | D1 | 1 | `D1` `D5` |
| `vars` `Aᵢ = … × (1 − r)` → `(1 + r)` | E1 | 1 | `E1` |
| `vars` `LR` 에서 표본 구간 `d−20 ~ d−11` 삭제 | G9 | 1 | `G9` |

5건 전건 잡힘. 무변조 사본은 판정 81건 · FAIL 18건(화면 검사 제외분)으로 실물과 같은 집합.
실물 원고 md5 `8992dcbab5db70f94a9f3ff24a342c08` — 검사 전후 동일, 손대지 않았다.

새는 네 갈래 차단.

| 갈래 | 막은 자리 |
|---|---|
| FAIL 찍고 exit 0 | `main()` 끝 `sys.exit(1 if fails else 0)` |
| try-catch 가 SKIP | `section()` 이 예외를 구획 FAIL 로 기록 (`*.EXC`) |
| 판정 없이 값만 출력 | 출력은 전부 `chk()` 를 거친다 — 판정 없는 칸 0개 |
| 대상 0건이면 통과 | 루프마다 「대상 0건 아님」 판정 (A0 A0b E0 G11 I3 I12 I18) · `R` 이 비면 종료코드 1 |

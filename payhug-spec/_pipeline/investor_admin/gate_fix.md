## §4 아카이브 링크 — G-7

### 4-1. 원인 실측

| 대상 | 실측 | 판정 |
|---|---|---|
| `localhost:8901` (레포) | `LISTEN` 중, `curl` 200 | 정상 |
| `localhost:8902` (파이프라인) | `lsof` 프로세스 **없음**, `curl` 000 | **서버 미가동** |
| `build_archive.py` 경로 생성 | `PIPE = /Users/…/_pipeline/investor_admin` · `rel` = 파일명 그대로 | **경로 어긋남 없음** |
| 파일 이동 | 등재 파일 전건 디스크 실재 | **이동 없음** |

서버를 다시 띄우자(`nohup python3 -m http.server 8902 --directory …`) 64건이 즉시 200으로 돌아왔다. 원인은 **서버 미가동 단독**이고, 경로 오류·파일 이동은 없었다.

### 4-2. 서버 없이도 열리게 바꾼 부분

원인이 서버 의존이므로 의존 자체를 줄였다. 레포 파일은 `archive.html`과 같은 디렉터리에 있으므로 절대 URL을 쓸 이유가 없다.

| 구분 | 이전 | 현행 |
|---|---|---|
| 레포 파일 73건 | `http://localhost:8901/index.html` | `index.html` (상대 경로) |
| 파이프라인 69건 | `http://localhost:8902/…` | 그대로 — 레포 밖이라 서버가 필요하다 |

상대 경로 전환으로 레포 링크는 **서버 없이도, push 후 Pages에서도** 열린다. 안내문도 고쳤다 — `서버 2개가 떠 있어야` → 상대 경로 안내 + 파이프라인용 서버 실행 명령 전문.

`build_archive.py`의 `rows()`에 빈 base 처리를 넣어(`(base+"/" if base else "")`) 상대 경로가 루트 절대경로(`/index.html`)로 굳지 않게 했다.

### 4-3. 링크 전건 실측

| 구분 | 링크 | 200 | 실패 |
|---|---|---|---|
| 상대 경로(레포) | 73 | 73 | **0** |
| `localhost:8902`(파이프라인) | 69 | 69 | **0** |
| **합계** | **142** | **142** | **0** |

상대 경로는 파일 실재(`os.path.exists`)와 HTTP 200 양쪽으로 확인했다.

### 4-4. 설명 최신화

2"정산 차액·잔차는 어디서 나온 건가" — 전수 증명

물어보신 대로 정책서에 쓰인 말 전부를 코드와 대조해 출처를 밝혔습니다. 검증 방법은 화면에 실제로 출력되는 문자열인지(코드의 UI 리터럴 검색), 코드 안에만 있는지, 기존 스펙 문서에 정의된 것인지, 아니면 제가 설명을 위해 만든 말인지 네 갈래로 나누는 것입니다.

분류뜻개수조치
화면 표기화면·엑셀·툴팁에 그 문구 그대로 나옴 (근거: 파일·줄 번호 병기)84그대로 사용
코드 내부로직에는 있으나 화면에 안 나옴 — 우리가 한글로 옮긴 말8용어장에 출처 표기
스펙 문서기존 정책 문서(6대 개념 등)에 이미 정의된 용어10정의 일치 확인
작성 정의제가 설명을 묶으려고 만든 말 — 근거 없는 신조어11전부 화면 문구로 치환
'잔차'는 제가 만든 말인가요?
아닙니다. 선정산 제외액 카드의 보조 문구로 화면에 실제 출력됩니다("바로이체 외 잔차 포함"). 코드 근거까지 용어장에 적었습니다.
'정산 차액'은요?
정책서에는 없던 용어였습니다. 화면에 있는 '정산차액'은 플랫폼 조정 항목 중 하나로 전혀 다른 개념이라, 용어장에 구분 행을 만들어 우리 문서의 '차액' 4용어와 섞이지 않게 했습니다.
그럼 만들어낸 말은 있었나요?
있었습니다 — 11개. '장부'(→원장), '출금전용계좌'(→락계좌), '광고비 보전'(→광고비) 등으로, 전부 실제 화면 문구로 바꿨습니다(문서 81곳).

38/15 회의 결정이 문서에 들어간 모습

전사 기록을 정독해 결정과 미결을 갈랐습니다. 결정된 것만 본문에 확정 서술로 넣고, 개발이 아직 안 된 것은 상태를 함께 적었으며, 회의에서 결론이 안 난 것은 빨강 "확인필요"로 남겼습니다.

회의 결정문서 반영
선정산 시작일 이전 거래는 플랫폼 차감·환급을 지급액에 가감하지 않음[선정산 결과]·[차액 정산] 정책 절에 확정 서술 + 지급 흐름도에 분기 신설(시작일 이전이면 제외 경로)
'조정 금액'은 어드민·가맹점 모두 비노출화면 기준 절에 명시 — 혼란 방지 목적까지 함께 기술
이미지급 = 기록용 수동 이체 → 바로이체의 일종, 선정산 제외에 포함용어장·선정산 결과·미정산 누락에 반영, 흐름도 노드를 "바로이체—기록형"으로 재정의. 가맹점엔 실제 이체일 기준 노출
회수 기능 도입 후 임의 지급 버튼 제거, 태그는 영구 유지회수 3갈래 절에 방향으로 기술 + 흐름도에 점선 노드(도입 예정)로 표기
배민·쿠팡이츠 제외 건 가맹점 리스트 연동, 리스트=지급일 / 툴팁=거래일화면 기준 절에 기준 축 구분 명시. 프론트 미반영 상태라 "결정 — 반영 전·티켓"으로 병기

4흩어진 내용을 6개 클러스터로 묶었습니다

"엮인 것끼리 묶어서 설명해 달라"는 요청에 맞춰, 장을 주제별로 재배치하고 각 묶음 위에 헤더 밴드를 두어 무엇을 다루는 묶음인지 먼저 읽히게 했습니다. 관련 화면·흐름도·슬라이드도 소속 클러스터 안으로 옮겼습니다.

A · 개념·용어

용어장 4장 + 비교 슬라이드 2장('차액' 네 용어 / '회수' 세 갈래) — 뒤의 모든 장이 참조하는 정의를 앞에 둠

B · 실행·결과

선정산 결과 4장 + 미정산 누락 2장 + 지급 흐름도 + 관련 화면 — 돈이 나가는 과정

C · 차액 계열

차액 정산 3장 + 차액 정산 내역 3장 — 예상과 실제의 차이를 다루는 묶음

D · 배분·원장

정산 상세 4장 + 수수료 원장 4장 + 계산서 발행 2장 + 배분 흐름도 — 참여자에게 나누는 과정

E · 이체·대사

이체 내역·VOC 3장 + 관련 화면 — 실제 이체됐는지 맞춰보는 과정

5화면 첨삭 — 어느 화면의 어떤 기능인지

문서 옆에 실제 화면을 붙이고, 각 화면에 메뉴 경로·탭과 기능 한 줄을 담은 라벨 카드를 달았습니다. 화면 안 관련 영역은 빨간 박스로 표시하고, 아래 꺾쇠로 "이 화면이 설명하는 절 번호"를 가리킵니다. 이번에 화면 7장을 새로 추출해 총 13장이 됐습니다.

용어 치환 누락11본문은 '원장'인데 옆 슬라이드·흐름도는 '장부' — 같은 지면에서 신·구 용어 병존
겹침·형식2+화살표가 주석을 관통, 점선 표기 미적용
원인은 조판이 아니라 제 지시서였습니다. 23건 중 14건은 제가 재조판 지시를 A4 본문에만 내리고, 같은 지면의 슬라이드·흐름도·꺾쇠에는 용어 치환과 절 번호 갱신을 지시하지 않아서 생겼습니다. 조판은 지시받은 것만 했고, 지시 없는 문구는 구판 그대로 남았습니다. 그래서 결과물만 고치지 않고 원고 18곳과 규격서를 먼저 고쳤습니다 — 규격서에 "본문을 고치면 주변 자산도 같은 기준으로 동기화한다"는 규칙(§3.10)을 신설해 다음 라운드에 재발하지 않게 했습니다.
검수 범위의 사각지대도 드러났습니다. 1차 검수와 조판 자가점검이 둘 다 흐름도 2장 중 '선정산 지급 흐름'만 겹침 검사 대상으로 삼는 바람에, '수수료 배분 흐름'의 화살표-주석 관통과 색 구분자 누락이 두 라운드 연속 누락돼 있었습니다. 이번에 범위를 넓혀 잡아냈고, 검수 규격에 "벡터·프레임 전 범위"를 명시했습니다.

최종 상태 — 원 결함 23건 전건 해소

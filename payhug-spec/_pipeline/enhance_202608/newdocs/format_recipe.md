## 3. 콘텐츠 서술 패턴 (섹션 순서·문체)

### A4 정책 문서
1. `[대주제]` — 예: `[기본 정책]`, `[회수 정책]`. 한 프레임 = 한 대주제(길면 프레임 추가, 같은 제목 반복).
2. 번호 섹션(1. 2. 3.) — 예: 용어 정리 → 데이터 수집 기준 → 수수료 / 선정산 → 미수금·환급금.
3. 섹션 아래 소주제 블록들: **1행 = 소주제(용어·기능명), 이하 불릿 = 정의→조건→케이스**. 문체는 철저한 개조식(명사형 종결, "~한다" 최소).
4. 케이스 열거 규칙: `case1) …` 넘버링, 부호 분기는 `[-] 음수인 경우 : … 처리` / `[+] 양수인 경우 : …` 페어.
5. **빨간색(#FF3B30) = 미확정·개발필요·주의** (예: "(예상지급차액으로 표현)", "파트너 정산금 차감 로직은 정책 및 개발 필요").
6. 표는 네이티브가 아니라 **이미지 붙여넣기**, 증빙 스크린샷은 프레임 밖 캔버스에.
7. 우하단 날짜 = 정책 기준일.

### A4 사례 문서 (정산대사 검증 로그)
`[조회 정보]`(가맹점·지급일·수수료) → `[정산대사]` 채널별 1~6단계(각 단계에 **데이터 출처 명기**: "(매출조회 엑셀 추출)", "(가맹점관리-락계좌입금내역 엑셀 추출)") → `[결과]` 일치/미회수금+원인. 금액은 `= 300,861원` 형태로 등호 표기.

### 슬라이드
`[채널] 정산 대사` 제목 + 3단 비교(페이허그 내부 데이터 ‖ 외부기관 ‖ 계좌 실입금) + 하단 `매핑 기준 : …` 1줄. 빨강 = 대사 키 필드.

### 블록 1 — A4 정책 프레임 (신규 생성, clone 불가 사유는 §2)
```
frame = figma.createFrame(); frame.resize(595,842);
frame.name = '26.08.12 [정산 정책]'; frame.fills=[{type:'SOLID',color:{r:1,g:1,b:1}}];
```
1. 제목: createText → Noto Sans KR **Black 18px** #000 → `'[정산 정책]'` → x=24,y=31
2. 섹션 헤더: Black **14px**, x=24. **번호는 문자로 직접 `'1. 용어 정리'`** (참조 원본은 ORDERED 리스트 자동번호를 쓰지만 API로 시작번호 제어 불가 → 리터럴 번호가 안전. 접두 "N. "까지 포함해도 시각 드리프트 없음)
3. 본문 블록: 소주제당 텍스트 1개, x=39, Noto Sans KR **Bold 10px**, lineHeight AUTO, letterSpacing 0. 전체 줄을 `\n`으로 잇고:
   ```
   t.setRangeListOptions(0, len, {type:'UNORDERED'});
   t.setRangeIndentation(s, e, level); // 1행=1, 하위=2~4
   t.setRangeFills(rs, re, [{type:'SOLID',color:{r:1,g:0.23,b:0.19}}]); // #FF3B30 강조
   ```
   세로 리듬: 블록 간 12px, 섹션 전환 24px. 본문 1줄 ≈ 12px(10px auto).
4. 날짜: Black 18px `'26.08.12'` → x=503,y=796 (혹은 우하단 24px 마진 기준 재계산)
5. 표가 필요하면: 참조처럼 이미지 붙여넣기 or 10px 텍스트 정렬로 대체(신규는 텍스트 표 권장)

## 1. 판형 · 페이지 구조 · 명명 규칙

- **A4 595×842 (72dpi), fill #FFFFFF, auto-layout 없음(절대배치)** — 총 15장.
  - 정책 문서 4장: `5:17`·`5:33`·`5:48`·`5:55`, 이름 = **`YY.MM.DD [제목]`** ("26.07.18 [기본 정책]", "26.07.18 [회수정책]" ×3). 같은 제목 반복으로 다장 구성. 우하단 날짜 스탬프 있음.
  - 계산식 문서 11장(섹션 `22:208` "계산식 모음" 내부): 이름 = **주제명** ("계산식", "일반계산식(1-1)", "일반계산식(1-2)", "일반계산식(1-3)", "다우계산식(2-1)", "다우계산식(2-2)", "자금조달 이자정산식", "스크래핑 실패시", "선정산 계산식"). **날짜 스탬프 없음**. 가로 병치 피치 635px.
- 섹션 `22:208`: SECTION, fill **#444444**, 7841×1551 — A4 11장을 담는 그룹핑 컨테이너 (기존 타깃 페이지의 "정산 수식" 섹션과 동일 색).
- 화이트보드 판: RECTANGLE **#D9D9D9, 5991×2501** 2장(`22:261` 소수점/마감 정책, `22:260` 수수료 흐름). 판 위에 50px 텍스트·스크린샷을 자유 배치.
- 페이지 배경 **#1E1E1E** → 흰 A4·회색 보드가 대비. 프레임 밖 메모는 흰색 텍스트.

### A4 정책 문서 내부 앵커 (recipe1과 동일 확인)
- `[제목]` (24,31) 18px ExtraBold / 섹션 헤더 x=24 14px ExtraBold / 본문 x=39 10px Bold / 날짜 (503,796) 18px ExtraBold.
- 섹션 헤더 번호("1. 2. 3.")는 **ORDERED 리스트 + 타이핑 시작번호**(별개 텍스트 노드인데 `5:57`이 "3."으로 렌더 = 에디터에서 "3. " 타이핑해 시작번호 지정). API로 시작번호 제어 불가 → **재현 시 리터럴 "3. " 문자로**.
- paragraphSpacing/listSpacing/paragraphIndent 전부 0 — 블록 간격은 텍스트 노드 분리 + y 배치(블록 간 12px, 섹션 전환 24px)로만.
- 2단 배치 예: `5:24`(x=39) ‖ `5:25`(x=244) 동일 y=621.

### A4 계산식 문서 내부 앵커 (신규 패턴)
- 제목: **(40,40~49), Noto Sans KR Medium 14px**, 1~2줄("정산 1-1 : 일반 계산식\n건당 채권 매입 수수료만 반영, …" — 1행 제목 + 2행 전제조건).
- `[대괄호 소제목]`: x=40, Noto Sans KR Medium 14px — "[이자 계산 방식]" "[카드]" "[배달 3사]" 등.
- 본문: Noto Sans KR Medium 14px, Figma 리스트(ORDERED@ind1 + UNORDERED@ind2)로 계층.
- **2단 배치**: `22:234` "[이자 정산 처리 방법]" x=40 ‖ `22:235` "[어드민 기능]" x=322, 동일 y=374 (`22:231` 내).

## 2. 콘텐츠 패턴 (구획·문체·케이스·미확정 표기)

- 구획 순서(정책 A4): `[대주제]` → 번호 섹션(용어 정리 → 데이터 수집 기준 → 수수료 / 선정산 → 미수금·환급금 → 회수 기준) → 소주제 블록(1행 소주제, 이하 불릿 정의→조건→케이스).
- 문체: 철저한 **개조식 명사형 종결**. 정의는 `용어 = 산식/설명` 등호 문장으로 직접 기술 (`선정산 금액 = 카드/배달 매출액(전일 승인내역) - 카드/배달 예상 수수료 = 순지급액 +- 예상 지급 차액`).
- 케이스: `case1) 승인O, 매입O : …` 넘버링, 부호 분기 `[-] 음수인 경우 : … 차감 처리` / `[+] 양수인 경우 : … 지급 처리` 페어, 조건은 `승인O/매입X` 같은 O/X 축약.
- 상태 태그: `(이슈)` `(ASIS …)` `(TO BE해결방안)` `(진행)` `(미정)` `(개발확인필요)` `(어드민보고 추가예정)` — 소제목 뒤 괄호로 진행상태를 박음.
- **빨강 #FF3B30 = 미확정·개발필요·주의** (인라인 부분 색: "당일", "(예상지급차액으로 표현)", "파트너 정산금 차감 로직은 정책 및 개발 필요").
- **파랑 #007AFF = 상대방·핵심 요율 강조 + 화면 지시 주석** (화이트보드에서 "투자자 0.11% 매각" 인라인 파랑, "< 1. [전체] 금액 : …" 캡처 지시선 텍스트).
- 프레임 밖 흰색 10px 메모(`18:204` "현재 하고 이미지급이란?…", `19:205` 승인취소/매입취소 분기, `19:207` 수수료 노출 원칙): A4에 넣기 전 단계의 **회의 메모**를 해당 프레임 옆에 클러스터로 둠. 대형 목차 브레인스토밍은 Inter Regular 150px 흰색(`7:202`).

## 3. 계산식 표현법 — 3가지 모드 (전부 재현 가능 수준)

**모드 A. 텍스트 산식 (기본)** — 피그마 도형 없음. 수식은 `=` `*` `-` `/` 문자로 한 줄:
- `대출금 * 연 12% * (사용일수)/365` (`22:238`), `순지급액 = 승인금액 - (승인금액X카드사예상수수료율)` (`22:255`), `SUM (당일 순지급액 * 연 12% * 1/365)`.
- 구조: `[소제목]` 14px → ORDERED 리스트로 방식명(양일산입/초일불산입/…) → UNORDERED ind2로 산식 1줄. 항 정의가 이어질 땐 `예상승인금액 = 최근 3주간 (해당 요일과 같은) 요일별 평균 승인금액` 식으로 등호 체인.

**모드 B. 수치 예시 = 시트 캡처** — 주체별 금액 배분표(정산 1-1~2-2)는 네이티브 표를 그리지 않고 **스프레드시트 스크린샷 IMAGE 사각형**을 A4 안에 붙임:
- `22:215` (26,105) 544×550 IMAGE(CROP). 공통: **x=26, w=544** (좌우 26px 마진), y=100~105 제목 바로 아래. 제목 텍스트에 시나리오 전제("가맹점 원본 결제 대금 20,000원 기준…")를 기술.

**모드 C. 화이트보드 (협의·전개용)** — #D9D9D9 판(5991×2501) 위에 **Apple SD Gothic Neo Bold 50px 검정** 텍스트:
- 산식 한 줄: `22:287` "순지급액(매출액-예상수수료) - 선정산 제외액(바로이체) = 선정산 대상액(세금계산서발행기준) * 1% = 채권매입 수수료" (8138,2320) w=2324.
- AS IS / TO BE 블록: 헤더 ind0 + UNORDERED ind1~2 (`22:288`, `22:289`).
- 수수료 흐름(22:260 판): 화살표는 **도형이 아니라 `→` 문자**. 행 패턴 = `[면세]A → B 0.25% 매각 (매출원가)` + 하위 불릿 `B 수익 …% (매출액)`. 상대방+요율만 인라인 파랑 #007AFF. 벡터·커넥터 노드 0개 — 전부 텍스트.
- 좌 "수익 흐름" 나열 ‖ 우 "계약관계" 요약 리스트 2단 병치 (x=8247 ‖ x=11454).

## 4. 화면(스크린샷) 삽입법 — 4가지 패턴

1. **A4 내부 병치(본문 옆 미니 표)**: `5:46` "image 408" 112×151 IMAGE, (395,500) — case 리스트 오른쪽에 실제 환급명 표 캡처를 세로로 붙임. 캡션 없음(본문 case3이 캡션 역할).
2. **A4 내부 메인(제목 아래 풀폭)**: 모드 B — x=26, w=544, 제목 아래 y≈100.
3. **캔버스 자유 배치 + 빨간 하이라이트 박스**: 참고 문서·어드민 캡처(459×594 등)를 프레임 밖 주제별 클러스터로. 강조는 **RECTANGLE 358×29(1줄)/358×70(여러 줄), fill #D9D9D9 opacity 0%, stroke #FF0000 2px** (`5:74`~`5:76`)를 캡처 위에 겹침. 마커 번호·화살표 도형 없음.
4. **화이트보드 위 캡처 + 텍스트 오버레이 주석**: 어드민 캡처(`22:263` 1266×1844, `22:296` 1941×1606)를 판 위에 놓고
   - 옆에 **`< 1. …` 꺾쇠 접두 50px 텍스트**로 지시(파랑 `22:290`=변경 지시, 검정 `22:293`=현상 설명, 캡처 오른쪽 x=11685 세로 나열),
   - 입력 필드 위엔 **검정 50px 숫자 텍스트를 직접 겹쳐**(요율 0.11/0.25/0.5/1/0.4/0.3/300, `22:297`~`22:308`) 기입값을 표기. 캡처 위 제목 메모(`22:306` "매출액기준으로 넣었다").
   - 다크 캡처 박스(`22:309` 1909×501)로 ASIS/TOBE 서술문 인용.

캡션 규칙: 별도 캡션 요소 없음 — 캡처 "옆 텍스트"가 캡션·주석·지시를 겸함.

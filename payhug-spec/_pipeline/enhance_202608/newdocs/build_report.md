## 제작 노하우 (레시피 추가분)

- **TextNode.resize()는 textAutoResize를 NONE으로 되돌린다** — `resize(w,h)` 후 `textAutoResize='HEIGHT'` 순서로 설정해야 자동 높이가 산다.
- 같은 실행(호출) 안에서는 리스트/리사이즈 후 `node.height`가 갱신되지 않음(stale) → **다음 호출에서 실측 높이로 재배치하는 2-pass 파이프라인**(프레임 N 재배치 + 프레임 N+1 생성 병행)으로 해결.

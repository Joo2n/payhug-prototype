### 2.2 하나의 정책 항목이 서술되는 순서 (핵심 패턴)
1. **정의** — `용어 = 산식/설명` 등호 문장 (예: 미리 받는 돈 = 선정산 금액)
2. **대상 / 미대상** — 포함 조건 먼저, 제외 조건 다음. 각각 불릿 1레벨 소제목 + 2레벨 조건문
3. **조건·수치** — 시각(11시30분, 18시), 주기(9시·10시·16시·21시), 기한(D+5 영업일)을 본문 안에 그대로 박음
4. **케이스 분기** — `case1) 조건 : 처리` 넘버링, 금액 부호는 `[-] 음수인 경우 / [+] 양수인 경우` 페어
5. **예외 사항** — `(이슈)` → `(ASIS …)` → `(TO BE해결방안)` 순으로 전개, 진행 상태 `(진행)`/`(미정)` 태그
6. **화면 UI 기준** — 같은 페이지 안에서 "화면 UI에는 안내성 문구로 노출" 식으로 노출 원칙까지 마무리
7. (문서 말미) **확인 질문** — "1. …고 있는지 : 현황" 형태의 개발 확인 리스트

### 2.3 표/리스트/문단 비율, ID·넘버링 체계
- **불릿 리스트 ≈ 95%** (정책 4장 텍스트 36블록 전원 리스트), **산문 문장 1줄**(5:35 미수금/환급금 정의 한 문장), **네이티브 표 0개** — 표가 필요하면 전부 **이미지 캡처**(자체환급명 표, 스프레드시트, 어드민 화면)로 붙임.
- 항목 ID 체계 없음 (PH-001 같은 코드 없음). 넘버링 어휘는 5종뿐:
  - 절: `1.` `2.` `3.` (ORDERED 리스트, 장 넘어 연속)
  - 케이스: `case1)` ~ `case7)` / `(case1)` `(case2)`
  - 부호: `[-]` / `[+]`
  - 카테고리: `[카드]` `[배달]` `[스크래핑 수집 오류]` (1레벨 불릿에 대괄호)
  - 절차: `→` 문자 ("별로 알림 → 파트너에게 환매 통지 → 익월 파트너 정산 금액에서 차감")
- 들여쓰기 계층은 **최대 4단**(불릿 ind1~3 + case 하위). 위계는 굵기 변화 없이(전부 Bold) 들여쓰기로만 표현.

### 3.1 어미·톤
- 기본은 **개조식 명사형 종결**: "~한 매출", "~인 경우", "~ 부과", "~ 처리", "~ 표시".
- 규칙 선언에만 서술형 허용: "**차감한다**"(5:59), "**적용된다**"(22:255), "~**함**/안함"("진행 안함", "이미지급으로 처리함", "반영함"), "~**됨/짐**"("업데이트됨", "정해짐").
- 가맹점 노출 문구를 인용할 때만 존댓말: "(승인일(=거래일) D+5 영업일 후 선정산 금액에서 **차감돼요**)", "(상세 내용은 여신협회에서 **확인해주세요**)".
- 구어체 러프함 일부 허용(원문 그대로): "그냥 모든 금액을 보낼 수 있으므로 기능", "돈만 들어온 경우".

### 3.2 용어 수준
- **순한글 운영 용어가 원칙.** 영문은 딱 4종류만 등장: 외부 시스템 고유명(`쿠콘 API`, `Settle AMT`, `AI`), 조건 축약(`승인O, 매입X`), 기한(`D+5 영업일`), 세무(`VAT별도`, `ASIS/TO BE`, `On`, `CS`, `UI`, `DB`).
- **DB 필드명·상수·커밋 해시 0건.** 괄호 병기는 한글 동의어 연결에 씀: "이체 수수료(=전산 수수료)", "승인일(=거래일)", "출금전용계좌(락계좌)", "입금예정금액((Settle AMT))".

- 색 2개가 전부: **검정 #000000 (본문 전체 Bold)** + **빨강 #FF3B30 = 미확정·개발필요·주의** 인라인 부분 색.

## 4. 계산식 통합 방식

**산식은 별도 박스·도형 없이 "본문 리스트의 한 줄 텍스트"다. 항 이름은 전부 한글이고, 등호 체인으로 정의를 잇는다.**

- **위치 3곳**:
  1. **용어 정리 절 안** — 용어 정의 자체가 산식 (예시 3번 문장). 정책 본문과 완전 통합.
  2. **정책 절 마지막 블록** — "예상정산액 계산식 (개발에 적용된 내용 확인하기)" 소제목 → 카드/배달앱 하위 불릿으로 산식 2줄씩 (5:62).
  3. **전용 계산식 장** (계산식 모음 섹션, Noto Sans KR Medium 14) — 제목(주제+전제조건 2줄) → `[대괄호 소제목]` → 번호 리스트(방식명) → 하위 불릿 산식 1줄 (`대출금 * 연 12% * (사용일수)/365`).
- **모양**: `=` `-` `*` `/` `X` `SUM()` 문자만. 분수·첨자·수식 렌더링 없음. 단위·조건은 산식 안 괄호로: `(승인금액X카드사예상수수료율)`.
- **예시 수치**: 본문 산식에는 안 씀. 수치 예시가 필요하면 **스프레드시트 캡처 이미지**를 계산식 장 제목 아래(x=26, w=544)에 붙이고, 제목에 전제를 문장으로 박음("가맹점 원본 결제 대금 20,000원 기준 하위와 상위 파트너에게 시스템 이용료(0.1%) 반영").
- 산식의 미확정 캐비엇도 인라인 빨강: "(개발에 적용된 내용 확인하기)".

## 5. 화면 통합 방식

**별도 캡션 요소 없음 — 캡처 '옆 본문'이 캡션을 겸한다.** 4패턴:

1. **A4 안 본문 옆 미니 캡처**: `5:46` 자체환급명 표 캡처 112×151을 case3 리스트 오른쪽(395,500)에 세로 배치. 본문 case 문장이 곧 설명. ← *문서 흐름 속 화면 통합의 정답 사례*
2. **A4 안 제목 아래 풀폭 캡처**: 계산식 장의 시트 캡처 x=26, w=544, y≈100~105 (좌우 26px 마진).
3. **프레임 밖 주제 클러스터 + 빨간 박스**: 참고 문서·화면 캡처(459×594 등)를 해당 A4 옆에 모으고, 근거 위치에 **투명 fill + #FF0000 2px 스트로크 사각형**(358×29 한 줄 / 358×70 여러 줄)을 겹침. 화살표·번호 마커 도형 없음.
4. **대형 캡처 + 꺾쇠 지시 텍스트**: 어드민 풀페이지 캡처(1266×1844) 오른쪽에 `< 1. [전체] 금액 : 소수점 여섯짜리로 수정 - …` 식 **`< N.` 접두 텍스트**를 해당 y좌표에 나열(파랑=변경 지시, 검정=현상 설명). 입력 필드 위엔 숫자 텍스트를 직접 겹쳐 기입값 표시.

## 7. 재작성 지침 10계명

1. **A4 1장 = 대주제 1개로 쪼개라.** 595×842 흰 프레임, `[대괄호 제목]`, 우하단 날짜, 레이어명 `YY.MM.DD [제목]`. 표지·목차 없이 본문부터 시작하라. 넘치면 같은 제목으로 다음 장, 절 번호는 이어서 매겨라.
2. **영문 개발 용어를 전량 한글 운영 용어로 번역하라.** 필드명(preSettlementTargetAmt)·상수(DIRECT_PAYOUT)·커밋 해시·코드 경로는 한 글자도 노출 금지. 허용 영문은 외부 시스템 고유명(쿠콘 API, Settle AMT)·`승인O/매입X`·`D+5 영업일`·`VAT`·`ASIS/TO BE`뿐이다. 동의어는 "이체 수수료(=전산 수수료)"처럼 괄호 등호로 병기하라.
3. **정책 그 자체를 서술하라 — 검토 규칙을 서술하지 말라.** "통합 금지", "혼용 금지", "값 단정 금지", "C1/C2/C4", "07 등재 후보" 같은 레지스터·메타 문장을 본문에서 제거하고, 그 자리에 서비스가 실제로 하는 일(대상·시각·조건·처리)을 넣어라.
4. **항목 서술 순서를 고정하라**: 용어 정의(등호) → 대상/미대상 → 조건·수치(시각은 "11시30분, 18시"처럼 본문에 직접) → `case n) 조건 : 처리` → 예외 사항((이슈)→(ASIS)→(TO BE해결방안)) → 화면 UI 기준 → (말미) 확인 질문 리스트.
5. **개조식 명사형 불릿만 써라.** 규칙 선언만 "~한다", 현황 보고만 "~함/됨", 가맹점 노출 문구 인용만 "~돼요/해주세요". 산문 문단은 정의 1줄 외 금지. 표가 필요하면 네이티브 표 대신 캡처 이미지를 붙여라.
6. **미확정은 빨강 #FF3B30 인라인 + 상태 태그로만 표기하라.** `(미정)` `(진행)` `(개발확인필요)` `(검토 대상)`. 각주·별표·별도 미주 섹션을 만들지 말라. 확정 문장은 전부 검정이다.
7. **계산식은 본문 리스트의 한 줄로 녹여라.** 한글 항 이름 + `=` `-` `*` `/` 문자 등호 체인("순지급액 = 승인금액 - (승인금액X카드사예상수수료율)"). 항 정의가 이어지면 다음 줄에 또 등호 문장. 수치 예시는 본문이 아니라 시트 캡처(x=26, w=544)로 제목 아래 붙이고 전제는 제목 문장에 써라.
8. **화면은 해당 정책 블록 곁에 놓아라.** 작은 표·화면은 A4 안 본문 오른쪽(캡션 없이 본문이 설명), 큰 화면은 프레임 밖 해당 장 옆 클러스터 + 투명 fill·#FF0000 2px 스트로크 박스로 근거 영역 표시, 지시는 `< N. …` 꺾쇠 텍스트로. 화면 전용 장을 문서 뒤에 몰아넣지 말라.
9. **타이포는 3단뿐**: 제목·날짜 18 / 절 14 / 본문 10, 전부 볼드 계열, 위계는 들여쓰기(최대 4단)로. 신규 생성 시 Noto Sans KR Black/Bold를 쓰고(Apple SD Gothic Neo 로드 불가), 계산식 장은 이 파일 22:231/243/251을 clone+retext 하라.
10. **케이스·부호·절차 표기를 통일하라**: 분기는 `case1) 조건 : 처리`, 금액 부호는 `[-] 음수인 경우 / [+] 양수인 경우` 페어 완결, 절차 흐름은 `→` 문자, 카테고리는 `[카드]` `[배달]` 대괄호. 마커·화살표 도형은 그리지 말라.

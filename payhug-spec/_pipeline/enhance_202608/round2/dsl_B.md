EQ: 이체 수수료 표기 단가 = 공급가 ÷ 이체 횟수
EX) 2,700 ÷ 9회 = 300원 → "300원×9회" 표기(정수 아니면 "정액")

## 5. 화면 기준
- 구성 : 고정 안내문 + 가맹점 펼침 카드(선정산 대상·발행 합계) + 매출 유형 요약 표 + 발행 내역 표
- 정렬·필터 : 채권매입 → 시스템 이용료 → 이체 수수료, 같은 항목은 공급가 큰 순 / 가맹점 조건만 화면 거름
- 엑셀 : 두 시트 — 정산 요약(가맹점×매출 유형) / 계산서 발행 내역(요율 포함)

## 6. 미확정
- 수수료율 : [RED]화면 요율(1.004% 등)은 역산 추정 — 병존 요율(1% / 0.604% / 0.6+0.11+0.1% / 0.25%) 어느 것과도 일치 확정 불가(확인필요)[/RED]
- 이체 수수료 단가 : [RED]묶음당 300원 ↔ 하루 500원 불일치 — 부과 단위·부담 주체 계약 대조 필요(확인필요)[/RED]
- 발행 프로세스 : [RED]발행 방식·주기(월 추정)·정정 절차와 채권매입 면세의 세무 근거 모두 확인 전(확인필요)[/RED]

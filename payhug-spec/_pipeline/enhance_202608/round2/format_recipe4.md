## 2. 격차 목록 — 예시가 하는데 우리가 안 하는 것

1. **단락 위계**: 소주제별 노드 분리 없음 → 절 전체가 한 층. (반려 ①의 실체)
2. **하위 번호**: 절 1. 만 존재. 소절 ①②③ / case의 하위 배치 / [-]/[+] 별줄 페어 없음.
3. **들여쓰기 단계**: 2단 상한 → 예시는 4단. 위계 정보가 문장 안 "—"로 흡수돼 시각적으로 소실.
4. **한 줄 1사실 원칙 부재**: 불릿 1개에 사실 3~5개 압축(줄바꿈 2~3줄) → 스캔 불가.
5. **표 0개**: 용어 정의, 유형 8종, 배분 참여자, 발행 단위 3×3, 케이스 목록 전부 산문 불릿.
6. **케이스 구획 없음**: case1~10이 불릿 나열 — 조건|처리|화면 구분이 문장 속에 매몰.
7. **굵기·크기 대비 없음**: 본문 전부 Bold 10 한 종 (예시도 같은 약점이 있으나, 반려 ① 해소를 위해 신규격에서 라벨/본문 굵기 분리 신설).
8. **여백 리듬 없음**: 클러스터 갭·절 앞 여백 불균일, 꽉 찬 장 존재.
9. **소제목 밀도 낮음**: 절당 소주제 라벨 0개 (예시는 절당 3~7개).
10. **예시 수치 배치**: 산식과 수치가 같은 줄 인라인 → 등호 체인 블록·예시 줄 분리 없음. (반려 ②의 "계산식이 안 드러남")
11. **구성 순서**: "화면 구성" 절이 2절(상석) — 기능 개요·정책 절이 없거나 뒤로 밀림. (반려 ②의 "화면에 뭐가 보인다 수준")
12. **색 사용**: 빨강 통짜 절 — 인라인 국소+상태 태그 원칙 미준수. 부호(+/−)에 파랑·빨강을 쓰면 미확정 빨강과 혼선(현재 일부 장이 "환급 파랑/차감 빨강" 서술).
13. **절차 표기**: "→" 단계 체인 활용 부족(있긴 하나 복문 속에 매몰).
14. **2열 병렬 비교 없음**: 이원화(요약 지표 vs 날짜 머리글, 선정산 축 vs 가맹점 축) 서술이 산문으로만.

## 3. format_recipe4 — 재조판 규격

### 3.0 장 규격 (공통 캔버스)

- 프레임: 595×842(A4), fill #FFFFFF, auto-layout 없음(절대 배치 + 2-pass reflow).
- 프레임명: `26.08.XX [제목]`, 분할 장은 `26.08.XX [제목] ②`.
- 제목: `[제목]` — (24, 31) 시작. 날짜 스탬프: (503, 796) `26.08.XX`.
- 좌표계: 제목·절 헤더 x=24 / 본문 노드 x=39, 본문 폭 491 (우 여백 65) / 우측 레일(측면 표·미니 박스) x=395~530 (폭 135).
- 본문 세로 예산: y 90 ~ 780 = **690px**. 하단 20% 이상 비면 정상(예시 룩), 780 초과 = 분할.

### 3.1 구획 설계 — 절 표준 흐름 (한 장 = 기능 1개)

예시의 실제 흐름(정의→대상→조건→case→예외→화면 UI 기준)을 반려 ② 요구에 맞게 재배열:

| # | 구획 | 내용 | 분량 지침 |
|---|---|---|---|
| 1 | **기능 개요** | 이 기능이 무엇을 해주나 — 사용자(관리자/총판), 트리거(언제 실행), 산출(무엇이 만들어지나) 2~4줄. "탭"이 아니라 "기능"을 주어로 | 4~6줄 |
| 2 | **정책(규칙)** | 대상/미대상 → 시각·주기·기한(11시30분·18시, D+n) → 처리 원칙. 소절 ①②③로 분해 | 12~20줄 |
| 3 | **계산식 + 예시** | EQ 블록(등호 체인) + EX 수치 줄. 항이 4개 이상이거나 근거가 갈리면 미니표(항|금액|근거) | 8~14줄 |
| 4 | **케이스** | case1)~n) — 3건 이하면 불릿(하위 단), 4건 이상이면 케이스 표(케이스|조건|처리) 또는 케이스 박스 | 6~14줄 |
| 5 | **화면 기준** | 기존 "화면 구성"의 강등판 — 노출 규칙·필터·엑셀·권한만. 정책 근거가 아닌 표시 사실 | 4~8줄 |
| 6 | **미확정** | 전원 빨강 인라인 + `(확인필요)` 태그. C1/C2/C4는 문구 고정 인용 | 3~6줄 |

- 용어장([정산 공통 용어])은 예외: 용어표 중심, 구획 1·3·5 생략 가능.
- 절 번호는 장을 넘어 연속(분할 장 ②에서 "4. 케이스"부터 시작하는 식 — 예시 5:55 규약).

| 장 제목 `[제목]` | Black | 18 / 26 | #000 | x=24, y=31 |
| 절 헤더 `1. 절명` | Black | 14 / 20 | #000 | x=24, ORDERED list `start=n`. 절 앞 여백 22 |
| 소절 라벨 `① 소절명` | Bold | 10.5 / 15 | #000 | 클러스터 노드 첫 줄. ①②③ 문자 직접 입력 |
| 본문 불릿 | **Medium** | 10 / 15 | #1A1A1A | L1 라벨 불릿만 Bold 유지 — 라벨(Bold) vs 사실(Medium) 굵기 대비 신설 |

- 들여쓰기: **1단 = 15px** (indent1=15, 2=30, 3=45, 4=60 — 예시 실측). 최대 4단.
- 문단 간격: 노드 내 리스트 항목 간 0(행간으로 해결), **클러스터(노드) 사이 12px**, 절 헤더 앞 22px·뒤 9px.
- 한 줄 1사실: 본문 폭 491px @10px ≈ 한글 48자. **불릿 1개가 2줄로 감기면 하위 불릿으로 쪼갠다.** "—" 사용은 불릿당 최대 1회.

### 3.3 하위 위계 표현법 (Figma 실현 방식까지)

| 위계 | 표기 | Figma 실현 |
|---|---|---|
| 절 | `1.` `2.` | 절 헤더 = **독립 텍스트 노드**, `setRangeListOptions(ORDERED)` + 필요 시 start 조정(불가하면 "4. " 직접 타이핑 + NONE) |
| 소절 | `① 소절명` | 클러스터 노드 첫 줄, 리스트 NONE, ① 문자 직접 입력. **소절 1개 = 텍스트 노드 1개** (예시의 노드 분리 방식 — 이게 여백 리듬의 실체) |
| 불릿 L1 | `• 라벨` | `setRangeListOptions(UNORDERED)` + `setRangeIndentation(1)` |
| 불릿 L2~L4 | `• 사실` | 동일 + indentation 2~4 |
| 케이스 | `case1) 조건 : 처리` | indent 2에 텍스트 접두 "case1) " (리스트 기호와 별개) |
| 부호 분기 | `[-] 음수 = …` / `[+] 양수 = …` | case 아래 indent+1, 두 줄 페어 고정. **색 없음** (빨강은 미확정 전용) |
| 카테고리 | `[카드]` `[배달]` | L1 라벨 불릿에 대괄호 |
| 절차 | `A → B → C` | 본문 인라인 "→". 4단계 이상이면 단계표 또는 Flow 장으로 승격 |

- 인라인 스타일: 빨강 = `setRangeFills(#FF3B30)`, 라벨 Bold = `setRangeFontName(Bold)` — 문자 범위 단위.
- 예시의 노드 내 공백 줄(zero-width space 단독 문단)로 클러스터를 가르는 방식은 **금지** — 노드를 분리하라(재배치·검증이 기계적으로 가능해짐).
- 2-pass reflow 필수: 노드 생성 → 실측 height 조회 → 후속 블록 y 재배치(recipe2 규약). 쓰기 직렬·검증(스크린샷) 병렬.

### 3.4 표 규격 (네이티브 격자 — 이미지 표 금지)

- 컨테이너: auto-layout VERTICAL 프레임, 외곽 stroke #D0D3D8 1px, radius 4, clip.
- 행: auto-layout HORIZONTAL, 높이 20~22. 헤더 행 fill **#F2F3F5** + 하단 구분 stroke #D0D3D8 1px. 본문 행 fill #FFF, 행 사이 구분선 #E9EBEE 1px(행 프레임 하단 stroke 또는 1px line 노드).
- 셀: 고정폭 프레임, 패딩 좌우 8 / 상하 4. 텍스트: 헤더 Bold 9 / 본문 Medium 9. 금액·건수 우측 정렬, 나머지 좌측.
- 배치 2형: **풀폭 표** 폭 506(x=24) — 용어표·케이스표·발행단위표 / **우측 레일 표** 폭 135(x=395) — 짧은 열거(환급명 등, 예시 3390:410의 이미지 표 위치 계승).
- 표 1개 세로 소요 = 22(헤더) + 행수×21 + 8(외곽). 8행 초과 시 표 분할 또는 별지.

### 3.5 케이스 박스 규격

- 사용처: 조건-처리-화면반응이 3줄 이상인 굵은 케이스(예: 미회수 이월, 검증 차이 ≠ 0). 잔 케이스 다수는 박스 말고 케이스 표.
- 프레임: 폭 506(x=24), fill **#F7F8FA**, radius 6, 패딩 상하 10 / 좌우 12. **좌측 세로 바** 3px(x=0, full-height) 색 #1F2937 — 미확정 쟁점이 든 케이스는 바만 #FF3B30.
- 내부: 1행 제목 `case3) 검증 차이 ≠ 0` Bold 10 → 본문 Medium 9.5 #333 (조건 / 처리 / 화면 세 줄 라벨형) → 필요 시 NOTE 줄.
- 박스 세로 소요 = 내용 줄수×14 + 24.

### 3.6 계산식 표기법

- EQ 블록 = 독립 텍스트 노드(Bold 10). 형식: `좌변 = 항1 − 항2 + 항3` — 연산자 앞뒤 공백, 항에 조사·부연 금지(부연은 EX·NOTE로).
- 항 6개 이상: 둘째 줄부터 연산자로 시작해 등호 위치 정렬(예: `선정산 지급액 = 선정산 대상액 − 선정산 수수료` ↵ `+ 정산 반영 수수료 차액 − 오프라인 차감 …`).
- EX 줄(검증 가능한 실수치): `(예) 1,000,000 − 11,300 + 2,000 − 30,000 − 50,000 + 5,000 = 915,700원` — Medium 9.5 #555, indent+1. **모든 EQ에 EX 1줄 의무.**
- 항별 근거가 갈리는 산식은 미니표: `항 | 금액(예) | 근거(발생 규칙)`.
- 부호 규약 줄: `[+] 양수 = 환급 가산 / [−] 음수 = 차감` — 색 금지, 기호+단어로만. (화면이 파랑/빨강을 쓰는 사실은 [화면 기준] 절에 문장으로 기록)
- 요율 역산 등 "화면 표시값일 뿐 계약값 아님"은 EQ 뒤 NOTE 줄 + 미확정 절 중복 게시(C1 보호).

### 3.7 원고→조판 DSL

원고 작성자는 아래 마크업만 쓰고, 조판자는 표의 규칙대로 기계 변환한다.

```
# [선정산 결과]                         ← 장 제목 (새 A4 프레임)
DATE) 26.08.14                          ← 날짜 스탬프 (생략 시 직전 장 상속)
## 1. 기능 개요                         ← 절 헤더 (ORDERED, 번호는 원고가 부여·장 넘어 연속)
### ① 지급 확정 시각                    ← 소절 = 새 클러스터 노드
- 라벨 : 사실                           ← L1 불릿 (라벨부 Bold)
  - 하위 사실                           ← L2 (2칸 들여쓰기 = 1단씩 추가, 최대 4단)
    - 하하위
CASE1) 조건 : 처리                      ← 케이스 줄 (indent2 배치)
  [-] 음수 = 차감 처리                  ← 부호 분기 페어 (case 아래 indent+1)

SRC) page.tsx:242 / 노드 3907:2          ← 근거 병기 캡션
TABLE: 용어 | 정의 | 비고               ← 표 시작(헤더 행). 이어지는 `행|` 줄 = 본문 행
  선정산 대상액 | 실행에 들어간 금액 | =채권 매입 금액
  선정산 제외액 | 대상액 − 정산 반영액 | 부호 규약 별도

RTABLE: 환급명                          ← 우측 레일 표(폭 135, 1열)
BOX: case3) 검증 차이 ≠ 0               ← 케이스 박스 시작(제목줄)
  조건 : 값 표시 + '확인 필요' 취급
  처리 : [RED]발생 시 처리 절차·책임 주체 미정 (확인필요)[/RED]
ENDBOX
[RED]…[/RED]                            ← 인라인 빨강 #FF3B30 (미확정 전용)
COLS2:  … | …                           ← 2열 병렬(좌|우 클러스터, EUK 병렬 패턴)
```

### 3.8 분량 한계와 장 분할

- 세로 예산 690px 환산: 본문 1줄=15 / 절 헤더 블록=34(앞여백 포함) / 클러스터 갭=12 / EQ+EX 세트=30 / 표=30+행×21 / 박스=줄×14+24.
- 경험 상한: **본문 환산 42줄** (= 절 4~5개 + 표 1개 + 박스 1개). 원고 단계에서 줄 수 합산 → 초과 시 `PAGEBREAK`.
- 분할 규칙: 절 경계에서만 분할(소절·표·박스 중간 분할 금지). 분할 장 = 같은 제목 `[제목] ②`, 절 번호 연속, 날짜 스탬프 동일. 권장 쌍 구성: ① 기능 개요·정책·계산식 / ② 케이스·화면 기준·미확정.
- 하단 여백 목표: 본문 끝 y ≤ 760, 이상적으로 700 안팎(예시 룩 = 하단 숨 쉬는 공백).

### 3.9 슬라이드·Flow 보조 규격 (세트 4장 일관성)

- 16:9 비교 슬라이드(1920×1080): 중앙 상단 `[주제] 비교명` Black 28 → 파스텔 박스 2~4개 병렬(연녹 #E9F4E2 / 연파랑 #D7E9F8 / 연주황 #FAEBD3 계열, radius 16, 내부 헤더 Bold 16 + 불릿 Medium 13) → 핵심 필드만 빨강 → 하단 매핑 기준 1줄.
- Flow(1920×1280): 좌상 제목 `…_Flow`. 시스템 = 검정 필(#3A3A3A) 라운드 필 + 흰 텍스트 / 행위자·외부 = 흰 사각 + stroke / 분기 = 다이아몬드 / 소속 묶음 = 점선 사각 / 화살표 라벨 = 9~11px / 노드 옆 불릿 주석 허용(운영 실측치 기록 자리).

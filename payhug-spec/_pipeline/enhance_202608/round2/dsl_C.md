## 1. 기능 개요
- 선정산에 적용한 예상수수료와 이후 확정된 실제 수수료의 차이(차액)를 유형별로 모아 주는 기능
- 산출 : 환급·차감 순액 + 반영 상태를 기간 축으로 집계 — 요약 카드·일별 차트·건별 목록·엑셀

## 3. 계산식 — 이체 내역 요약 지표
TABLE: 요약 카드 | 집계 대상 | 산출
  지급 이체 | 지급 + 수동 지급 | 성공 건 / 전체 건 + 성공 금액
  매출 회수 | 회수 짝 묶음 | 성공 건 / 전체 건 + 성공 금액
  전체 성공 | 지급 성공 + 회수 성공 | 건수·금액 합산
  전체 실패 | 실패 상태 건만 | 건수·금액 합산 (중간 상태 미포함)
ENDTABLE
EQ: 성공 금액 = 성공 상태 금액 합 + 확인 완료 상태 금액 합
EX) 7,000,000 + 1,400,000 = 8,400,000원 (지급 성공 12건)
EQ: 전체 성공 = 지급 성공 + 회수 성공
EX) 지급 12건 8,400,000 + 회수 3건 1,500,000 = 15건 9,900,000원
EQ: 날짜 머리글 실패 = 그 날짜 전체 − 성공 = 실패 + 요청 중 + 시간 초과
EX) 실패 100,000 + 시간 초과 200,000 = 머리글 300,000원 — 요약 실패 카드는 100,000원
NOTE) 마지막 예시가 실패 이원화의 실체 — 두 값이 다른 날이 정상 동작

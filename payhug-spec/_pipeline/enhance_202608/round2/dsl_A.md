# [미정산 누락]
DATE) 26.08.13
## 1. 기능 개요
- 선정산 실행이 끝난 뒤 도착한 매출 건을 모아 정리하는 기능
- 위치 : 선정산 결과 화면 상단의 빨간 배너 — 내부 관리자 전용
- 트리거 : 누락 건 존재 시 상시 노출 — 조회 기간과 무관
- 산출 : 바로이체(실제 이체) 또는 이미지급(장부 기록) 처리 완료
## 2. 정책
### ① 대상 · 모집단
- 대상 : 실행 완료 날짜에 뒤늦게 도착해 선정산에서 빠진 매출 건
- 모집단 = 조회 기간 무관 전 기간 — 기간을 좁혀도 배너 숫자 불변
- 열람 · 처리 모두 내부 관리자 전용(지급 권한이 내부에만 있음)
### ② 처리 두 경로
- 바로이체 = 실제 이체 + 장부 기록 — 경고 확인 창 필수
- 이미지급 = 이체 없이 장부에만 지급 완료 기록(간주 처리)
- 미리보기 = 이체 · 기록 없는 무부작용 조회 — 실행 전 필수 관행
- 이틀 이상 지난 건 = 선정산 아닌 순 지급액 전액 이체(고지 문구 확정)
  - [RED]'이틀' 판정 기준(달력일 · 영업일 · 기산점) 미정 — 충돌 대장 2번 연동 (확인필요)[/RED]
### ③ 이체 묶음 규칙
- 같은 가맹점 여러 거래일 → 합산 1회 이체, 장부는 거래일별 기록
- 이체액 0원 가맹점 = 이체 0회, 장부 기록만 생성
### ④ 처리 절차
- 선택 → 미리보기 → 실행 → 완료 알림 → 선택 해제 → 목록 · 요약 재조회
- 부분 실패 → 실패 안내 → 선택 유지 → 재시도(행 단위 실패 표시 없음)
## 3. 계산식 · 예시
EQ: 순 지급액 전액 = 매출액 − 카드 · 배달 수수료
EX) 500,000 − 12,000 = 488,000원
NOTE) 선정산 수수료는 떼지 않음 — 면제의 정책 근거는 미확정 절
EQ: 선택 합계 = 선택 건 순 지급액 합
EX) 152,000 + 98,000 + 50,000 = 300,000원

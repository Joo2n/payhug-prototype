## ③ 용어 유의

1. **폭포수 / 병렬 배분** — 구조 명칭으로만 사용. "최상위"·"파트너"는 **폭포수 전용** — 병렬 배분(다우 직계약) 서술·화면에 사용 금지 [출처: 회의록 §1]. 다우데이타의 위상이 최상위여도 '최상위'라 부르지 않는다 [출처: 사용자 답변 P4].
2. **6대 개념 무접촉 확인** — 이번 자료는 배분 구조·계약 체인 영역으로, 미지급금·선정산 제외금액·바로이체·과지급·미회수금·환급 어느 것과도 병합·재정의하지 않는다. '회수' 3갈래(매출 회수/과지급 회수/플랫폼 조정 회수)도 미접촉.
3. **충돌 C1(수수료율)** — 회의록·답변에 등장한 0.6%·0.45%·1%·53원 배분 예 등은 전부 **예시**로만 기록. 어떤 값도 채택하지 않음. 단, **이체수수료 300원 고정(M9)은 요율이 아닌 건당 정액**이며 회의에서 확정 — C1 병존값(채권매입 요율)과 별개 축임을 명시. 기존 문서의 "300원 | VAT 별도 +30원"(`spec/_figma_ref/04_기능정책분석.md:33~35`)과 정합(300 = VAT 전 기준).
4. **충돌 C2(지급 캘린더)·C4(예상 지급 차액)** — 이번 자료 미접촉, 변동 없음.
5. **계약 용어 ↔ 운영 6개념 매핑 미확정 유지** — 회의록의 "채권 양수인/재양수인/재재양수인"은 세무 판정용 계약 사슬 용어로, 운영 6개념과 매핑하지 않는다. 매핑 불가 — `07` 등재 후보.
6. **"흑인"** — 회의록 원문 표기(다우 하위 영업조직 = 예스넷을 가리키는 호칭). 정책서 정식 용어로 승격 금지 — 공식 문서에는 "다우 하위 영업조직(예스넷)"으로 풀어 쓸 것. 매핑 불가 — `07` 등재 후보.
7. **상태 id 표기 충돌** — 프로토타입 Flow C의 상태 C1~C6과 충돌 레지스터 C1~C6이 표기가 같다. 후속 문서에서는 "상태 C1(Flow C)" / "충돌 C1(수수료율)"로 구분 표기할 것.

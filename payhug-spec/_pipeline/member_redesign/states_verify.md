### 앱 실기능 추가·변경 (v2)

1. 파트너 계약 위치 라디오 삭제 → 직속 상위 select("없음(최상위)"+활성 상위파트너) + 관계 기준 자동 판별(목록 배지·프로필·후보 매칭 전부 `activeRel` 기준). P5 확정 반영.
2. 등록 자동 생성 — 아이디(한글 로마자화 앞 4자+순번, 대소문자 무시 접두 카운트), 추천코드(난수 6자, 하네스에선 이름 시드 고정), 초기 비밀번호(휴대폰 뒤 4자리) + "최초 로그인 시 변경" 안내. 휴대폰번호 필드 신설(등록 필수). 기존 목데이터 아이디 불변.
3. 이체수수료 300원 전 건 고정 — 입력 제거·고정 표시, 수취 주체 "페이허그 수취 — 확인 필요" 고정. 등록·수정·프로필·체인(기본/풀컬럼/컴팩트)·이력·G시리즈 전 뷰 통일.
4. 병렬 배분 트랙 — PARALLELS 데이터(인베스트원↔엔케이 체인, 다우데이타↔페이허그 직계약), 체인 병렬 가지 렌더(점선 밴드·순차 화살표와 구분·접기/펼치기), 제휴 직계약 전용 체인 뷰(가맹점→양수인→병렬 수취, 최상위/파트너 용어 미사용), 프로필 '투자자 연결(선택)' 섹션.
5. 수정 흐름 — 파트너를 최상위로 전환 시 기존 관계 종료 처리(commitEdit top 분기).

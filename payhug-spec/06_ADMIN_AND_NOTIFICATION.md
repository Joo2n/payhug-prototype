# 회수 어드민 및 알림톡

## 1. 회수 어드민

### 회수건 생성 조건

- 선정산 완료 후 플랫폼 정산액 감소
- 카드 미정산
- 취소·환불 지연 반영
- 스크래핑 데이터 수정
- 수동 입력 오류
- 가게배달 음수 발생
- 플랫폼 차감 항목 추가
- 운영자 수동 등록

### 필수 필드

- 가맹점명
- 사업자번호
- 플랫폼
- 정산 기준일
- 원 지급일
- 발생일
- 발생 원인
- 원 지급액
- 최종 정산액
- 과지급액
- 회수 대상액
- 기회수액
- 잔여 미회수액
- 회수 방식
- 회수 상태
- 예정일
- 완료일
- 관련 정산번호
- 처리자
- 메모
- 수정 이력
- 가맹점 알림 여부

### 기능

- 목록 조회
- 상세 조회
- 수동 회수건 등록
- 상태 변경
- 부분 회수
- 회수 완료
- 회수 취소
- 차기 지급 상계
- 지급·회수 이력
- 엑셀 다운로드
- 중복 회수 방지
- 감사로그

## 2. 중복 방지

중복 판단 후보:

- 가맹점
- 플랫폼
- 정산일
- 품목
- 금액
- 원 거래번호

수동 지급·회수 완료건은 재처리되지 않도록 완료 상태와 처리 이력을 보존한다.

## 3. 알림톡 정책

### 현재 우선순위

알림톡 정책 정비가 1순위 과제.

### 확인 대상

- 원샷 홈페이지 기존 템플릿
- 실제 사용 템플릿
- 미사용 템플릿
- 구 페이허그 링크
- 현재 문구
- 변수값
- 버튼
- 이미지
- 발송 대상
- 발송 시점

### 발송 케이스 후보

- 계약 완료
- 계좌 등록 완료
- 선정산 이용 가능
- 데일리 선정산 예정액
- 지급 완료
- 지급 실패
- 추가 지급 예정
- 바로이체 완료
- 플랫폼 환급 지급
- 선정산 미반영
- 이전 지급 조정 예정
- 회수 완료
- 정보 수정 요청
- 서비스 중지
- 계약 해지

### 발송 조건 확인

- 모든 가맹점 대상인지
- 특정 플랫폼만 대상인지
- 지급액 0원도 발송하는지
- 플랫폼별 개별 발송인지 합산 발송인지
- 실패 시 재발송하는지
- 회수 내용을 알림으로 고지하는지

### 링크 정책

- 기존 링크 전면 교체
- 모바일 정상 동작
- 로그인 후 상세 화면 이동
- URL 개인정보 노출 금지
- 정산 건 식별값 처리

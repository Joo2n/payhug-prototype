## 훑을 것

**산출물**
- 화면에 임의로 만들어 넣은 설명 텍스트·안내 문구·캡션·주석 블록
- 문장 중간에 대시를 놓고 같은 말을 되풀이한 것 (`A입니다 — 즉 A라는 뜻입니다`)
- `입니다`·`습니다` 종결. **단 실제 프론트에서 가져온 제품 UI 문구는 예외** — 예외마다 출처가 `파일:라인` 으로 병기돼 있는지 확인. 출처를 못 대면 예외가 아니다
- `반영`·`요청하신`·`지시에 따라`·`말씀하신` 같은 수행보고체
- 변경이력체(`종전에는`·`기존에는`·`~로 바뀌었다`)
- 이모지
- `.html` 영어 파일명 화면 노출. 예외는 `archive.html`
- 근거 없는 요소 — 스토리보드·실제 프론트·대표 정의 셋 중 어디에도 없는 것

**규칙**
- `request_register.md` 의 확정 D 전건이 실제로 지켜졌는지
- 게이트 G-1~G-10 전건

**W금융일수 가중 기준 — 두 기준을 섞은 자리**
- 가중치는 **금액**이다. `Ai = 순지급액 x (1 - 할인율)`, `w금융일수 = Σ Ai x Di / Σ Ai` — 대표 워드 `용어 정의.docx` 4~6번 문단 · 레지스터 `TP-87` `확정`. 되물을 사항이 아니다. 확정 기준의 화면·원장 값은 여기 적어 두지 않는다 — `platform_duration.BOOK_MIX`(플랫폼 금액 구성비) 와 `ledger_facts.json` 의 `wRaw`·`w`·`ty`·`s` 에서 읽는다
- 대표 엑셀 `정산주기.xlsx` `비중` 시트의 MAU(이용자 수) 비중 — 카드 65% · W 2.7504 · Ty 14.60% — 는 **참고값**이다. 지우지 않는다(`platform_duration.MAU_MIX` · `MAU_W`). 쓸 때는 같은 문단·표 안에 「대표 엑셀 시장 평균 참고값」으로 갈라 적는다. 갈라 적지 않은 자리가 곧 위반이다
- 대표가 `배달앱/전체 0.35` 와 `카드 65%` 가 **매출액 기준**이라고 답하면 그때는 65%로 되돌린다. 그 확인 문항은 살아 있다 — `build_audit_xlsx.py` 「확인 문항 2」. 문항이 사라진 것도 위반이다
- 기계 검사는 `verify_weighting.js` 가 한다. 배포 3주소의 렌더된 텍스트 · 배포 3주소 원천 텍스트 · 파이프라인 원고 · 산출 문서가 범위다. 네가 손으로 훑을 자리는 그 범위 밖 — 답변 본문·새로 쓴 문서·시트다

## 방법

`grep` 으로 기계 검사하되, **문맥을 보고 오탐을 걸러라.** `미반영` 안의 `반영`, 인용문 안의 존댓말, 근거 표의 파일 경로는 위반이 아니다. 오탐으로 판정하면 그 사유를 적어라.

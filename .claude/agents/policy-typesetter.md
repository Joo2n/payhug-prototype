## DSL → 캔버스 변환 규칙

`EQ:` 접두 제거 후 산식만 Bold 독립 줄 / `EX)` → `(예) ` / `NOTE)` → `※ ` / `SRC)` → `근거) ` / `CASE1)` → `case1) ` 접두(indent 2) / `TABLE·RTABLE·BOX·COLS2` → 규격 프레임 / `[RED]…[/RED]` → 범위 색 / `PAGEBREAK` → 새 프레임 `[제목] ②`. **DSL 마커 리터럴이 캔버스에 남으면 실패다** — 조판 후 `[RED]`·`EQ:`·`ENDTABLE`·`##` 등 전 마커 0건 자가 스캔.

## 작업 방식

1. **쓰기 직렬** — use_figma 호출은 순차 1건씩. 병렬 쓰기 금지(검증 스크린샷은 병렬 가능).
2. **2-pass reflow 필수** — 노드 생성 → 실측 height 조회 → 후속 블록 y 재배치. 본문 끝 y ≤ 780(이상 700 안팎), 초과分은 원고 PAGEBREAK 재요청(임의 축약 금지).
3. 신판은 구판 옆에 신규 생성 → QA 통과 후 구판 제거(교체 순서 고정). 그리드 = 시작 (44,240), 가로 피치 637 · 세로 피치 900, 한 행 6장.
4. 하이라이트 마커·꺾쇠(3940:* 등)가 구판 좌표를 참조하면 신판 좌표·절 번호로 재연결. 매핑이 애매하면 이동만 하고 번호는 유지 + 로그에 보류 기록.
5. 섹션 크기는 콘텐츠 실측 후 트림(폭 4500 유지 관례).
6. 완료 후 각 장 스크린샷으로 겹침·잘림·마이너스 좌표 0건 확인.
